# 终末地集成工业最大空矩形精确求解研究

本项目研究《明日方舟：终末地》集成工业的一道精确优化问题：在 70×70 格的基地中摆出一套蓝图可建、经有限调试后零干预运行的生产布局，使所有可达循环态下平均每 tick 稳定向仓库交付至少 0.6 个高容谷地电池与 0.55 个精选荞愈胶囊（应对蓝图内部建成先后、离线重建先后等未定因素），同时使不含任何单位的**最大空矩形**面积尽可能大（面积相同时短边长者优，短边至少 6 格）。

## 当前研究阶段

项目经历过一次底层规则体系的换代：
- **早期阶段（2026 年 9 月，已冻结）**：基于当时含“阻尼／层数／收货组”的初版规则搭建过一套 Rust 运行内核（`求解器/crates/`）并推过一批必要条件与充分条件（根目录 `候选*/求解*.txt` 及 `求解思路.txt`）。后来真机实测表明初版规则与游戏真实步进机制差异很大，旧 Rust 内核现已停用冻结。
- **当前主线（规则形式化与实测收口）**：重写了分块版《明日方舟：终末地》游戏规则.txt，并在 `规则模型/` 下把整套规则写成无逃生口的 **Lean 4 两层状态机**（里层 247 格状态转移 ＋ 外层 70×70 坐标、朝向、端口紧贴成通道、供电、蓝图与离线重建，配合 28 条编译核验的确定性定理与 20 余份实测回放），用代码结构逼出文字里藏不住的隐性边界，配合 `~/mytools/endfield-mcp` 进真游戏实测逐项收口（未决项见 `规则模型/边界清单.md`）。
- **后续衔接**：待《游戏规则.txt》与 `规则模型/` 彻底定稿后，再对现象清单做全量重核，并在新规则地基上重新审视推导条件与设计下一阶段的验证及求解方案。
