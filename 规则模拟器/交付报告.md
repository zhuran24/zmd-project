## 规格书与源码的差异

按可接受的输入写法和规则成立的条件计，共 **3 处**。前两处是规格书第 1、3、4 节引用的 v1 格式说明与实际解码行为的差异，第三处是第 4 节省写的条件。全部按源码实现。黄金文件的期望与实时 Lean 输出没有差异。

1. **段内操作的物品参数也接受单键构造子对象。** 格式说明将物品写作物品名字符串。Lean 的 `readAction` 对物品用派生的 `FromJson`，单键对象只取已知构造子名，其载荷可以是任意 JSON。例如 `["入库",{"钢块":[]},2]` 成功，结果与普通字符串写法相同。放货、出库、设准入口、设取货指向中的物品遵循同一解码规则。未知构造子、多个键、段首仓库表中同样的对象均被拒绝。重复 JSON 键在构造子解码前即被拒绝。[编码.lean](../规则模型/对拍/编码.lean#L93) · [状态.lean](../规则模型/对拍/状态.lean#L128)
2. **离线携带的历史中，九个制造机种也接受单键对象。** 例如原有 3 号研磨机时，离线历史中的 `["建成",3,{"研磨机":[]}]` 可以重建该机。原因是 `readKind` 把制造种类交给派生解码器。另八类单位逐个匹配字符串。`readContext` 会用重新编码的字段核对段首原值，因此段首的机种仍须写成字符串。这两种上下文分别有成功及失败回归用例。[编码.lean](../规则模型/对拍/编码.lean#L52) · [执行.lean](../规则模型/对拍/执行.lean#L48)
3. **分流器返回自身作为终点有一个前提。** 第 4 节第 2 项的“对分流器返回自身”只适用于末端元件。源码先执行 `是末端元件` 检查。一个有进口、没有出口的分流器，其终点为 `none`。它在回放中仍可通过独立的“待接箱的次序”分支取得次序 1。[拓扑与级别.lean](../规则模型/Endfield/拓扑与级别.lean#L67)

另外核对了几处源码写法与规范结果的对应关系。

- `框架.计时` 内的已停与拍都直接加一，输出快照时才将已停封顶为 8、拍取模 4。规格书第 4 节给出的是规范值，Rust 在每步直接保存这两个规范值。[框架.lean](../规则模型/Endfield/框架.lean#L266) · [状态.lean](../规则模型/对拍/状态.lean#L64)
- Lean 的 `整理` 有单位数大小的递归燃料，Rust 按现有带内通道顺序整趟扫描，遇到整趟无移动即停止。整理过程里每件移动的货都清零已停，下一次计时前至多移动一次，两种停止条件给出的货位相同。[判定.lean](../规则模型/Endfield/判定.lean#L106)
- 段首表键须合法，若干表的**值**可以带历史引用。例如有货格的来处可以指向已不存在的格。出货已移动可以含当前组外的通道，甚至有重复值；输出保留原序。（数字的写法第二轮改过：两个入口都只认普通十进制非负整数，`1e0`、`0.1e1`、`1.0` 一律拒绝，见「第二轮修改」。）这些边界均有黑盒用例。[状态.lean](../规则模型/对拍/状态.lean#L144)

## 模块与使用入口

单份脚本可用 `cargo run --locked --release -- ../规则模型/对拍/黄金/格子边界.json` 回放。求解器可从库入口调用 `LegalBase::new(&events, parameters, &snapshot)`，随后调用 `step()`、`apply(&action)`、`snapshot()` 或 `history()`。

| 文件 | 职责 |
| --- | --- |
| `src/lib.rs` | 正式入口 `LegalBase`。在构造与离线替换时验证合法基地，固定使用 `Twice`。正式参数类型只含供电、端口、箱传输位置和计数策略。 |
| `src/oracle.rs`、`src/oracle/input.rs`、`src/main.rs` | 回放入口 `OracleRunner`、段和操作解码、逐行期望及行数检查、CLI。待接箱次序、四种历史输入判定和各自需要的额外读数均在回放模块内。 |
| `src/model.rs`、`src/nat.rs` | 物品、单位、格位、通道、事件、配方和非负整数。无规则上限的读数保留任意长十进制整数。 |
| `src/topology.rs` | 校验历史并依次重建布局，计算终点、时刻、次序、组级别和判定表。 |
| `src/state.rs`、`src/snapshot.rs`、`src/json.rs` | 规范状态、十二张输入输出表的校验与投影、逐对象重复键检查。运输格用 `Option<Load>` 保存一件货及其停步数和来处。制造缓存用空闲、加工中、成品待转三种状态表示，加工中的原料缓存由配方唯一确定。开关只存在于箱或制造单位上。 |
| `src/movement.rs`、`src/step.rs` | 放进哪、可移动物品、移一件、反复整理、轮询、两次输入判定、箱传输、结束及开始制造、计时。 |
| `src/action.rs` | 同一套类型化的段内操作和前置条件。离线成功后替换历史及判定表，沿用段供电、端口和策略。 |
| `tests/`、`验收/` | 正式入口测试、三关重跑脚本及随机输入。 |
