# 退化形态值守清单

〔解读层：实践经验综合，非真源内容；案例史与频次会随时间变化，不在此固化〕

值守时对号入座的常见退化形态：

- **修复代替构造**：全部工作都在一个求解器产出的稠密解附近做局部精确修补，每步买回
  极小的代理指标收益；链完整但步幅毫米级。解法不是放弃推导，而是换**大链节定理**——
  结论落在结构层（区域、子系统、自由空间形态）而非点层（单个 pose）的定理。
- **可证明性挤掉重要性**：优化「能对它做精确陈述的代理量」，而不是「拿到目标所需的量」
  ——路灯下找钥匙。判据：当前优化的量与终局目标之间的推导链是否还接得上。
- **坐标基底过细**：在求解器原生坐标（pose、literal、枚举签名）上量化一切，使一句话
  的结构常识变成巨型约束、按碎片逐周重新发现。信号：多个独立发现原来是同一句话的
  碎片；大量物理组合折叠成少数接口类。解法：换到由必要账推出的更粗、带类型的基底。
- **精确税错位**：可行性问题（只需一份 witness、无最优性要求）的每一步都付校准+精确
  OPTIMAL+冻结证书的全额税。带标注的松弛与临时过约束本来就是合法工具（§3.5），
  税应付在结论要承重的地方。
- **外环 nogood 工厂化**：见 §2.2/§2.3。
- **不稳定编号当语义身份**：见 §3.7；此前多次复发，已固化为常设方法条目。
