## 1. 前提与核验口径

规则和任务只取本轮的 [前提快照](前提快照/)：游戏规则 115 行、求解任务、77 条求解约束和 11 条求解充分条件。[推导92F.md](推导92F.md) 是被复核材料。没有使用其他复核席的报告。

本报告提到的规则行号均指快照《明日方舟：终末地》游戏规则.txt；“S08”“S11”分别指快照《求解充分条件.txt》第 17 行“采种单元的回路存量下界”和第 23 行“全厂专用进路接法达标”。S11 在这里首先用于指定接法和起态，不能由接法名称反过来假设它已经达标。

脚本和结果在 [复核93F/](复核93F/)。两套制造、运输编码均从头写成，没有导入推导席脚本或 sim2。它们在本次构型里只处理指定的本线物品；每台机器的原料和产物不同，进路也不会把物品直接移回刚离开的单位，因此不触发任务书所列 sim2 的两处错误。一般收货的独立核验另检查了规则第 13 行的同种唯一。

有限程序核验用于查错；第 2、3 节的规则推导承担全称结论。抽象图和流量代数没有被当成可摆放的布局。

## 2. 无分流网络的判定先后无关：未否证

保留候选原文的全部前提，包括：运输单位每轴至多一条出通道、至多一个非运输来路、没有纯运输通道环，以及仓库取货端只取持续可得的两种矿石。这里的桥接器始终按互不相干的两轴分别处理；“往同一个单位收货”对桥接器也分别指各轴。

### 2.1 层数与收货组

把连续传送带合成元件、桥接器两轴分开。每个元件至多有一个外部送货终点。送往非运输单位或不再向下送货的元件时，按第 28 行层数为 1；否则层数等于唯一的后续元件层数加 1。

由于没有纯运输环，沿后续元件递推必在有限步内结束。“有几个这样的元件”造成的选支不出现，所以每层唯一，接通先后不能改变层数。往同一收货单位或桥接器同一轴送货的元件，使用同一个后续，层数相同。

将往同一终点送货的全部元件放在一起。没有分流器，所以它们全是第 31 行要求一起判定的上游。无论先轮到其中哪一个，终点都按**自己的收货轮询**尝试同一批通道，全部组员均用掉本步的判定。组内谁先被外层遍历碰到，不改变这次收货。

### 2.2 同层判定为什么能交换

不同终点的两组没有共同送货元件：否则那个元件有两条出通道，违反前提。

若终点还向下送货，它本身所在的元件层数严格更小，已在低层判定，不能同时成为这一层另一组的送货元件。若终点是制造单位或协议核心，它的送货要等全部元件之后，也不会混入当前层。因此，同层各组只改动各自送货元件、各自终点及各自轮询记录，既不抢同一运输格，也不改变另一组判定时需要读取的量。

需要单独补全的边界是**没有出通道的运输元件**。它和上游可能同为第 1 层，不能用“终点总在低一层”略过。这个元件没有向外送货的动作。连续传送带内部仍依第 23、24 行移动：一件物品进入下一格后未满 1 tick，不能在同一步再进第三格；从末端往前检查即可得到唯一的前移结果。内部可动的物品一直尝试移动，空的外送判定不改变这些移动，因而不破坏交换性。不能额外规定“断头带只有轮到自己的外送判定才向内移动”；快照没有这种限制。

桥接器两轴的物品格、收货和送货互不相干（第 64 行），各轴归入自己的组。物品的“刚离开的单位”仍记真实物理单位，不能把它改成整段带子的编号。这个记录属于各件物品，不会造成两条独立轴共享可变库存。

### 2.3 非运输单位为什么能交换

全部元件判定完之后，非运输单位才判定。对任一非运输单位，它可能送入的各首运输格没有另一个非运输单位直接送货；本步元件又不会第二次判定。因此，别的非运输单位既不能抢这些首格，也不能在其判定之间把首格腾空。

制造单位只改自己的取货格、缓存格、送货记录和这些首格。协议核心的收货已经在元件阶段结束。仓库取货口和协议核心的取货端只取源矿或蓝铁矿，任务“外部过程”保证二者一直可得且足够任意消耗，因此也没有“最后一件矿石先被谁取走”的竞争。各次送货于是可以交换。制造结束及下一批开始各自只作用于本机，仍分别放在第 25 行规定的头、尾阶段。

这证明接通先后固定时，任意交换同层组及非运输单位先后，都给出相同的步后状态。

### 2.4 接通先后还需保留什么

剩下的依赖正是候选列出的收货轮询，以及非运输单位取货分级、轮询。

对收货，若一批送来的物品能全部收下，则换尝试次序也能全部收下：运输物品格只能收一件；制造单位要为每种已有物品保留唯一的物品格，新种类使用空格，每种不得超过 50；协议核心对每种物品分别计容量。某种物品已在同一制造单位的其他非缓存物品格中时，也不能违反第 13 行再占新格。以上限制都只由种类集合及数量决定，不由全收批次的排列决定。机器没有协议储存箱那样的编号取货规则。

全收之后的轮询记录可能不同，但它只有在后来遇到不能全收的一批时才会改变收下谁。因此，“一直全部收下”的前提不能只检查一次或一个短窗口。送货一侧只有一条取货通道时，没有取货次序选择。

离线只改变接通先后；在每次改变后重新应用上述交换性即可。它并不要求离线前后沿用同一套判定排列。因此，此简化是删除重复的运行分支，不是删去候选范围内的布局，也不改变这类布局的最优值。

### 2.5 两处待定桥接器条文

两个桥接器同轴相邻，会形成互相指向的通道，至少违反无纯运输环这一前提；如果轴上还有继续向前的出通道，也违反至多一条出通道。故本候选不包含该构型。

现行“最先判定”的收货读法，以及拟议“最先往它送货”的读法，在候选允许的构型中指向同一批具有出通道的上游；数层数也没有绕回自身的情况。**两种读法下本节结论相同。** 不能将本候选拿去消除相邻桥接器的 8/9 问题。

## 3. 全厂专用进路接法的调试办法：修正

### 3.1 原流程有一条允许发生但做不完的操作顺序

取蓝图中的矿石设定一开始就正确的情形。这是候选明确包含的情形，清理步骤没有物品要取出。

首先只给一个荞花采种单元的 A 放 50 件荞花种子，暂不执行给 C 放 50 件荞花，也暂不给其他采种单元放料。原文没有限制这两次操作之间的等待；而 A、B、C、K 已经全部开着。

于是 A 制造荞花，经 AC 到 C；C 制造荞花种子，经 CA、CB 到 A、B；B 的荞花进入 K，K 制造荞花粉末。此单元下游研磨机的砂叶粉末来路始终为空，因为全部砂叶采种单元尚未放料。研磨机不能开批，荞花粉末最终塞满其存货格及来路。

等待可以使 **C 的存货格自行达到 50 件荞花**。这时原步骤要求再放入 50 件，容量上限不允许。等它空出来也不一定可行：继续等待后可得到永久满住的状态。这个反例只用了候选列出的放料操作以及其允许的操作间隔，没有错物品、改配方、停止供电或在调试中额外关机。

### 3.2 独立复算的可达过程与局部几何

两套程序分别用“物品进入时刻＋制造完成时刻”和“运输格年龄＋制造剩余步数”编码，逐状态核对。

| 量 | 编码甲 | 编码乙 |
|---|---:|---:|
| CA、AC 格数 | 7、31 | 7、31 |
| L1+L2 | 38 | 38 |
| C 存货格首次有 1 件荞花时，已完成的步数 | 2465 | 2465 |
| C 存货格首次有 50 件荞花时，已完成的步数 | 3249 | 3249 |
| 此时再放 50 件是否成功 | 否 | 否 |
| 6000 步后 A、B、C、K 存货格 | 各 50 | 各 50 |

步从 0 编号，所以“完成 3249 步”对应最后完成编号 3248 的那一步。反例不要求玩家数步；看到 C 已满再做下一次放料即可。

6000 步后的状态是一个可直接检查的停机证书：A、B、K 取货格各 50，C 取货格 49；缓存格分别是一批做好的 1、1、2、2 件产物；六条进路全满，下游研磨机存货格有 50 件荞花粉末、没有砂叶粉末。所有制造开关均开着，每个整批都因取货格放不下而等待，所有通道的目标格均收不下。再过 80 步，物品、制造状态及累计收发数全部不变；更长时间不变由同一“没有任何可成功的动作”判据直接推出。

坐标采用格的左下角，矩形用 `(x,y,宽,高)`：

| 单位 | 矩形 |
|---|---|
| 采种机 C | (20,20,5,5) |
| 种植机 A | (32,20,5,5) |
| 种植机 B | (33,27,5,5) |
| 粉碎机 K | (43,28,3,3) |
| 下游研磨机 | (51,26,4,6) |

五台机器均从左收货、向右送货。CA 是 `(25,22)…(31,22)` 的 7 格连续带。AC 的折点是 `(37,21)→(38,21)→(38,17)→(18,17)→(18,21)→(19,21)`，共 31 格。其余进路和供电桩、协议核心坐标见 [local_geometry.json](复核93F/local_geometry.json)。程序逐格核了占格、端口朝向、通道自动形成和供电：267 个占格，72 条通道，无占格冲突、无意外通道，三桩覆盖五台制造单位。格数另由折线段长独立计算；占格与通道数也另作求和核对。

证书同时给出可选的接通序号：A、B、C、K 的最早取货通道依次接通，六段连续带的送货通道依次为 CA、CB、AC、BK、K0、K1。离线允许这样的次序。交换 C 的 CA、CB 首通道顺序也不影响反例成立。

**这张坐标证书是合法局部构型，不是一张完整 221 台达标布局。** 它核查局部模拟构型的可摆放性；下面的论证说明操作失败也适用于任何满足候选几何前提的完整接法实例。局部证书不承担完整几何存在性的证明。

### 3.3 为什么不是靠一个无来源的堵塞初态

对完整接法中首先启动的荞花单元，仍取上述“先 A、后 C，中间任意等待”的操作。下游研磨机没有砂叶粉末，不可能消耗荞花粉末。研磨机、K 及两条粉末进路的容量有限，所以 K 只能再制造有限批。

将该单元内的荞花、荞花种子合计，正在制造的缓存按投入记，做完的缓存按产物记。C 每做完一批使这个合计增加 1，K 每做完一批使它减少 1，其他制造和移动不改变总数。由于 K 的批数有限、全部物品格及单批缓存容量有限，C 也只能制造有限批，继而 A、B 的批数有限。进路有限且没有纯运输环，最后所有物品移动也停止。

还需排除“回路先漏空，所以停机时 C 恰好空着”。设第一次 Φ 变成 0，它只能发生于 C 向 CB 送出最后一件种子；此前 C 取货格只有 1 件，CA、A、AC、C 存货及 A、C 缓存全空。此时 CA 首格必能收。CA、CB 均不直连汇流器，属于同一级，按最近成功时刻轮询：若 C 上一次成功送给 CB，现在应先送给 CA，矛盾；若上一次送给 CA，那件种子及其后代尚未经过任何新的 C 外送，仍在回路内，其对 Φ 的贡献保持为 1，也不可能只剩半件。若还没有任何送货历史，C 的第一批产生 2 件，第一次送货同样不能清零。故 Φ 始终大于 0。

在最终不再变化的状态里，沿任何一件仍在回路中的物品往前看：运输格有货却不再移动，最终收货存货格必满；制造存货格有原料却不开批，必有做好的批次被取货格挡住；取货格有货却不送，专用进路首格必满。沿 CA、A、AC、C 这一圈继续，必得 C 的存货格满 50。这里使用的是最终各件均已满足滞留、通道只走前后且不阻断，和机器一直有电开着。

因此，任意合法几何实例中都存在这种允许的长等待，使下一次“再放 50 件荞花”无法完成。现有必要条件不禁止**调试期间**出现这种暂时未达标的状态；它正是候选声称能处理的放料过程。此论证没有借用旧 S08。

### 3.4 推导与实验具体漏了什么

推导从“放种前单元空”直接跳到“A、C 两处都放完时只有这 100 件”。空的是**第一次放料之前**的单元；第一次放料会启动整个循环。第二次操作前 C 不必仍为空，单元也不必仍只有原来的物品。

即使两处恰好同时装入，之后 C 先向 CB 送一件也会使 Φ 从 100 降到 99.5。因此，操作分散进行时不能把“放完那一刻 Φ=100”当成无需证明的事实。

推导席的 [s11_sim.py](推导92F/s11_sim.py) 第 241—245 行，先断言 A、C 存货均空，然后连续给二者各写入 50，中间没有推进一步。其 360 次整厂试验不覆盖本反例的两次人工放料间隔。本席没有复述该统计数作为独立验证结果。

常数本身的代数正确：`100−1/2 ≥ L+5/2` 给出整数 `L≤97`。错误在于尚未证明原操作能完成并取得可代入这个式子的起态。即使 S08 在新规则下成立，这一操作断点仍需单独修复。

### 3.5 修正版条文全文

> 制造单位与通道采用快照中“全厂专用进路接法达标”的接法，几何合法且全部制造单位有供电状态。本线物品指各进路规定运输的物品，以及各机器指定配方在相应存货、取货和缓存格中的原料、产物或在制批次。蓝图一次建成后：（1）关闭所有采种单元的 A、C 并保持关闭；设好 52 条矿石取货通道，物品准入口不设收下上限、放行种类不设或设为本线物品，打开其余制造单位。（2）取出运输、制造单位物品格中的非本线物品；缓存格中的非本线批次等做完、进入取货格后取出，必要时先取出挡住整批入格的取货物品，直到全部干净。（3）每个单元给 A 的存货格放 50 件对应种子、给 C 的存货格放 50 件对应植物。记 L=L1+L2；L>97 时再将 CA 放满对应种子、AC 放满对应植物。（4）全部准备完成后，一次打开全部 A、C，以此操作完成后、下一步开始前为调试期终点。此时各制造单位有电且开着，运输及制造物品格只有本线物品，Φ 在 L≤97 时为 100、L>97 时为 100+L，均不小于 L+5/2。该起态保证不依赖操作间隔或离线改变接通先后；后续达标仍须按现行步进规则证明。

荞花单元的“对应种子、对应植物”即荞花种子、荞花；砂叶单元即砂叶种子、砂叶。

### 3.6 修正版为什么足够

**准备期间不启动回路。** 全厂接法没有从外部进入采种单元的种子或植物通道。在第一次放料前，四台机器及四条进路均空。关闭 A、C 后，它们没有正在制造或做好的批次，也没有可向外送的物品。给 A 放料后，无论过多少步，它都不会制造荞花或砂叶；C 的存货格仍空，第二次 50 件一定放得下。反过来的放料顺序也成立。先准备好的单元可以等待其他单元，不会损失库存。

**清理会结束。** 设对所有矿石取货端口后，没有新的非本线物品进入。尚存的非本线物品可能继续变成别的非本线物品，但只处于没有回头路的矿石加工链及下游；采种单元此前没有外来物品。初始非本线物品有限，每次制造的后代有限、所经制造链有限。因此，把可直接取出的物品取出，缓存里的批次在有电开着时等其做完，给整批腾出取货空间，再取出，有限次即可清完。允许为此临时取出挡路的本线产物，补上了原步骤没有明说的操作。之后只处理规定的本线原料，每台的这些原料只符合其指定配方，清洁状态保持。

**仓库能供应放料。** 荞花的 6 个单元各需 50 件荞花种子、50 件荞花；砂叶的 11 个单元各需 50 件砂叶种子、50 件砂叶，分别合计每种 300、550。蓝图矿石设定正确时，未播种前没有消耗它们。误设取货端口的情形也不会耗尽初始 80000：未播种时砂叶单元全空，蓝铁矿入口后的精炼炉又不能加工植物，所以蓝铁系研磨机没有砂叶粉末，因而没有钢块、钢制零件、钢质瓶和成品；物品没有由成品通道离开布局的出口。初始植物最多滞留在第一层 52 台矿石机器、18 台源矿粉碎机的产物和缓存、9 台源石研磨机及 3 台封装机，加上运输格中。对每一种初始植物单独计其来源，每件这些派生产物至多承载一件该植物；缓存按最多 3 件保守计。一个足够宽的上界是

`52×50 + 18×(50+3) + 9×(100+50+3) + 3×100 + 2×70×70 = 15031`。

最后一项连基地全部格子都各算两个运输物品格，已覆盖桥接器两轴。种子不能被上述矿石机器加工，也被同一个上界覆盖。故设对端口后，每种仍至少有 `80000−15031=64969` 件。即使所有长进路也要手动放满，每种额外放入的件数仍不超过全基地运输物品格的上界 9800，故总需求至多 `550+9800=10350`，仍取得出来。此处只使用初始仓库物品、接法和配方，不假设游戏中仓库会自动补植物。

**长进路可逐格放满。** A、C 存货格都满 50 且制造关着，CA、AC 末端不能把物品送进它们。按末格到首格给 CA 放对应种子、给 AC 放对应植物即可，前后操作间隔任意。途中移动也只保留道路总件数，不会漏到 CB。最终两路全满，A、C 的取货格及缓存仍空。

**终点存量直接计算。** 全部准备好后，第 21 行允许一次打开多台制造单位。把这次操作完成定义为调试期结束，不需要测量几分之一 tick，也没有“开机后再等待其他单元放料”的空档。操作发生在两步之间（第 25 行），故下一次制造开始前：

- L≤97：两存货格各 50、回路进路空、A/C 取货及缓存空，所以 Φ=100≥L+5/2；
- L>97：另有 CA、AC 合计 L 件，所以 Φ=100+L≥L+5/2。

其他机器和道路在等待中可能运行，但始终只有本线物品；全部开关与供电状态也满足目标起态。接通先后不改变以上关闭制造、容量和件数事实。这一证明不引用 S08 的下降常数，也不预先使用 S11 的后续达标结论。

对原文仍可保留的内容，修正版保留了一次蓝图、矿石端口与准入口设定、有限清理、每单元两处各 50 件及长路放满的办法；只改变 A、C 的开启时点，明示清理时的腾格操作，并把结束调试绑定到最后一次开启操作。它们都是修复已发现断点所需的操作。

S11 的专用进路要求每格只向后一格或终点送货；相邻桥接器的反向通道不满足此要求。现行及拟议的两处桥接器读法都不改变本节修正。

## 4. 对候选之外的可疑断言抽查

推导报告没有另列“确认成立／不受影响”的正式条目清单。以下抽查的是它在第 2—4 节直接当作可用结论的断言。

### 4.1 “其余 144 台机器收货、送货都无关”：修正表述

台数正确：`51+52+34+6+1=144`，另由 `221−(17+17+32+5+3+3)=144` 独立算得。

能保留的结论是：**给定周围单位送来的物品和腾空时刻，这 144 台没有额外的收发通道次序选择。** 不能把它读成这些机器的收发过程完全不随全厂接通先后改变。

同一合法荞花单元，两处同时各放 50 的干净起态有 Φ=100，满足 L=38 的起态门槛。只交换 C 的两条取货通道先后，CA 先时 A 第一次收到返回种子在步编号 64，CB 先时在 65。两套编码一致。A 属于那 144 台，接收时刻确实改变。影响来自候选明确保留的 C 送货轮询，未反驳候选一。详见 [side_claims.json](复核93F/side_claims.json)。

### 4.2 “两个仓库取货口直连同一汇流器”的反面对照：修正构型

作为抽象模拟，它说明两个非运输单位会争一个格。但按任务“仓库取货口只放左、下边界”，两取货口不能这样合法摆放。同一边的不同取货口不可能把中央端口送到同一个邻格；一左一下若送到同一格，只能送到 (1,1)，于是两个 3×1 取货口在 (0,0) 重叠。

可替换为两台粉碎机：左机占 (7,8,3,3)、向右送；上机占 (10,11,3,3)、向下送。汇流器在 (10,10)，向右接两格带，再进研磨机。格子互不重叠。调试时各给两台粉碎机 1 件源矿，一次打开制造，8 步后各有 1 件源石粉末；元件已判定完，先判定的粉碎机把物品送入汇流器，另一台送不出。交换两机先后，甲乙两套计算分别得到发送数 `(1,0)` 与 `(0,1)`。坐标、供电桩和原料来源一并记录在 `side_claims.json`。

这仍证明“至多一个非运输单位直接往同一运输格送货”不能随便删除，但应使用合法来源的局部对照，不能把原来的两个边界取货口图当成合法布局。

### 4.3 换主料的存货侧不额外拖一步：未否证其条件结论

对粉碎机、采种机的一件原料配方，上一批在 s 步末开工并腾空存货格；若下一种原料确实在 s+1 至 s+8 的某步判定阶段收到，而且上一批能全部进取货格，则第 s+8 步开头结束制造、判定后开始下一批，下一种原料赶得上。八种到货步由两种编码均给出下一批在 s+8 开始。

它只证明这个条件下不因存货阶段先后多停一步，不能据此断言来料必能在 s+8 前到达，或忽略取货格同种唯一、整批进格和来料排列。

### 4.4 对面积 1110 的适用说明：保留全部结构前提

“面积 1110 没有协议储存箱”是快照面积预算的结论；本文没有重跑该几何上界证明。即使另知不用分流器、没有两个非运输单位共送一格，也仍应检查候选一写明的出通道数及纯运输通道环。推导报告没有证明面积条件自动排除了后二者。可用的修正说明是：**1110 布局满足候选一的全部前提时，才使用本简化。** 本复核没有据该省略的应用说明排除任何 1110 布局。
