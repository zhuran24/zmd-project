# 分流器先判时的首段传送带容量

日期：2026-10-02。状态：证明完成，候选待审。无面积前提。

本报告给出一个对任意可到达循环态成立的容量上界，再推出满速分流器与断头支的限制。容量上界不要求传送带先被塞满，不把局部模拟结果当成全厂布局，也不假定某种满带初态可由调试达到。

## 前提与记号

规则、任务与正式条目仅使用 `../../前提快照/` 内的四份文件。下文规则行号均指快照《明日方舟：终末地》游戏规则.txt：运输物品格上限 1、滞留至少 1 tick（第 23、60 行）；每 tick 为 8 步，每元件每步只判定一次、一次最多送一件（第 25—26 行）；元件层序、收货的一起判定、分流器不参与这种一起判定（第 27—32 行）。任务第 14 行要求覆盖离线后的接通先后变化。

设分流器 X 的一条取货通道直接接到一段连续传送带 B 的首格。B 有 n 个传送带格，n≥1，只有首格从 X 收货，只有末格对外送货，途中没有其他进出口。这正是一个连续传送带元件；其物理长度 n 和层数无关。用“X 先于 B”指每步实际执行的判定次序，已计入规则第 31 行可能把 B 提前拉入的收货判定，不能只比较第 27—28 行给出的名义层序。

取一个循环周期 P 步，B 在其中送出 Q 件，周期平均流量为 q=8Q/P 件/tick。令 H_t 为第 t 步一切移动完成后，B 内占用的传送带格数。

## 候选一

分流先判的首段带容量：在任一可到达循环态中，分流器 X 直接向一段 n 格连续传送带 B 送货，B 只在首格从 X 收货、只在末格向外送货。若按本循环态的接通先后与收货的一起判定，X 每步实际都在 B 之前判定，则 B 的平均流量 q 至多为 8n/(8n+1) 件/tick。若 X 同时平均收货 1 件/tick，则 X 的其他取货通道合计平均流量至少为 1/(8n+1) 件/tick，因而这些其他通道不能全部为零流量。以上限制须对每种接通先后下的每个可到达循环态成立，无面积前提；本条不给出 B 一定达到该上界的充分条件。

    据：规则第 23—27、29、31、60—61、68 行；求解任务第 2、8、10、14 行；运输物品格的周期收支。
    推导：B 每一格每周期收、送同为 Q 件，每件在一格至少占据 8 个步末状态，故 ΣH_t≥8nQ。B 送货的每一步，X 已用掉本步唯一判定，B 送出后不能再从 X 补入；末格虽可由带内物品补上，整段总件数已少一，故该步末 H_t≤n−1；其余步骤 H_t≤n。B 每步至多送一件，故 ΣH_t≤nP−Q，得到 (8n+1)Q≤nP。X 每周期收支相等，满速时其他支流量为 1−q，代入即得下界。
    状态：待审。

种类：必要条件。relation：新条目。

### 证明中需要特别说明的三点

1. **周期边界不漏算滞留。** 在循环周期的两端把时间线继续周期展开，逐格对进入与离开计数。进入步为 a、离开步为 b 的一件物品，在 a,…,b−1 的步末状态中占据该格，至少有 8 个这样的状态。对跨周期的物品按周期平移分摊。任何永远不离格的库存只会增加 ΣH_t，所以仍是下界。
2. **内部自动前移不能补回总件数。** “一直在尝试移动”允许 B 内部前移，但内部前移不改变 B 的总件数。B 对外送出以后，X 已判定且不能再判，本步不可能新增 B 的总件数。这比“首格在 B 判定前一定仍满”更强，也没有要求整段一开始是满的。
3. **分流器必须实际先判。** 若 B 的末端单位另有一个非分流器元件上游提前判定，规则第 31 行可能使 B 一起提前。此时不能仅凭名义层数断言 X 先于 B。本条的前提必须按真实的一起判定检查。

也可对一个周期内混有不同实际次序的情形写成计数式。若 B 共送 Q 件，其中 Q_先 件发生在 X 已先于 B 判定的步骤，仍有

\[
8nQ+Q_{先}\le nP.
\]

因此 B 满速时，任何出货步都不能属于 X 先于 B 的步骤。固定接通先后时的候选是 Q_先=Q 的特例。这一扩展只对已覆盖完整状态变化的周期使用，不把离线随意切换之后的时间段冒称循环态。

### 对矿石线的用法

由快照正式条目“取货口配置”可知，达标布局中的 52 条矿石取货通道都必须满速。对其中一条取货通道，从仓库端口到第一个分流器 X 之间若只有不分叉的运输通路而没有协议储存箱，周期守恒和每格容量使 X 收货也恰为 1 件/tick。这一步也正是快照“满速独占”的结论。

此时，若 X 的某一支满足本条的先判条件，其余支必须承担至少 1/(8n+1) 件/tick。一个纯运输断头支只能再收有限件；进入封闭有限运输区域的支路也同样如此，因为区域没有消耗或外送，物品总数单调且有上界。因此这些支在任何循环态中流量为零，不能用来承担该正流量下界。

没有声称任何经过分流器的矿石通道都不可能满速：若其他支能够持续消耗足够的物品，本条允许总流量为 1。

## 候选二

满速分流的断头支层数限制：设某分流器 X 在所考察的每个达标循环态都必须平均收货 1 件/tick。X 的唯一可能有正循环流量的支路，先经过一段连续传送带，再由传送带元件与未设阻断的物品准入口首尾相接，合计 m 个元件后到达一个非运输单位；这些元件没有其他进出口。X 另有一条由同类元件串成的断头支，共 k 个元件，最后一个元件没有向外通道，k≥2。若层数按该断头支计算，则 X 层数为 k、活支首段带层数为 m：k<m 的取值不允许出现；k=m 时，X 在活支首段带之前的同层判定次序也不允许出现。故如果规则允许按这条断头支数层数，并在 k=m 时允许 X 先判，则达标布局必须 k>m。本条无面积前提，不适用于只含一个无向外通道元件的断头支，也不能把其他支实际有正流量的构型套入。

    据：候选“分流先判的首段带容量”；规则第 25—32、60—61、65、68 行；求解任务第 14 行；纯运输断头支的有限容量。
    推导：断头支无消耗、无出口，周期进货为零。其末元件无向外通道，不是上一元件数层数时的“还往下送货的元件”，因此第一元件层数为 k−1；按它计算时 X 层数为 k。活支到非运输单位的最后元件层数为 1，首段带层数为 m。k<m 时 X 严格先判；k=m 且 X 同层排前时也先判。由于 k≥2，这两种情形都有 m≥2，活支首段带的下一个单位是仅从它收货的运输元件，规则第 31 行不会把它提前。活支首段带因此满足上一候选，却因 X 满速、所有其他支零流而被要求 q=1，与 q<1 矛盾。
    状态：待审。

种类：必要条件。relation：新条目。

### 层数限制的适用边界

这里按“元件”计 m、k：一段再长的连续传送带仍只算一个元件；上一候选的 n 才按带格数计。两者不能互换。

k=1 时，X 所遇的断头元件自己不再往下送货，不能凭这条断头支把 X 的层数压低；该情况没有被候选二排除。

当 k<m 时，只需出现按断头支定层的取值就产生矛盾，与同层次序无关。当 k=m 时，报告保留“允许 X 先判”这个条件，不把未知的选支与同层次序关联机制当成已经证明独立。任务要求覆盖每种规则允许的接通先后；只要其中有一个允许的组合满足该条件，就足以排除此构型。可直接从一张布局的完整接通排序证书检查，而不依赖两个量独立变化的假设。

更一般地，对 X 的一条零流支，只要它允许 X 的层数小于活支首段带的层数，且活支首段带不会被一起判定提前，同样不达标。候选二选取纯运输断头支，是为了让零流量、层数和不提前三件事都能从结构直接证明。

## 桥接器两种读法

候选二的两条局部支路均不含桥接器，因此按现行第 28、31 行以及拟修改的两种表述，证明相同。

候选一只要求首段 B 是连续传送带，不禁止更远处存在桥接器。其证明对两种读法都成立，但必须分别按各自读法确认 X 是否实际先于 B。若现行相邻桥接器使某些层数无法确定，不能把拟修改后的数值当作现行数值；应将现行规则允许的各实际判定情况分别代入。本报告未据此声称一个含相邻桥接器的具体结构必然迟滞。

## 两套编码的核对

脚本 `check_capacity.py` 自行实现两个局部模拟器，没有导入仓库的模拟器。一套存物品进入各格的绝对步数，另一套倒序存格并维护成熟倒计时；比较循环起点、整个循环中每步的完整局部状态、出货数与占格数。

局部构型为：源头→分流器 X→n 格带 B→物品准入口 G→持续接受的边界；X 另接已满的两个物品准入口组成的断头支。选择按断头支数层数时，X 与 B 都在第 2 层，G 在第 1 层，因而可以检查两种相关同层序。边界是容量核对用的外部接口，未被认证为 70×70 工厂布局。

对 n=1,…,32、X 先或后、初始空或满，128 个案例的两套编码逐状态一致。X 先判时周期速率均等于 8n/(8n+1)，其周期格步占用同时达到证明中的上下界；X 后判时均为 1。数字和完整计数在 `capacity_checks.json`。选例为 n=1 时 8/9、n=2 时 16/17、n=3 时 24/25、n=6 时 48/49。

模拟只是检查证明中的计数与上界的局部可达程度。所有 n 的容量结论依赖前面的计数证明，绝不依赖有限枚举涵盖所有布局或所有可到达状态。

## 未得出的结论

- 未证明“存在较短支路”本身就排除满速；需要剩余支流量不足，或需逐一使用容量不等式。
- 未证明所有分流器的选支方式和同层接通排序能独立指定；候选二的等层情形保留可允许组合条件。
- 未用 8n/(8n+1) 作为任何含分流、汇流、箱子或机器的一般长支路的精确速率。
- 未提出删除断头支或移除分流器的“不丢最优”简化。删支可能改变层数、轮询、取货优先级，必须另证全局效果。
