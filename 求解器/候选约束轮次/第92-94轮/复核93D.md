### 被复核条件的完整含义

C 是一台采种机，A、B 是两台种植机，K 是一台粉碎机，均只处理同一种植物。四条进路为 C→A 的 CA、A→C 的 AC、C→B 的 CB、B→K 的 BK；除 K 的取货通道外，四机没有其他通道。每路至少一格，只用传送带、桥接器的一轴，以及放行本路物品、没有累计或每5 tick收下上限的物品准入口；没有分流器、汇流器或协议储存箱。各运输格仅与本路前后相接，桥两轴互不相干；现货沿最终进路正向进入，随后不改接。现行读法排除同轴相邻桥，两处拟改同时采用时删去该排除。

L1、L2 分别是 CA、AC 的运输格数。Φ 为 CA 和 A 存货中的种子数，加 A 取货、AC 和 C 存货中的植株数，加 A、C 非空缓存各1，再加 C 取货种子数的一半。

候选一只要求：s 为完整步末，所计各格只有本线物品或空，A、C 缓存为空或本配方一批，C、A 此后有电且开着。其结论是150下界，允许 B、K 及下游任意合法停收恢复、离线重排。

候选二还要求：四机此后都持续有电且开着，四缓存各有本机本配方一批，Φ(s)=L1+L2+177，B、K 存货和取货各50，CB、BK各运输格满。所有存取货和运输格都只含本线物品。K 每批产k件粉末，荞花k=2、砂叶k=3；全部取货通道固定为n条，0≤n≤k。各首格互不共用，首单位只可能是传送带、桥的一轴或始终放行的物品准入口；首格只从K收货，空着就能收下粉末。复核包括其库存下界、补货时限和附条件的平均产率结论。

## 2. 两种桥接器读法与共同的链性质

### 2.1 现行第28、31行

候选排除同一路同轴相邻桥，各格仅与本路前后相接。传送带和物品准入口为单向端口；孤立桥这一轴接在这样的单向端口之间，也没有可以向上游送货的通道。桥的另一轴由第64行明确为互不相干。故一条进路的最后一个元件层数为1，沿前驱逐级加1，必然下游先判定。

四条进路各自只有一个终点来路，不存在终点收货竞争把本路中段提前到后继之前。桥另一轴也不能借“单位”二字参与这一轴的收货。接通先后改变不了本路这个严格的先后关系。

同一连续传送带段内，前格的旧货可以进入后格本步腾出的空位；在进入之后必须重新滞留8步，不能让同一件货连走两格。把连续带段和特别运输元件串起来可得：若一串格子全满且货都成熟，尾部收下一件时，空位能在同一步传到首格；源机器在全部运输元件之后判定，单出口且有货时能在本步补首格。这没有要求一个元件重判。

### 2.2 两处拟改同时采用

对一串正向装料的同轴桥，向上游数的路径最终会返回已经经过的元件；排除这种回返以后，能数到路尾的路径只有正向路径，仍为下游先判定。又因桥中的货来自前一单位，第24行禁止它送回该单位，它不会成为“往前一单位送货”的触发者。因此拟改第31行不会再由下游桥提前带动上游带子判定。正向来源对以后每次前移保持不变。

所以两处拟改同时采用时可以删除同轴相邻桥的排除，其余链证明不变。只改其中一处，不具有这里的结论。

### 2.3 抽查相邻桥的8/9证据

局部 `U传送带→P桥⇄Q桥→D传送带`，取现行未定层数所允许的 D、Q、P、U 次序。Q 判定触发 U 提前尝试，U 看到 P 满而失败；P 此后放空，U 本步已经不能重判。P 的新货最早下一步进入，再滞留8步，相邻两次送出至少隔9步。

在源不断供、尾端始终可收的饱和局部试验中，独立的两种编码对12000步的全部交付步号一致：

|读法|最初交付步号|稳定间隔|稳定速率|
|---|---|---|---|
|现行所示次序|0、8、16、25、34、43…|9步|8/9 件/tick|
|两处拟改|0、8、16、24、32、40…|8步|1 件/tick|

证书见[bridge_results.json](复核93D/bridge_results.json)。这证明省略排除条件后，本文使用的8步链性质不再无条件成立；它不是一张完整工厂反例布局。

## 3. 候选一：150下界的逐步复核

### 3.1 存量的变化只来自采种机两个出口

制造开始把一份原料转到缓存；A 的一株产物和 C 的两粒种子整批转入取货格，都保持 Φ。CA、AC 的运输同样保持 Φ。只有 C→CA 使 Φ 加1/2，C→CB 使 Φ 减1/2。

规则18、24、36使已完成的一批在空间足够时整批进入取货格。缓存与取货格之间是本单位内部的零时移动，规则26限制的则是单位把物品送出自己的一次判定；内部整批转入不额外占用一次对外判定。

按先后把 C 的成功发送记为 A、B。每步 C 只判定一次，所以一个步骤至多添加一个字母。任一段都有

`2ΔΦ = A的发送次数 − B的发送次数`。

同一 CB 首运输格两次接收至少相隔8步。这不依赖 B、K 有没有开着，以及更下游的接收节奏。

### 3.2 连续两个B的后一个步骤

设连续两个 B 发生在 b₁、b₂，且 b₂−b₁≥8。

1. b₂ 时 CA 上次成功严格早于 CB；CA 若从未成功，也排在已经成功的 CB 前面。两口同属非汇流器的一个级别。因此 C 既然发给 B，CA 首格必满。
2. 从 b₁−1 步末到 b₂ 的这次 C 判定之间没有 C→CA 补货，这个首格只能是原来那件货，已经成熟。若它后面空着，必能前移。沿路反推，CA 各格均为一直没有离开的旧货，A 的存货在 b₂ 运输阶段为50。
3. A 在这段时间没有收到种子，末时仍有50，说明 b₁ 到 b₂−1 没有开始新批。初始在制批次最晚在这段时间内完成；取货若腾出一格，已完成的一株就会进入，随后必开新批。因此 A 在该段也没有发送，取货为50，缓存里有完成的一批。
4. 在 b₂−1，AC 首格若空，A 就会补货。重复第2步的反推，AC 也是满载成熟的旧货；b₂−1 的运输阶段 C 存货为50。
5. 随后的两个步末 C 至多开一批，因此 b₂ 步末 C 存货至少49；A 存货至少49。A 若在 b₂ 送一株，已完成批次立即补入，取货仍为50。两机都有原料，缓存一旦释放就在步末开新批，故两缓存非空。CA 仍满；AC 若本步前移，A 的单出口在本步补回，AC 仍满。

C 取货中的种子暂只用非负性，便得

`Φ(b₂) ≥ L1+L2+49+50+49+1+1 = L1+L2+150`。

离线只改变接通先后，没有条文把已经成功的时刻清除。b₁ 的成功使 CB 比 CA 更新，这个严格先后不会被重排逆转。这是第1步所需的全部轮询信息。

### 3.3 接成任意长时间的界

如果没有连续 BB，每个 B 除了最初可能多出的一次，都能配到前面的 A，因此 Φ 至多比起点少1/2。

如果有 BB，取最后一对的后一个 B。该点已有150界；以后每个 B 前面都有尚未配掉的 A，因为这一后缀从 B 后面开始且不再出现 BB。因此此后不低于该点的 Φ。

两者合并正是候选的

`Φ(t) ≥ min(Φ(s)−1/2, L1+L2+150)`。

特别地，原来 `Φ(s)≥L1+L2+5/2` 所需的保底 `Φ(t)≥L1+L2+2` 仍然保留；它本身不说明缓存不空。

这套证明覆盖候选的全称量词，不需要随机模拟补齐逻辑缺口。

## 4. 与原S08的差别：176仍有应保留的部分

### 4.1 正常完整步末的176界

增加一个明确的观察截面条件：**C、A 在 s 这一步运算时就已经有电且开着，观察点在该步开始制造阶段之后。** 在这个范围，候选的150可以加强为原来的176。

证明沿用第3节的 BB。那里已经得到：从 b₁−1 步末到 b₂−1 的运输阶段，AC 没有向 C 送货，而该末端时刻 C 存货为50。因此 C 在 b₁ 到 b₂−2 不能开新批。

在正常完整步末，若 C 的存货为50，它的在制批次剩余步数不可能是8：剩8说明刚在步末开批，刚消耗一株后存货至多49，运输阶段已经过去，无法再补到50。因此 b₁−1 时 C 的在制品至多还剩7步；它至迟在 b₁+6≤b₂−2 完成。缓存也不能空着，否则50株原料会使它更早开批。

如果第一次 B 发出以后 C 取货不超过48，这个批次便会在 b₂−2 以前整批转入，并在步末开新批，矛盾。于是第一次 B 只能把取货50减成49，并让已完成的两粒种子留在缓存。第二次 B 把49减成48，整批进入后恢复50，C 在 b₂ 步末开始新批，存货降到49。

在 b₂ 的运输阶段 C 此前还没有空位，所以 AC 没动，A 也没腾取货空间。该步末的各项恰为：CA、AC 全满；A 存货50、取货50、缓存一批；C 存货49、取货50、缓存一批。故

`Φ(b₂) = L1+L2+50+50+49+1+25+1 = L1+L2+176`。

再按最后一个 BB 分段，得到

`Φ(t) ≥ min(Φ(s)−1/2, L1+L2+176)`。

所以150是较弱的有效结论，不是已经证明必须下降到的常数。正式修订若保留正常完整步末这一范围，176这部分结论不应被丢掉。

### 4.2 起态时序与边界证书

快照允许制造停用时保留进度。因此“缓存剩8步、存货50”不能一概称为任何调试过程中都不可能出现：停用期间原料仍可能进入；但它不能作为**该步已开着运行**之后的完整步末。是否在 s 与下一步之间才恢复制造，必须分开。

独立复算92D边界数据：L1=L2=1、C取货49、两机存货50、A取货50、两个缓存都剩8步时，Φ初值178.5、最低177.5；把余时改为7，最低为178。另一组把C取货改为1，分别得到154.5降到153.5，以及154.5降到154。两编码逐步一致，见[boundary_results.json](复核93D/boundary_results.json)。

前一种拼态不满足第4.1节的观察条件，不能否定那里保留的176界。上述起态没有附逐步调试来源，不能拿来当原正式条目的合法反例，判为**来源不明，当线索**。候选150界无需依赖它们。

如果允许 s 在恢复制造之前，只能直接使用候选150界；从第一步运行结束的 s+1 起，又能应用本节176界。由第一步最多损失1/2，还得到一个覆盖这种起点的附加界：以后完整步末均有

`Φ(t) ≥ min(Φ(s)−1, L1+L2+176)`。

它与150界可以同时使用，不能把两个式子中的损失项混用。

## 5. 候选二：满库存不断料的逐项复核

### 5.1 最大存量起态与C的两条进路

容量给出 Φ 的最大值为 `L1+L2+177`：三处存取货共150，两缓存共2，C取货折算25。达到等号时，CA、AC及这些库存均满，两缓存均有一批。

C 初次给 CB 只使取货50变49，不能放入缓存中的两粒。第二次给 CB 至少隔8步，到该步 u，初始运输货和初始制造批次都已经成熟。C 取货48后整批补到50，步末用掉一株。

若 CB 始终不请求，或只请求这一次，A、C 的存货和运输路没有空位，缓存留存，C 取货分别保持50或49，结论直接成立。以下处理第二次请求确实发生的情形。

u+1：AC 向 C 补一株，成熟旧货逐格前移，A 的唯一出口补首格；A 的完成批次补回其取货，步末消耗一粒种子。

u+2：CA 向 A 补种子，C 对 CA 发一粒，取货为49。

CB 的首格在 u 才进入一件，最早 u+8 才能再空，故它不会与 u+2 的 CA 请求竞争。其后任一次 CB 腾空 v≥u+8，都重复“v开采种新批、v+1补AC、v+2补CA”；各次相同进路的移动至少隔8步，前次的运输和制造都已成熟。任意延长停收只延长间隔。

因此 C 能在 CB 首格腾空的本步补入，A、C 的缓存始终在步末非空。这个结论不需要固定 C 与 A 在非运输单位中的判定先后。

### 5.2 满路给接收机器补原料

设一条 m 格进路初态满，源在首格腾空时当步补货。接收机器初始原料50，每批耗一件，实际开批步为 x₁、x₂…，相邻至少隔8步。

记 Dᵢ(j) 为从上游数第 i 格第 j 次送出的步号。第一次受初始货龄及下游空位限制；以后由两件事取较晚者：本件从上格进入满8步，以及下格第 j 次腾空。于是

`Dᵢ(j)=max(Dᵢ₋₁(j−1)+8, Dᵢ₊₁(j))`。

首格第一项改为自身上一次发送后8步；末格第二项改为 `xⱼ+1`，因为本步的原料消耗在全部运输判定以后。这个末端的一步延迟不能省略。

所有初始货龄都改成0，只会推迟发送。在这一比较过程，各格第 j 次发送的共同步号为

`Tⱼ=max(s+8j, xⱼ+1) ≤ xⱼ+8`。

后一不等式来自相邻开批至少隔8步。因此实际补回在下一次可能开批之前，或恰好在那一步的运输阶段。完整步末原料至少49。独立逐步模拟与上述递推核了23113种情形，逐格逐次时刻全部相同；全称结论由单调性和递推归纳给出。

用于 CB 得 B 存货至少49。B 唯一出口在任意连续8个判定步至多取一株；从取货50、已有一批的起态出发，下一批完成之前至多损失一株，有空间时完成的一株立即补回。因此 B 取货至少49，BK 首格一空就能本步补入。再用于 BK，得 K 存货至少49。于是 B、K 清空缓存后都能在本步末开下一批。

### 5.3 K的取货下界、服务时间与平均批次

每条首运输格两次收货至少隔8步，n条合计在连续8个判定步至多取n≤k件。K 从取货50出发；一批制造期间不会降到50−k以下。完成批次若还放不下，保持在缓存；当取货降到50−k，整批进入恢复50，随后开新批。制造完成先于该步判定，边界步骤没有多出一次未被补回的发送。因此 `K取货≥50−k>0`。

K 所有出口的首单位都不是汇流器，属于同一级。目标首格空着时，机器每步都有货可送；若先选择别口，该口在轮询历史中变得更新，而且接下来至少8步不能再接收。n≤3，最多n−1个别口排在目标前面，目标最迟在第t+n−1步补入。这里 t 的含义是：该首格在**第t步K的判定之前**已经腾空。即使采取更早的“该运输元件判定之前”解释，结论也成立。

离线改变并列或未成功通道的接通次序，至多改变这n个口的排列；它不能让一次已经收货的首格提前再次收货。n=0 时没有要服务的口，制造完成而放不下的批次仍留在缓存，缓存不空结论照样成立。

最后，若循环态中 K 完成的一批从不等待取货空间，原料又不缺，K 每8步一批。周期内所有有限库存恢复原值，依配方和唯一去路逐级守恒，有 B批数=K批数、A批数=C批数，以及 `2C批数=A批数+B批数`，所以四机平均各1批/tick，K平均送出k件/tick。这里说的是平均数，不推出四机同相开批。

|---|---|
|观察点改为完整步末|必要。开始新批在本步最后阶段，不能在缓存刚释放的步内截面要求缓存不空。|
|给进路增加正向现货来源，现行条文排除同轴相邻桥|保证第2节的链性质；不能拿无来源信息或反向通道仍参与判定的状态套用本证明。拟改两处同时生效后桥排除可删除。|
|低库存门槛改成全满起态|足以证明更强的“所有以后步末”结论，但本轮没有证明它是必要门槛。原低门槛版本不能仅凭外部服务试验被整条否定。|
|删除K多口当步全补|必要。一次判定至多送一件；多口同时空不能都在本步补齐。新条文正确改成逐口至多等待n−1步。|
|不再宣称任意8步窗口逐口各一件|正确。有限等待上界不能推出每个口满速。|
|无取货等待时的四机平均批次率|保留，且第5.3节重新由配方守恒推出。|
|K取货口数量限定n≤k、首格独占且始终可收|这是充分的服务条件，不是所有合格采种单元都必须满足的必要条件。新条文没有证明超过k条口的原先局部发送下界。|

满库存起态可以通过调试中的临时供料、阻断下游等方向尝试准备，但候选没有给可操作的全过程，本复核也没有提供调试证书。不能由条件命题直接得到一张认证布局。

### 九步服务证书的独立复放

从证书给出的低库存开始，独立模型采用砂叶配方、三个输出首格，每个抽象下游在收货后第9步放空。所得周期为9步；Φ在4.5、5之间；C和A每周期各有1个完整步末缓存为空；四机每周期各完成一批。

与推导92D的`plant_nine_certificate.json`比较，把两种缓存状态编码统一、把路线排列统一，再平移周期起点，九个状态的四机存货、取货、缓存余时、四条路线货龄、C两口成功历史及Φ全部相同。完整复放见[independent_nine_cycle.json](复核93D/independent_nine_cycle.json)和[nine_recheck.log](复核93D/nine_recheck.log)。

但是，“收货后第9步放空”的抽象下游仍然不是给出的游戏单位网络。并且 L1=L2=1 的两条回路长度没有附两台5×5机器的几何实现。因此这份证书只否定“这个放宽服务模型已经排除周期断料”的说法；它既不是候选二的反例，也不是原S09或全厂S11的合法布局反例。来源归类：**抽象模型内来源明确；游戏布局来源未给出，当线索。**

## 7. 对未作为候选的已确认断言的抽查

92D正文没有另列字面标为“确认成立”“不受影响”的正式条目清单。本节选其作为确定事实使用、且最容易被扩大解释的断言复核。

### 7.1 满速纯链以及相邻桥拟改

第2节已分别核查：满足候选进路条件时下游先判；尾端始终可收、路首每次腾空都得到补货时，满成熟链每8步一次；当前相邻桥存在9步瓶颈的所示读法；两处拟改及正向来源共同恢复8步。**未否证。**

### 7.2 高库存排除A、C空缓存

完整步末若 A 缓存空，A 存货必为0；其余各项即使都取最大，Φ至多L1+L2+126。C缓存空也同样，另一机存取货100、一个缓存1、C取货折算25，合计126。

故 `Φ(s)>L1+L2+253/2` 与150界合用，严格保证以后 Φ>L1+L2+126，排除两机空缓存。等号不能用这个严格不等式论证。容量逐项相加和独立枚举所有容量端点两种编码相同。**未否证，但没有因此得到B、K不断料或全厂满速。**

### 7.3 固定S11接法的52矿口等价

记源矿速率x、蓝铁矿速率y、电池交付b、胶囊交付c。在所述固定接法的循环态中，源矿到致密源石粉末按2∶1，电池每件用15件，故x=30b。蓝铁矿到钢块按2∶1；电池消耗10b钢块，胶囊消耗20c钢块，故y/2=10b+20c。解得

`b=x/30，c=y/40−x/60`。

18个源矿口、34个蓝铁矿口由首运输格的滞留给出x≤18、y≤34。b≥3/5先迫使x=18，c≥11/20继而迫使y=34；反向代入得到目标值。因此**对固定接法，达标与52口都满速等价**。此为守恒等价，完全没有证明其前件会在所有可达循环态发生。

独立复算：221台机器、317条进路；一条必需源矿口若只有8/9且另外17口都满速，则电池率上界161/270；若一口长期为0，则17/30。两种计数/配方编码一致，见[numbers.json](复核93D/numbers.json)。这些条件上界不充当布局反例。**守恒与数值未否证；全厂满速未证成。**
