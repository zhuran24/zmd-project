## S08　采种单元的回路存量下界

判定：**改写**。保留 `176` 和起值减 `1/2` 的强界，明确收窄拓扑和起点。对原拓扑的强界既未确认也未否证。

采种单元的回路存量下界：采种单元由只处理同一种植物的一台采种机 C、两台种植机 A、B 和一台粉碎机 K 组成。C 的取货物品格恰有两条取货通道，分别经 CA、CB 进入 A、B；A 的一条取货通道经 AC 回 C，B 的一条取货通道经 BK 进入 K；除 K 的取货通道外，四台机器没有其他通道。四条进路都只由传送带首尾相接，各路运输物品格只从前一格或起点机器收货、只往后一格或终点机器送货。记 CA、AC 的运输物品格数为 L1、L2。Φ 是 CA 的种子数、A 存货格种子数、A 取货格与 AC 的植株数、C 存货格植株数之和，A、C 缓存格有本机的一批时各加 1，再加 C 取货格种子数的一半。s 取一个完整步的步末，C、A 在该步及此后始终有供电状态且开着；s 时 CA、A 存货格和 C 取货格只有这种植物的种子，AC、A 取货格和 C 存货格只有这种植物的植株，A、C 缓存格为空或只有本机做这种植物的一批。则以后每个步末都有 Φ≥min(Φ(s)−1/2,L1+L2+176)。结论不要求 B、K 持续运行，允许 K 下游任意停收与恢复，并对所有接通先后及其离线改变成立。

据：快照游戏规则第 13、17—18、23—33、36 行的格容量、整批入格、滞留、步进、判定、轮询、取货优先级和制造；采种、种植配方。

推导：如下完整证明。

### 1. 精确收支

把 C 向 CA、CB 送出一粒种子分别记作 A 次、B 次。这只是事件计数，不是增加单位或新游戏术语。一次 A 次使 Φ 增加 1/2，一次 B 次使 Φ 减少 1/2。其他运输、开始制造、完成制造、缓存整批进入取货格均保持 Φ。特别是 C 的一批缓存计 1，而两粒取货格种子合计也为 1。任意两个步末 p、q 间严格有

`Φ(q)−Φ(p) = (A(p,q]−B(p,q])/2`。

同一 CB 首格两次收货间至少 8 步。C 两条出口同属非汇流器的一级；一次向 B 成功后，在下一次 A 成功之前，只要 CA 首格为空，C 必先向 A 尝试。A 从未成功时同样排在已经成功的 B 前面；离线改变接通次序不改变这个比较。

### 2. 纯传送带反压引理

一条纯传送带进路在 `(u,t]` 没有从机器获得新货，`t−u≥8`，而在 t 的机器判定时首格仍有货，则全路满，且 `(u,t]` 没有格间前移或末端出货；终点机器在 t 的运输判定时存货格为 50。

首格仍满，又没有新货补入，说明它一直放着同一件物品。到 t 这件物品已满 8 步。若第二格为空，成熟的首件会前移，所以第二格满。第二格也不可能在此区间得到补货，因为首格没有移出；若它曾移出，现在应为空，矛盾。因此第二格也是同一件成熟物品。逐格归纳到末格。末格成熟而不能送入一个只收正确种类、没有其他来路的机器，其唯一障碍是存货格满 50。传送带内部前移一直尝试，元件又先于机器判定，不需要假定机器判定之后还能重判运输单位。

### 3. 两次 B 次之间没有 A 次时的强界

取连续两次 B 次，发生在 u、t，且 `(u,t]` 没有 A 次。u、t 都在 s 之后；`t≥u+8`。在 t，C 若看到 CA 首格为空就应优先送 A，故此时 CA 首格满。对 CA 用反压引理，得 CA 全满、`(u,t]` 没给 A 补过料、A 在 t 的运输判定时存货为 50。

于是 u 步末 A 的存货也为 50，A 在 `u,…,t−1` 没有开过批。否则开批会使存货变为至多 49，又没有补料，不能在 t 达到 50。A 在 u 这一步也没有开批。因此其原有缓存若仍在制造，剩余至多 7 步，最迟 `u+7≤t−1` 完成。A 必有这一批缓存：若缓存为空，50 粒正确种子会在步末开批。

A 的取货格在这段中一直为 50，且在 `u,…,t−1` 一件也没有送出。若期间任何子时点低于 50，在当前唯一缓存批完成以前没有其他途径增加取货格，因此空位会保留至该批完成。它已经完成或最迟在 u+7 完成的一件批次就能整批进格，同一步末会再开批，与上段矛盾。因此在 t−1，A 有取货而无法送出，AC 首格满；AC 在 `(u−1,t−1]` 没得到 A 的补货，跨度至少 8 步。对 AC 再用反压引理，得到 AC 全满且这段没有向 C 补料，C 在 t−1 的运输判定时存货为 50。

据此，u−1 步末 C 的存货也是 50，C 在 `u−1,…,t−2` 没有开批。C 在 u−1 这一完整步中持续开机；它不能在该步末刚开始一批，否则存货应至多 49。因而缓存最迟在 `u+6≤t−2` 完成，却不能进取货格，否则会再开批。因此 C 取货格至少有 49 粒种子。C 在 u 成功送 B 后、t 成功送 B 前没有别的成功出货，故 u 步末 C 取货格也至少为 49。

这样，在 u 步末，CA、AC 都满；A 存货 50、取货 50、缓存一批；C 存货 50、缓存一批、取货种子至少 49。故

`Φ(u) ≥ L1+L2+50+50+50+1+1+49/2 = L1+L2+176.5`。

从 u 到 t 只有后一次 B 次改变 Φ，故 `Φ(t)≥L1+L2+176`。这里没有错误地要求 t 步末 C 存货仍为 50：C 可能在 t 送出后让两粒种子整批入格并再开批；这些操作都保持 Φ。

起点条件是实质条件：u−1 可能正是 s，因此明确要求 s 是完整一步的步末，且 C、A 在 s 所在的整步已经供电开启。不能把“调试时暂停着、存货已补满 50、缓存还需完整 8 步”的手工状态冒充这一截面。

### 4. 全时段结论

把“连续两次 B 次之间没有 A 次”的后一次 B 次作为分界。若截至某步没有分界，每相邻两次 B 次之间都有 A 次，所以 B 次总数至多比 A 次多 1，Φ 至多比起值低 1/2。

若有分界，取最后一个。第 3 节证明该处分量至少为 `L1+L2+176`。从它之后到所考察的步，每次 B 次之前都必须已有 A 次，否则会产生更新的分界；故该段 B 次不多于 A 次，Φ 不再净下降。两种情形合并即得修正版。

### 5. 防灭绝推论

在本修正版范围内，`Φ(s)≥1` 保证以后 `Φ≥1/2`。更一般地，防灭绝本身不依赖 `176`：若首次从 1 降到 1/2，只能是 C 向 B 送出后全回路只剩 C 取货格的一粒种子。CA 此后一直为空，其他环内物品、缓存全部为空，不能凭空产生新批；C 上次成功是 B，故下一次成功必是 A，不能再送 B 把 Φ 降到 0。初值至少 1 排除了开始时就只有最后一粒种子的边界。

## S09　采种单元不断料

判定：**改写**，结论降为无限次开批和循环态共同正批率，不声称原条一般范围已被完整否证。

采种单元不断料：采用修订后的「采种单元的回路存量下界」中的纯传送带采种单元、L1、L2 和 Φ。四台机器从 s 所在的完整步起一直有供电状态且开着；s 是该步的步末。s 时 CA、CB、A 和 B 的存货格及 C 的取货格只有本植物种子；AC、BK、A 和 B 的取货格及 C、K 的存货格只有本植物植株；K 的取货格只有本植物粉末或为空；四个缓存格为空或只有本机本植物配方的一批。若 Φ(s)≥1，且 K 取货格中在 s 已有及以后进入的每件粉末都在有限时间内被下游取走，则 C、A、B、K 都会无限次开批。在所考察后续的任一可到达循环态中，四台机器每 tick 的平均批数相等，为某个 0<r≤1，K 平均每 tick 送出 kr 件粉末，其中荞花 k=2、砂叶 k=3。本条不保证 r=1、缓存每步非空、首运输格腾空当步即补货或任意一刻的各出口份额。结论对接通先后及其离线改变成立；粉末有限时间被取走这个前提也须覆盖所声称的全部离线和停收恢复后续。

据：快照的格容量、整批入格、制造、配方、滞留、每步一次判定、轮询、循环态，以及本报告重新证明的「采种单元的回路存量下界」。

推导：如下完整证明。

### 1. 纯传送带上有出路的物品不会永久不动

对一条有限纯带，如果终点机器最终一直收得下某件头件，则末格物品成熟后在下一次判定即可进入；空位向前传播，有限个运输格中的有关物品都在有限步内通过。元件或机器的同层次序只能影响有限等待，不会使唯一来路永久失去判定。机器 C 的两条出口处于同一级；只要某个首格从某时起一直空，C 又不断有可送种子，它不会被另一个出口永久排挤，因为成功最早的出口先试。

### 2. 四机不可能最终全部停批

假设 C 只开有限批。C 生成种子有限，初始库存和各运输、存取货、缓存容量均有限，A、B 也只能开有限批，K 同样只能开有限批。取它们最后一次开批以后，所有正在制造的批次会在有限时间内完成。

由粉末逐件有限时间清出的前提，K 的取货格最终清空；如果 K 有完成的一批，它也会整批入取货格再被清出。若 K 存货格、BK 或 B 取货格/缓存格还留有植株，沿纯带的有限通过性最终会让 K 再开一批，矛盾。所以这些位置最终都空。若 B 存货格或 CB 还留种子，它会经 B 制成植株而导致 K 再开批，仍矛盾。故 B 侧最终空出，CB 首格最终一直可接收。

C 若仍有取货种子，CB 的这个永久空位使其不能永久留在 C；C 若有已完成缓存，也会在取货格腾出空间后整批进入再清出。因此 C 的取货格、缓存最终空。此时 C 存货若有植株就会再开批，故 C 存货也空。沿 AC、A 取货/缓存、A 存货、CA 逐段反推，任何余下物品最终都会造成 C 再开批；所以这些位置也都必须空。于是最终 Φ=0，与 S08 给出的 Φ≥1/2 矛盾。故 C 无限次开批。

### 3. 其余机器也无限开批；循环态的速率

C 的植株全部来自 A，库存有界，因此 C 无限开批要求 A 无限开批。C 每批产 2 粒种子，而 A 每批只用 1 粒；将 C、A 的植株守恒与全部种子守恒相减，B 累计批数与 C 累计批数之差有界。因此 B 也无限开批。B 的植株只进 K，植株库存有界，所以 K 也无限开批。

若存在一个可达循环态，周期内每种库存回到原值。记周期内批数为 n_C、n_A、n_B、n_K，则逐物品守恒给出 `n_A=n_C`、`2n_C=n_A+n_B`、`n_B=n_K`，故四者相等。第 2 节排除了零批次循环。每台机器的一批至少 8 步，所以共同批率 `0<r≤1`；K 的取货格周期前后相同，粉末出货恰为 `k·n_K`，平均为 kr。

### 4. 原即时证明的明确断点

一台荞花粉碎机 K 的两条首带同一步空出、取货格有足够粉末时，K 当步最多送一件，只能回填一条；另一条至少等下一步。`s08_s09_cycle.py` 的第 1 步保留了这一合法有限转移：两条首带都向一个耗 2 份荞花粉末的研磨机交货，K 只给一条补货。初态可在调试中先使这些格存满，研磨机已有足够砂叶粉末，再开机得到。它不使用无限精度操作挑选某个 tick。

这个例子只显示旧证明把“空了立刻补”用于任意瞬态是不成立的。原条把这段结论放在循环态中；该脚本随后进入的局部 8 步循环两路已错相，所以它**不是原条循环态即时补货结论的反例**。脚本中的砂叶粉末 `Source` 和粉末接收 `Sink` 是局部边界，未给出其完整生产与成品消费布局，也不能作为一张全厂布局证书。

另外，原文“判定全部完成后缓存非空”与步进顺序不一致：正常批次在步首先完成并整批入取货格，新批在判定后才开始，这两个阶段之间缓存可以为空。本报告统一采用完整步末；未仅凭这个语义问题宣布原生产性结论被否证。
