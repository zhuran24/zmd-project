单条混料进路逐件判据：一台只做 a 件原料 A 加 b 件原料 B 这一个配方的机器，两个存货物品格开始时有 x_A 件 A、x_B 件 B、没有别的物品，此后唯一存货通道的全部来料也只含 A、B，送料路上没有分流器。把这条进路的来料（含开始时路上的货）按到达机器前的先后排成 w；对每个前缀 k 记其中 A、B 件数 I_A(k)、I_B(k)，令 m(k)=min(⌊(x_A+I_A(k))/a⌋,⌊(x_B+I_B(k))/b⌋)，r_A(k)=x_A+I_A(k)−a·m(k)，r_B(k)=x_B+I_B(k)−b·m(k)。若每个有下一件的前缀之后，下一件是 A 时 r_A(k)<50、是 B 时 r_B(k)<50；机器一直有供电状态并开着，每批产物都在有限时间内清出，每件可收的头件都在有限时间内送到，则每件来料最终都能进入存货物品格，不会永久互等。离线或仓库停收使料序改变时，须对保留所有未送完物品后实际拼成的料序同样满足上述条件。本条不给批次率。

### S06 整批k件配k条取货通道的均分

#### 按临时规则

**适用范围收窄：固定轮转和差至多1的结论只在不含离线的连续运行段内给出，类型为充分条件。**

临时第4条明确了重建及接通次序的来源，但只明确保留物品，没有明确写出“上次成功”记录是否保留；第7条沿用轮询算法与起点，也没有单列重建对历史记录的处理。最终候选不预设这一点。若只重排接通先后而保留成功历史，快照版的跨离线归纳仍成立；若重建把新通道按从未成功处理，第一轮以后固定的轮转顺序就不能这样沿用。此次对两种情况都安全的最终版本为下方无离线段版本。

完整证明仍是快照S06的七步归纳，应用在该连续段内：所有出口同级；首格是否可收由上次成功距今是否满8步决定；最久未成功者不能收时，较新的也不能收；有货可送时只给队首一条，再排到队尾。因此实际成功顺序是固定循环序，其任何连续子串的计数差至多1。周期重复后每路流量相同。段首允许任何合法建造次序。

历史重置影响的诊断已留档：初始取货格只剩一件、两首格空，先给 A；下一批两件到来时两首格又都空，若把成功记录清空并使 A 先接通，会再次先给 A，成功序开头为 A、A、B。这个诊断只是说明额外的“清空记录”语义会破坏跨离线轮转，不宣称临时文件已经规定必须清空记录，也不作为完整布局反例。

旧逐刻全取反例仍成立：第7步才完成两件产物，机器当步只能送一件。新收货触发代码与独立状态模型在4种排序和18步轨迹上核对相同。

**最终候选条目**

整批k件配k条取货通道的均分：某制造单位的取货物品格只由整批进入，每批恰 k 件同一种物品，k≥2；恰有 k 条取货通道从这个格取这种物品。各通道的首运输物品格只从这个取货物品格收货，空着时总收下这种物品，且各首运输单位都不是汇流器。取一个不含离线的连续运行段；段内某一步开始时，这 k 个首运输物品格全为空，此后段内每个首运输物品格每次收下一件，都恰在 8 步后、该制造单位在那一步判定之前把这件移出。则从该步起至该段结束，实际成功取件的通道按同一个含全部 k 条通道的顺序循环出现，任意连续子时段中任两条通道的取件数相差至多 1；若该段无限延续，则其中可到达循环态的 k 条通道流量相等，各为这个取货格出货量的 1/k。段首的接通先后可以是任意单位建造次序按规则产生的结果。本条不把同一个轮转顺序或计数差界跨离线拼接；离线后须重新找到满足上述前件的起点。

据：第92—94轮规则快照：步、判定、制造、缓存格、滞留、轮询、取货优先级及植物配方；临时规则1—7。

推导：快照版跨离线轮转；临时版不预设重建后成功记录保留，限无离线段。证明见按临时规则S06。

状态：待审。

### S07 植物专机一一配对满库存不断料

#### 按临时规则

**数值结论不变：仍为第0—399步的有限保障，类型为充分条件。** 最终仅将离线措辞改成按单位重建次序派生接通先后。

缓存和取货库存证明只用初始50件原料、8步制造时长、整批入格、每步最多送一件及运输格至少停8步。临时第1、2条不改变这些事实；重建保留物品，不能额外取走初始库存。本条内部进路没有准入口，因此第5条不直接作用于这些进路。下游因准入口少过而反压，只会延后出货；库存下界原本允许任意停取。

首格至多 k_v 次判定回填另给一份不依赖历史记忆的证明。植物配方的 k_v 只有1、2、3。目标首格空着、源机取货库存为正，其他每条通道在这最多3次连续判定中至多成功一次：一旦收到新件，至少要停8步，不能在这个窗口再次腾空抢货。因此至多 k_v−1 次可先送给别路，最迟第 k_v 次必给目标路。这即使每一步都重排或重置取货轮询也成立。程序分别枚举1、4、216种逐步优先次序，最大等待分别为1、2、3次，与独立计数一致。

原同一步补回反例不变：运输判定时库存50拒收，之后开批减为49，下一步才补回。新触发规则下720种排序及400步植物小构型与独立模型一致。相邻桥接器的新层数和收货规则不提供无限期库存证明；本轮不据此扩大50 tick结论。

**最终候选条目**

植物专机一一配对满库存不断料：对同一种植物，取 n 台只做它采种的采种机、2n 台只做它种植的种植机、n 台只做它粉碎的粉碎机。采种机的两条种子进路一一接到全部种植机，种植机的一条植株进路一一接到全部采种机和粉碎机，每台粉碎机有 k 条粉末进路，荞花 k=2、砂叶 k=3。进路只由传送带和方向已定的桥接器的一轴首尾相接，互不争用物品格，这些机器没有别的通道，路上没有物品准入口和协议储存箱；机器一直有供电状态且开着。选定第 0 步开始前的状态：各机存货格有 50 件本机原料，取货格至少有 50−k_v 件本机产物，采种机 k_v=2、种植机 k_v=1、粉碎机 k_v=k；各进路都满、只有该进路该送的物品且已停留至少 1 tick，各取货通道的首运输物品格只从本机收货、空着时总收下本机产物；缓存格为空、正在制造本配方的一批，或放着本配方已经完成的一批。则第 0—399 步的每一步结束后，各机缓存格都不空，各机取货格始终至少有 50−3k_v 件本机产物。在这 400 步内，某条取货通道的首运输物品格空下来后，只要接下来的 k_v 次本机判定仍在这 400 步内，就最迟在其中第 k_v 次判定收到一件本机产物。该结论只保障起始 50 tick，对任意单位建造次序派生的接通先后及临时规则允许的离线重排成立，不保证第 400 步起仍不断料，也不保证开批当步补回原料或进路末端任意时点即时供货。

据：第92—94轮规则快照：步、判定、制造、缓存格、滞留、轮询、取货优先级及植物配方；临时规则1—7。

推导：数值结论同快照；回填改用滞留与k_v≤3计数，允许重排甚至重置轮询记录。见按临时规则S07。

状态：待审。

relation：修订正式条目「植物专机一一配对满库存不断料」。kind：充分条件。

### S08 采种单元的回路存量下界

#### 按临时规则

**强界的时段范围收窄，并新增不依赖轮询记忆的跨离线防耗尽结论，类型为充分条件。**

在不含离线的连续段内，两次向 B 成功之间若没有向 A 成功，A 的成功时间必更早；由此仍能使用快照S08的反压证明，得到 `Φ≥min(Φ(s)−1/2,L1+L2+176)`。纯带每条进路只有一个出路，临时第1条不再让无货元件提前带动其他判定，但成熟首件、满路反推和两个至少8步的区间均不变。没有桥接器和准入口，临时第2、3、5条不作用于这段证明。160个小构型、25600个完整状态在新触发代码与独立整数模型之间一致。

这份强证明比较两次成功的历史，不预设它能跨“全部单位重建”继续使用。最终条文把强界限在无离线段，允许每次离线后选满足前件的新 s。若后续明确保留轮询历史，则原快照版跨离线强界可由同一证明恢复；这里没有先把该保留行为当作规则。

**跨离线的防耗尽证明。** Φ只在 C 向 A、B 送种时分别改变正、负1/2；其他移动、制造、整批入格及保留物品的离线重排都不改Φ。假设Φ(s)≥1以后会降到0。此前必有一次从1降到1/2；这是 C 刚向 CB 送出一粒。降到1/2后的全部回路物品只能是 C 取货格余下的一粒种子：回路中任何其他一件或一批的权重均为1。于是 CA 首格为空，C、A 没有其他原料或缓存能发生制造。

到下一步，CB 首格里刚收到的种子尚未停满8步，仍占着该格；CA 首格仍空，且只会接受 C 的种子。C 有一粒可送、两条出口都要按规则尝试，无论轮询起点是否重置，试 CB 都因满而失败，试 CA 则成功。因此下一步Φ回到1，不能继续送 B 而降到0。若途中离线，物品原样保留，滞留条件不被豁免，同一论证仍适用。每次进入1/2都是这种情况，故以后始终Φ≥1/2。

这不是沿用“上次成功是 B 所以下次必须 A”；承重事实是刚收货的 CB 在下一步仍满。即使额外允许重置轮询记录也成立。80个小构型共12800步，在按真实单位建造次序派生通道时刻并额外清零记录的6318次诊断重建下，两套编码逐态一致，没有跌破1/2。另用只有C初存一株植物、四路全空的启动过程检查临界边界：C在第0步开批，第8步先送B时Φ=1/2，第9步即使再次清零成功记录也只能把余种送A，Φ回到1；两套编码与独立事件算式一致。这一有限启动来自仓库初始植株经调试送入C，不需要定时下游接收器；路长只影响更晚的到达，不影响这两步首格核对。有限核对不代替上面的首次跌破证明。

**最终候选条目**

采种单元的回路存量下界：采种单元由只处理同一种植物的一台采种机 C、两台种植机 A、B 和一台粉碎机 K 组成。C 的取货物品格恰有两条取货通道，分别经 CA、CB 进入 A、B；A 的一条取货通道经 AC 回 C，B 的一条取货通道经 BK 进入 K；除 K 的取货通道外，四台机器没有其他通道。四条进路都只由传送带首尾相接，各路运输物品格只从前一格或起点机器收货、只往后一格或终点机器送货。记 CA、AC 的运输物品格数为 L1、L2。Φ 是 CA 的种子数、A 存货格种子数、A 取货格与 AC 的植株数、C 存货格植株数之和，A、C 缓存格有本机的一批时各加 1，再加 C 取货格种子数的一半。s 取一个完整步的步末，C、A 在该步及此后始终有供电状态且开着；s 时 CA、A 存货格和 C 取货格只有这种植物的种子，AC、A 取货格和 C 存货格只有这种植物的植株，A、C 缓存格为空或只有本机做这种植物的一批。在从 s 起不含离线的连续运行段内，每个步末都有 Φ≥min(Φ(s)−1/2,L1+L2+176)。此外，若 Φ(s)≥1，则允许临时规则规定的任意离线重排、甚至轮询成功记录重新起算，此后每个步末仍有 Φ≥1/2。以上结论不要求 B、K 持续运行，允许 K 下游任意停收与恢复，并适用于任意单位建造次序派生的接通先后。强界不跨离线拼接；离线后满足前件的完整步末可以重新取作 s。

### S09 采种单元不断料

#### 按临时规则

**活性和平均批率结论不变，类型为充分条件。** 最终引用临时S08的跨离线防耗尽结论，不把其强界的“无离线段”限制带入本条。

完整推理如下。Φ(s)≥1保证所有后续Φ≥1/2，此事实刚刚重新证明，不需要离线保留轮询历史。若 C 只开有限批，初始库存有限，A、B、K也只开有限批。所有在制批有限时间内完成；K已有和以后进入取货格的每件粉末有限时间被取走，迫使其完成缓存最终清出。最后一次开批之后，若BK、B取货/缓存、B存货或CB仍有物品，正确物品沿唯一纯带来路有限时间前进，就会使K再开批，矛盾。因此B侧最终空出。

C的取货种子不能永远不动：CB首格此后一直可接收，所以一次有货的C判定至少能向某一出口送走一件；即使它先选CA，也是在清走C取货格。C的已完成缓存随后也会整批清出。若C存货、AC、A取货/缓存、A存货或CA还留任何回路物品，唯一正确来路和有限制造时长会再次触发C开批。于是全部回路空、Φ=0，与防耗尽矛盾。故C无限开批。

C的植株都来自A，有限库存迫使A无限开批；两粒种子的产出、A每批只耗一粒与有界库存迫使B也无限开批；B的植株只能进入K，故K无限开批。周期中逐种库存回原值，仍有 `n_A=n_C`、`2n_C=n_A+n_B`、`n_B=n_K`，共同批率为 `0<r≤1`，K出货为kr。临时重建保留物品，不改变这些收支。

临时第5条可能使含准入口的下游不再满足粉末逐件有限清出的前件。此前件需要覆盖实际后续；它成立时上述证明仍有效，不成立时本条不作活性保证。原缓存处处非空、逐刻即时供货和满速结论仍未得到认证。

**最终候选条目**

采种单元不断料：采用修订后的「采种单元的回路存量下界」中的纯传送带采种单元、L1、L2 和 Φ。四台机器从 s 所在的完整步起一直有供电状态且开着；s 是该步的步末。s 时 CA、CB、A 和 B 的存货格及 C 的取货格只有本植物种子；AC、BK、A 和 B 的取货格及 C、K 的存货格只有本植物植株；K 的取货格只有本植物粉末或为空；四个缓存格为空或只有本机本植物配方的一批。若 Φ(s)≥1，且 K 取货格中在 s 已有及以后进入的每件粉末都在有限时间内被下游取走，则 C、A、B、K 都会无限次开批。在所考察后续的任一可到达循环态中，四台机器每 tick 的平均批数相等，为某个 0<r≤1，K 平均每 tick 送出 kr 件粉末，其中荞花 k=2、砂叶 k=3。本条不保证 r=1、缓存每步非空、首运输格腾空当步即补货或任意一刻的各出口份额。结论对任意单位建造次序派生的接通先后及临时规则允许的离线重排成立；粉末有限时间被取走这个前提也须覆盖所声称的全部离线和停收恢复后续。

据：快照步进、滞留、整批入格、轮询、制造和配方；详见报告；临时规则1—7。

推导：活性结论同快照；改用临时S08不依赖轮询记忆的防耗尽结论，仍覆盖离线。见按临时规则S09。

### S10 专用进路下缓存格不空的传递

#### 按临时规则

**适用进路收窄：最终输入只用纯传送带，附加即时输出的首单位也排除物品准入口，类型为充分条件。**

快照版本允许没有限额的物品准入口，证明在原料格不满时每条路的末格至迟每8步交一件。临时第5条允许满速准入口离线少过、且不给缺量下界，“不设上限”不能排除这种行为，因此该供货下界不能原样移植。这里没有擅自规定少过一件、固定迟一步、恢复时限或丢失物品；仅撤去证明依赖的准入口范围。附加即时输出若首单位是准入口，也不再自动认证其离线时的收发条件。
