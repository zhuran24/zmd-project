# N49、N51 独立文字复审

日期：2026-10-02。状态：完成。审阅对象为本目录 `polling_audit.md` 中的完整证明及修订条文；未发现实质漏洞。该结论依赖修订条文明写的“本单位全部新成待出的物品计入组，起点旧货计首组，其他通道可能送出的物品也计入组”的口径，不能恢复成只计所考察通道最终成功件数的较弱前提。

1. 固定时序的一次运行中，每组最多六件，某组出现后最迟下一步获得本单位的一次判定。只要归纳所证明的下一条首格为空，一次成功无论经所考察通道还是其他通道送出，都会减少该组的一件。因而最迟六步内清掉整组；八步之后的下一组到来前没有旧组挤占判定。这里不以组内全在同一步送出为前提。
2. 第 n−2 组最后一次出货最迟在其组时刻后六步，首格再八步腾空；合计十四步，严格早于第 n 组的十六步边界。因而当前组开始时只需防止绕回上一组的占格区段。上一组实际走所考察通道的件数不超过其全组件数，相邻两组全组件数和不超过 k，正好保证当前组不绕回。这与清组时长互相闭合，不是循环引用尚未证明的服务能力。
3. 其他通道成功不改变所考察 k 条通道之间的相对接通顺序或上次成功的相对先后。运输单位按整个通道表循环时，投影到子集仍保持相对环序；在下一条所考察通道可用的前提下，不会无故跳过它。非运输单位把其他通道的时间戳更新为最新，不改变所考察子集内的相对次序。故允许 k 条只是全部取货通道的子集不破坏归纳。
4. 非运输单位一次判定最多成功一件，已成功通道的上次成功时间不并列；从未成功的通道由规则第 32 行给出的接通先后排在前面。所用顺序只承诺一次固定接通取值下的实际成功历史，不从“首格全空”推出“历史清空”。
5. 均分可直接将完整循环态周期重复多次，再用任意连续成功段件数差至多一件，除以重复次数得到；无须假设绝对上次成功时间戳本身数值周期复原。N51 按成功件数位置作同余计数，不要求各成功事件等间隔，因此组内跨步发送不影响最大公约数公式。

初态反驳原“按接通先后循环”句子使用的是可调试取得的有限运行，不是达标全厂反例；这一证据边界在原报告中已明确。原条目的“均分”子结论与 N51 公式不被该反例否证。本复审没有另增候选。
