# 第99轮 R组独立复核：分叉分支

日期：2026-10-02。状态：复核完成。结论：**未否证**。

| 候选 | 种类 | 结论 | 理由 |
|---|---|---|---|
| 分叉分支 | 必要条件 | 未否证 | 单位重建限制接通先后；同次建成留下的并列处理、规则未定的合法数层选择及其可到达循环态仍须覆盖。两套独立编码复算一致。 |

这里的“未否证”针对候选原文。**同刻通道的“排法”是并列项需要顺序处理时的分支，不是给通道补造不同的接通时刻。** 已确定的层数先后、元件与非运输单位的先后、收货联动和轮询记忆仍须遵守。按这个由前提直接限定的含义，不需要改动候选条文。

## 1. 对象与依据

复核对象是[复核97M](../第95-97轮/复核97M.md)第1节的修正版，即本轮 R 组提交的完整条文；其前身是[推导95M](../第95-97轮/推导95M.md)第1节。没有把两份报告中的结论直接当作证明，也没有读取本轮另一席的报告或脚本。

本次论证实际使用的前提如下：

- [游戏规则快照](前提快照/《明日方舟：终末地》游戏规则.txt)：第9—10行的蓝图与重建，第16行的通道，第23—33行的步进、判定、层数、元件、接通与轮询，以及各单位的尺寸和端口。
- [求解任务快照](前提快照/求解任务.txt)：第2行的目标、第8—13行的零干预、循环态、建造和调试条件。第14行的离线条文由临时规则替换。
- [求解约束快照](前提快照/求解约束.txt)第3—7行：目标不能依赖未定量的有利取值。这里不沿用“任意通道排列都可由离线实现”的旧解释。
- [临时规则](临时规则.md)第1、2、4、7条：收货联动的范围；数层避开绕回自身及桥接器例外；按任意单位次序重建、保留物品；轮询做法和起点按现行规则。其余临时规则没有被用来扩大顺序或数层选择的范围。

已核对必要条件与充分条件快照，但本候选不需要调用其中旧时间模型下的流量、均分或不断料结论。[不补的设定快照](前提快照/不补的设定.txt)只作背景核对，没有把其中的社区数层算法添加为前提。特别是，不用“末端序”的具体实现删去规则仍允许的选支。

复核97M把“同层按最早送货通道判先后”引到规则第29行；本轮快照中正确位置是**第27行**，第29行是元件定义。这是引用位置问题，不影响候选。

## 2. 逐句核对

### 2.1 接通先后必须来自单位建造次序

固定最终摆放、方向和端口，令 `b(U)` 是单位 U 在一次重建中的建成事件序号。通道 e 的两端为 U、V，则其形成事件为

`c(e) = max(b(U), b(V))`。

理由是：先建的一端单独存在时，两端的端口还未相遇；后一端建成时端口相遇，规则第16行立即形成通道，第30行把这次形成事件定为接通。这里的序号只表示建成事件的先后，**不是运行中的步号，也没有假定每建一个单位耗时一步**。

因此，若一次建成的单位碰到几个已建单位，就会有几个通道在同一建成事件形成。它们的 c 相等；不同建成事件之间已有的严格先后必须保留。对全部通道独立作任意全排列，会加入一些单位建造次序根本不能产生的关系。

临时第4条允许离线后的单位建造次序任意改变。因此，对调试期后的保证不能只检查初次蓝图的“传送带最后建”次序。候选对所有单位次序取全称是必要的。反过来，也不能把旧离线条文中“任意两条通道”的说法当作额外公理，越过临时第4条已经给出的单位端点关系。

§4.1—4.2给出了能按端口规则实际摆出的例子，并独立复算了第97轮的数字。

### 2.2 同刻并列不能默认为一种有利顺序

固定一种单位次序后，把 c 相同的通道放在一组。对每组列出各种并列处理顺序，同时保留组与组之间已确定的先后。这种列举不改变任何 c 值。

规则没有给出同次建成的几个通道在需要顺序处理时怎样排列。任取一种不违背已有比较结果的排列，都不能仅凭现有前提将它排除。目标又要求对不得依赖量的各种取值成立，所以证明不能只保留其中有利的一种。第97轮增加的这句覆盖要求成立。

它在实际核验中有以下边界：

1. **判定先后。** 先比较层数，元件判定完才轮到非运输单位；最早送货通道只参与规则第27行规定的比较。还要应用临时第1条的收货联动。通道并列排列不能让不该被带动的机器参加联动，也不能变成任意的元件判定排列。
2. **轮询。** 并列处理需要覆盖各种起点或通道次序，但其后必须按第32行保留成功记录。非运输单位取货侧有自己的“上次成功最早”规则。不能每一步重新挑一个最有利或最不利的起点，也不能每次送货都重置为“第二条”。
3. **取货优先级。** 第33行中一级的接通时刻仍然是其通道实际 c 值的最小值。若两个级的层数与最早 c 都相等，原规则没有给出它们之间的进一步先后，需覆盖未规定的并列处理；不能通过给同刻通道虚加一个时间差，把相等事实改成严格早晚。

例如，§4.3中先建三个下游传送带、最后建分流器时，三个取货通道的实际 c 完全相同。列出它们的各种轮询排列不会使这个相等关系消失。

本候选提出的是必须覆盖的分支要求，**没有声称一个全局通道排列就足以描述所有未定的运行行为**。用“统一按编号”之类未给出的办法，把不同场合的并列处理绑定起来并删去不利情况，也不能从本条得到授权。

### 2.3 建造次序与数层选择之间，不能补一个有利对应办法

规则第28行说，有几个合资格的下游元件时，按哪一个数随接通先后而定、无法确定；它没有给出可据以计算该选择的对应办法。连接关系相同，不代表已知了选支。

这不必解释成“元件每步随意改层数”。即使把未知对应办法视为固定的办法，对一种给定的接通状态，也不能仅凭现有文字断言它必选某支。只要一个完整数法满足规则已经给出的关系，就不能借用一个尚未给出的对应办法删掉这个组合。候选的“不得用规则未给出的……对应办法排除不利组合”准确保留了这一点。

量词中的“每一种数层选择”必须是**整套相容的数法**：

- 合资格下游按规则第28行确定，不能增加一个本来不合资格的元件；
- 确实选择下游 F 来数的元件 E，满足 `L(E)=L(F)+1`；没有该类下游时按规则取层数1；
- 同一个元件的层数在同一次确定中是同一个值，不能把它在几种不同数法下的有利数值拼接；
- 临时第2条禁止的绕回数法不能再当成一种不利分支加入。

推导95M第1节第3步明确作了上述最后一项限制。R版保留“合资格”“临时规则允许的每一种”这些限定，没有把全称扩大到各元件单独选择的任意组合。

### 2.4 有环、避开绕回、仍然未定是不同情况

图中存在一条环，不足以推出层数仍然无法确定。若有符合临时第2条的数法能沿分支离开，就不能以另一个绕回自己的选法排除整个构型。

§4.4的合法局部构型有一个由分流器组成的环，各分流器还可按通往粉碎机的传送带数层。独立枚举得到的合法完整数法确实存在；唯一始终沿环数的逐点组合应删除。候选已经作了这种区分。

同一轴上相邻桥接器的来回通道由临时第2条另作例外，不能套用普通有向环检测直接判为未定。本次没有把这个例外改写成“删掉一条真实通道”，也没有自行规定桥接器数层算法。

若按临时规则处理后层数仍无法确定，前提没有给出可填的有利数值，更没有说这种摆放禁止建造。因此：

- 不能把“未定”当作层数1或其他自行选择的整数来认证运行；
- 不能只因“未定”就认定没有达标布局会采用此构型；
- 要进一步使用它，须证明所要的结论不受未定部分影响，或给出覆盖允许运行的证明。

这不等于已证明这样的构型达标。R版只保留未决构型、拒绝无依据的赋值或排除，没有越过这个边界。

### 2.5 覆盖的是由合法历史到达的循环态

固定一种实际可操作的调试办法。取它结束时可能出现的状态，继续应用步进规则以及临时规则允许的离线变化。每次离线改变的是按单位次序导出的接通关系，物品按临时第4条原样保留。此前已经形成的库存、堵塞和物品位置不能因为换了一种次序，就自行换成另一个有利起态。

对任何这样的合法运行历史，只要到达仓库可以接受两种成品的循环态，任务目标就要求该循环态达标。如果漏掉一种允许的次序、并列处理或相容数法，便没有核验该分支下可能到达的循环态。因此候选的全称覆盖是达标认证的必要要求。

反方向不成立：在放宽模型中发现一个坏环，若不能从允许的调试后状态经合法历史到达，不能用它排除布局。候选写的是“由此到达的循环态”，没有要求所有抽象状态、所有抽象周期都达标。也不能对每个固定次序各自重新调试一次，就声称已覆盖一次调试后的全部离线历史。

由此，候选没有把“放宽模型可行”当作达标，也没有把“放宽模型失败”自动当作必要条件反例。

## 3. 与原版的差别是否必要

| 差别 | 复核结论 |
|---|---|
| 正式“分流器分叉、阻尼按哪支计”改为元件与层数 | 规则第28行针对元件，不仅针对分流器。使用现行术语并保留合资格限制是必要的。 |
| 旧“任意通道先后”改为单位建造次序导出的先后 | 临时第4条已经改变离线前提，必须保留单位端点所带来的关系，不能继续取全部通道全排列。 |
| 第95轮补明“每种单位次序下的每种允许数法” | 保留了原版不得依赖有利选支的要求，又避免补入未给出的对应办法。 |
| 第97轮补明同次建成的并列处理 | 有用且正确的显式补全，避免实现中只保存一种并列顺序。没有创造额外的物理接通时间差。 |
| 绕回限制及相邻桥接器例外 | 直接来自临时第2条，不能恢复旧的“图中有环便一律未定”。 |
| 层数仍未定时既不填值、也不只据此排除 | 原版仍成立的证明边界被保留，没有借“未定”丢掉可能的最优构型。 |

第97轮称第95轮“丢掉”同刻排法，准确说是**条文容易使实现漏掉这些分支**。若第95轮的“接通先后”本来就保存了完整并列关系，并覆盖所有未规定的并列处理，它没有必然丢支。第97轮新增一句消除了这处省略；不需要把第95轮解释成必然错误，才能认可R版。

## 4. 从零复算与否证尝试

### 4.1 三个单位两两有通道，确实能按规则摆出

三个单位可以如下摆放。坐标以左下角格为起点，x向右、y向上。

| 名字 | 单位与位置 | 存货边 | 取货边 |
|---|---|---|---|
| A | 粉碎机，左下角(20,20)，占3×3 | 西 | 东 |
| B | 分流器，(23,20) | 西 | 东、北、南 |
| C | 汇流器，(23,21) | 西、北、南 | 东 |

实际通道恰为 `A→B、A→C、B→C`。粉碎机东边两个相邻端口分别对着 B、C，B 的北取货端口对着 C 的南存货端口。机身不重叠，也没有非运输单位之间直接形成通道的问题。

全部单位都不是传送带，初次蓝图也没有额外的“带最后建”限制。两套编码分别从格与端口、矩形边线段求通道，再独立列举建造次序，结果为：

- 单位次序共6种，全部出现同次建成的并列通道；每种非空接通批的大小均为1、2。
- 固定一种单位次序，并列两条通道有2种顺序，合计12个“单位次序、并列顺序”组合。
- 合并相同的通道顺序后共有6种，没有严格先后无并列的建造次序。

这复算支持第97轮的三角形数字，并补上了它的端口摆放见证。它只证明接通关系的现象，不是达标全厂。

### 4.2 四边形：通道的全部排列不能任意实现

用四个分流器摆成一个小方块：A在(30,30)，B在(31,30)，C在(30,31)，D在(31,31)。A、B、C、D的存货边依次为北、西、东、南，其余边为取货边。通道恰为

`A→B→D→C→A`。

下面用两端名字标记通道，不用名字的字母顺序表示运输方向。独立复算结果：

| 项目 | 结果 |
|---|---:|
| 单位建造次序 | 24 |
| 出现同次建成并列的单位次序 | 24 |
| 接通批大小为1、1、2的单位次序 | 16 |
| 接通批大小为2、2的单位次序 | 8 |
| “单位次序、并列顺序”组合 | 64 |
| 去重后的通道顺序 | 16 |
| 全部24种通道排列中未出现者 | 8 |

未出现的排列恰是：前两条为不相邻的一对通道，后两条为另一对。例如 `AB、CD、AC、BD` 不可能是与建成事件相容的顺序。

不用枚举也可证明这个例子：AB已经形成后，若AC、BD都还没形成，则C、D都还没建成。此后C、D中先建的一个，会先形成AC或BD；等后一个建成才可能形成CD。于是不能让CD排在AC、BD之前。同次建成的并列处理也救不了这个严格的较早建成事件。

这个局部环的数层问题不用于流量或达标证明。它作为合法的单位与端口摆放，已足够否定“单位建造可产生任意通道排列”这个扩大解释。两套编码核出了第97轮所列8种缺失排列的全部清单，保存在结果文件中。

### 4.3 同刻排列可能影响实际的第一件送往哪里

分流器 A在(10,10)，西边存货；三个传送带 B、C、D分别在(11,10)、(10,11)、(10,9)，各自存货边朝A、取货边背向A。先建B、C、D，再建A，则AB、AC、AD的 c相等。

让A首次收到一件源矿并停留满1 tick，而三个下游传送带仍空着。这个状态有规则内的准备办法：在左边界放一个覆盖(0,9)—(0,11)的仓库取货口，端口朝东，用第1—9列、行10的连续传送带接到A西边。取货口从开始就设为仓库里为空的高容谷地电池，所列运输单位初始为空，因此A尚未收到物品，也没有成功送货记录；在B、C、D已建成后，于调试期重建A，随后把取货口改设为源矿。第一件沿传送带到达A之前，下游三带没有别的来源，必为空。此准备不要求玩家卡准某一步，也不依赖“重建会清除已有轮询记录”这个未给出的断言。含取货口与来路的通道也由两套几何编码逐项核对。

物品不返回刚离开的单位；AB、AC、AD都不是它的来路。第一次轮询从第二条通道开始，因此6种并列顺序的首件去向分别覆盖全部三个下游，每个下游出现2次。编码A按逐次尝试搬运这件源矿求首件去向，编码B按通道名次直接求第二条，逐项相同。

这个例子证明遗漏并列排列可能遗漏不同的合法局部后续。没有将一次不同的移动夸大成全厂产率不同，也没有将它称为R版的反例。

### 4.4 环上有出口：不能把所有逐点选支都当成允许数法

在§4.2的四个分流器外，各添一段只有一格的传送带，分别直接送入一台粉碎机：

| 对应分流器 | 传送带位置与方向 | 粉碎机左下角与存货边 |
|---|---|---|
| A | (30,29)，向南 | (29,26)，北 |
| B | (32,30)，向东 | (33,29)，西 |
| C | (29,31)，向西 | (26,30)，东 |
| D | (31,32)，向北 | (30,33)，南 |

粉碎机取货边均为对边。两套几何编码确认没有机身重叠，通道正是环上的通道以及各条出口进路；四段传送带都直接向非运输单位送货，层数为1。

每个分流器可以按环上的下一个分流器数，或按自己的出口带数。结果如下：

- 逐点选择总共16种；全都选环内下一个的1种绕回自身，应删除。
- 其余15种是相容的无绕回数法，得到15个不同的完整层数向量；四个分流器的层数落在2—5之间。
- 编码A枚举选支并沿选定边递归求层数；编码B从整数层数向量出发，直接检查每台满足“层数为2，或比环上下一个大1”，不读取A的选择记录。完整向量集合相同。

这同时检查了两个容易产生假反例的错误：看到连接图有环就把全部数法丢掉；或保留各元件的所有单独取值，再拼成不相容的向量。R版的“临时规则允许的每一种数层选择”不包括这两种错误。

若去掉全部出口，沿普通分流器环强行写有限层数等式，相加会得到 `ΣL=ΣL+4`，不可能。这说明不能给这个未定处填入有限层数以冒充按该环数出的值；没有证明这种摆放被规则禁止，也没有给桥接器的特殊往返套用此等式。

| 几何和通道 | 逐格占用、相邻端口匹配 | 矩形互斥、相向端口线段相交 | 上述全部构型的有向通道逐项相同 |

| 分流器首件去向 | 顺序尝试，把一件源矿移入第一个空格 | 通道名次中寻找第二条 | 6项逐项相同 |
| 环上数层 | 选支枚举与递归 | 有限整数方程枚举 | 15个完整向量逐项相同 |

此外，两套接通编码对1—4个标号顶点的全部75个简单无向图逐图核对，结果一致。这是有限算法交叉检查；没有声称这些抽象图全部可以在基地摆出，也没有从这个有限检查外推任意规模布局的结论。任意规模的接通公式由§2.1直接证明。
