## 3. 五类矿物的切线收支

### 3.1 几何及原矿来源

格坐标为0…69。宽21、高53、左下角(49,b)的空矩形占列49…69、行b…b+52。其下侧剩余条带在行0…b−1，第0行是仓库取货口，所以可过货的切线只有行1…b−1，共b−1行。

每边的唯一空格坐标为0、3、…、69，23个取货口按3格铺排。左、下边至少一边空出角格，故有47种共同排列。逐格铺排后，每一种的下边取货端口在列49…69内都恰有7个；每个满速，合计7件原矿/tick。端口设为哪种原矿不影响合计数。

第0行唯一空格不能承担循环正流量：它左右是取货口的无端口短边，下面是基地外，最多只与上方一个单位有通道；物品不能移回刚离开的单位，无法经这个格持续转运。因此切线第0行不提供额外容量。制造单位也不能占第0行，因为其宽至少3，无法塞入这个单格。

### 3.2 按配方计件，完整机器的净作用

令K为五种物品的集合：蓝铁矿、源矿、蓝铁块、蓝铁粉末、源石粉末。每件都只算1，不按矿石当量加权。

| 单位、配方 | 一批对K的净减少 | 每台每tick最多收到的K件数κ |
|---|---:|---:|
| 粉碎机：源矿、蓝铁块配方 | 0 | 1 |
| 精炼炉：蓝铁矿、蓝铁粉末配方 | 0 | 1 |
| 研磨机：致密蓝铁粉末、致密源石粉末配方 | 2 | 2 |
| 其余制造配方 | 0 | 相应单位为0；粉碎机、精炼炉、研磨机仍取以上安全上界 |
| 协议核心 | 不收K；可能另提供原矿 | 0 |
| 供电桩 | 不收物品 | 0 |

循环态中库存净变化为零；误料不能被当成长期吸收项。因而完整位于条带内的机器，对K的总净减少恰为2G。协议核心即使完整位于条带内，也只增加原矿来源，不减少本条的7件下界。面积1113无协议储存箱，无无线转移的漏项。

### 3.3 跨线机身怎样收费

把条带内的运输单位和完整机器归入一组，跨过x=48.5的整台非运输单位归到组外。这样，组内收支没有把机器库存切成虚构的两半。

一台跨线单位占h行切线，这h行不能再同时放运输格形成跨线通道；组内K可以从该单位位于条带一侧的任何端口进入该单位，但合计最多κ件/tick。κ来自真实配方及制造频率，不是端口数。不同跨线单位的行区间互不重叠，因为它们都占第48、49列。

其余切线行每行至多形成一条向外通道，每tick至多送1件。桥接器在这条竖切线处只使用横轴，纵轴不重复计为向左出口。分流、汇流、混料只会分配这份实际通过量。

周期K收支给出：

`7 ≤ 完整研磨机净消耗 + 跨线通道外送 + 跨线单位接收`

`≤ 2G + (b−1−Σh) + Σκ = b−1+2G−D`。

来自主区的K或跨线机器送回条带的K，只会增加需处理的件数，舍去它们是放宽。没有假定条带里的机器专做原矿、按最短路运输或某端口独占满速。

小制造单位h=3，κ至多1；中制造单位h=5，κ=0；研磨机h为4或6、κ=2；其他大制造单位κ=0；核心h=9、κ=0；桩h=2、κ=0。因此h−κ都至少为2。结合G≤N得到第1节的整数台数条件。

## 4. 排除(49,6)及转置

这时条带可用行是1…5。

研磨机若取4×6朝向，机身高度6，放不下。取6×4朝向时，两条长边是输入、输出边；机身只能在行1…4或2…5，前者有一条端口边正对第0行，后者有一条端口边正对空矩形。两种都没有正流量的输入或输出。逐个枚举所有位置、两种端口方向及47种边带排列，完整研磨机域为空。

因此G=0，而D≥0。必要条件成为`7≤5−D≤5`，差2件/tick。跨线机身减少容量，不能修复这个缺口。该结论没有固定机器位置、矿石种类、核心位置或桩数。

横纵坐标互换后，(6,49)同样排除。两处的P=10、11、12全部排除。

## 5. 七格条带迫出的形状

本节假定(49,7)存在达标布局，随后第6节给出矛盾。这里可用行是1…6。

### 5.1 完整大制造单位只有一种机身摆法

4×6朝向必须占行1…6；任意连续4列的第1行都含一个必需的原矿运输格，所以机身不能放下。6×4朝向要同时有输入和输出，只能占行2…5，端口邻格分别位于第1、6行。完整大制造单位都具有这一机身形状。

它下面的第1行是一段长6、高1的运输走廊，下面为仓库取货口，上面为该机身；不能从上下绕出，只能经左右两个端部与外部交换物品。

一个端部双向实际流量之和至多1件/tick。普通运输物品格一格上限1，滞留至少1 tick；桥接器在此只用横轴。又因不能移回刚离开的单位，同一次占格不能既从该端部进来又立刻经同一端部出去，因此不能把相反方向各算1而得到2。端部若接非运输单位，该端口方向固定，也不增加容量。两端总共至多2件/tick。

### 5.2 下侧原矿挤占走廊，唯一例外来自边带空格

记机身6列内的下边原矿端口数为m，逐格计数只能为1或2。这些原矿都不能进入大制造单位的配方，必须从走廊两端离开。

- 输入边朝下：若该机实际输入总量为I，则`m+I≤2`。
- 输出边朝下：若该机实际输出总量为O，则`m+O≤2`。

同一周期内，每台研磨机至少做1/2批/tick，因为其他31台至多做31而全厂需要31.5；每台封装机恰做1/5批/tick；每台灌装机至少做3/20批/tick，因为另外两台至多做2/5而全厂需要11/20。对应最低输入总量分别为3/2、5、3件/tick，最低输出量分别为1/2、1/5、3/20件/tick。

m=2时，任意正输入或正输出都超过走廊容量。m=1时，输入朝下也因最低输入量大于1而不可能。所以有正制造量的大机必须m=1且输出朝下。

设下边唯一空格坐标为g。长6区间只有一个原矿端口时，机身左端只能为g−4或g−1；两种区间重叠3列，不能放两台。故条带至多一台完整大制造单位。矿物切线要求`2G≥1+D`，所以必须有一台完整研磨机；它就是条带内唯一的大制造单位，且`1/2≤G≤总批次率≤1`。

再由`D≤2G−1≤1`和每个跨线单位亏额至少2，得到**没有任何跨线制造单位、协议核心或供电桩**。入口切线因而确实是6条物理边，跨线总件数可用6作为上界。

所有仍可能的空格与机身起点如下；表中每种均要求左边界空格为角格。

| 下边空格g | 研磨机左端x；机身行固定2…5 |
|---:|---|
| 51 | 50 |
| 54 | 50、53 |
| 57 | 53、56 |
| 60 | 56、59 |
| 63 | 59、62 |
| 66 | 62 |

六种边带、十个起点组合是形状必要域，不是十个可行布局。

### 5.3 制造机身都经过同一行

第1行连续没有原矿运输格的长度通常至多2，唯一长3的区间是g−1…g+1。上述研磨机无论取哪个起点，都占了这个区间的第2…5行。小制造单位若想占第1行，必须把3格宽机身放在这个唯一空隙，随后与研磨机重叠。因此其他制造单位都从第2行或更高处开始。

小制造单位高度3，起始行只能为2、3、4；中制造单位高度5，只能从第2行开始。它们和研磨机都经过第4行。机身不能重叠，故有：

`6 + 3(n粉碎+n精炼+n配件+n塑形) + 5(n种植+n采种) ≤21`。

供电桩、运输格或空格占第4行只会收紧此式，放宽模型不扣这些占格。协议核心高度9，不能放入条带；封装机、灌装机已被唯一大机结论排除。

## 6. 七格条带的全物料切线

### 6.1 允许两侧重新分配生产

把条带内每种配方的平均批次率记为r，六种其他机型的整数台数记为n。每台机器可以在允许的配方间混做；主区提供或接收任何缺余物品，不固定上游配对。

研磨机总批次率在[1/2,1]，两种矿物研磨批次率G至少1/2。粉碎机、精炼炉、配件机、种植机、采种机均受现行「满载配置」约束，同一机型的条带批次率之和等于该机型台数。塑形机在全厂只有半批/tick余量，故其条带批次率在`[max(0,n塑形−1/2),n塑形]`。

各配方不能超过全厂所需批次率，按规则顺序为：

| 机型 | 配方平均批次率上限 |
|---|---|
| 粉碎机 | 源矿18、蓝铁块34、荞花11/2、砂叶21/2 |
| 精炼炉 | 蓝铁矿34、致密蓝铁粉末17、蓝铁粉末回炼0 |
| 研磨机 | 致密蓝铁粉末17、致密源石粉末9、细磨荞花粉末11/2 |
| 塑形机、配件机 | 11/2、6 |
| 种植机 | 荞花11、砂叶21 |
| 采种机 | 荞花11/2、砂叶21/2 |

这些上限来自目标恰产率、非成品零入库与机型下限；精炼炉已有34+17=51批填满，故回炼为0。条带没有封装机、灌装机，其批次为0。没有额外加入专机、纯料或整数批次率假设。

令z为7个原矿入口中的蓝铁矿入口数，另有7−z个源矿入口。精确证书把z进一步放宽成[0,7]中的连续数，包含全部整数配置。

对19种物品逐种定义：

`v_i = 条带仓库取货口供给_i + Σ_r(配方r每批产出_i−每批用量_i)r`。

周期库存不变给出`实际外送_i−实际送入_i=v_i`，因此实际跨线总量至少为`Σ_i |v_i|`。各物流支路如何混料、分流、汇流，不改变这个下界。入口线没有跨线机身，六条物理边每条的双向总量至多1，故达标布局必须满足：

`Σ_i |v_i| ≤6`。

### 6.2 精确最小值及证书

对满足第5.3节机身宽度条件的六元整数台数，一共215种，全部枚举。每种台数用变量t_i≥v_i、t_i≥−v_i，最小化Σt_i；这是包含真实布局平均流量的连续放宽。结果为：

**所有215种的最小值都至少19/3，其中一支恰为19/3。**

达到这个数的一个放宽点是：条带有3台粉碎机、1台研磨机；7个入口全为源矿；粉碎机每tick做8/3批源矿、1/3批砂叶，研磨机做1批致密源石粉末。需向外送13/3源矿、2/3源石粉末、1致密源石粉末，向内送1/3砂叶，合计19/3。这个点只证明放宽目标可取到该值，不是布局、接法或循环态反例。

证明下界不依赖浮点容差。对每一支，存档其原始点x及对偶乘子。把不等式写成Ax≤b、等式写成Ex=d、变量界0≤x≤u，检查：

`y≤0，l≥0，v≤0，c=Aᵀy+Eᵀe+l+v`，

`下界=bᵀy+dᵀe+uᵀv`。

无上界变量的对应v必须为0。独立核验器使用Fraction逐项检查全部等式、符号、原始可行性、目标相等，以及215支不重不漏；每个下界都至少19/3。核验器不调用数值求解器。证书证明的是必要条件放宽本身的下界，求解器的“Optimal”状态只作数值对照。

最后`19/3>6`，至少缺1/3件/tick，故(49,7)不可能。坐标互换后所有单位尺寸及端口方向仍属允许旋转，左、下边带条件互换，得到(7,49)同样不可能。两处的P=10、11、12全部排除。

对未排除位置，最后两式是本轮入口切线的完整参数差额。G=D=0时分别尚余1、9件/tick；这些是收支模型的基准值，不表示有对应完整布局。一般情形必须随机器摆法重算G、D：b=9要求跨线单位数U≤完整研磨机数N；b=17要求U≤N+4，能作为几何搜索的局部必要条件。

对上侧条带，入口高度依次为11、10、8、0。那里没有边界仓库取货口；仅凭原矿入口计数不能强迫正跨线下界。没有把全厂各机型台数按面积比例摊进两条带。位于上条带的核心或机器会改变其来源、消耗和出入量，必须在完整摆位模型中重新核算。

本轮没有求得剩余四处在全部摆位、供电与19种物料共同约束下的最紧切线差额。阻点很具体：b=9、17允许更多完整研磨机和不同高度的机身，不能复用七格条带的“唯一大机、同过第4行”论证；目前没有覆盖全部这些摆法的联合下界证书。上表给出已证明的差额公式，不将未完成的联合优化写成通过或不可行。
