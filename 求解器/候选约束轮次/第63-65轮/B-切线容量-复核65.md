## 2. 候选一：窄条矿物切线

**结论：修正。** 数学收支未否证，但原条文对 D 的单位集合缺少纵坐标限制。

### 2.1 D 的范围为什么必须补全

推导报告第 1 节写的是“对同时占第48、49列的制造单位、协议核心和供电桩……令D=Σ(h−κ)”。这句话按字面包括空矩形上方的单位；第 3 节真正计算的却只是 x=48.5、行 1…b−1 的有限切线。一个单位只有占了这段切线的行，才扣它的 h。

例如 b=9 时，空矩形占列 49…69、行 9…61。在 (48,63) 放一个 2×2 供电桩，其占格是列 48、49 和行 63、64，不碰空矩形或取货口，位置来自规则允许的普通建造。它会被原文“同时占第48、49列”计入 D，贡献 2；它占下侧切线的行数却是 0。程序逐格核对了这两个事实。这里的供电桩不涉及物品接法。

这个局部占格例子**不是一个达标全厂反例**，没有声称它能扩成满足全部 72 条约束的布局；它说明的是原定义会向下侧切线多扣上侧单位，原证明没有支持这种扣法。故结论取“修正”，不取“已否证”。若按报告上下文把“跨线”理解为仅穿过这段有限切线，则下列修正就是把这个必要范围写进条文本身。b=17 的空矩形贴上边界，没有上侧条带，仍统一采用同一定义。

### 2.2 修正版条文全文

> 窄条矿物切线：以左下角格为(0,0)，面积1113的空矩形宽21、高53且左下角为(49,b)时，令S为列49…69、行1…b−1的条带。在任一可到达循环态中，G为机身完整位于S内的研磨机平均每tick进行致密蓝铁粉末、致密源石粉末两种配方的批数之和。D仅对机身同时占第48、49列且全部位于行1…b−1内的制造单位、协议核心、供电桩求和：D=Σ(h−κ)，h为单位高度，粉碎机、精炼炉κ=1，研磨机κ=2，其余κ=0。必须有7≤b−1+2G−D。若机身完整位于S内的研磨机共N台、计入D的单位共U个，则还有D≤b−8+2N、U≤N+⌊(b−8)/2⌋。横纵坐标互换、行列及下侧和左侧相应对换时同理。

依据保持原候选所列正式条目；D 中的 κ 是循环平均接收上界，不是对每一个 tick 的收件数作限制。机器能用存货物品格缓冲，不能把平均上界误写成禁止短时成批收件。

### 2.3 七件来源、零行及桥接器的核对

一条长 70 的边放 23 个长 3 的仓库取货口，唯一空格坐标为 0、3、…、69。左、下边至少一边空出共同角格，所以联合排列数是 24+24−1=47。程序从每个空格两侧重新铺排，47 种中下边取货端口落在列 49…69 的数量**全部恰为 7**。取货口配置使这些口全部满速，原矿种类不影响总件数。

第 0 行的取货口只有朝内长边的中间取货端口，没有接收条带物品的存货端口。其唯一空格左右是取货口无端口的短边，下方是基地外，最多与上方一个单位形成通道；不能移回刚离开的单位使这个格无法持续周转。即使预装物品或用物品准入口作一次性放行，也不能在周期库存不变时提供正的长期跨线流量。因此第 0 行没有额外出口，切线只有 b−1 行。

一条竖切线只穿过桥接器横向物品格，纵向物品格不能在桥内转成横向。对同一物理边，若一端为普通运输单位，其端口方向固定；若两端都是桥接器，同一次横向物品格占用不能既从该边进入、又向刚离开的单位退回。因此把两个方向的移动都记在一端的横向物品格访问上，每次访问至多记一次，滞留至少 1 tick、格内上限 1 使双向总流量也至多 1 件/tick。若一端是非运输单位，该端口方向固定，另一端运输格给出相同上界。

### 2.4 五类物品及跨线机身收支

把蓝铁矿、源矿、蓝铁块、蓝铁粉末、源石粉末组成集合 K，按件数计。程序从 18 条配方独立得出：

| 单位 | 每批对 K 的净减少 | 每台接收 K 的循环平均上界 κ |
|---|---:|---:|
| 粉碎机 | 所有配方均为 0 | 1 |
| 精炼炉 | 所有配方均为 0 | 1 |
| 研磨机 | 两种矿物研磨配方为 2；荞花配方为 0 | 2 |
| 其余制造单位 | 0 | 0 |
| 协议核心、供电桩 | 不吸收 K | 0 |

矿物配方用料率给出 κ；逐机库存守恒使存货接收率等于用料率。误料在循环态中不能被持续吸收，协议核心不能接收含矿物品，无协议储存箱也排除了无线出路。

将 S 内运输单位和完整非运输单位归入一组，穿过下侧切线的非运输单位整台归到组外，不拆分机器库存。它们全高位于行 1…b−1：否则其第 49 列占格会撞上空矩形或边界取货口。不同跨线单位的行区间不重叠。

组内完整研磨机净消耗 K 为 2G。跨线单位接收来自组内的 K 合计至多 Σκ，剩余 b−1−Σh 行的通道外送至多同样多件。来自主区、核心出库或跨线机器送入组内的 K 是额外来源，舍去这些来源只会放宽必要条件。所以

`7 ≤ 2G + (b−1−Σh) + Σκ = b−1+2G−D`。

独立列举尺寸：小制造单位 h−κ≥3−1=2，中制造单位为 5，研磨机为 4−2=2 或 6−2=4，封装机和灌装机为 4 或 6，协议核心为 9，供电桩为 2。于是 D≥2U；又 G≤N，得到 D≤b−8+2N 以及 U≤N+⌊(b−8)/2⌋。这些步骤不要求物品专线、最短路、固定供需配对或特定判定次序。

## 3. 候选二：1113位置（切线修正）

**结论：未否证。** 条文不需改变；证明中使用第 2 节已经明确范围的 D。修正 D 不削弱下列四处排除。

### 3.1 (49,6) 与 (6,49)

b=6 时完整机身只能使用行 1…5。研磨机的 4×6 朝向高度 6，放不下。6×4 朝向只能占行 1…4 或 2…5，两条长边分别用于存货和取货；前者一边面对第 0 行，后者一边面对空矩形，至少一边无法获得正的循环通过量。第 0 行孤立空格也不能弥补。

故完整研磨机的矿物研磨率 G=0。切线条件成为 7≤5−D≤5，至少缺 2 件/tick；跨线机器即使有接收量，其 h−κ 仍非负，不能补上缺额。程序对 47 种边带、所有完整大机左下角和四种端口朝向复算，b=6 的有正制造量大机必要域为空。

坐标互换保留规则允许的旋转、左下边取货口及尺寸，得到 (6,49) 同样排除。这里没有使用 P 的具体值，故两处 P=10、11、12 均排除。

### 3.2 b=7 的机身域与下侧走廊

行 1…6 中，4×6 大机必须占行 1…6，但任意连续 4 列的第 1 行都有必需的原矿运输格，机身不能占它。6×4 大机只有占行 2…5 才能使两条端口边都有正流量邻格。

这台机器下方行 1 是长 6、宽 1 的运输走廊。第 0 行无下方出口，第 2 行是机身，左右各一个端部；每端双向总量至多 1，合计至多 2 件/tick。其下有 m=1 或 2 个满速原矿取货端口。三种大机均不能消费原矿，原矿误入也不能作为循环出路，所以这些 m 件必须离开两端。

独立由全厂配方收支和机型下限重算，每台研磨机、封装机、灌装机最低批次率分别为 1/2、1/5、3/20；最低输入总量分别为 3/2、5、3，最低输出总量分别为 1/2、1/5、3/20。若端口边朝下为存货边，原矿外流 m 与物料输入 I 必须满足 m+I≤2，三种大机的最低 I 都使此式不成立。若朝下为取货边，则 m+O≤2；O>0 排除 m=2。所以所有完整大机均须 m=1、输出朝下。

独立枚举留下的必要域如下，所有情形左边空格都在角格，机身行均为 2…5：

| 下边唯一空格 g | 大机左端 x |
|---:|---|
| 51 | 50 |
| 54 | 50、53 |
| 57 | 53、56 |
| 60 | 56、59 |
| 63 | 59、62 |
| 66 | 62 |

共 6 种边带、10 个起点组合。一般形式为 x=g−4 或 g−1，再与 49≤x≤64 相交。两个机身相互重叠，所以条带至多一台完整大机。矿物切线又要求 2G≥1+D，迫使它是研磨机，并有 G≥1/2。单台批次率至多 1，故 D≤2G−1≤1；每台跨线单位贡献至少 2，所以**没有穿过下侧切线的制造单位、协议核心或供电桩**。

这里不推出上侧条带也没有跨第 48、49 列的单位；这正是候选一需要明确 D 范围的原因。

### 3.3 第4行及215种整数台数组合

第 1 行不被原矿运输格占据的连续空隙，通常最长 2 格，唯一可能达到 3 格的区间是 g−1…g+1。研磨机的两种起点都覆盖该区间的第 2…5 行。任何小制造单位若占第 1 行，必须放入这唯一的 3 格空隙，随后会撞上研磨机。因此其起始行只能是 2、3、4，机身全经过第 4 行。中制造单位高 5，避开第 1 行后只能占行 2…6，也经过第 4 行。协议核心高 9，条带放不下；其他大机已排除。

程序对上述 10 个组合重新枚举其他机型的全部机身位置，甚至放宽端口是否畅通，仍全部经过第 4 行。故必有

`6+3(n粉碎+n精炼+n配件+n塑形)+5(n种植+n采种)≤21`。

设四种小机总数为 s、两种中机总数为 m，3s+5m≤15。按 m=0、1、2、3 分别有 126、70、15、4 种六元整数台数，共 **215** 种。供电桩、运输格和额外空格占用第 4 行只会减少可用宽度，因此省略它们保持模型为必要条件的放宽。

### 3.4 全厂配方与条带内批次范围

目标与 52 口满速供矿固定成品率，非成品零入库及周期库存守恒固定后续收支。精炼炉最低 34 批原矿精炼加 17 批致密粉末精炼已填满 51 台，蓝铁粉末回炼率只能为 0。独立有理数消元得到下表；它给出条带每条配方的非负批次率上界。

| 机型 | 配方按正式规则顺序的全厂批次率（批/tick） |
|---|---|
| 粉碎机 | 18、34、11/2、21/2 |
| 精炼炉 | 34、17、0 |
| 研磨机 | 17、9、11/2 |
| 塑形机 | 11/2 |
| 配件机 | 6 |
| 种植机 | 11、21 |
| 采种机 | 11/2、21/2 |
| 封装机 | 3/5 |

乘配方耗时后重新计算台数下限，合计 217 台、面积 3291。条带内粉碎机、精炼炉、配件机、种植机、采种机批次率之和分别等于各自整数台数；塑形机批次率在 [max(0,n塑形−1/2),n塑形]；研磨机总批次率在 [1/2,1] 且 G≥1/2。条带内封装、灌装批次率为 0。模型允许配方混做、平均率为分数，也允许任意物料从主区补入或送出。

### 3.5 全物料跨线下界和精确证书

令 z 是条带七个取货口中的蓝铁矿口数，实际为 0…7 的整数；模型放宽为 0≤z≤7 的实数。对全部 19 种物品定义

`v_i=条带取货口供给_i+Σ_r(该配方每批产出_i−用量_i)r`。

周期库存守恒给出外送_i−送入_i=v_i，所以实际双向跨线总件数至少为 Σ|v_i|。下侧切线已无跨线机身，只有六条物理边，每边双向合计至多 1；因此达标布局必须满足 Σ|v_i|≤6。

独立模型以 t_i≥v_i、t_i≥−v_i 最小化 Σt_i，共 38 个变量、43 个不等式和 5 个等式。18 个配方变量、1 个矿口变量及 19 个绝对值变量均有明确含义。逐一求解所有 215 种整数台数后，把数值原始点、对偶乘子转为有理数，并逐项验证：

`Ax≤b，Ex=d，0≤x≤u`；

`y≤0，l≥0，w≤0，c=Aᵀy+Eᵀe+l+w`；

`cᵀx=bᵀy+dᵀe+uᵀw`。

无上界变量的对应 w 必须为 0。只有上述精确分数等式全部通过才接受证书；浮点最优状态本身不作证明。

核验结果：原推导的 215 份证书全部通过，独立生成的 215 份证书也全部通过；分支无重复、无遗漏，独立重建矩阵与存档矩阵一致。所有分支下界均至少 **19/3**，其中 **6 支**取到 19/3。按（粉碎、精炼、配件、塑形、种植、采种）顺序，这六支为 (3,0,0,0,0,0)、(3,1,0,0,0,0)、(3,2,0,0,0,0)、(4,0,0,0,0,0)、(4,1,0,0,0,0)、(5,0,0,0,0,0)。推导报告“其中一支恰为19/3”是存在性陈述，不影响结论。

其中一支的放宽取值为：七口全源矿，三台粉碎机合计做 8/3 批源矿和 1/3 批砂叶，研磨机做 1 批致密源石粉末。净外送源矿 13/3、源石粉末 2/3、致密源石粉末 1；净送入砂叶 1/3；合计 19/3。这个点核实放宽最小值能取到，**不宣称存在对应接法、机身布局或循环态**。

由于 19/3−6=1/3>0，(49,7) 不可能。转置得到 (7,49) 不可能。整个证明不依赖 P=10、11、12 中的选择，所以这些分支全部排除。

## 4. 否证检查的结果

| 尝试绕开论证的情形 | 核对结果 |
|---|---|
| 第 0 行空格多提供一条路 | 它最多只有一个邻接单位，禁回退与周期库存守恒使其没有持续流量。 |
| 桥接器反向送货或另一轴并行 | 同一切线只穿一轴；禁回退使同一物品格访问不能在这条边计两次，双向合计仍≤1。 |
| 原矿误入其他机器、借存货格暂存 | 误料不能持续离格；循环态接收为零，不能吸收七口长期供给。 |
| 跨线研磨机直接吸收粉末 | 已按最大平均 2 件/tick 计接收；同时机身占 4 或 6 行，净亏至少 2。 |
| 一格高走廊两端各方向都跑满 | 各端双向总和≤1，不能把进出各算 1 后相加成 2。 |
| 将矿石种类固定成有利配置 | 矿物切线只算合计；全物料模型已允许 z 为连续数，覆盖所有整数分配。 |
| 多台机混做、部分负载、从主区补植物 | 配方平均率连续，条带任意双向补料；仅保留正式满载与全厂半批余量条件。 |
| 上侧跨列单位扣下侧容量 | 原 D 定义确有范围问题，按候选一修正版处理；不把局部占格当全厂反例。 |

没有发现可由规则接法产生、且突破修正后收支或四位置排除的反例。也没有用来源不明的流量模式否证候选。当前结论不依赖待补充的规则事实。
