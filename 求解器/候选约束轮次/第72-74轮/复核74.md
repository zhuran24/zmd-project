## 4. 「共同格组供电并集界」：未否证

### 4.1 小块选择与共同格组的完整证明

如果面积1113的达标布局存在，第2节已证明其217台制造单位全都得电。给每台机器临时选择一根实际覆盖它的桩，这只是计数分配，不改变真实覆盖关系。

如果某根桩覆盖一台机器，机身内至少有一格也在12×12供电范围内。取这一格，把其横坐标夹在机身允许的小块中心区间`[x0+1,x0+w−2]`中，把纵坐标同样夹在`[y0+1,y0+h−2]`中，就得到一个包含该格、完整位于机身内的3×3小块。三种制造单位两边均至少3，两个中心区间非空。小块因此不碰指定空矩形、不碰供电桩身，并且位于列1…69、行1…69内，中心确属该桩的C_p。程序另外检查六种规格相对12×12范围的1414个相交锚点，均能按此构造取块；一般证明不依赖这些有限例子。

如果两块中心归入同一个`(⌊(x+a)/3⌋,⌊(y+b)/3⌋)`格组，两轴坐标差均至多2，两个3×3小块就必有共同格。但两块分别在不同制造机身内，而机身不重叠，所以同一格组至多对应一台机器。

对任意桩子集I，如果一台机器分给I中的桩，它选定的小块中心必落入U_I触及的某个格组。因此分给I的机器至多`|U_I|`台。如果分给I外的桩，第p根桩被分到的机器只是它实际覆盖机器的子集，至多c_p台。因此

`217≤Σ_{p∉I}c_p+|U_I|`。

这对九种(a,b)和所有I分别成立。把右式移项得

`Σ_p(23−c_p)+(Σ_{p∈I}c_p−|U_I|)≤23P−217`。

再对有限的全部I取最大值，正好得到候选的`ΣL_p+D_ab≤23P−217`。空集合的被最大化项为0，所以D_ab≥0。整个推导不需要所选格组都是可实际摆下的机器位置；允许虚假的中心和格组只会扩大上界。

如果同时使用重复覆盖预算，两条式子共同推出的是

`ΣL_p+max(D_ab,Σ_m(k_m−1))≤23P−217`，

不是把两种附加项直接相加。它们可能反映重叠的覆盖损失。候选已明确禁止未经证明相加，不需修正。

### 4.2 对185点的独立全部子集计算

本席对九种(a,b)分别穷尽十桩的1024个子集，计算`Σ外c_p+|U_I|`的最小值。同时另写整数增广匹配：每根桩拆为c_p个容量名额，每个格组容量1，只允许名额连向该桩C_p触及的格组。逐项核对所得匹配的连接、每桩容量和格组互异性；九次最大匹配数均与子集最小上界相等。

| (a,b) | 十桩共同触及的全部格组数 | 加入单桩容量后的上界 |
|---|---:|---:|
| (0,0) | 191 | 184 |
| (0,1) | 191 | 190 |
| (0,2) | 191 | 190 |
| (1,0) | 198 | 189 |
| (1,1) | 200 | 195 |
| (1,2) | 199 | 192 |
| (2,0) | 194 | 184 |
| (2,1) | 194 | 191 |
| (2,2) | 195 | 192 |

取(a,b)=(0,0)，I为

`{(7,68),(20,62),(27,58),(35,60),(38,21),(39,32),(40,48),(40,62),(46,12)}`。

九根桩的容量和为196，共同格组仅161；余下一根(61,8)容量23。因此全厂制造单位数至多`161+23=184<217`。等价地，单桩总亏额11，D_00=`196−161=35`，两者之和46>13。没有再加已知的2次重复覆盖。

如果保留这十个桩位并企图补齐217台机器，无论怎样补、怎样选择物料来路，上述容量上界都不变，所以该点确实不能扩成达标布局。这个论证甚至不需要固定原来的21台边段机器。它仍只排除这一组桩位，不覆盖其他所有S=185摆位，更不能排除S=186或187的全部摆位。

完整1024子集计算的最小切割及等值匹配见[common_grid_audit.json](复核74/common_grid_audit.json)。

## 6. 否证尝试与结论边界

| 尝试的例外 | 核查结果 |
|---|---|
| 217台中留一台停机备用，以免其计入在产供电 | 按机型总批次率减其余最大产能，每台最低制造率均为正，不成立。 |
| 用调试期存货或无限缓存绕过必需端口 | 循环态要求周期首尾状态恢复，不能长期净耗初始库存或净积压产物。 |
| 让第0行、列唯一空格或桥接器补进出料口 | 只有一个可连接的外部邻居，正周期周转会要求退回刚离开的单位，不成立。 |
| 大制造单位只碰供电范围一个格，找不到内部3×3块 | 以实际相交格构造包含它的内部小块，一般证明及1414个相交锚点检查均通过。 |
| 把两处X、Y重叠格只算一次 | 正式两笔费用须分别算；独立重算138次、136个物理格，185点没有借此少付2。 |

| 丢掉未接触计数边的占边桩，漏减J | 所有占边桩都保留；旧标量表也显式允许遗漏占边桩，未少算−2J。 |
