## 1. 复核用的模拟器

[engine.py](复核97T/engine.py) 按快照第23—33行加临时第1、2、4条逐步运行：

- **每步顺序**：先结束到时的制造（做好的一批能整批进取货物品格就进），然后按层数判定元件（同层的按最早送货通道接通先后），再判定非运输单位，最后开始制造。
- **传送带**：连续传送带是一个元件；带内成熟物品只要下一格空就前移，每进一格重新等 8 步。
- **收货**：非分流器元件把物品真正送往某单位时，才带动该单位其余尚未判定的非分流器元件上游；被带动的元件做它自己的判定。不能移回的物品、手里没有成熟物品的元件都不触发。机器、仓库取货口、协议核心不被带动。
- **轮询**：元件的送货按接通先后循环，从上次成功的下一条开始，分流器和汇流器第一次从第二条开始；非运输单位的取货侧先试上次成功最早的，从未成功的按接通先后排在最前。
- **层数**：同轴相邻桥之间的反向通道不参与数层数；其余数法不绕回已经过的元件。
- **离线**：按任意次序重建全部单位，通道的接通时刻取两端建造时刻中较大的，同刻的随机定先后。默认保留物品的来源、货龄、轮询记录和制造进度；可以选择清空轮询记录或清空来源，用来测读法依赖。
- **桥接器**：第31行和临时第1条的「单位」可选按轴读或按整台读。

验证这个引擎时发现一处自身错误：起态生成器一度允许「s 步末的物品在 s+1 步才进格」，这种状态不可能出现，它造成过 3 个假违例。改正后这 3 例全部通过，下文的数字都是改正后的结果。

## 2. 三条候选

### 2.1 专用进路下缓存格不空的传递：未否证

逐段核 §5.2：

- **源机单出口回填。** Y 每步结束后缓存都不空，又只有一条出口。首格在 p 收货，最早 p+8 腾空。这时 Y 取货格空，缓存里就只能是在做的一批，而这一批在 p 步末以前开批，最迟 p+8 完成。首格在元件阶段腾空，Y 在全部元件之后判定，所以当步补入。
- **逐格传递。** 纯带进路是一个元件，层数为 1。带内成熟物品随时前移，后格当步补满。临时第1条只在 X 的各路末端之间形成收货组，组里谁先只决定 X 现有余量分给谁。
- **补足原料。** 一格要么在 (u,u+8d] 内满过 50，要么一直没满、每条路至少送 d 件。大制造单位一种物品只占一格，所以另一种原料挤不走它。
- **周期性。** 用周期性排除空缓存，论证正确。
- **附加单出口结论。** 首格相邻两次送出至少隔 8 步，一个 1 tick 的半开时段里至多送一次，送一次就当步补一次。

收窄是否必要：零余量（d·c_i=a_i）时每条输入路都满速。临时第5条允许离线时满速准入口少过，且少多少不定；一个含周期性离线的循环态里，每周期都可以少过，X 就供料不足、缓存会空。原版靠准入口「每 8 步必过一件」，现前提给不出这一点，去掉准入口是必要的。输出首单位排除准入口也是同一原因：满速准入口不能保证「空着时总收下」。其余前提和结论与原版及第94轮 C 组修正版一致，矿石起点限源矿、蓝铁矿也已写入。

程序：[check_c24.py](复核97T/check_c24.py)，1500 例，每例 3000 步，后 1500 步逐步检查（[out_c24.json](复核97T/out_c24.json)）。覆盖六种配方，含精炼炉、粉碎机、研磨机（两路蓝铁粉末加一路砂叶粉末、多一路两种）、封装机（d=5，2+3 路）、灌装机（d=5，2+2 路）。随机路长 1—8、随机起态与货龄、随机接通先后与离线、X 下游随机停收。X 缓存空、Y 缓存空、单出口首格步末空都是 0 次；852 例是 d=1 单出口。

### 2.2 采种单元的回路存量下界：未否证

逐步核 §6.3 的 150 证明，结论成立：

- b2≥b1+8。
- CA 上次成功早于 b1，C 的取货侧轮询会先试 CA。
- CA 首件自 b1−1 步末起没换过，到 b2 已成熟。逐格反推，CA 全路的货都在 b1−1 前进格，b1 到 b2 没动，所以 A 在 b2 的元件阶段存货 50。
- A 在 [b1,b2−1] 不开批、不出货，取货保持 50。
- AC 首件到 b2−1 已停留至少 8 步，反推出 C 在 b2−1 存货 50。
- b2−1、b2 两步里 C 至多开一批，A 在 b2 至多开一批。
- 两机缓存都非空，得到 Φ(b2)≥L1+L2+49+50+49+1+1。
- 末次 BB 的拼接正确。

**同轴相邻桥（§6.2）。** 推导席自己的程序只测了纯带，相邻桥没有程序证据，本席补上。设桥 P 在前、Q 在后，前后接带 U、D：

- Q 中的货来自 P，第24行禁止它回 P，所以 Q 判定时只往 D 送，不触发 P 的上游 U。
- U 往 P 送货时，P 的另一个上游 Q 层数更低，已经判定过，不会重判。
- 按临时第2条不把 P⇄Q 当环，层数从尾到首递增：D 为 1，Q 为 2，P 为 3，U 为 4。紧贴机器的末桥层数为 1。

这样正向链保持「下游先判、上游当步补位」。

**另一轴无通道是否必要。** 临时第1条写的是「一个单位的非分流器元件上游」，按字面，桥接器两轴的上游同属一个单位。本席按这一读法构造（§2.3 的程序）：

- BK 上的桥 X 另一轴接一条出口堵死的路 Z，Z 的上游带层数低于 X 在 BK 一轴的元件。
- Z 的上游带每步都「往 X 送货」，于是把 BK 上 X 之前的元件提前带动。那时 X 本轴还没腾空，这个元件就失败了。
- 结果 BK 每 9 步才过一件。

在 D 组不断料的满起态下，K 存货在第 57—103 步就跌破 49（20/20 例）；改按一轴读则 0/20 违例。所以在「单位」读法没定之前，限制另一轴无通道是必要的。本条 150 界在交叉桥下是否仍成立没有证，推导席没把它写进来是对的。

程序（[check_d.py](复核97T/check_d.py) d25、[stress_d25.py](复核97T/stress_d25.py)、[enum_d25.py](复核97T/enum_d25.py)）：

- **随机全过程。** 1500 例，每例 3000 步（[out_d25.json](复核97T/out_d25.json)），1473 例含同轴相邻桥（每段桥链 1—3 座）。起态随机，含货龄、缓存相位、高存量偏置；接通先后与离线随机；B、K 开关和下游停收随机。0 违例。
- **高存量压力测试。** 600 例，0 违例。
- **贴边枚举。** CA、AC 满且成熟、含相邻桥的三种进路，A、C 库存与缓存取边界值，共 46656 个起态，0 违例。在 Φ(s)−1/2 一侧起作用的起态里，最低到 Φ−L1−L2=150.5，与下界贴边。

和原版的差别：

- 去掉准入口：理由同 §2.1，又有推导席 §4 的缺服务诊断，必要。
- 另一轴限制：上段已说明，必要。
- 取消相邻桥排除：在保留来源记录的读法下成立。

150 没有提到第94轮 D 组复核给出的 151.5，这不算错，只是保守。

### 2.3 采种单元不断料：修正

逐步核 §7.2：

- **满回路。** 起点取等就迫使 CA、AC 满，A 存取、C 存货各 50，C 取货 50。第一次 CB 送货只使 C 取货降到 49，第二次降到 48 才让卡住的两粒种子进格，并在同一步开批（记为 u）。之后 AC 在 u+1、CA 在 u+2 依次补位。CB 再次腾空在 v≥u+8，CA 最早在 v+2 腾空，所以 CA、CB 永不同步争 C 的一次判定。这一点不依赖轮询记录：清空轮询记录的读法下 400 例×3000 步 0 违例（[out_d26_reset_poll.json](复核97T/out_d26_reset_poll.json)）。
- **单链补料。** 递推 D_i(j)=max(D_{i−1}(j−1)+8,D_{i+1}(j)) 对初始成熟时刻单调。比较过程得到 T_j=max(s+8j,x_j+1)；又 x_j≥s+1+8(j−1)，所以 T_j≤x_j+7，存货始终≥49。
- **K 的库存与服务。** K 取货≥50−k；n≤3 条首格中，另一路先得货后至少 8 步不能再抢，所以最迟 t+n−1 补到目标。
- **附加批率。** 由周期守恒得到，正确。

程序：d26 模式 1000 例×3000 步，984 例含相邻桥，0 违例（[out_d26.json](复核97T/out_d26.json)）。检查项全部按条文逐步核：

- 四机缓存不空。
- B、K 存货不少于 49，B 取货不少于 49，K 取货不少于 50−k。
- CB、BK 首格步末非空，也就是腾空当步就补上。
- K 各首格等待不超过 n−1 步。

**要修正的一处。** 推导席把 K 取货首单位从原版的「传送带、桥接器的一轴或始终放行的物品准入口」改成「传送带或另一轴无通道的桥接器」：

- 去掉准入口是必要的：满速准入口在临时第5条下不能保证空着时总收下。
- 加上「另一轴无通道」没有必要。首格只从 K 收货，K 是非运输单位，不属于任何收货组。即使按整台读，另一轴的上游往桥送货时带动的也只是元件，K 的送货和首格的空满都不受影响。
- 结论里涉及 K 的几句只用到 K 的轮询和首格只从 K 收货。
- 程序按整台读、让 K 的桥首单位另一轴有外来通道，300 例×3000 步 0 违例（[out_d26_kout_cross_unit.json](复核97T/out_d26_kout_cross_unit.json)）。
- 推导席自己的 C 组候选（§5.1）对 X 的输出首单位也只排除准入口、不限桥的另一轴，两条应当一致。

**修正版条文**（只改 K 首单位一句，其余照推导席）：

> 采种单元不断料：采种单元、四条进路、L1、L2和Φ均同「采种单元的回路存量下界」：四路无物品准入口，仅用传送带及另一轴无通道的桥接器，现货沿最终进路正向进入，允许同轴相邻桥。取完整步末s，四机此后持续有供电状态且开着，各格只有本线物品，四缓存各为本机本配方一批；Φ(s)=L1+L2+177，B、K存货和取货各50件，CB、BK各格均有一件正向进入的本线物品。K每批产k件粉末，荞花k=2、砂叶k=3；全部取货通道固定为n条，0≤n≤k，其首格互不共用、只从K收货，首单位为传送带或桥接器的一轴（另一轴有无通道不限），空着时总能收下本粉末。则以后每个完整步末四机缓存均不空，B、K存货各≥49，B取货≥49，K取货≥50−k；CB、BK首格腾空均在本步由C、B补货；K任一首格在第t步判定前腾空，最迟在第t+n−1步补货，n=0时此句为空命题。结论覆盖下游任意合法堵塞恢复及临时规则允许的离线重排，不保证K各口当步补齐或任意8步各取一件。若某可到达循环态中K完成批次从不等待取货空间，则四机各平均每tick一批，K平均送出k件/tick。认证布局仍须另给该起态的可操作调试办法。

## 3. 七段补证

| 补证 | 结论 | 核对要点 |
|---|---|---|
| §3.1 分叉分支 | 成立 | 临时第2条缩小了合法数法；原条「规则允许的选择」自动跟着缩小。**另需转 M 组**：第94轮修正版写「每个这样的下游元件都是允许的选择」，在临时第2条下把绕回自己的数法也算进去，对必要条件要求过宽，会误删布局；应改成「不绕回自己的数法里的每个下游元件」，并写明同轴相邻桥来回不算环 |

| §3.3 密集结点 | 成立 | 两套编码（通用引擎、只为这张网写的数组递推）逐件事件完全相同（[density.json](复核97T/density.json)）。U 先：周期 40 步，S→M 0、S→N 1/5、U→M 1/5；S 先：周期 80 步，各为 1/10、1/10、1/5，与推导席一致。两种建造顺序都是合法蓝图顺序。摆放逐格核过：无重叠，取货口在左边界，回库带接核心左边第 2、3 个存货端口，没有多余通道。P、Q、U 都是 1/5 件/tick，不受临时第5条影响 |
| §3.4 整批k件配k条取货通道的均分 | 成立（依赖轮询记录保留） | 「队首收不下则全部收不下」与固定轮转的论证正确。若离线清空成功记录，各通道离线后都变成从未成功，轮转次序可以每次离线都重排，跨离线的「相差至多 1」就不再成立。推导席已声明这一依赖 |
| §3.6 C 组采种单元的回路存量下界（176） | 成立（依赖轮询记录保留） | 逐句核过：A 在 u 到 t−1 不开批、取货保持 50；C 在 u−1 到 t−2 不开批。s 所在整步 C 有电开着，保证既有批最迟 u+6 完成，所以 u 送 B 后 C 取货≥49，得 Φ(u)≥L1+L2+176.5，Φ(t)≥L1+L2+176。活性一段（Φ≥1/2、不会降到 0）不用轮询记录，也成立 |
| §3.7 满速分流的断头支层数限制 | 成立 | 层数公式（断头首元件 k−1、分流器 k、活支首带 m），k、m=2…8 两种写法一致。格步占用不等式成立，且是紧的：分流器先判、首带 n 格时，模拟的活支流量恰为 8n/(8n+1)，n=1、2、3 分别得 8/9、16/17、24/25（[arith.json](复核97T/arith.json)）。等层时先建分流器和断头首单位、最后建活支首带末格，是合法建造顺序 |
| §3.8 无分流网络的判定先后无关 | 成立 | 组内无货或方向不合法的成员不触发，跳过它们不删掉可竞争的货，组的结果与先后无关。原条的死路带段和双轴桥缺口仍在，推导席没有用这段补证宣布原范围成立，这是对的 |

## 4. 「不受影响」条目抽查

| 条目 | 抽查结论 | 理由 |
|---|---|---|
| 21 C／植物专机一一配对满库存不断料 | 不受影响，成立 | 进路允许「方向已定的桥接器的一轴」，本以为会和 D 组一样受交叉桥影响。但条文只保 400 步，靠的是初始各 50 件存货和本机取货侧轮询，不靠补料速度。程序按最不利的整台读法，在 BK 放交叉桥、其余路放相邻桥，按条文起态跑 300 例（[check_c21.py](复核97T/check_c21.py)）：K 存货到第 399 步降到 44，但 0 违例；首格补货最多等 k_v 次判定（C 为 2、K 为 3） |
| 23 C／采种单元不断料（活性版） | 成立 | Φ≥1/2 和「不会降到 0」都可以不借轮询记录直接证（降到 1/2 时 CB 首格刚收货，下一步只能送 A）；有限开批推出回路全空的反推正确 |
| 27 E／分流先判的首段带容量 | 成立 | 前件写的是实际判定先后。临时第1条可能把首段带提前带动，那时前件不成立，结论不被打破 |
| 6 A／来源定序 | 成立 | 准入口少过只会降低其余来源的量，上界方向不变 |
| 2 A／传输相位 | 成立（依赖同一组离线读法） | 若离线重建会重置协议储存箱的冷却，离线时刻相位可以重新取，「不把相位自由拼接」就要改。推导席的读法是不重置 |

## 5. 离线即重建时的读法依赖

临时第4条说离线「相当于按任意次序把全部单位重新建造一遍，物品原样保留」。它没说下面几项是否保留。推导席（§1 第5条）明说都保留，本席按这一读法给出上面的结论。换成清空的读法时，有以下具体后果（程序 [construct.py](复核97T/construct.py)，结果 [construct.json](复核97T/construct.json)）：

- **甲：清空 C 取货侧的成功记录。** 回路存量下界的「Φ(s)−1/2」一支会失效。
  - 构型：L1=L2=1。s 时 C 取货 2 粒、存货 0；CA 唯一一格有 s 步进的种子；A 存货 50、取货 49、缓存一批刚开（第 s+8 步完成）。
  - 过程：s+1 步 C 只能送 B。s+5 前离线，清空记录，且 C→CB 先于 C→CA 接通。s+9 步 CA、CB 同时空着，两条通道都「从未成功」，按接通先后再送 B。
  - 结果：Φ 从 102 降到 101，低于 min(101.5, 152)。不清空时 s+9 送 A，Φ 回到 102。
  - 同一依赖也在 §3.4、§3.6 里。
- **乙：清空物品来源。** 同轴相邻桥会永久卡死。
  - 构型：CA 为「带→P 桥→Q 桥→A」。Q 有成熟种子（来自 P），P 空，A 存货、取货都满、做好的一批卡着。
  - 过程：离线清空来源，且 Q→P 先于 Q→A 接通，Q 轮询先试 P，种子倒回 P。这时 P 中的货来自 Q，P 唯一的出口又是 Q，永不能动，CA 永久堵死。
  - 结果：Φ 从 154 一路降到 2，远低于下界。不清空时 Φ 一直不低于 154。
  - 不断料一条在同一读法下 300 例中 9 例违例（[out_d26_reset_prev.json](复核97T/out_d26_reset_prev.json)），机制相同：相邻桥中的货倒流后互相堵死。
- **桥接器「单位」按整台读。** 见 §2.2：内部进路有交叉桥时，不断料一条失效。两条 D 组候选已经用「另一轴无通道」避开。

这三项都不是本轮推导席的错。请主会话在 owner 实测轮询（临时第7条）时一并确认：离线后物品来源记录和上次成功记录是否保留。若定为清空，D 组两条的「允许同轴相邻桥」要撤回，150 下界的 Φ(s)−1/2 一支、C 组 176 版和整批均分都要重证。
