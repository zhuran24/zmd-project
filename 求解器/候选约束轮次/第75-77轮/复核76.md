## 3. 从正式文件推出模型前提

### 3.1 台数、供电与面积

如果达标布局含指定的1113空矩形，正式上界使最大空矩形面积就是1113。正式「面积预算」于是给出九机型恰为下限、没有协议储存箱；「供电下限」及面积预算给P∈{10,11,12}。这不是额外假定最少机器、纯料制造或满载直连。

对各机型，用合计必需批次率减去其余机器的最大批次率，得到逐台最低制造率：

| 机型 | 台数 | 单台最低批数/tick |
|---|---:|---:|
| 粉碎机 | 68 | 1 |
| 精炼炉 | 51 | 1 |
| 研磨机 | 32 | 1/2 |
| 塑形机 | 6 | 1/2 |
| 配件机 | 6 | 1 |
| 种植机 | 32 | 1 |
| 采种机 | 16 | 1 |
| 封装机 | 3 | 1/5 |
| 灌装机 | 3 | 3/20 |

如果任何一台停产，该机型其余机器的产能就小于循环态所需流量，故217台均在产、均须得电。初始存货不能持续净消耗，无限缓存也不能持续净积压而仍保持循环态。

小、中、大制造单位分别131、48、38台，占地`131×9+48×25+38×24=3291`。若T为运输单位数、F外为指定矩形外空格数，则精确面积账为

`T+F外=4900−3291−81−138−1113−4P=277−4P`。

面积预算要求`S=16P−2J+X+Y≤4639−4×1113=187`。P=10时单桩亏额与实际重复覆盖的合计预算是`23×10−217=13`。

### 3.2 必需端口与边带

如果一台机器在循环态中生产，周期原料和产物收支均为正，所以两条相对的端口边外各须至少一个有效运输邻格。第0行、第0列除一个物理空格外均被仓库取货口占据。该空格沿边邻接的是无端口的短边或基地外，向内至多连接一个单位；如果物品进去后还要持续离开，只能退回刚离开的单位，违反「移动」。因此不能把这个格作为正循环流量的端口邻格。

研磨机每台至少1/2批/tick，一批进3件，故每台至少2条存货通道；「研磨进料」又给至多一台少于3条。封装机各至少5条。灌装机每台至少3/20批/tick，一批进20件，故至少3条。于是对所有大制造单位采用“进料侧至少2格，至多一台少于3格”是放宽；进料侧允许二选一，没有把输入输出反向漏掉。

没有协议储存箱时，1.15件/tick成品只能经协议核心入库，至少需要2个存货邻格；六个取货邻格全部必需。模型没有强制核心两条存货边各留一个。核心离带的坐标与取货方向必要条件也保留。

从70格边界中去掉位置3k的唯一空格、把余下格逐段铺成23个三格取货口，独立生成左、下两边的47种共同排布：24种左角留空，加23种下角留空且左侧不在角留空。每种都重建46个首运输格，故没有重复角格分支或漏排布。

## 4. 供电证书从头复算

[certificates.json](复核76/certificates.json)与[逐桩容量](复核76/capacities.json)记录完整结果。

占边桩经过平移、交换轴或反射后，可放宽成供电范围`[0,12)²`、桩身`[5,7)²`、机身和有效邻格均在x≤6。根据六种尺寸及端口轴，独立生成550个机身选项、1352条不等式。

设机器选择变量为u，格c上的机身占用为o_c，则占格条件为o_c≤1。端口边的有效邻格集合为N时，必要条件是`u+Σ_{c∈N}o_c≤|N|`：选中机器时至少留一格，未选中时不额外禁止占格。38个非负有理数乘数逐列合成的系数均至少1，右端精确为`1846/135<14`，所以整数台数至多13。

对右下395处桩位，分别重建局部机身与矩阵，又从实际基地坐标独立枚举、平移比对全部选项。总计275888个变量列、669475条约束，所有分数证书通过。p=68、q=1…15的上限复得

`(7,7,8,9,10,11,12,12,12,11,10,9,8,7,7)`。

全部3511处合法桩位的532890个小块中心组合重新生成，每个中心均被证书中宽、高各不超过3的格组覆盖。同格组的两个中心各轴距离至多2，3×3小块必重叠，故这种覆盖数是有效供电台数上限。

同一桩的格组、端口、占边、侧旁等上限先取最小值；相应亏额取最大值，不相加。49处桩位亏额超过13，P=10不能用，余3462处。两处转角桩(47,68)、(68,15)亏额分别15、16。

如果实际每桩覆盖n_p台、每台被k_m根桩覆盖，则

`Σ_p n_p=Σ_m k_m=217+Σ_m(k_m−1)≤Σ_p c_p`。

因此`Σ_p(23−c_p)+Σ_m(k_m−1)≤23P−217`。只保留部分机器时删去的重复项非负，仍是必要条件。机器被三根桩实际覆盖就收两次重复费，不能通过指定一根“负责桩”消除。

## 6. 第二条：剩余容量与共同格组的证明

令F为K台保留机器的全部机身、已定位核心、全部桩及所选必占运输格的并集。如果某达标布局扩展了这些单位，其余217−K台机器的机身就避开F。每根桩实际覆盖保留机器n_p台，已证明的上限为c_p，因此r_p=c_p−n_p≥0。

对每根桩，C_p^余是所有符合候选条件的3×3小块中心：小块在列1…69、行1…69内，避开指定空矩形和F，并与该桩的12×12供电范围相交。固定任意a、b∈{0,1,2}，中心(x,y)共同归入格组(⌊(x+a)/3⌋,⌊(y+b)/3⌋)；U_I^余是I内桩的中心集合触及的格组并集。

给每台其余机器临时选择一根实际覆盖它的桩。机器两边都至少3格；如果机身与供电范围相交，选一个相交格，在机身两轴上各取包含该格的3格区间，就得到机身内部、仍与供电范围相交的3×3小块。小块避开F与指定空矩形，位于列1…69、行1…69，因此中心属于C_p^余。四种尺寸共962种相交相对位置的独立枚举也全部能取到块。

不同机器机身不重叠，其小块也不重叠。如果两个中心属于同一共同格组，两轴坐标差各至多2，3×3小块就重叠，矛盾。因此所有桩共用同一(a,b)时，每格组至多计一台其余机器；另对6561个同组坐标对作了直接检查。

任取桩子集I。分给I内桩的其余机器至多占|U_I^余|个格组。分给I外某桩的其余机器数，不超过该桩实际覆盖的其余机器数，而后者至多c_p−n_p=r_p。两部分相加，必有

`217−K ≤ Σ_{p不属于I}r_p + |U_I^余|`。

如果令L_p=23−c_p、R_K=Σ_p n_p−K，则

`Σ_p r_p=Σ_p c_p−Σ_p n_p=23P−Σ_p L_p−K−R_K`。

把主式右侧改写成`Σ全r_p−(Σ内r_p−|U_I^余|)`并移项，得到

`Σ_p L_p+R_K+(Σ_{p属于I}r_p−|U_I^余|)≤23P−217`。

它对每个I都成立，故对括号取最大值就是候选的收费形式。空集合给0，所以D_ab^余≥0。已保留机器每台至少被覆盖一次，故R_K也是非负实际重复数。

这里能够相加的原因是：保留机器的所有实际覆盖已逐桩从容量中扣去，D_ab^余只对剩余机器计数。若改用旧C_p及旧容量c_p算出的D_ab，就丢失了这一分解，不能把旧D_ab直接与R_K相加。候选明确要求重新计算，范围正确。

若F只保留一部分已证明必占的运输格，中心域会变大、上界变宽，仍是必要条件；若将尚未证明必占的空格随意塞进F，才可能错误排除。原条文没有允许后一种操作。

## 8. 否证尝试与全域边界

| 否证方向 | 核查结果 |
|---|---|
| 让一台机器停产，或依靠初始库存与缓存免除进出料端口 | 各机型逐台最低制造率为正；周期库存守恒排除持续净消耗或净积压。 |
| 让第0行、列的空格或桥接器提供额外循环通道 | 只接一个可连接邻居，持续出入要求原路退回，不成立；另一轴不创造另一个外部来源。 |
| 输入输出反向、两台机器共享运输邻格 | 输入方向可选；模型只禁止机身占用邻格，没有额外强制不同机器的运输邻格互斥。 |
| 投影时删掉真正覆盖边段机器的桩，或删掉漏计J的占边桩 | 删除条件逐桩对全部400个制造选项核查；两类桩均保留。 |
| 两个转角各只算一次，造成假低缺口 | 独立保留138次计数、136物理格；两笔计数不合并。 |
| 同桩多种容量亏额相加、或任选负责桩少算实际重复 | 容量取最小值；重复按所有实际相交桩计数，双计数恒等式支持相加。 |
| 机器只碰供电范围一角，取不到内部小块 | 任一相交格均可嵌入机身内3×3小块，一般证明与962种相对坐标检查通过。 |
| 两台不同规格机器使用同一共同格组 | 同组中心各轴差≤2，小块必重叠，违反机身互斥。 |
| 以负责桩覆盖数代替n_p，或把旧D_ab直接相加 | 原条文使用实际n_p并重建剩余容量和中心集合，未作这两种不合法替换。 |
| 任意圈定未来可能使用的运输格并加入F | 未证明必占则不允许加入；三个点即使不扣首运输格仍失败。 |
| 一个或三个点不能扩展，便宣布全部P=10不可行 | 点的机身和桩位均固定，不能覆盖其他摆位；未作这种推广。 |
| 将四次600秒UNKNOWN当不可行 | 原始日志仍为UNKNOWN；本席没有用超时作排除，也没有为重现超时重跑整域模型。 |

原推导的更强全域程序只采用(a,b)=(0,1)的403个格组、3376个合法3×3中心，要求“可用格组数＋已保留制造单位数≥217”；没有纳入各桩剩余容量及全部子集条件，也未扣必占首运输格。对全部机身与桩位联合选择的四次运行仍未决。这与本轮第二条的完整数学条件有明确差别。

最终边界是：J=0被全称排除，J=1的三个具体旧放宽点被新界排除；所有J=1摆位是否均失败，仍没有证明。P=11、12的独立排除不能弥补这一缺口，因此1113不能降到1110。
