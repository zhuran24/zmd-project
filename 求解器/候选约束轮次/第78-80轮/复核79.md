## 4. A组：单桩规格计数和全部十桩分配

### 4.1 局部放宽没有裁掉跨片机身

把供电范围写成列、行0…11，桩身为列、行5…6。宽w、高h的机身与供电范围相交，锚点恰在`[1−w,11]×[1−h,11]`。小、中制造单位分别保留两个端口轴；大制造单位保留6×4的上下长边和4×6的左右长边。交换输入、输出不改变“两侧各有邻格”的必要条件，因此合并反向朝向不漏真实摆位。

普通模型保留完整机身，允许机身伸出供电范围和任意分片边界，删除其他单位、基地边界、空矩形及运输续接条件。占边桩经过平移、交换行列或反射，可把有效机身和邻格限制为x≤6：右、上侧来自基地边界，左、下侧来自第3节已证的第0行、列不可用性。另一方向的边界删除；占两边时仍包含在这个更宽的单边模型中。

每格占用至多1。若选项i的一侧有效邻格集合为A_i，记o_c为该格机身占用，则必要条件为

`u_i+Σ(c∈A_i)o_c≤|A_i|`。

每台真实被覆盖机器都在相交坐标域内、机身互斥、两侧有真实邻格。删掉其他单位后仍满足上述条件，所以这是正确的上界放宽。

### 4.3 分片交界和表中每格的证据

每台在产机器至少被一根桩覆盖。以正权重相加，重复覆盖只会增加各桩总账，不能漏掉全厂总账。因此

`2N小+3N中+3N大≤54(P−J)+29J=54P−25J`。

任意把桩分成不重不漏的片，再把每台机器临时分给一根实际覆盖它的桩。跨片机器仍保留完整机身，按该桩归片；不要求机身在片内，更不要求各片的独立放宽点能拼起来。某片p根桩、j根占边桩，分得n台、其中b台中或大制造单位，则

`2n+b≤54p−25j`。

故分片表每格均由p−j份54界和j份29界直接相加得到，p>1时只声称上界，不声称可达。结合正式23/14台界，表为

`F(p,j,b)=min(23p−9j, floor((54p−25j−b)/2))`。

F<b的组合删除；p=0只允许j=b=0。三片按桩锚点条件分组，十根桩恰落在其中一片。临时归桩使86台中、大制造单位也恰计一次；所有合并满足`Σp=10、Σj=1、Σb=86`。

[分片复算](复核79/fragment_checks.json)保存完整表。直接枚举130905个合法资源组合与逐片动态规划都得到`max ΣF=214`。不依赖分片数的代数复核为

`2Σn+86≤54×10−25=515`，所以`Σn≤floor(429/2)=214`。

第3节的217台在产机器权重为`2×131+3×48+3×38=520`，超过515。**A组两条均未否证。** 本路线不使用S、空矩形位置、前轮边段表或前轮全域搜索结果。

## 5. B组前两条：权重与方向余量

### 5.1 权重下界109.5

仅给研磨机、塑形机、封装机、灌装机的正流量存货通道记权。按机器边上的位置排序，相邻两个所列位置相距≤3时，给两端运输格朝间隙的方向各记该通道平均流量。记单机输入率d_m、权重W_m，总权W。

被记权方向若直接接另一个制造单位或核心的正流量端口，其机身沿该方向至少伸入3格，会压住另一个必需运输格。仓库取货口也不能插入这两个有效邻格之间。同一运输格同一方向最多由相对两侧的收货机器记权；这些出货共用一个运输物品格，或桥接器的同一轴，合计至多1件/tick。因此每方向权重至多1，且不与实际非运输接口重算。

对六格边，至少3个正流量位置时最多一个位置没有相邻记权，故`W_m≥d_m−1`；至少4个位置时它们连成一段，故`W_m≥2d_m−2`。三格边至少2个位置时有`W_m≥d_m`。

研磨机输入总量94.5件/tick、每台至多3。若两台各≤2，总量至多`30×3+2×2=94`，不足；故至多一台输入率≤2。

* 没有这种机器：32台各至少3条正量通道，研磨权重≥`94.5−32=62.5`。
* 恰有一台，输入率d_0≤2：其余31台权重≥`94.5−d_0−31≥61.5`，低输入机器权重非负。

塑形机至多一台输入率≤1，其他五台各至少2条通道，故权重≥10；封装机每台输入5，权重≥8，合计24；灌装机至多一台输入率=3，其余机器用四格以上支持界，合计权重≥14。总计

`W≥61.5+10+24+14=109.5`。

[权重复算](复核79/weight_checks.json)枚举长度3的7个、长度6的63个非空支持。第一种算法在支持内按系数从小到大分配流量，再作精确分数动态规划；第二种独立生成各系数类别并作整数线性优化。固定支持后的流量约束是盒子、逐机总量区间和全厂总量，极点可取半整数，因此这里半单位网格没有漏掉更小的连续最优值。四类最小值分别为`123/2、10、24、14`。

旧逐机线性界也在全部相关流量顶点重验：研磨`W_m≥2d_m−4`，塑形`W_m≥2d_m−2`，封装`W_m≥8`，灌装`W_m≥4d_m−10`。相加得到W≥109，而新增0.5是这**同一组余量**的整体加强，不能再重复叠加。提交的六份连续线性原始点、对偶乘数均独立转为分数，逐项检查符号、系数、可行性及原始/对偶值相等，见[证据核查](复核79/evidence_audit.json)。

### 5.2 角区N+W_O≤91的独立重证

令I为第1列1…69行与第1行2…69列，共137格；46个仓库矿石端口正对的运输格组成O，U=I\O有91格。N为运输端落在O的非运输正流量接口数，W_O为落在O的上述权重。

每个O格已有一股满速原矿。朝内法向若接正流量非运输端口，只能把原矿交给3×3粉碎机或精炼炉；满速物品格不能再接另一股正流量，桥接器相同轴也不能。机身位置保留所有三个端口偏移。沿边切向可能相接的制造单位，只有唯一非角空格旁的一台3×3小制造单位；其两个切向接口合计先放宽为2。W_O只可能来自这台机器是塑形机时的存货边，至多1，而且还须有另一个未被机身占用的输入邻格。

全部47种共同边带排布由23个不重叠三格仓库取货口重新生成。一边空格g∈{3,6,…,66}时，分别考虑没有贴边小机、有小机但不使用W_O、有小机且允许W_O；合计135支。

g=3还需两个容量事实：

1. 如果另一边23个法向消费机全在，第2…4行（转置为列）被23个三格机身铺满。第1行有24件原矿/tick进入，却只有23件/tick消费且没有其他出口，矛盾。因此那一边法向接口至多22个。
2. 左侧g=3的贴边小机还能接下侧首格(2,1)，但该接法与(1,1)向北接同一机器不能同时有正量：前者或后者已经由满速原矿前缀占满该机每tick1件的消费能力。若(1,1)向东另有分流，(2,1)必须以桥接器两轴分开南侧满速矿石，其南北轴仍满速送往这台机器。故两个下端接法合计至多1，再加上端至多1，仍由总额2覆盖。

## 8. B组第六条：运输和矿石切线余量

### 8.1 运输物品格总账

只计236个有接口运输单位；q没有正流量。桥接器b活个，其他h活=236−b活个，物品格共`472−h活`。每格周期平均收件率v_j≤1，记未用容量`u=Σ(1−v_j)≥0`，运输到运输的平均移动次数为e≥0。

每次运输收件来自非运输单位出货或另一运输单位，所以第3节精确物料账给

`Σv_j=305.65+e`，从而`166.35=h活+e+u`。

正式“回路转弯”要求至少4个有正流量非桥接器，不可能由q承担。故

`162.35=(h活−4)+e+u`，各项非负。

### 8.2 52条来源的首停点

正式“取货口配置”使52口各满速。沿每个原矿满速前缀到第一个分流器或非运输单位：无协议储存箱，矿物又不能回仓库，故后者只能是原矿消费机；由正式“矿线专机”它是满速原矿专机。有限容量的无消费回路不能持续接纳一个满速来源，所以不能以永久转圈规避首停点。

不同满速来源不能共用首分流器或同一满速专机：前者只有一个物品格，后者原矿消费上限1件/tick。于是52个互异首停点分成C首、D首，两数之和52，并分别是全厂C矿、D矿的子集。因此

`C矿+D矿−52=(C矿−C首)+(D矿−D首)≥0`。

### 8.3 完整单位分组和切线恒等式

取B={49…69}×{1…16}。两种边带生成法都核对全部47种排布，B底边恰有7个满速矿石来源。仅计源矿、蓝铁矿、蓝铁块、蓝铁粉末、源石粉末五种物品。程序从18个正式配方逐个计算这五种的净变化：除两种矿物研磨配方每批减少2件外，其余均为0。

跨第48、49列且纵向完整在1…16行内的制造单位、核心、桩整台放组外，避免切开虚拟库存。其高度记h_i；粉碎、精炼κ_i=1，研磨κ_i=2，其余κ_i=0。令a_i为B向该完整单位净送出的五类物品率。逐机周期库存守恒给`a_i≤κ_i`；它可以为负，故没有偷偷假定只出不入。κ是周期平均量上界，不是制造存货格的瞬时收件上限。

完整位于B内的两种矿物研磨批次率合计G，完整核心原矿供给q核为0或6。其余切线物理边的五类流量记f出、f入。周期守恒为

`7+q核=2G+Σa_i+f出−f入`。

跨线机身占去Σh_i行；其余每条物理边双向合计至多1件/tick。普通运输端口方向固定；桥接器同一轴仍受单物品格滞留约束，不能用同tick反向切换和立即退回制造额外容量。故

`u割=16−Σh_i−f出−f入≥0`。

消去f出，得到候选的精确恒等式：

`9+2G−Σ(h_i−κ_i)=u割+2f入+Σ(κ_i−a_i)+q核`。

右端全部非负，程序另以独立仿射系数展开检查移项。令D=Σ(h_i−κ_i)，便有D≤9+2G。每个所计跨线单位h_i−κ_i≥2：最小的小机为3−1，大机两种朝向至少4−2，核心和桩也分别≥2。若完整研磨机N台、跨线单位U个，则G≤N、2U≤D，整数取整给U≤N+4。

统计范围只含实际占这16行切线的完整机身，没有把其他高度、其他位置的单位扣进来。该候选未否证。

## 10. 否证尝试及来源检查

| 否证方向 | 复核结果 |
|---|---|
| 让一台机器不制造，靠调试库存免去供电或端口 | 逐台最低制造率为正；周期库存守恒阻止持续净消耗、净积压。 |
| 利用第0行、列唯一格q，或桥接器另一轴绕过半平面限制 | q没有第二个可持续接通的外部邻居；另一轴不创造来源或去向，不能持续正流量。 |
| 让机身只碰供电范围一格、越过分片界，或把机器分给多个片 | 局部域保留全部相交机身及完整尺寸；临时归桩只归一次，跨片部分没有裁掉。 |
| 用实际多桩覆盖消除B组重复收费 | k_m按全部实际覆盖计算；不能任选负责桩消掉重复。A组临时归桩只用于另一套求和证明。 |
| 随意叠加同一桩的容量亏额 | 所有适用台数上限先取最小值，亏额不累加。 |
| X、Y重合处只计一次，或同方向记两次 | 两处重合格的两个朝向不同，各计一次；计数138、物理格136及四个r=2格均独立复得。 |
| 研磨机使用非连续支持、混料、非满载或分数流量 | 所有70个支持和连续流量极点均纳入；61.5与109.5没有依赖连续端口、纯料或满载直连。 |
| g=3贴边小机同时使用下端两种原矿接法 | 满速前缀和单机消费上限排除同时正量；有权重塑形分支另扣死端，135支全部包含。 |
| 把跨线制造存货格当作每tick只能收κ件 | 本报告只用周期平均逐机用料界；瞬时库存、混料与批次不破坏净流量恒等式。 |
| 用未被计数的跨线单位、核心原矿来源或双向流量绕过切线 | 跨线完整机身范围明确；a_i允许负值，q核保留，f入和未用容量均非负入账。 |
| 只排掉一组桩位或前轮三个放宽点，却声称整支排除 | 本轮两套全域模型枚举全部必要选项，不固定旧点；A组更不依赖具体位置。 |

没有找到来自正式规则、满足现有条件而违反九条候选的反例。局部最优几何点、权重最优分配和资源表214的取等组合都只是放宽见证，缺完整机型、物料来源、接线及循环态，不能用作达标布局反例。
