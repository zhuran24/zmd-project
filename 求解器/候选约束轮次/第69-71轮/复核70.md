## 4. 占边在产供电十三台界：未否证

### 4.1 从正制造量到两条有效端口边

如果一个制造单位在循环态中制造过，配方至少消耗一种原料并产出物品。循环前后存货、取货及缓存状态相同，所以周期进料量、出料量都为正。初始库存只能影响进入循环前的过程，不能替代每周期进出料。由「端口对接」，这要求两条相对端口边外各至少有一格运输单位，且相应通道有正通过量。

如果桩身占第69列，桩左下角横坐标只能为68，朝外没有基地格；第69行同理。如果桩身占第1列，左下角横坐标不能为0：第0列只剩一格未被本边取货口占用，放不下高2格的桩。故该坐标只能为1，第1行同理。

第0列、行的单个空格也不能成为上述有效邻格。如果它被另一边取货口占用，则不能再放运输单位；若未占用，其沿边邻居是取货口无端口的短边或基地外，向内至多连接一个单位。一个物品若从内侧单位进入，再离开只能返回刚离开的同一单位，违反「移动」。调试期预置的物品至多提供有限次离格，不能形成周期正流量。桥接器的另一物品格不会增加可接通的外部邻居。

因此四种占边情形都能通过平移、轴交换或反射，映入同一个放宽：供电范围为列、行0…11，桩身为列、行5…6，所有机身和有效端口邻格满足x≤6。另一方向的边界、仓库取货口位置限制及其他单位全部舍去，只会增加可选机器。

### 4.2 枚举域与每条不等式

宽w、高h的矩形机身若碰到12×12供电范围，左下角满足1−w≤x≤11、1−h≤y≤11。遍历此有限域，保留不碰桩身、位于半平面内且两侧各有有效邻格的选项。遍历的六种规格是3×3左右端口、3×3上下端口、5×5左右端口、5×5上下端口、6×4上下端口、4×6左右端口。交换存货边与取货边不改变“各留至少一格”的必要条件，故没有遗漏实际朝向。

令z_j表示是否选第j项，o_c为所选机身在格c上的占用总数。机身互不重叠给出o_c≤1。对第j项的一条有效邻格集合N，使用

`z_j+Σ_{c∈N}o_c≤|N|`。

如果z_j=1，就至少留一格未被所选机身占用；如果z_j=0，每格o_c≤1已经保证此式，不会额外排除其他摆位。即使某邻格不属于任何候选机身，也仍计入N，此格的o_c恒为0，不能误把它从右侧减掉。

其他未被本桩覆盖的机身、核心、桩和运输续接均未加入占用，只会让该放宽更宽。共享邻格也没有被禁止，实际桥接器或物流单位可否同时服务各端口留待真实布局决定。

### 4.3 精确证书与全厂预算

独立生成的550项及完整矩阵与提交数据逐项相同。38项乘数均非负；乘数相加后，每个选择变量的系数至少1，最小值恰为1，右侧恰为1846/135。因此

`Σz_j≤1846/135<14`。

台数为整数，故至多13台。本条只需要上界，不依赖局部模型能否实际摆到13台。检查器在内存中把整数界改成12、删去一项非零乘数，均拒绝了破坏后的证书。

一般达标布局中，即使总机器数大于217，每个循环态中有制造的机器仍须逐机型达到产能下限，合计至少217台。若共有P桩，其中J桩占边，则供电并集不大于逐桩覆盖数之和，得到

`217≤13J+23(P−J)`，即`10J≤23P−217`。

如果某桩同时占两边，正式8台界更强，该桩取min(13,8)=8，其亏额是15；不能把“亏10”和“亏15”相加。候选原文已经保留这个限制，无须修正。

## 6. 供电重复覆盖预算：未否证

如果A=1113，在固定布局、固定循环态中，每台机器都有制造，故其实际覆盖桩数k_m≥1。设第p根桩实际覆盖n_p台机器，选取适用上限c_p，有n_p≤c_p；同时与正式23台界取最小值，所以L_p=23−c_p≥0。

每个“桩覆盖机器”的配对，无论按桩还是按机器计数，总数相同：

`Σ_p n_p=Σ_m k_m=217+Σ_m(k_m−1)`。

又有Σ_p n_p≤Σ_p c_p=23P−Σ_p L_p，移项即得

`Σ_p L_p+Σ_m(k_m−1)≤23P−217`。

如果只计任意一部分机器，其余k_m−1均非负，删除它们会减小左侧，因此仍是必要条件。这里一台机器被三根桩覆盖要计两次重复；不能只数“有重复的机器台数”，也不能任选一根负责供电后把其他实际覆盖抹去。

如果P=10且J=1，一根普通占边桩至少亏10，全部预算只有13；其他桩亏额非负，所以全部重复次数至多3。如果该占边桩位于上一节p=68的右沿，至少亏11，重复次数至多2。占边、临空矩形、局部证书针对同一桩的容量损失先取最大，随后才与重复次数相加，两类收费没有重复计算同一损失。

对提交的S=186点，本轮不采用其预存端口列表或覆盖计数，而是按机身重新生成端口、检查不重叠并重新计算供电相交。它含小制造单位2台、中制造单位13台、大制造单位7台、核心1座、桩10根；四段缺口分别4、9、9、6，J=1，故S=160−2+28=186。22台已选机器共出现11次重复覆盖；逐桩亏额合计10，故已有收费21>13。任何保留这些在产机器与桩位的完整217台扩展都会违反本条。

这个点没有构造制造物料来源和循环运行：**来源不明，当线索**。它是被新预算排掉的放宽点，不是正式规则反例，不是十桩可行实例。仅排掉它不能代替对所有十桩摆位的排除。详情见[witness_results.json](复核70/witness_results.json)。

### 7.2 从真实布局到整数表

如果一台单位碰计数边，它在该边上产生一个连续投影。完整投影保留制造单位、核心、桩的类别；截短投影统一放宽为可任意紧邻的类别。完整的制造单位—制造单位、制造单位—核心、核心—桩不能无间隔相接。本轮逐对检查全部1630组相应机身组合，均有机身重叠或至少一台的必要端口受阻。没有把该禁止条件套到截短投影，也没有禁止制造单位与桩直接相邻。

每段从头到尾扫描，每步或者留一个计数格，或者放入一个合法投影。状态记录前一类别、核心数、桩数、亏额；转移至少前进一格。四段合并时核心至多一座、桩数至多P、亏额至多23P−217。程序在段内及合并中保留全部精确资源状态；仅在比较提交的保留结果时，删除同核心数、桩数下亏额更多且代价不小的结果。

新S账对已计占边桩每根减2。不接触四段的占边桩仍可能存在，不能漏掉它们对−2J的贡献。若四段已用c座核心、p根普通计费桩、亏额l，转角桩共k根、亏额l_c，则额外占边桩放宽允许数为

`t≤min(P−p−k, floor((23P−217−l−l_c)/10))`。

把最多允许的t用于减2，得到真实S的下界。遗漏桩的实际位置、其他容量损失及与机器的冲突均未强制，只会放宽。原X+Y账用正式每占边桩至少亏9，且目标不计−2J。

逐桩格组上限也没有直接引用前轮候选：本轮重建3511个桩位的532890个3×3小块中心，逐点检查所给格组覆盖。每台被供机器可在自身机身内取一个碰供电范围的3×3块；两块中心若位于宽、高均至多3的同一格组，两块必重叠。因此每组至多计一台，组数给出有效上限。逐桩再与23台、占边、正式「侧旁供电」及适用的新上限取最小值。详细检查见[group_results.json](复核70/group_results.json)。

### 7.3 P=11：两条独立核算路径

使用原供电资源的四段X+Y账，四个转角分支均复得X+Y≥19。若P=11，正式面积预算给出X+Y≤11+2J，正式供电预算给J≤4。因此若J≤3就有X+Y≤17，与19矛盾；只能J=4、X+Y=19。

如果J=4，新13台界使四根占边桩和其余七根桩合计至多覆盖

`4×13+7×23=213<217`，矛盾。

等价地，直接用10J≤36得到J≤3，已与X+Y≥19矛盾。该路径中的19由本轮程序重新计算，不把第66轮待审取等候选当作正式前提。

第二条路径把新占边亏额直接放入S的整数表，四支结果见下表，最小也为189>187。两条路径分别按覆盖台数与面积账证明同一排除，不把“少4台”和“超2个S单位”混成同一种缺额。

### 7.4 P=10、11、12：逐支最终数字

下面先使用13台界与经本轮验证的格组上限；两处转角桩各亏15。

| (47,68)有无 | (68,15)有无 | P=10最小S | P=11最小S | P=12最小S |
|---|---|---:|---:|---:|
| 无 | 无 | 180 | 190 | 199 |
| 无 | 有 | 转角亏15>13，排除 | 189 | 199 |
| 有 | 无 | 转角亏15>13，排除 | 189 | 198 |
| 有 | 有 | 转角亏30>13，排除 | 191 | 200 |

如果P=12，不论落在哪一支，S至少198，超过187至少11，所以P=12排除。若P=11，S至少189，超过至少2，排除。若P=10，三个含转角桩的分支先由亏额预算排除，剩下无、无一支的放宽最小值180≤187，不能排除。

再加入右下395项局部供电界，(68,15)的上限从8降为7，亏额从15变为16；另一转角仍亏15。四支转角亏额相应为0、16、15、31。程序重新计算全部整数表，最终各P最小S仍与上表相同。两套数字不是对同一桩重复收费，而是分别使用较弱和较强的一组上限。

原X+Y账、两套新S账均核验了四个分支及每个P；P=10被转角亏额直接排掉的分支显式记录，没有因证书只存可计算的9项最终值而漏掉另外3支。完整36个“方法、转角、P”组合见[edge_results.json](复核70/edge_results.json)。

### 7.5 转置与1113的范围

横纵坐标互换把(49,17)映为(17,49)，21×53映为53×21；3×3、5×5保持，6×4与4×6互换，长边端口仍在长边。核心两组端口的偏移排列对反向对称，输入输出方向可由允许的旋转取得；运输单位的允许端口、桥接器两轴及供电范围也保持。仓库取货口仍只在左边界或下边界。故每个P及全部四个转角分支都可双向对应，不需要另假设右边、上边有取货口。

| 指定位置 | P=10 | P=11 | P=12 |
|---|---|---|---|
| (49,17)，21×53 | 未排除，放宽余7 | 排除，全部四支 | 排除，全部四支 |
| (17,49)，53×21 | 未排除，放宽余7 | 排除，转置全部四支 | 排除，转置全部四支 |

前轮另外六个位置的候选排除仍按各自三审状态处理，本轮没有把这些候选当作正式前提。正式「1113位置」八处清单未改。即使前轮六处全部采纳，本轮仍缺最后两处P=10的全称排除，所以不能宣布1113不可达。

## 8. 否证尝试与证据边界

| 尝试构造的例外 | 检查结论 |
|---|---|
| 用调试期原料库存让没有进料边的机器周期制造 | 周期库存必须恢复，有限初始料不能支持正的周期消耗；缓存也属于循环状态。 |
| 输出全部留在缓存或取货物品格，不需要出料边 | 周期有正产出而库存不变，必有等量离机，不能成立。 |
| 利用第0行、列唯一空格或桥接器绕开边界 | 单空格至多接一个外部单位；禁止原路返回排除正的周期周转。 |
| 大机只擦到供电范围，枚举漏掉其大部分机身 | 锚点按实际相交完整外扩；六种规格都保留整台机身，未缩成3×3机器。3×3小块只用于另一个有明确证明的分组上限。 |
| 对偶只有非负乘数，但漏了一个变量或删了邻格 | 所有变量独立生成并逐列检查；右下域另用实际坐标枚举比较，完整端口集合保留。 |
| 同一桩同时占边、临空矩形，亏额相加过头 | 程序取各亏额最大值；占两边仍只取15，未算成20或25。 |
| 机器任选一根供电桩后没有重复 | 候选计的是实际相交覆盖，配对恒等式不能通过分配归属改变。 |
| 四段各自使用一座核心或各自使用P根桩 | 四段共享核心、桩数、亏额资源；转角桩统一计一次。 |
| 只枚举无转角桩，或未计边段外占边桩 | 四个二进制分支全部核验，遗漏占边桩用剩余名额与亏额预算显式放宽。 |
| 把右沿至少亏11收给每个十桩布局 | 未证明必有右沿桩，故本轮不作这种推断。 |
| 把S=186点被排掉推广为十桩全排 | 仅检查了这一个点；完整十桩联合模型的全称证书仍缺。 |

没有找到满足三份正式文件却违反四条候选的反例，也没有发现需要改动四条条文的范围错误。局部机身放宽、格组覆盖、整数表取等和限时搜索均未被当作达标布局。

若要从现有S账排除P=10，需证明所有实际布局都有S≥188；现有放宽只给180，至少还差8个S单位。或需对所有S≤187的十桩配置证明“逐桩亏额＋实际重复覆盖”至少14。单个点的21不能补齐这段全称论证。
