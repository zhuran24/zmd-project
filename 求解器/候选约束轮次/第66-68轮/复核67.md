## 4. 窄条矿物切线修正版：未否证

### 4.1 来源及切线范围

一个边界长70格，23个仓库取货口占69格，唯一空格坐标 g 为0、3、…、69。把空格两侧各按3格重新铺排，再取向内长边中点，得到24种单边排布。左、下两边至少有一个空格在共同角格，所以联合排布是 `24+24−1=47` 种。程序逐个重建这47种排列，列49…69内的下边取货端口始终恰有7个。正式「取货口配置」使这7个口各满速，合计供入7件原矿/tick。

如果物品进入第0行唯一未铺取货口的格，该格左右至多是取货口的无端口短边，下方为基地外，只有上方可能接通；物品再离开只能退回刚离开的那个单位，规则不允许。因此该格没有正的周期通过量。调试期预置物品至多产生有限次流动，不能成为循环来源。角格被另一边取货口占用时更没有额外绕路。

如果非运输机身穿过第48、49列之间的下侧切线，它在第49列的占格不能向上伸进空矩形；也不能向下占第0行，因为最窄机身为2格，而该行空隙仅1格。因此它的全高确实在行1…b−1内。空矩形上方跨第48、49列的单位不占这段线，修正版已明确不计入 D、U。

### 4.2 五类计件和跨线接收量

令 K 为蓝铁矿、源矿、蓝铁块、蓝铁粉末、源石粉末，按件数计。逐配方解析得到：

| 单位 | 每批对K的净减少 | 每台接收K的周期平均上界 κ |
|---|---:|---:|
| 粉碎机 | 0 | 1 |
| 精炼炉 | 0 | 1 |
| 研磨机的两种矿物配方 | 2 | 2 |
| 研磨机的荞花配方 | 0 | 仍可使用机型安全上界2 |
| 其他制造单位 | 0 | 0 |
| 协议核心、供电桩 | 不吸收K | 0 |

如果制造单位在循环态中从条带收下 K，那么这部分周期收货不超过该机全部配方的 K 用量；每台每tick最多一批相应配方，得到 κ。存货格突发收件不受这里的瞬时限制，但周期库存不变使平均上界成立。误料不能持续积累，核心也因「矿系不入库」不能成为 K 的消耗处。

把条带内运输单位、完整制造单位和完整核心归组，跨线机身整台归组外。完整制造单位仅通过两种矿物研磨配方净消耗 `2G` 件K/tick。完整核心若出矿，只会额外增加来源，舍去它仍是安全的下界。

如果跨线机身高度为 h，它占据的 h 行不能再放跨线通道，但允许条带通过该机在条带一侧的所有端口合计送入至多 κ 件K/tick。所有跨线机身都占第48、49列，因此其行段互不重叠。剩余 `b−1−Σh` 行每行向外至多送1件/tick；桥接器只有横轴穿竖切线。

周期收支于是给出：

`7 ≤ 2G + 条带经普通切线向外送K + 跨线单位收下的K`

`  ≤ 2G + (b−1−Σh) + Σκ = b−1+2G−D。`

如果主区或跨线机器送回 K，会增加需处理的量，省略它只放宽不等式。面积1113无协议储存箱，没有无线移出的漏项。

### 4.3 两个整数条件

如果完整研磨机共 N 台，则 `G≤N`。按正式尺寸，小机的 `h−κ≥2`，中机为5，研磨机为2或4，封装机与灌装机为4或6，核心为9，桩为2。因此计入 D 的 U 个单位满足 `D≥2U`。

从主式依次得到：

`D≤b−8+2G≤b−8+2N`；

`2U≤b−8+2N`，故 `U≤N+⌊(b−8)/2⌋`。

这里已补齐原版缺少的纵向范围，无须再修正条文。b=9、17分别给出 `U≤N`、`U≤N+4`，本条本身没有排除这两个位置。

## 5. 矩形旁供电分组上限：未否证

### 5.1 小块覆盖为什么给台数上界

如果一个制造机身与桩的12×12范围相交，就从相交格开始，在该矩形机身内选一个包含此格的3×3小块；各制造机身的两维至少为3，所以总能选到。该块是机身子集，不能碰桩身或空矩形。不同机器的小块也不重叠。

如果两个小块中心进入同一格组，两轴坐标差都不超过2，则两个3×3小块必重叠。因此一个格组最多包含一个被选中心。给每个所选中心任取一个覆盖它的格组，即得到到 m 个格组的单射；格组之间可以重叠，也可以包含域外点，都不影响上界。

故台数至多 m。第3节证明全部机器均有正制造量，再与正式23台上限取小，得到 `min(23,m)`。各个适用上限必须取小，等价于各项亏额取**最大值**，不能把同一桩的多个亏额相加。

若每个桩的上限是 `23−L`，全部217台都要得电，且供电并集台数不超过各桩所供台数之和，则

`217 ≤ Σ(23−L)`，即 `ΣL≤23P−217`。

这里没有先分配“某台机器归某个桩”，也没有假定多桩覆盖不存在。

### 5.2 中心域与证书核验

桩占格左下角为(p,q)，其范围按格边界为 `[p−5,p+7)×[q−5,q+7)`。小块中心为整格(x,y)，占列x−1…x+1、行y−1…y+1。独立检查器按实际矩形相交重建中心域，没有用证书提供的中心清单代替枚举。

检查内容包括：桩位无重复且与完整几何域相等；每组两轴各1—3个连续坐标；每个中心被覆盖；给定 cap 等于 `min(23,组数)`；占边及侧旁亏额从正式条件重新计算。

3490和3511是“2×2机身在列、行1…69内且避开空矩形”的完整候选桩位数。这个域没有加入与其他单位和必需矿石运输格的全部冲突，因此是实际可用桩位的超集；“合法桩位”不表示各位置已能延伸成全厂布局。用这个超集核验上界和放宽摆位不会漏掉真实布局。

b=9时，下条带列49…69、行1…8内有140个完整桩候选位；上条带行62…69同样有140个。两者的 `23−min(23,m)` 最小值均为7；合并正式亏额后最小值也均为7。

b=17的(47,68)、(68,15)两处各有8个覆盖组，cap均为8，亏额均为15。全部7001个桩位的1047210个“桩位—中心”组合通过覆盖检查。

## 6. 1113位置与桩数：未否证

### 6.1 边段模型确实包含实际布局

独立枚举从全基地出发，而非只在证书给出的边段起点内搜索。单体规格为小制造单位3×3、中制造单位5×5、两种大制造单位朝向6×4及4×6、协议核心9×9、供电桩2×2。

如果协议核心位于某处，其6个取货端口邻格全部要有效。面积1113没有储存箱，两种成品共1.15件/tick必须进核心，所以存货端口外还须至少2个有效邻格。协议核心两个取货轴均枚举；只要求单体必要端口可用，省略别的机身对端口的额外遮挡，是放宽。

全基地枚举得到 b=9 的26082个、b=17 的26921个“几何机身—端口轴”候选。它们不是九机型计数，也不是全厂可行布局数。同一尺寸的不同机型共用必要几何条件。

把机身与一段计数边的交集记为一个连续投影。如果投影只露出机身的一部分，将其标为部分投影，不用完整投影的禁止紧邻规则。如果两个完整投影紧挨且种类为“制造单位—制造单位”“制造单位—核心”或“核心—桩”（顺序可换），本轮逐坐标核查全部7624组对应实际机身：每一组都机身重叠，或堵住至少一个必需端口。其他相邻关系允许，额外的碰撞省略。

动态规划的状态为已经走到的位置、上一段类型、已用核心数、已用桩数、已用亏额。一步或者留下一个按X/Y定义收费的格，或者放入一个实际枚举出的投影。每一步严格向前，末端取最小值，所以有限递推穷尽全部投影序列。资源仅保留核心数≤1、桩数≤12、亏额≤59；这覆盖三个正式P分支。相同核心数、桩数下，如果另一状态亏额更少且计数空格不更多，删去劣态不可能抬高最优下界。

不同边段合并时核心数、桩数、亏额相加。没有接触被计数边的单位不收费，单独边段之间的大部分实体冲突也省略。因此每个真实布局都能映入此模型，而模型取等点未必能映回真实布局。

原证书计算的是“下无完整桩”和“上无完整桩”，两者在“上下都无”上**确有重叠**；不是两个互斥事件。但第一张表覆盖前两行，第二张表是第三行的放宽，故仍能证明不重不漏划分的每一支都不可能。候选仅说“两支覆盖”，并未据此重复计数或相加费用，所以无需修改条文。

在各支里，独立程序删除被禁止条带内的完整桩。若一台制造单位找不到任何未被禁止、单桩亏额≤13且能覆盖其机身的桩位，则删除该机身选项。反之保留，甚至不要求这些候选桩能同时摆下。这是必要条件的放宽。穿过第48、49列的桩并未因为“完整桩被禁”而删掉。

这两支只用P=10。该档右上角桩本身亏额超过13，不能出现，故分支证书未另列“有角桩”表不是漏支。至此 b=9 的三档 P 全部排除。

### 6.4 b=17：四段联合及转角四分支

b=17时空矩形贴上、右边界，计数边恰为：

1. 第69列，行1…16；
2. 第69行，列1…48；
3. 第48列，行17…69；
4. 第16行，列49…69。

全基地单体枚举确认：能同时接触其中两段的有效非运输机身恰有(47,68)、(68,15)两个2×2供电桩。若制造单位或核心跨这些凸转角，至少一个必要进出料方向被基地外或空矩形封住，不在正运行必要域内。其他任一有效单体至多碰一段。

对两个转角桩分别取“无、有”，共有00、01、10、11四支，互斥且完整。每个有桩分支固定其两段投影，删除与该桩机身重叠的其他选项，桩数、亏额、J都只在外层计一次；无桩分支删除对应桩。四段随后**共用一份**核心、桩数及亏额预算。

计算S时，普通占边桩在目标里扣2。没有接触这四段的桩仍放宽允许占边：每增加一个这样的占边桩，须至少消耗1个桩名额、9亏额，再扣2。若段内资源为(c,p,l)、已固定转角桩数为k及亏额为d，段内目标值为v，则未计占边桩最多按

`u=min(P−p−k, ⌊(23P−217−l−d)/9⌋)`

处理，候选值为 `16P−2k+v−2u`。真实未计占边桩不会更多，因此这一步只能降低放宽下界，不能误排真实布局。

两种目标分别重算：不扣J的表给X+Y下界，扣J的表直接给S的精确放宽最小值。

| (47,68)桩 / (68,15)桩 | P=10：X+Y / S | P=11：X+Y / S | P=12：X+Y / S |

| 无 / 无 | 22 / 180 | 19 / 187 | 16 / 196 |
| 无 / 有 | 亏15>13，无状态 | 19 / 189 | 16 / 198 |
| 有 / 无 | 亏15>13，无状态 | 19 / 189 | 16 / 198 |
| 有 / 有 | 亏30>13，无状态 | 19 / 191 | 16 / 198 |

所以P=12全部分支至少S=196，超过187至少9；P=10、11的总最小值为180、187，仍不能排除。以上全部选项、边段表和汇总值均与提交整数证书一致。

## 7. 十七位置的十一桩取等条件：未否证

如果 b=17、P=11，上一节四支均给出 `X+Y≥19`。面积预算则给 `X+Y≤11+2J`，正式供电预算给 `J≤4`。因而

`19≤X+Y≤11+2J≤19`，

只能 `J=4、X+Y=19`。

如果四个占边桩中任一个亏额大于9，或者七个其他桩中任一个亏额大于0，则总亏额超过 `4×9=36`，违反P=11的预算。因此占边桩的L各为9，其他桩L各为0，总亏额恰36。

四个占边桩各至多供14台，其余七个各至多供23台，上限和为

`4×14+7×23=217`。

令每个桩实际覆盖的制造单位集合为 C_j。全部217台都要得电，所以

`217=|∪C_j|≤Σ|C_j|≤217`。

如果任一桩少供一台，最后的不等式严格；如果任一制造单位被两个桩覆盖，中间的不等式严格。两者都会使供电并集少于217，故每个上限都取等，且每台制造单位恰被一个桩覆盖。这是几何供电覆盖的结论，不是任意选一份供电归属后得到的说法。

如果使用(47,68)或(68,15)任一桩，该桩也是四个占边桩之一，但其分组亏额为15；总亏额至少 `15+3×9=42>36`，矛盾。因此两桩都不能使用。此结论与联合表中有转角桩时S≥189的结果相符。

这条取等链给出必要结构，没有证明00分支的边段取等状态能同时满足其余机身、供电、运输及全部循环态要求。

## 8. 条带全物料切线：未否证

### 8.1 有限线段与完整单位分组

允许的行段是 b=9 的下侧1…8、上侧62…69，以及 b=17 的下侧1…16。对每个 a=49…69，取这些行中的列a…69为R。

如果制造单位、核心或桩穿过第a−1、a列之间的有限线段，其机身右部已经在列49…69。机身若越过行段的孔侧端点，会撞上空矩形；若越过基地端点，会出基地或占第0行连续至少2格。因此实际穿线机身的高度全部在该线段内，扣其全高h不会多扣。独立几何枚举验证全部63个所需线段；a=69等很窄的R也包含在内。

把运输单位和完整机身归到R组，把穿线制造单位、核心整台放在组外。这样每个库存格、缓存格只属于一个组，不会把机器的虚拟库存按占地面积拆开。供电桩无物品库存，只承担占线扣高。

### 8.2 收支符号和跨线机器接口

对每个物品i，v_i包括三项：组内直接仓库来源减去组内直接入库量、完整制造单位的配方净产出、跨线整台单位送入组的量减去从组收下的量。仓库取货口不作为R中的制造机身，它向R供给的物品仍计入第一项。完整核心的出库、入库按第一项计；跨线核心与R之间的接口按第三项计，同一次移动不重复记账。

如果对组内该种物品连同缓存做一个周期的库存守恒，则库存净变化为0，余下经普通物理切线外送减去送入的量恰为v_i。若分别记这两种量为E_i、I_i，则

`E_i−I_i=v_i`，所以 `E_i+I_i≥|v_i|`。

如果跨线制造单位从R收到某种物料，该量不超过该机从全部存货通道收到的该物料；按正式「双料逐机收支与存货界」，后者等于该机配方总用量。相应地，该机向R送出的物料不超过全部物理出货，周期取货库存与缓存不变使其等于配方总产量。误料没有正周期收货量，不能作为额外吸收项。

对多条切线，同一实际循环态中的一台机器只有一组配方平均率。因此多线模型必须共用这些率；不能为了不同切线分别选择对自己有利的机器负载。

### 8.3 每条物理边双向总量为何≤1

如果边上有方向固定的端口，只能沿一个方向通货，另一端运输格的容量1和滞留至少1 tick给出平均速率≤1。

如果两个方向都可能通货，考虑固定一端与这条边相连的物品格；桥接器只取对应轴的那一格。一次从进入到离开的占格过程若在这条边上被计作两次移动，就必须从该邻居进入，再退回该邻居，即回到刚离开的单位，规则禁止。因此一次占格最多贡献一次这条边的移动，不论方向。

如果这些占格过程在一个周期内重复，它们互不重叠，每次至少1 tick；周期首尾可循环配对，不能多出一笔首尾容量。所以这一边两个方向合计也至多1件/tick。桥接器另一轴没有穿此边，不能再加1。

这是一项任意周期的占格论证，不依赖只检查若干短周期。脚本另枚举48种“进邻居、出邻居、所计边”组合核对局部计数，但有限枚举不替代上述一般证明。

### 8.4 合并容量

所有穿线机身都占第a−1、a列，相互不能重叠，所以它们占掉的行段总长是Σh。剩余至多 `H−Σh` 条物理边，每条双向总量≤1。结合逐物品收支，得到

`Σ_i |v_i| ≤ Σ_i(E_i+I_i) ≤ H−Σh`，

即候选主式 `Σ_i|v_i|+Σh≤H`。

R的另一端是基地右边界，孔侧为空矩形；下条带的第0行没有额外周期出口，上条带的顶端是基地边界。面积1113没有协议储存箱，故不存在未计无线传输。若某个跨线单位另向R供料或收料，其作用已经在v_i内，不能再借其机身虚增普通切线容量。

本条只是必要引理，没有提供 b=17、P=10或11 的新排除证书。
