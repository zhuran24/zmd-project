# 「矿系不入库」改法提案：必要性复核

日期：2026-09-22。状态：复核完成；提案涉及的五条正式条文及保留的逐次传输条件未否证；正式文件未修改。

**结论：同意提案保留纯矿石守恒引理、迁移四条“据”的改法。** 对这些条文逐句尝试否证后，未发现需要进一步收窄正文的反例；下文给出不使用箱子物理白名单的必要性证明。这个结论不等于重新认证全部 71 条、历史几何计算或全厂可行性。

“植物系物品”确实来自候选第 5、6 轮的旧证明范围：当时一般情形只排除了含矿物品入库，植物零入库另带“种植机恰 32 台”的前提。它不是游戏规则给出的传输例外。现在植物零入库可直接由仓库存量周期复原推出，与种植机台数无关。

旧箱体物理禁令的跨相位证明不成立；**该禁令在完整达标布局上的必要性仍未决**。局部闭环能否定该证明中的推理步骤，尚不能替代完整达标布局的反例。删除未经证明的附加禁令，不需要先宣称其反命题已获全厂见证。

## 1. 复核范围与量词

被审文本为 [P-改法提案.md](P-改法提案.md)，并已全文读取 [A-箱内中转.md](A-箱内中转.md)、[B-条目依赖.md](B-条目依赖.md)、[C-内核依赖.md](C-内核依赖.md)。正式依据为根目录的[游戏规则](../../../《明日方舟：终末地》游戏规则.txt)、[求解任务](../../../求解任务.txt)、[求解约束](../../../求解约束.txt)；候选与报告只用于追踪推导，不代替正式依据。

固定一个达标布局 L，任取不得依赖量 u 的一组取值，再任取该取值下调试后可到达、满足任务“仓库同时可以接受两种成品”目标前提的循环态 c。设周期为 τ。以下证明均在这个任意选定的 `(L,u,c)` 内进行，没有选择有利相位或有利判定先后。

正确量词是：

`∀达标 L，∀u，∀c∈Cycles(L,u)：该循环态满足所述必要条件。`

u 改变时，可到达循环态集合也可能改变。不得把 `Cycles(L,u₀)` 中的物品轨迹固定不动，只插入 u₁ 的一次传输，再把所得非闭合轨迹称为 u₁ 下的循环态。零入库限制也不延伸到调试期或进入循环态之前的有限过渡。

## 2. 改动条文及逐句判定

### 2.1 新「矿系不入库」：成立

提案正文仅保留十种含矿非成品在循环态中零入库。以蓝铁矿、源矿份数分别赋权；从当前正式规则全部 18 条配方独立复算，权重如下。

| 物品 | 蓝铁矿份数 | 源矿份数 |
|---|---:|---:|
| 蓝铁矿、蓝铁块、蓝铁粉末 | 1 | 0 |
| 源矿、源石粉末 | 0 | 1 |
| 致密蓝铁粉末、钢块、钢制零件 | 2 | 0 |
| 致密源石粉末 | 0 | 2 |
| 钢质瓶 | 4 | 0 |
| 高容谷地电池 | 20 | 30 |
| 精选荞愈胶囊 | 40 | 0 |
| 七种植物系物品 | 0 | 0 |

每个配方均保持两种权重。未完成批次中的投入仍在缓存格内计权，完成时用等权产物替换；周期首尾所有仓库外库存及制造状态复原。

据“取货口配置、出库上限”，一周期恰有 `52τ` 件原矿出库，其他物品没有出库。将两种矿权重相加，据“周期倍数、单位矿耗”，成品交付恰带走：

`50×0.6τ + 40×0.55τ = 52τ`。

所以仓库外矿权重收支给出：

`0 = 52τ − 52τ − Σ_x 矿权重(x)·I_x`。

这里 x 遍历十种含矿非成品，`I_x` 是周期实际入库件数。每项非负、每种权重严格为正，因此所有 `I_x=0`。这个证明不使用原条被删的核心／箱体类别限制，不使用植物零入库，也不使用任何箱内最低停留时间。

否证尝试：调试时准备额外钢块、周期中把其送回仓库。若每周期减少仓库外初存，就不满足“循环态”；若周期末补回这些钢块，补回的矿权重也在上述总账内。有限初存不能为循环中的重复返库支付矿耗。

**据行判定：成立。** 提案的“周期倍数、单位矿耗、出库上限、取货口配置、循环态、配方”支持这个独立引理；不能反引“非成品零入库”来证明它。

### 2.2 「非成品零入库」及其新据：三部分均成立

| 分句 | 判定与理由 |
|---|---|
| 除两种成品外，核心与箱子两条途径的周期入库件数均为零 | 成立。原矿由上节补齐；其余物品由下面的仓库单调性证明。 |
| 植物零入库不以恰 32 台为前提，植株／种子入库项在所有台数下为零 | 成立。仓库出口种类、玩家拿取种类及周期复原均与种植机台数无关。 |
| 每种植物采种批次等于粉碎植株批次，种植批次等于两倍采种批次 | 成立。直接列配方收支即可，不需要回引“回路守恒”。 |

对既非原矿又非成品的物品 x，仓库取货端口只取原矿；外部过程只补原矿；玩家只拿成品；制造不使用仓库格作为制造缓存。由“仓库、协议核心、取货口配置、外部过程、零干预运行、拿取成品、循环态”：

`0 = W_x(t+τ)−W_x(t) = I核,x + I箱,x`。

两个非负入量分别为零。这里禁止的是成功入库，不是试图入库；满仓拒收不增加 W，完全相容。“物品格数量不限”也不改变这个论证：同一种物品在核心只能占一格，且整个仓库属于基地状态。

对一种植物，记周期完成采种、种植、粉碎植株批数为 a、z、f，植株、种子入库件数为 w、s。据“配方、制造、缓存格”，周期首尾包括在制状态的库存复原给：

`z=a+f+w，2a=z+s`。

已证 `w=s=0`，故 `a=f，z=2a`。跨周期的未完成批次首尾相同，不会产生额外差额。

否证尝试：增加种植机、调试时腾出植物仓库空间、同刻先入库再“取走植物”、让同种植物另开仓库格。前两种只改变台数或初值，没有制造周期性仓库出口；第三种违反“取货口配置、零干预运行、拿取成品”；第四种违反“物品格”，且仍不能让整个仓库状态周期复原。

**据行判定：成立。** 删除“回路守恒”，补“物品格、配方、制造、缓存格”，保留独立矿石引理，足以支持全部正文，且消除了这两条在植物零入库部分的互相引用。

### 2.3 「回路守恒」及其新据：三部分均成立

1. **周期批次式成立。** 上述两式消元即 `a=f+w+s，z=2a−s`。虽然已知 w、s 为零，保留带入库项的恒等式不产生额外限制。
2. **逐 tick 总量式成立。** 按“缓存格、制造”计在制投入，种植完成使“种子＋植株”总数净变 0，采种完成净变 +1，粉碎植株完成净变 −1，入库净变 −1。物理移动及箱内中转只改变位置。变化归属完成事件，不能把粉碎开工误计为植株已消失。
3. **恰 32 台时的零入库及 5.5、11、10.5、21 数值成立。** “满载配置”给种植总批次率 32；“物料流量”给两种种植率分别至少 11、21，下界相加已为 32，故各自取等，再用 z=2a、a=f。原文此处数值沿用周期平均每 tick 口径，不是各 tick 批次都相等。

**据行判定：成立。** 把“矿系不入库”换为“非成品零入库”正好提供所需植物零入库。新证明不要求删去正文的 32 台前提；保留较弱的条件结论仍然必要。

### 2.4 「回路存量」及其新据：逐时刻与时间平均两部分均成立

据“端口对接、运输单位、滞留”，植株或种子从制造单位产出到下一制造单位，至少经过一个运输物品格，停留至少 1 tick；据植物配方与“制造、缓存格”，进入下一批加工后到该物品身份消失再需 1 tick。因此每件种子从采种完成到种植完成、每株从种植完成到采种或粉碎完成，均至少存续 2 tick。植物零入库排除了这段生命周期中的无线捷径。

恰 32 台种植机时，“满载配置”使每台相邻种植完成恰隔 1 tick，即任意长 2 tick 的半开窗内全体恰完成 64 批。对时刻 t 同刻全部判定完成后的状态：

- `(t,t+2]` 将完成种植的 64 粒种子已经存在，且尚未变成植株，所以种子至少 64。
- `(t−2,t]` 刚完成种植的 64 株尚未完成消耗，所以植株至少 64。

两个半开窗正确处理了恰在 t 和 t±2 的完成事件，不需要所有机器同相位。按每件至少存续 2 tick 求周期时间积分，结合两种种植平均率 11、21，分种的种子与植株平均存量分别至少 22、42。

否证尝试：在箱内同刻进出、各机器错相、混种降低某一时刻的荞花数、漏掉粉碎缓存。箱内零停留不能消去机器间的运输格；错相不改变长 2 tick 窗的逐机批数；混种可以改变分种瞬时存量，但条文只给分种时间平均界；漏掉缓存则改变了条文明确的计数对象。

**据行判定：成立。** 新“非成品零入库”足以替代旧植物条件句，不需要任何箱体物理白名单。

### 2.5 「植株半分」及其新据：成立

对任一种植物反设三项都不成立。第一项不成立使所有种植机在这个循环态中各只做一种植物；这只是反证分支，不能作为一般布局的默认前提。恰 32 台时每台满载，按平均产率分别有 11、21 个该种植株的整股源，每股 1 件/tick。

第二项不成立使每个种植机对该种植株只有一条正流量出口。第三项不成立使每股到首次被采种或粉碎前，沿途分流器及箱子对该种植株也至多只有一个正流量出口；桥接器两轴独立、汇流器只能合流。由“端口速率、非成品零入库、循环态”，一个唯一物理出口必须承接完整的 1 件/tick，既不能无线消失，也不能再合收另一股正流量。有限闭环、静态箱存、误料机器均不能持续吸收新来的整股并周期复原。

所以每股最终完整交给一台采种机或粉碎机；每台这类机器每 tick 至多消耗一株，收到一整股就没有余力再混做。采种与粉碎的该种植株总流量遂均为整数，与各自必须达到 5.5 或 10.5 矛盾。

否证尝试：单出口箱先攒货再时分出货、开传输箱向仓库分出半股、只在周期不同时间使用两口。第一种不能让唯一物理路径变成两个消耗目的地；第二种违反植物零入库；第三种已经满足“完整周期两口各有正通过量”的第三项，不是反例。

**据行判定：成立。** 只需要“非成品零入库”排除无线植物出口。三择一是必要析取，不是任一分支单独足以达标。

### 2.6 完整保留的「传输按仓库余量判定」：逐句成立

| 分句 | 判定与适用边界 |
|---|---|
| 有电、开传输、冷却已结束的实际传输判定前，有某非成品就必须对它零余量 | 成立；n 与 f 必须取紧邻该判定前的真实状态。 |
| 等价地，有余量时，该次判定前箱内该物品必须为零 | 成立；是同一非负等式的等价形式。 |
| 分别适用于每种相位和固定次序 | 成立；先固定 u，再在它自己的可到达循环态内证明。 |
| 满格且不再出库的非成品，不因开传输而被禁止物理中转 | 成立于所述机制层面；不保证下游有空间、格序不卡货或整个布局达标。 |

令 n 为一次传输判定前箱内各格同种非成品的合计数，f 为仓库此时能接收的该物品件数。据“传输、物品格、协议核心”，发送量为 `min(n,f)`。由“非成品零入库”，周期内各次非负发送的和为零，故每次均满足：

`min(n,f)=0 ⇔ n=0 或 f=0`。

同刻另一个箱先传走物品、核心先收货或原矿先出库，均已体现在这个判前快照中。同种物品在箱内分占多格不改变合计发送量。未满仓非成品在冷却间隔中物理进出，完全可能满足 n=0 分支，不是否证本条。

对满仓且不再出库的钢块，f 始终为零；零无线发送保留原物品，物理端口仍依据“协议储存箱、移动”工作。不得把这句话扩大为“所有满仓物品的所有中转接法都可行”。

## 3. 核心通道与被删分句

**核心的非成品正入库流量为零：成立。** 据“仓库、存货/取货端口、协议核心”，成功通过核心存货端口就是入库；核心没有仓库外的过站箱格。由“非成品零入库”可直接推出该结论。满仓时只能拒收，不能以“只是瞬间经过核心”为由允许非成品正通过量。

**恰 32 台时植物零入库：成立但冗余。** 不限台数的结论已在第 2.2 节独立证明。删除旧特例不会删去其结论。

**“开传输箱只能物理输送成品或已满仓物品”：不能判为已证必要条件。** `min(n,f)=0` 只约束传输判前，而游戏规则“滞留”不适用于仓储单位。旧第 6 轮证明虽然承认箱子可同刻进出，却从“另一相位可能抓到”直接跳到“该循环态不达标”，没有证明换相位后的轨迹仍是相应参数下的可达循环。

这项删除可以采纳：它撤去的是未经证明的限制，并未加入“任何物品都能通过任何开传输箱”的新断言。

## 4. 具体局部时间线及反例边界

采用 A 报告的一个箱子、十格传送带、唯一一件钢块的闭环。箱子有电且传输常开，仓库钢块为 0。各运输格停留恰 1 tick，箱内同刻完成进出；没有制造或外部源向这个环继续补钢块。完整局部占格及端口方向见 A 报告第三节。

| 参数与时刻 | 实际事件 | 对必要条件的影响 |
|---|---|---|
| 传输在 `5m`，进箱在 `1+10k` | t=0 空传输；t=1 进箱后立即出箱；t=5、10 空传输；t=11 再进出。每 10 tick 重复。 | 仓库余量 80000；物理中转 0.1 件/tick；所有传输判前 n=0。满足新条件，却违反旧物理白名单。 |
| 改为传输在 `1+5m`，固定“进箱→传输→出箱” | t=1 传走唯一钢块，出箱失败；以后空环，仓库钢块恒为 1。 | 捕获只发生一次；它不属于最终循环态。最终循环仍零非成品入库。 |
| 仓库钢块改为 80000 | 任一相位、任一固定先后，钢块无线发送均为零。 | 满仓物理中转不违反逐次发送条件。 |

对前两种情形的所有相位、所有固定先后，不必依赖有限相位枚举：闭环里只有一件不可再生钢块，仓库钢块没有出口，所以至多成功入库一次；任何可到达周期均不包含使仓库永久增加的捕获事件。相位不重合时又确有永久未捕获的局部周期。

这条时间线对相关现行条目的检查如下。

| 条目 | 不排除它的理由 |
|---|---|
| “物品格、协议储存箱” | 箱内至多一件，仅用第 1 格；没有编号遮挡或多物种碎片。 |
| “端口对接、端口速率、滞留” | 箱前后均接运输单位，每运输格每圈停留 1 tick，每口 10 tick 才通过一件。 |
| 新“矿系不入库、非成品零入库、传输按仓库余量判定” | 未捕获与空环两个长期分支均零循环入库；捕获所在过渡段不是周期。 |
| “传输箱不满” | 箱内至多一件，未超过 18；每周期入箱等于物理出箱。 |
| “箱内滞货封住后格、满速箱头限存” | 不存在被全部箱口按身份拒绝的物品；也没有逐口满速外送前提。 |

**没有完成的部分不能写成“全部正式条目已通过”。** 模块不生产成品；把它与一个全参数达标生产系统组合，仍需证明 70×70 几何、供电、必要空矩形、全部产率及可达性，并排除共享钢块仓库余量对主生产的反馈。现行条目未给出这样的可嵌入布局见证。不能拿面积上界反推存在足够空地。
