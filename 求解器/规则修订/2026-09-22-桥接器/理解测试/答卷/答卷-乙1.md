# 桥接器理解测试答卷（席位乙1）

仅依据指定的《游戏规则.txt》，行号按原文件计算。下文的箭头表示允许的移动方向；实际移动还需要发送方有货、接收物品格能接收，并满足滞留要求。区分“规则有两种读法”与“规则明确允许不同运行次序”：后者不等于前者。

**1. 传送带取货端口—桥接器—精炼炉存货边**

允许的路径是：传送带 → 桥接器这一对边的物品格 → 精炼炉的存货物品格。

依据与推理：

- 第15行以“本单位”为基准定义存货、取货：传送带的取货端口向外送，炉子的存货端口向内收。第44–46行确认精炼炉属于具有存货边的小制造单位。
- 第63行规定桥接器两边的端口都兼有存货、取货身份。因此，靠传送带的一边可以收货，靠炉子的一边可以出货；两处都满足第16行形成通道的条件。
- 两边属于同一对，共用该对的物品格（第63行）。物品进入桥接器后至少停留1 tick（第23行），随后在能接收时送进炉子；移动本身耗时0（第24行）。炉子不能接收时，物品留在桥接器，进而可能阻塞来料。
- 不能沿这些接口退回传送带，也不能从炉子原路倒灌：相邻的带端口只有取货身份，炉子这一边只有存货身份（第15、44、60行）。

**答案是否唯一：允许的方向与路径唯一。具体何时移动取决于有货、空位和判定次序，并非固定时刻；第6题的容量歧义不改变这里的路径。**

**2. 同一对边接两条都向桥接器送货的传送带**

两条传送带都会各自与桥接器形成入向通道，即“左带 → 桥接器”和“右带 → 桥接器”。但没有“桥接器 → 左带”或“桥接器 → 右带”的出向通道。因此，如果“形成通道”是问两处接触是否接通，答案是都接通；如果是问能否由一条带穿过桥接器送到另一条带，答案是不能。

依据与推理：

- 每条带的取货端口都能与桥接器的存货身份匹配（第15–16、60、63行）。第16行没有要求另一侧必须存在出口才建立入口通道。
- 两个入口通往同一个物品格（第63行）。多个存货通道的权限按第29–32行处理：本题两条直接相接的单位都是传送带，属于第32行的“其余通道”同一级，在该级内轮询。先后涉及接通顺序（第28–29行），题目没有给出。
- 进入的物品没有沿这一对边离开的出口；另一对边另有物品格，不能据第63行把它当成这个格的出口。物品会积存在本对物品格内。按每格上限1的读法，收下一件后就满了，后续来料受阻；按上限未定的读法，可以继续接收该格容许的同种物品，直到达到上限（见第6题）。
- 第13行仍要求一个物品格只放一种物品。若两侧送不同种类，已进入的那一种会使另一种无法进入这个格；桥接器的例外并没有取消“单格只能放一种”的限制。

**答案是否唯一：接通关系和没有出口的结论唯一。具体运行结果不唯一：可能左侧先进入，也可能右侧先进入；积存一件即满还是能积存更多，则取决于第6题的两种容量读法。不存在由现有条文支持的“两处都不接通”或“能输出到另一条带”的读法。**

**3. 左带—A—B—右带**

允许的方向是：左带 → A，A → B，B → A，B → 右带。A、B之间会接通，而且允许回流。

依据与推理：

- 左带的取货端口与A的存货身份匹配；B的取货身份与右带的存货端口匹配（第15–16、60、63行）。
- A、B相接的端口都兼有两种身份（第63行），所以“A取货—B存货”和“B取货—A存货”都满足第16行。条文没有规定首次来料后锁定方向，也没有禁止沿进入的一侧返回。
- 一件货可以走“左带 → A → B → 右带”。但到B后，若A能接收，B → A也是合法移动；例如右带暂时满、A已经空出时，物品满足滞留要求后可以返回A，再由A送往B。
- B有通向A和右带的两个取货方向，适用第29行的取货侧轮询。第31行的取货优先级针对非运输单位，不能据此给作为运输单位的B指定“右带优先”。A若已被新的来料填满，则该时刻B不能把物品退回A。
- 每次进入A或B，都须满足运输物品格至少停留1 tick的要求（第23行），不能在同一瞬间无限往返。具体判定先后还受第25行的不确定性约束。

**答案是否唯一：通道存在、双向许可和“可能回到A”的答案唯一；实际轨迹不唯一，包括直接由B出去、先退回A再向B移动、因接收方不能接收而滞留。不能读成“必定回到A”，也不能读成“绝不回到A”。**

**4. 两座桥接器相邻，除此之外没有接东西**

有通道，且相接处两个方向都允许移动：A → B和B → A。没有外部来料，不等于没有通道；若两座里都没有物品，就只是没有实际移动。

依据与推理：第63行直接赋予双方端口存货、取货双重身份，已经满足第16行的两种匹配。第28行把接通时刻定义为较晚单位的建造时刻，没有要求接上传送带或收到第一件货。建造先后用于确定接通时刻，并未被定义为移动方向的来源。每个方向都连接双方的横向物品格，不连接各自的纵向物品格（第63行）。

**答案是否唯一：通道存在与允许的方向唯一，两个方向均成立；不能由材料推出单向或不接通。**

**5. 横向直接接分流器来料，纵向直接接传送带来料**

物品格是分开的；但“全部流动过程都互不影响”没有被明确写出。按通用调度规则直接适用，两轴的输入通道会参与同一座桥接器的存货优先级判定。

依据与推理：

- 第63行的明确表述是“每对独立拥有一个物品格”。因此，横向物品不会占用纵向物品格，也不能在桥接器内转入纵向。
- 第32行却以“一个单位的多个存货通道”为分级范围，没有为桥接器另设范围。横向直接接分流器的通道独占一级，纵向直接接传送带的通道进入“其余通道”一级；各级按最早接通时刻排序。
- 若横向这一级接通更早，且两边都能进货，第30行会先把移动权给横向级；若纵向级更早，则反过来。横向级不能移动时，不能仅因它级别高就继续压住可移动的纵向级，因为第30行明确只在“能移动”的通道中选择。题目没有给接通先后。
- 这能推出调度权限存在跨两轴的比较，却不能直接推出横向会使纵向少走一件、降低吞吐或多等1 tick。第24行规定移动耗时0；例如横向先收下一件后不能继续接收，纵向仍可能在同一tick接着收货。材料也没有规定“整座桥接器每tick只能接收一件”。

这里有两种需要区分的读法：

- **读法甲，按明文限定独立范围：**“独立”只修饰物品格的拥有。两格容量、内容分开，但第29–32行仍按整座单位调度。因此不能保证流动权限互不影响；是否造成实际时刻或数量差异，还要看具体状态。这是与第32行“一个单位”最直接相容的读法。
- **读法乙，把独立理解为两对边各自完整运行：**把轮询和优先级也分别在每一对边内执行，则横向不通过桥接器内部调度影响纵向。但这是把第63行的“独立”扩大解释成“传输调度独立”，材料没有明确写出这一点，也没有明确写出对第29–32行的例外。

**答案是否唯一：物品格分开这一点唯一；若题目要求笼统回答所有流动是否互不影响，文字没有给出无歧义的独立范围。上述甲、乙两种读法分别得到调度有关联、调度独立，甲的直接条文依据更强。即使采用甲，也不能断言纵向一定减速或停流。**

**6. 每一对边的物品格最多放几件**

最自然的读法是每对边最多1件，但文字不能排除“桥接器的具体上限没有给出”的读法。

依据与推理：

- 第59行是“运输单位：一个物品格（上限1），桥接器例外”。第63行则写“每对独立拥有一个物品格（例外）”，没有单独重述上限。
- **读法甲，例外只针对格数：**一般运输单位只有一个格，桥接器有两个格；上限1继续适用于每个格。于是每对边最多1件，整座最多2件。这也能解释第63行为什么把“例外”紧接在物品格描述之后。
- **读法乙，例外涵盖第59行整项描述：**“一个物品格”和括号里的“上限1”都不直接适用于桥接器。第63行补出了格数，却没有补出容量，所以每格具体上限未知，可能是1，也可能大于1。
- 读法乙不等于无限容量。第13行仍说物品格“有放置上限”；无限数量是第18行对缓存格的专门规定，不能移给桥接器。第17行的50也只适用于制造单位物品格。

**答案是否唯一：不唯一。可读出“每对最多1件”；也可读出“每对有上限，但材料没有给出数值”。不能把后一种读法擅自补成某个数或无限。**

**7. 两对边能否同时放同一种物品**

可以，例如横向物品格放一件蓝铁矿，纵向物品格也放一件蓝铁矿。

依据与推理：第63行给两对边各设一个物品格。第13行原本限制“一个单位内一种物品也只能放在一个物品格内”，但紧接着明确把桥接器列为例外，因而同一种物品可以分别存在桥接器的两个格中。这个例外只取消同种物品不得占多个格的限制，并不取消每个格只能放一种物品的限制。第6题两种容量读法都不妨碍每格各放一件这个例子。

**答案是否唯一：唯一，可以同时放同一种物品。**
