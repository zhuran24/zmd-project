# 老项目上界可用性

日期：2026-09-22。状态：完成《上界表》283 条记录的适用范围审查；这是迁移审查，不是重新认证旧证书，也没有产生新的现行上界。

## 结论

**没有找到可以直接把现行 U=1113 再压低的旧上界，也没有找到能够直接排除现行 8 个 1113 位置中任何一个的旧证据。** 这表示已有材料不能支持这次迁移，不表示 1113 已可达，也不表示更小的上界为假。

最值得看的是固定清单的 **1102**，但它扣了现行不必放的两台机器，共 **34 格**。旧证明换成现行最少机身后，同一边界公式在 10、11、12 桩时分别只给 **1136、1133、1130**，全部大于 1113。现行《求解约束》还已给出“粉碎69、采种17、其余在下限、无箱”的 **1089** 分支界，因而旧清单对应分支本身也已被现行结果加强。

**1082、1083、1090 等不能当作捷径。** 268 清单多放了机器，其中的活口数又曾被轮换配方和闲置机器击穿。1015、1014、1012 等小数主要属于单层、单商品或其他受限分支；现行允许桥两轴独立，也允许混料。旧准入口的 **27件/分** 界直接依赖已经不同的限额语义。

可以回收的是局部几何计数、供电装填、带流量的切线容量等证明办法。第五节只列“建议送候选约束流水线重推的条目”；这些建议尚未成为约束。

## 三、最容易误拿来压1113的数字

### 1. 1102：可回收边界计数，不能搬原常数

[旧1102原式](</mnt/wd_external/zmd-old-extract/docs/zmd-all/01-项目仓库与工作树/C-zmd-projects/zmd-research-next-docs/CONJECTURES.md:31>)为：

`A ≤ 4900 − 3544 − 4P − (718/4 + 44 − P) = 1132.5 − 3P`。

这里3544是旧固定清单机身，718是活口加非角口的权重，44−P来自左／下内带低接触容量的额外代价。不是把“有34格空余”再扣一次；34格正是旧清单与现行下限的机身差额。

现行A=1113时，非桩非运输机身恰为：

`131×9 + 48×25 + 38×24 + 46×3 + 81 = 3510`。

即使暂保留旧718和完整边界证明，只改机身，便成为：

`A ≤ 1166.5 − 3P`。

P=10、11、12取整后分别为1136、1133、1130。这里是**检查旧路线还有多少强度的代入计算**，不是未经流水线就另发一条现行约束。718在现行最少台数、无箱下可由基础口数619与非角口99重新获得，但内带几何仍应以现行证明为准；正式《约束》的921、X、Y等已比这本旧粗账细。给机器改名、把“266”改成“264”不能保住1102。

旧266清单相对当前九机型下限恰多粉碎1台、采种1台；若只研究其无箱分支，现行《约束》145行已经给1089，比旧1102更小。然而A=1113已强制这两台都不增加，不能用1089反过来消掉1113。

### 2. 1082／1083／1090：台数与活口前提已经断裂

N05—N08继承268清单、625或621等活口数。原文自己已撤回“每台22／12种植机均有正活量”的625前提；1083修补又未覆盖轮换分摊。[反驳记录](</mnt/wd_external/zmd-old-extract/docs/zmd-all/01-项目仓库与工作树/C-zmd-projects/zmd-research-next-docs/reviews/2026-09-03-codex-bound-refute-check.md:11>)没有给超过这些面积的完整工厂，但足以使旧证明不能承担剪枝。现行台数口数只能从正式下限和逐机流量重算。

### 3. 1015／1014／1012：都是要带分支的数

P07—P09把每格最多两个运输物品格进一步限为一个；P09还要求每状态单商品。现行桥的独立双轴与混料都不能删。**不用桥的分支**确实值得单独看，但正式《约束》138行已经给A≤1040，已排除无桥1113；它不证明允许桥的全域也≤1040。

把P2.0的吞吐计数改到当前最少机身、10桩、包括成品的305.65件/tick，得到运输物品格至少306、运输单位粗下界153，于是粗算A≤1197；若不用桥则粗算1044。旧1015不是当前这条粗公式的输出。当前更强的运输／内带条件应保留，不能被粗算替换。

P10、P11的“平均路长至少2／3”若真能在当前证明，确有压界潜力；目前材料没有建立该前提。按现行账代入，两轴粗面积分别为1044／891；单轴为738／433。它们只是“假如先证明路长”后的算术，不是新增上界。一格运输件即可连接局部产耗口，所以不能从“工厂很复杂”直接假定平均路长≥2。

### 4. 旧接触松弛不可能原样打1113

[Q50的严格能力界](</mnt/wd_external/zmd-old-extract/docs/zmd-all/01-项目仓库与工作树/C-zmd-projects/zmd-pj/.artifacts/sixpred_upper_next_band_20260821/certs/EXHAUSTION_CHARACTERIZATION.md:92>)使用排除条件：

`raw ≤ 4wh − 4545`，且`raw ≥ 0`。

面积1113代入右边为−93。因而**无论再把旧raw证书做得多精确，原公式也不可能排除1113**。此外Q01—Q49针对的尺寸、旧库存、738权重和1320面积预算都不是现行8位置模型。若改变预算和权重、换成外侧实际占地模型，那是在重推新模型，不能声称沿用旧证书。

### 5. 27件/分准入口界有现行规则下的局部反例
