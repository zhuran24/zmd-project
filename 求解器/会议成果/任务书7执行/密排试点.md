## 3. 自动通道、交叉、阻尼与供电

R16：“相遇时将自动形成通道”；owner三审L51定共边相遇、角点接触不成通道。核验从各型单位的完整边界重新生成端口，扫描所有相邻格上的反向法线及存/取角色，并要求至少一端为运输单位（C28）。得到的182条边与计划路径逐边相同，详见[自动通道](证据/密排/自动通道.json)。检查覆盖所有端口，包括零流量和未使用端口；相邻两台制造机只共边也不产生制造机直连。

R23给每运输格至少1tick，R26—27把连续带段计一个元件。两圈PH/PG/HP分别长1/3/15格，均为连续带，各阻尼1；转弯没有增加连续带段数。粉末出口只有一格已铺带，后面的非运输消费者尚未接入，记录已知元件前缀1，完整阻尼为null。52条矿石续路同样保留完整阻尼null。

成品的每组三路长15、7、16格，阻尼分别3、3、5：第一、第二路各为带段—桥—带段；第三路为带段—桥—带段—桥—带段。三路不同长度保持，R31使它们各自源机的唯一取货通道处在唯一一级。植物P的两条路也同属“其余”一级。全部实际非运输输出都先接带，取货侧阻尼比较无作用；轮询、到货和库存条件仍按接口使用。

四桥在(15,41)、(18,40)、(49,41)、(52,40)。第一/第三座水平W→E、竖直S→N；第二/第四座水平E→W、竖直S→N。R63给每轴自己的单件物品格；各桥四邻全部是定向带，桥之间不相邻。蓝图按R9先建桥后建带，某一轴先接任意一端，邻带的角色都给出上述同一方向；另轴独立决定。逐桥24种邻带接通次序均满足这个一致性条件，完整建造排序投影到每桥也仍在这24种之内。由此本例桥链定向前件结清。T14只改接通先后，保持已建桥方向；重建桥属于另一次调试动作。

桥两轴物品各沿原轴通过；R13明确豁免桥接器，可同时装同种，各轴1件/tick。六路服务、17/22长路等待及正确有限预装106tick恢复见[成品输出通路§2—4](成品输出通路.md)。

供电按R76的12×12范围与需电单位占地作正面积相交检查。8桩无占格冲突，12台制造机和2只箱全部有覆盖，见[桥与供电](证据/密排/桥与供电.json)。总运输占地166格、物品格170个，四桥各增加1个物品格；同时占货容量170。植物42格、成品76格、矿石边界52格；成品占地72格、同时占货容量76。

## 4. 改摆前件逐项保持

被承接的窄式是[植物运行试点](植物运行试点.md)L149—161的辅助起法，不是默认堵满。[调试与释放](调试与释放.md)L185—189已经区分二者。

| 前件 | 改摆后的核查与结论 |
| --- | --- |
| 每种一台P/H/G、正确原料、P两出口分给H/G | 编号保持B的两个半分根；自动通道保持这张局部图，用途为1:1 |
| 独占首格、独占回路路径、无额外入口 | 全端口重建得到这6条植物内部路径，无共用运输物品格 |
| P出口同级，H单种子口，G一口/三口 | 出口均先接带；实际度数分别2、1、1/3；桥只在成品区 |
| 路径整数长度、种子及时回到P | 旧3/3/17改为1/3/15；首返上界重新算为1+15+3=19 |
| 空线、空H/G普通格和缓存，P输入q种子，H/G先开 | 程序及全部这些起点保留；19≤q≤50均满足新长度界 |
| 供电 | 每台至少一桩覆盖；桩移动后的逐台交叉检查通过 |
| 粉末每口一件恰1tick送走 | 四个实际外接口已列，外部研磨未接；作为明确前件保留 |
| 任意固定接通/同刻顺序 | 按旧窄式，在持续服务与空线起法内覆盖；任意时刻反复离线仍须共同安全集合 |
| 运行库存和容量 | 每圈种子/植株运输格23→19，正常槽位与单批缓存的N容量277→273；q=50的首返余量27→31 |

在以上接收和起法条件下，P每tick一批，H/G各每2tick一批；荞花粉末1/tick，砂叶三出口各1/2/tick，合3/2。这是带条件的实际保证。将外部研磨接上后，应逐事件证明这四口服务；在整厂登记中仍保留实际率null。

改摆后的273由正常P/H/G槽位250、正常单批缓存的植物计数上界4、运输19相加。R18物理缓存容量无限，273仅用于规定的正常槽位及正常门控域。辅助程序实际初始N=q，其余为空；它与容量上界分列。默认“输入满、输出积压、缓存空或完成”的状态不满足空线前件，因此没有从几何变紧推出默认程序进入安全集合。

计入每圈三机59格、两桩8格，荞花局部实体占地由91减到87，砂叶由93减到89，共省8格；其来源是每圈PH和HP各缩短2格。这个比较只计同一局部部件的占用，完整基地最大空矩形没有据此增加。
