### 分解与割（主责 seat-opus-1；覆盖核 seat-codex-1）

长论证：seat-opus-1.md 第二节；代码 seat-opus-1/toy.py、fulllp.py、coarse70.py。

1. 子问题定义在一张不随布局变化的母图上：每个可放运输单位的格三个物品格结点（c0 给传送带、分流器、汇流器、准入口共用，cH、cV 给桥的两轴），每个可能的机器位置（存货侧、取货侧分开），每个可能的核心、取货口、储存箱位置，仓库一个汇；弧是所有可能的端口对。布局只进右端：容量行 C z ≤ u(x)、下界行 D z ≥ t(x)，u、t 是主问题 0/1 字面量的线性式；守恒行 E z = 0 和全部左边系数与布局无关。z 是弧×物品的周期平均流量、机器×配方的批率、取货口的出量，全部连续。
2. 任何达标布局取一个可到达循环态的周期平均量，就满足子问题的每一行（依据逐条见 seat-opus-1.md 2.2）；只要求有一个循环态，不要求各循环态内部流量相同。
3. 割：取 ρ ≥ 0、μ ≥ 0 和任意 π，只要母图每一列都满足 (Eᵀπ + Dᵀρ − Cᵀμ) ≤ 0，就有 μᵀu(x) ≥ ρᵀt(x) 对一切使子问题可行的布局成立。乘子取第一阶段线性规划（所有「≥」行加松弛，保证第一阶段本身可行）的对偶；有理化后在整张母图的全部列上逐列精确核，违反的列只抬高该列所在容量行的 μ；乘整数后系数、右端都向上取整加回 CP-SAT，仍对一切布局成立。每条割单独可核：给出乘子和母图定义，逐列复算即可。
4. 实测（玩具工厂，不是正式问题；12×12，两个源矿口、一个砂叶口，粉碎机 ≥3、研磨机 ≥1，成品 ≥1 件/tick；运输层是完整 28 种格状态；CP-SAT 4 线程；负载 13–32，24 核上另有他席实验。每行只说明这一次）：
   - 甲，几何＋自动通道＋每台机器两边各 ≥1 条通道：1.05 s 出解，子问题判一件成品都送不出。
   - 丙1，甲＋上面的割循环：200 轮、290 s 未收敛，缺口始终是目标的 100%；割 14–34 项、右端都是 1，每条只说「这一小块还缺一条进来的通道」，主问题每轮补一格。
   - 丙4，甲＋五种物品各一份全幺模子集流＋割循环：16 轮，主问题合计 564 s（每轮 12–133 s），缺口在 33%–100% 之间来回，未收敛。
   - 乙，甲＋按物品、带配方、共用容量的整数流一次求解（刻度 60，变量 24812）：900 s UNKNOWN，一个解都没找到。
   - 对照：人摆一张 D1 布局只要 11 格运输（三台粉碎机输入正对取货口、研磨机输入正对粉碎机输出、一列直带），母图线性规划判流量可行；把它钉进乙、丙4 的模型都判可行。D1 可行且解很简单，上面三种写法在各自时间里都没找到。
5. 由此得出的两条（只说明这几次）：一是连通性必须由主问题里的紧凑流量写法负责，割只补各物品绑在一起的部分（共同容量、配方比例、矿口指派、准入口限速），主问题一点流量都不带时割循环一格一格地补、在 12×12 上就不收敛；二是即使主问题带上流量（乙、丙4），通用 CP-SAT 搜索在一个有 11 格简单解的 12×12 实例上也没找到解。抬 L 不能指望通用搜索自己找到布局，要靠有结构的受限表示（1.3）；压 U 要的是证明不可行，比找解更难，只能指望比格级更粗、更小的放松（下一条）。
6. 压 U 侧的下一档：粗网格流量放松。格级几何照旧；线性规划只在 b×b 块上建：每块每种物品守恒；相邻块之间两向流量和 ≤ 边界两侧各自的运输格数；每块「进入本块物品格的件数」≤ 本块物品格数（非桥运输格 1、桥 2，会议 2 密度律的逐块版）；机器按位置记配方，从块 B 收、向块 B 送 ≤ 该块里它端口外侧运输格数。块内求和就是从格级流到块级流的映射，所以是真放松（seat-opus-2 核过两条块级约束）。70×70 实测：（待填）。
