## 2. 从带下界网络到一次最大流：完整构造与证明

### 2.1 被判定的对象

先固定几何、单位类型、z 及其他共用离散选择 x。对总量流进行以下网络扩展：运输物品格拆为入口、出口及内部容量弧；机器输入、输出分开，各侧用一条弧表达逐台上下界，再用机型汇总节点和弧表达合计上下界；供给、核心收货等同样用弧及记账节点表达。

本节判定的是这个平均总量放松网络，不是运行系统。未知逐台配方比例、多商品共享容量、均分等额外关系不在此网络保证内。桥若合并成容量 2，是另一项明确的 U 放松；保留独立双轴也仍可用网络处理。

设有向图为 G=(V,E)，弧上下界为 l_e、u_e，节点净需求定义为：

    流入(v) − 流出(v) = d(v)。

因此 d>0 为需求，d<0 为供给。先检查 0≤l_e≤u_e 及 Σ_v d(v)=0。纯循环流形式取 d=0，但弧下界仍可能非零。

### 2.2 消去下界并建立超级源汇

令：

    y_e = f_e − l_e，c_e = u_e − l_e，
    r(v) = d(v) − Σ入v l_e + Σ出v l_e。

原问题等价于 0≤y≤c 且“流入 y−流出 y=r”。建立新网络：

- 原弧容量改为 c；
- r(v)<0 时，加超级源 s*→v，容量 −r(v)；
- r(v)>0 时，加 v→超级汇 t*，容量 r(v)；
- 记 H=Σ_v max(r(v),0)，它也等于总供给。

**原问题可行，当且仅当该网络的最大 s*—t* 流值等于 H。**

证明：原可行 f 给出 y=f−l，将所有新增弧取满，扩展节点守恒便成立。反过来，最大流值为 H 时，超级源和超级汇所接弧全部饱和；去掉新增弧后 y 恰满足残余需求 r，再加回 l 就得到原可行 f。H=0 时，这一判据仍成立。

若缩放后的 l、u、d 为整数，则 c、r、H 也为整数，可用整数最大流，并得到整数替代见证。这里“一次”指一个固定 x 下的一个网络因子；不意味着整个几何搜索只调用一次，也不意味着耗时已测到毫秒级。

### 2.3 最小割如何还原

任意原节点子集 X 都必须满足：

    d(X) + l(δ⁺(X)) ≤ u(δ⁻(X))，

其中 δ⁺ 为离开 X 的弧，δ⁻ 为进入 X 的弧。必要性来自把 X 内平衡式相加：进入量有上界，离开量有下界。

充分性由上述最大流变换给出。若最大流不足 H，取最小割源侧 A，令 X 为不在 A 中的原节点，即原节点的汇侧部分，则该割容量为：

    H + u(δ⁻(X)) − l(δ⁺(X)) − d(X)。

它小于 H，恰好给出上式的严格违反。这既提供不可行证书，也说明下界项不能省略。

最小例：a、b 均 d=0，a→b 强制送 1，b→a 上界为 x∈{0,1}。若只查“原始净需求 0≤入弧上界”，所有子集都通过；实际可行当且仅当 x=1。正确的 X={a} 割是 1≤x。

所以“无节点源汇需求”不表示“无强制流量”。矿口满速、机器侧下界及机型合计可以全部藏在弧下界中。若同时没有节点需求和任何正下界，零流本来就可行，那种模型无法检查生产任务。

本节公式与 seat-codex-1 最新第 6.3 节一致；本席核对其符号及构造，不重复其 280 个小网络核验。

### 2.4 z 和全局反馈的边界

固定 z 后，0≤g_e≤20z_e 只是整数上界，不破整性。几何、方向、计数等纯离散约束筛选哪些 x 可被采用，也不改变每个固定 x 下的网络性质。

但 z=1 不推出替代流为正。U 覆盖可以沿“取真实支持 z→在同一 x 内改选整数替代流”建立；报告候选时不得把 z 当成已实现的正支持。零流量运输单位也不能因实体存在就被强制参与正流。

反馈到其他布局时，应在固定母图中保留参数：

    d(X;x)+l(δ⁺(X);x) ≤ u(δ⁻(X);x)。

X 是扩展图节点集，可能切过机器侧、运输内部容量弧或机型汇总节点，不一定是一块平面区域。地理区域割是可以另选的一族必要条件，不能冒充全部网络割。整数割解决了这层的浮点证书问题，没有省去母图、分支覆盖和容量参数化检查。

## 3. 独立物品子集：认可命题，限定使用方式

对选定的物品子集 K_j，真实流相加得到每份连续见证。若每份只用自身变量，固定共用的 x 后，流量可行域确为：

    P(x)=P_0(x)×P_1(x)×…×P_m(x)。

每个非空因子都有整数替代见证时，各自选一份便得到同一 x 下的整数联合见证。K_j 互相重叠没有问题，因为模型没有要求这些副本之间保持逐边的集合关系。

共用 z 不构成反例：在这个证明步骤里 z 已固定，只改变各份网络的容量。未固定 x 的整个混合整数模型当然不是一个直积，但证明不需要它是直积。

必须保留三项前提：

1. 各子集的逐台上下界及机型合计，分别是实际运行的必要条件；“合计已知”不能把仅有下界的量改成精确等式。所用刻度下数据须确为整数，或另做有覆盖证明的外放松。
2. 子集之间不共享连续配方批率、不加逐弧包含关系、不合并限容，也不要求各自替代流具有同一正支持或饱和集合。否则应重新核验，不能沿用直积证明。
3. g^j 是彼此独立的松弛见证，不是同时可执行的多物品流。即便子集包含关系为 K_1⊆K_0，也不保证所得 g^1≤g^0。

“矿石子集＋全体物品”值得试作加强层。本席只补上述与运行接口有关的边界；完整数值及映射复核仍由 codex-3、codex-1 主做。该层可以每个因子各做一次带下界最大流；不能把若干独立可行判定合称已得到联合运输计划。

## 4. 分母问题：限定 K=20 与一般 LP 没有矛盾

当前已认可的 K=20 结论适用于：去逐台配方挂钩、机器两侧分别限量、机型汇总可网络化，且全部必要上下界乘 20 后为整数的那一层。上述独立子集版也只能逐因子使用同一条件。

一般带配方、共享容量和额外机制条件的 LP 尚无已给出的实用统一 K 保证；这不等于证明不存在任何有限倍率。固定有界有理 LP 可取有理顶点，基矩阵行列式给理论分母信息；统一倍率需要兼容相关分母的整除关系，不能把“分母不超过 D”直接写成“K=D”。

需要保存的性质是“每个达标离散布局至少有一份网格替代见证”，而非“每份真实循环流都落在网格”。本席限定网络证明与 codex-1、codex-3 的一般性陈述一致，不构成对其反驳。

保持整数替代流 g 与连续物品流 f 分开；未经新证明，不加 g_e=20Σ_k f[e,k]。同样，不能根据 g 中偶然满速或归零的边，直接声称真实运行对应边也满速或归零。

## 5. 对 P2P 回应的确认与具体校验发现

### 5.1 三项概念回应可以确认

接受 seat-opus-3 的下列回应，但范围是其明确的受限类和静态计划：

- 若每条结构通道恰属一条源端口到汇端口的路径，路径标签已有固定速率 r_p>0，且端口与物品格容量、机器物料账都核过，则 δ=min_p r_p>0 可直接取，不必再解 max δ。当前铁砖计划每路为 1。这回答了“z=ch 本身不保证正流”的问题：补足保证的是路径速率见证，不是那个布尔等式。
- 无分汇流器、各侧只有一级，只减少竞争机制；堵塞、库存、供料和运行先后义务仍保留。它不证明实际流等于静态计划。
- 从全部实体和边界来源沿重算通道追踪，列出未覆盖运输物品格，是排查无源环的适当静态接口。最小化运输格不替代这项检查。

不需要让 P2P 发生器在本轮就完成全部运行证明；但“以后交内核”仍不是已经完成量词覆盖的证据。

### 5.2 轮询定理的使用范围

正式《轮询均分》说的是取货侧，并非机器存货侧的通用均分定理。一般 P2P 中若某机器有多个取货通道，要使用它仍须核全部前提；“只有一级”不能省去首格独占、接受物品、腾空时刻、事件组及起点等要求。

当前 `iron_brick` 的每台机器 n_out=1，取货侧没有出口选择问题，因此不必为该单出口证明多路均分。研磨机仍有三条存货通道；其输入轮询、两个独立存货格、各料及时到达以及制造/出料服务条件仍须单独处理。这是局部简化，不是整砖运行认证。

### 5.4 单路纯料不自动等于单机单配方

opus-3 最新稿从“每条路径单物品”直接推出“排除全部混做”，这一步仍需补前提。前者限制路径，后者限制机器执行序列；机器有多个取货端口时，不能只凭二者的名字推出等价。

## 6. 机制审查：删除条件与四个不得依赖量

### 6.1 对 opus-4 主结论的判断

压 U 暂不编码阻尼、具体轮询和其他运行机制，可以是正确放松。理由是删除真实可行域的限制会扩大可行域，不取决于被删除的条款是不是条件句。

但这只支持“第一档选择暂不编码这些机制”，不证明“除满速传播之外，再无有用的几何必要条件”。也不能把所有已知机制结论一概称为某个粗流量模型的自动推论。

满速独占的传播要求正确端口拓扑、相应独立容量 1 物品格及分流停止条件；准入口 k<5 的排除还要求模型已保留 q≤k/5。自由转向、合并桥的容量模型缺少部分前提。删除相关条件依然可以放松，但须如实记录强度。

### 6.2 四类不确定量的表示边界

本席建议候选验证接口明确记录四类选择及其合法范围：

| 不得依赖量 | 记录与覆盖义务 |
|---|---|
| 接通先后 | 记录合法通道先后、由其导出的级序和轮询顺序；桥方向另由首接及建造/调试历史推出。离线可改变通道先后，接续运行须保留当时库存，不能无证明重置回调试初态 |
| 判定先后 | 作为正式要求固定的同刻判定顺序参数；不能每 tick 任意换序，也不能只取最有利的一份。离线条文明说可改变的是接通先后，不能自行让判定顺序也随段改变 |
| 分叉分支 | 保存阻尼所用的合法联合分支选择，对同一联合取值比较级间阻尼；不能未经证明把相关选择独立化成区间极值比较 |
| 传输相位 | 有储存箱时保留合法无线事件相位及与库存、接收条件的关系；无箱候选可明确消去这项 |

不先把各局部次序、相位选项随意作笛卡尔积，也不擅自删去组合；先给出覆盖映射。对运行随时间是否可变的量，按正式文件处理，不能因验证方便一律冻住或一律每 tick 重抽。

任务需要的是：调试可执行，且其可能后置状态在全部合法不确定量及允许接续下，每个相关可达循环态都达标。不同情形可以有不同内部流量；不要求统一逐边流、统一周期或逐 tick 状态不变。

N1–N5 或 P2P 可以消去某些机制入口，但消去哪一项须逐项证明。单次内核运行、单份状态或单一周期见证，不自行覆盖上述范围。
