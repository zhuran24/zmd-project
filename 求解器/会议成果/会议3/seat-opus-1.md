# seat-opus-1 立场（会中覆盖更新）

## 定位

分解路线：带子这一层拆成「离散几何」和「连续流量」两半。离散几何进 CP-SAT 主问题，只放整数；流量是给定主问题取值以后的线性规划子问题；子问题无解时由乘子得到一条只含主问题变量的线性割加回主问题。我交：子问题的完整写法和依据、割的构造与有效性证明、有理数核法、取整法、一批事先可加的整数割、小尺寸对照实测。seat-codex-1 否证割的有效性，seat-codex-3 审流量映射。

主问题的格状态表和按机型位置变量用 seat-opus-2 的；抬 L 侧的受限表示归 seat-opus-3；机制条件归 seat-opus-4（压 U 用的满速布尔 u 按他给的写法接进来，见第二节）。

## 一、主问题：离散几何

每格一个局部状态：空、非运输单位的一部分、传送带 12 种、分流器 4、汇流器 4、准入口 4、桥接器两轴方向 4 种。机器、核心、仓库取货口、储存箱、供电桩按「机型×朝向×位置」建布尔 y，不编号。由状态推出每格每条边的端口字面量，再推出每条有向通道的字面量（两端口相对即有，至少一端是运输单位）。

主问题里的量全是整数：位置、格状态、通道字面量、「通道有流量」布尔 z、满速布尔 u、各种计数（求解约束里和运输层有关的条目），以及第三节那种按条件可以取整的子集流（整数替代流，不是实际流）。带配方比例、共同容量的连续流量不进主问题。

## 二、母图和子问题（问题 2）

### 2.1 母图：一张不随布局变的图

割要对一切布局成立，子问题就要定义在一张不随主问题取值变化的图上，布局只改容量和右端。这张图 G* 取所有可能出现的东西：
- 结点：每个可放运输单位的格 c 三个物品格结点 c0（传送带、分流器、汇流器、准入口共用的那一格）、cH、cV（桥接器两轴）；每个可能的机器位置 m 一个机器结点（存货侧、取货侧分开记账）；每个可能的核心位置、仓库取货口位置、储存箱位置各一个结点；仓库一个汇。
- 弧：每一对相邻格、每一种可能的端口对（c 的某个物品格从朝 c′ 的边送出、c′ 的某个物品格从朝 c 的边收进；水平边只接 c0 或 cH，竖直边只接 c0 或 cV）；每个可能的非运输单位位置和它端口外侧格之间的弧；储存箱、核心到仓库的无线或存入弧。
- 变量：每条弧每种物品的平均流量 f ≥ 0；每个机器位置每个配方的批率 λ ≥ 0；仓库取货口、核心取货端口每种物品的出量 g ≥ 0（「设成哪种」是设定项，这里放成连续，是放松）。

行分两类。左边系数全是常数，与布局无关：
- 守恒（=0）：每个物品格结点每种物品收＝出（桥两轴各自）；每个机器结点每种物品存货侧收到＝Σ配方用量×λ、取货侧送出＝Σ配方产量×λ；储存箱每种物品收＝外送＋无线入库。
- 目标（≥ 常数）：两种成品进仓库 ≥0.6、≥0.55。

容量行（≤ 右端），右端是主问题变量的线性式：
- 实体通道弧：Σ物品 f ≤ 该弧的通道字面量（两端端口字面量之与；一端是机器位置 m 时是「端口字面量 ∧ y_m」）。z 布尔另写 Σ物品 f ≤ z_e，z_e ≤ 通道字面量；z 只给上界，是支持的放松，不能把解出的 z=1 当成实际有流。
- 物品格：c0 的总送出 ≤ e0_c − Σ_{k=1..4} (5−k)/5 × 门_{c,k}，其中 e0_c 是「c 是非桥运输单位」，门_{c,k} 是「c 是准入口且每 5 tick 上限设为 k」；非准入口和不设上限的准入口就是 ≤ e0_c，设了 k 的是 ≤ k/5。cH、cV 各 ≤「c 是桥接器」。
- 机器：Σ 配方时长×λ ≤ y_m（带供电时改成 y_m 与「被照到」之与）。
- 仓库取货口、核心每个取货端口：它只有一条实体弧，弧上各物品流量就是它的出量；物品只限两种矿（取货口配置），总量 ≤ 位置字面量；取货口配置的「全部满速」写成下界行 ≥ 位置字面量。
- 核心存货端口进仓库：核心结点就是汇，实体弧那一列直接记到目标行，不另设记账列；每个核心存货端口那条实体弧照常 ≤1。储存箱无线入库：记账列不限 1，但给它一条按规则算的容量行 ≤ 60 ×「该位置是储存箱且有供电、传输开着」（每次至多送出 6 格×50 件、5 tick 一次），这样每一列都至少在一条系数为正的容量行里，逐列修补 μ 的做法对它也成立（codex-3 指出记账列不限 1 后修补要另处理）。
- seat-opus-4 的满速：若主问题取 u_n=1，则 n 的总送出 ≥ u_n（右端带主问题字面量的下界行），分流器各支和同理。

一张布局对应一组主问题取值，于是对应这张图上的一组容量：不存在的格、机器、通道，容量是 0，流量被压成 0；存在的就是规则给的容量。所以不同布局只改右端，G* 和左边系数不变。

### 2.2 为什么任何达标布局都满足子问题

取达标布局的任一可到达循环态（周期 P），把一个周期里每条通道过的每种物品件数除以 P：
- 运输物品格只经通道进出，周期首末库存相同，所以每种物品收＝出（依据：运输单位、通道、移动、循环态）。
- 物品格上限 1、每件至少停 1 tick，所以一个物品格每 tick 至多送出 1 件；端口每 tick 至多 1 件（依据：运输单位、滞留、端口速率）。
- 机器的存货格、缓存格、取货格周期首末相同，所以每种物品收到＝用掉、送出＝产出；1 tick 配方每 tick 至多一批、5 tick 配方每 5 tick 至多一批（依据：制造、缓存格、存货/取货物品格、配方）。
- 两种成品进仓库的速率恰是目标（依据：周期倍数）。
这组平均量满足全部行。子问题只需要有一个循环态，不要求各循环态内部流量相同；它是真放松。

### 2.3 割：怎么来，为什么对一切布局成立

子问题写成：E z = 0，D z ≥ t，C z ≤ u(x)，z ≥ 0。其中 z 是全部 f、λ、g，x 是主问题取值，E、D、C 不随 x 变，u(x) 是 x 的线性式。

取任意乘子：π（守恒行，正负不限）、ρ ≥ 0（目标行）、μ ≥ 0（容量行），只要求每一列满足
  （Eᵀπ + Dᵀρ − Cᵀμ）的该列分量 ≤ 0。
则对任一使子问题可行的 x′（可行解 z′）：
  ρᵀt ≤ ρᵀDz′ ≤ z′ᵀ(Cᵀμ − Eᵀπ) = μᵀCz′ ≤ μᵀu(x′)。
所以
  μᵀu(x) ≥ ρᵀt
是对一切达标布局都成立的线性不等式。它的有效性只用到三件事：ρ ≥ 0、μ ≥ 0、逐列条件；不用到 π、ρ、μ 是不是最优、是不是从当前布局算出来的。

乘子从哪来：当前主问题解的子问题不可行时，解第一阶段线性规划：凡是「≥」行（成品目标行，以及右端带主问题字面量的下界行，例如满速 u_n=1 ⇒ 送出 ≥1）都加松弛 s ≥ 0，最小化 Σs。z=0、s=右端 总是可行，所以第一阶段一定有有限最优值；最优值 > 0 时它的对偶给出 π、ρ、μ，且在当前 x 上 μᵀu(x) < ρᵀt(x)，割切掉当前解。下界行的右端 t(x) 带主问题字面量，割写成 μᵀu(x) − ρᵀt(x) ≥ 0，字面量系数可以为负（codex-1 指出只给目标行加松弛时第一阶段可能本身不可行，已照此改）。

对 seat-codex-2、seat-codex-1 的质疑（「只补当前图未开通弧的罚项不足以覆盖任意新布局」）：逐列条件必须对 G* 的每一列成立，不只是当前通道图的列。第一版实现只在当前图上解、图外结点 π 取 0 再补 μ，在玩具上出了问题（见第五节 D1-丙0：同一格背后多个可能机器位置合用一个字面量时，图外位置补的 μ 落到了当前为真的字面量上，割不再切掉当前解；有效性没坏，强度坏了）。现在的实现是在整张 G* 上解第一阶段（右端取当前布局的字面量值，图外的容量就是 0），对偶天然覆盖全部列：机器×配方列、取货口列、桥轴列、汇的列都在；然后有理化，逐列精确核，违反的列只抬高该列所在某条容量行的 μ（每列至少在一条系数为正的容量行里），最后再独立全量复核一遍。

### 2.4 有理数核与取整

- 核：π、ρ 从浮点解四舍五入成有理数（ρ 截到 ≥0），μ 按上面公式用有理数重算，逐列用有理数验条件。验的只有「逐列 ≤ 0、ρ ≥ 0、μ ≥ 0」，全部精确，不依赖求解器容差。
- 取整：割 Σ a_i L_i ≥ R（L_i 是 0/1 字面量，a_i 有理数、可正可负）乘 K 以后每个系数向上取整、右端向上取整：Σ ⌈K a_i⌉ L_i ≥ ⌈K R⌉。因为 ⌈K a_i⌉ L_i ≥ K a_i L_i 对 L_i∈{0,1} 都成立，左边整数且 ≥ K R，所以取整后仍对一切布局成立。取整会让割变松，K 取大些（例如 10⁴），加回前再核一次它在当前解上仍被违反。
- 每条割因此单独可核：给出 π、ρ（有理数）和 G* 的定义，任何人都能逐列复算。

### 2.5 区域割和最小割是这种割的特例

取 π 在某个结点集 S 里、某类物品上取 1、别处取 0，上面的构造退化成计数割：S 的净需求必须由进入 S 的弧运进来，每条 ≤1。seat-opus-2 指出，对全幺模的子集流，最大流不可行时最小割直接给出这种整数割（Gale–Hoffman，要带下界：d(S)+l(出S) ≤ u(入S)）。codex-1、codex-4 补正：S 是扩展母网络上的结点集，可以含机器两侧结点、机型汇总结点，不一定是一块地图区域；反馈给主问题的是母网络上随布局变量变化的割本身，能否化成「一块区域边界上的运输格数」要另核。第五节 D1-丙1 的割就是这一类，实测里它们只管很小的 S，所以一格一格地补。

## 三、流量哪些能留在 CP-SAT 里取整，哪些必须交子问题

周期只知是 20 的倍数，一条通道的平均流量「每周期件数/周期」分母没有上界。CP-SAT 里写成 1/K 整数倍，要不漏布局，需要一个整性保证：固定全部布尔以后，只要连续可行，就有 1/K 网格上的可行点。全幺模是一个充分条件，不是必要条件；「不是全幺模」只说明通用保证没有了，不等于已经漏了某张达标布局（codex-1、codex-2、codex-3 的措辞，我照用）。现在对带配方比例的写法没有实用的分母界，所以它不能在 CP-SAT 里取整后拿去压 U。

能留在 CP-SAT 里的（seat-opus-2 第二、四条，我核过）：
- 任取若干物品子集（可以是全体物品、单一物品、或几种物品的并），每个子集一份不分物品的流，各自守恒、各自限容 ≤1、≤ 通道字面量；每台机器对该子集的收量、出量各自只给整数上下界（按每 tick 至多一批算），按机型给合计。子集与子集之间除共用布尔外不写任何联系。
- 为什么对：固定布尔后，每个子集的约束是网络矩阵（每台机器的收量、出量各是一个中间结点，按机型的合计是总结点），乘 K 后界都是整数，有理可行 ⇒ 整数可行；子集之间没有共用的连续量，可行集是直积，各自的整数解拼起来就是整体的整数解。
- 条件：同一子集里的各条合计，所涉机器集合要成层（两两不交或互相包含）；交叉的合计就不再是网络矩阵，整性要另证。每台机器同一子集的「收」和「出」之间不能写比例（那就是配方挂钩）。
- 代价：丢的是「各子集流都是同一份底层分物品流的投影」这层联系——所以逐弧的共同容量（底层各物品合计 ≤1）在子集层表达不出来；子集可以重叠，不能把各子集流直接相加去限容（全体层与矿石层相加就把同一件矿算了两次，codex-3 指出）——以及逐台的配方比例。这两样交子问题。

所以流量分两层：CP-SAT 里放若干份各自全幺模的子集流（整数、不漏）；共同容量、配方比例、矿口指派、准入口限速这些把各物品绑在一起的东西，放在第二节的线性规划里，经割回来。

## 四、先后机制（问题 3）落到这两半的哪里

- 压 U：先后机制本身什么都不加（seat-opus-4 的结论，我同意）。正式约束里由机制推出的几条（满速独占、矿线专机等）在分物品、运输物品格容量 1、桥两轴分开的流量模型里都是推论；在更粗的放松（不分物品、粗网格）或不带流量的主问题里不全是推论，要用就写成 z、u 和格状态上的式子当冗余割。「u=1 ⇒ 送出 ≥1」「Σ流量 ≤ z」是子问题里右端带主问题字面量的行，割里自然出现这些字面量（系数可为负，取整规则照 2.4）。
- 抬 L：设计限制只进受限模型，登记覆盖损失（seat-opus-3）。阻尼不进主问题（seat-opus-4）。

## 六、压 U 侧的粗网格流量放松（70×70 实测）

代码 seat-opus-1/coarse70.py。格级几何照旧（机型×朝向×位置布尔、核心位置、运输格 t、桥 b ≤ t、每台机器两边外侧各 ≥1 运输格、46 个取货端口外侧格是运输格；取货口固定一种合法排布、角格空；不放供电桩，这是放松）。线性规划只在 5×5 块上建，母图＝全部块＋全部可能机器位置＋全部可能核心位置：
- 每块每种物品守恒（块内运输网络当一个结点）。
- 相邻两块之间两向流量和 ≤ 边界上 B 一侧的运输格数，也 ≤ B′ 一侧的运输格数：非角的边界格只有一个跨界邻格，一对相邻格之间至多一条通道，每条 ≤1。
- 每块「进入本块物品格的件数」（来自邻块、机器取货端口、取货口／核心取货端口）≤ 本块 Σ(t+b)：每件进入都进本块某个物品格，物品格上限 1、至少停 1 tick，每个物品格每 tick 至多接收 1 件。这是密度律的逐块版。
- 机器按位置记配方（Σ时长×批率 ≤ y），从块 B 收、向块 B 送 ≤ 该块里它端口外侧格的 t 之和、≤ 端口数 × y。
- 取货口每口 ≥1、≤1 件矿；核心每个取货端口 ≥ 核心位置字面量、≤ 同；核心存货端口收任何物品；成品进核心 ≥0.6、≥0.55。
- 不在当前布局里的机器位置补乘子：存货侧 α = 它各存货块 π 的最小值，取货侧 β = 各取货块 (π − σ) 的最大值（σ 是逐块密度行的乘子），这样它的弧列不需要 μ，λ 列只在 y 上要系数 max(0, (Σ产量β − Σ用量α)/时长)。全部乘子按整数刻度 10⁶ 有理化、逐列精确核。

块内求和就是从格级流到块级流的映射，所以这一层对一切达标布局成立（seat-opus-2 核过两条块级约束）。

## 未决

- 70×70 上「解得动」没有正面测点：主问题不带流量时割循环缺口降得很慢（第六节 C2），带格级流量的单体模型找不到解（第五节乙、seat-opus-2 E1′）。块级子集流进主问题、粗网格线性规划补挂钩，这个组合没测。
- 1113 这一级钉住 21×53 以后，只有装箱和端口邻接的放松 600 s 判不出（第六节 C1）；压 U 用的放松在这一级先卡在装箱上。
- 图外结点的 π 怎么取最好、要不要 Pareto 最优割、一轮回送几条割，没研究（影响割的强弱，不影响有效性）。

## 最终立场

1. 带子这一层的精确表示用 1.1 的格状态：通道由状态按「当且仅当」推出，机器按「机型×朝向×位置」建布尔。「谁接给谁」不另设变量，它是按物品平均流的路径分解。
2. 流量分两层：
   - 主问题里放若干份各自有网络扩展的子集流。这是整数替代流，不是实际流，条件见第三节。
   - 共同容量、配方比例和未由共同设定固定的来源身份，放在母图上的连续线性规划里，经有效割回到主问题。
   割对一切使子问题可行的布局成立，每条可以逐列精确复核（第二节）。这一点有 codex-1 独立复算的一条证书。
3. 先后机制：
   - 压 U 时第一档不另写约束。
   - 已证的必要条件照前提加入。
   - 抬 L 时机制落成受限类，并登记覆盖损失（第四节，同 opus-4、opus-3）。
4. 所有测点都只说明那一次（第五、六节）：
   - 主问题不带流量、全靠割补，12×12 和 70×70 上缺口都没有收敛；70×70 那次割积到 28 条，主问题 600 s 就解不出了。
   - 带格级流量的单体模型，在已知有解的 12×12 实例上也没找到解。
   - 1113 这一级钉住 21×53 以后，只有端口邻接的放松 600 s 判不出。
   本轮的工程排序是：先比较紧凑的连通／容量代理条件、块级子集流和粗网格放松，联合线性规划补挂钩。这个排序没有排除别的编码或算法。
5. 本会没有交付在 70×70 上解得动、覆盖全域的完整模型，也没有交付达标布局。
