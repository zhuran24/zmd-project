# 修正版堵满起法：双料库存、植物回路、传输箱

日期：2026-09-22。状态：**双料通用选库存没推完；植物“填满便能一直供给”给了可摆放的局部反例；传输箱完成了单一非成品接口的前缀条件和不靠计时的清理办法，任意共享箱的通用版没推完。**

## 1. 结论、依据与量词

| 本轮问题 | 标记 | 得到的结论 |
| --- | --- | --- |
| 双料机器起步库存 | **没推完** | 刻画了堵满停态必须满足的局部条件，给出完整料序已知时的库存区间和整数批次检查；不能由三份文件直接列出任意布局的可达混料词。“不补，停在哪算哪”没有通用保证；单看差值摆幅也不够。 |
| 植物接回出口 | **给了反例** | 封口时确能繁殖并填满回路带子的纯砂叶回路，开口后可以把回种逐渐耗尽，最后零供应。问题是开口后的分配。另给出了分区收支、起步前缀和逐格检查的明确条件；没有把它们说成所有布局自动满足。 |
| 清理传输箱后留成品格 | **证明了，限第 4 节的接口条件** | 一个非成品 X 占第 1 格时，所有事件前缀的供取差落在指定区间，就能永久把 X 限在第 1 格。给出了清到什么状态、库存怎么选、怎样避免抢时间接线。多种非成品、没有此前缀界的任意共享箱，**没推完**。 |

这三项没有合起来证明一条适用于全部可达标布局的起法，也没有排除任何布局类别。植物反例检验的是回路局部命题，不是一张达到全厂产量的布局，更不是最大空矩形的最优性反例。

### 1.1 正式依据

“规则”“任务”“约束”分别指根目录的：

- 《明日方舟：终末地》游戏规则.txt，114 行。
- 求解任务.txt，16 行。
- 求解约束.txt，158 行、72 条。

所有引用都是实际文件行号。“第 58 行”不是“第 58 条”。第 1 轮第 2 节只用于保持量词一致，第 5—7 节用于定位问题；未用其他仓库文档补充游戏规则。

单位按用途读取：制造开关关掉，不等于输入端口不收货；缓存用来完成当前一批，不是玩家可任意编排的无限仓库；储存箱按编号存取，不会自动整理碎片；传输把仓库能接收的东西送走，不会替满仓腾位置。依据：规则第 17—18、20—21、35—36、72 行。

### 1.2 本文使用的量词

按任务第 2 行仓库同时可接受两种成品的目标口径，调试结束后的每个可达循环态都须达到电池 0.6 件/tick、胶囊 0.55 件/tick。对接通先后、分叉取支、传输相位、固定判定次序的每一种允许取值都要成立。离线之后还可能改接通先后。玩家的动作不能要求落在某 tick，也不能要求两次操作相隔准确时长。依据：任务第 2、8、10、12—15 行，约束第 3—11、36 行。

因此，本文的“所有前缀”包括：起步瞬态、周期内部、同 tick 内逐个事件之后、后续允许离线重排产生的前缀。只查一个周期的净量、只查 tick 结束、只查初次建造顺序，都不够。固定判定次序在一次运行中保持固定，不能逐 tick 任意改它来制造反例。

给反例只需一个允许的坏取值；给安全起法须覆盖全部取值。局部条件缺失造成的失败，不直接证明同一布局不存在其他调试办法。依据：任务第 12—15 行。

### 1.3 收到了，与本来要送来，必须分开

实际收货 I 总满足容量上限，因为满了就拒收。一个堵死的机器可以永远有 I=0；这不是安全供货证明。

下面算前缀余量时，先说明正在检查哪条**拟送达、拟开工的事件轨迹**。它必须包含被拒收之前原本会尝试送来的那件货。把容量放宽的轨迹作为参考时，还要证明有限容量系统直到第一次失败前与它一致。不能用失败后的实际 I，替换原来要求收到的数量。

同样，拟开工必须是游戏的自动开工过程；不能把“还不想开工”写进机器调度。依据：规则第 18、24—25、35 行。

## 2. 双料机器的起步库存【通用版没推完】

### 2.1 堵满不决定一个统一的库存对

现行研磨三种配方都是 2A+B；封装是 10A+15B；灌装是 10A+10B。规则中没有第四类双料用量；换做多种研磨配方时，要分别记录蓝铁粉末、源石粉末、荞花粉末和共同的砂叶粉末。依据：规则第 92—94、111、114 行。

关着的封装、灌装机不消耗存货，但仍能收货。两格都满只在两种正确原料都能继续到达时才会发生。混线的料头先被某一满格挡住，后面的另一种原料就到不了。此时可以停在“一格 50，另一格没满”，甚至另一格为空。停制造本身不会让后面的货穿过料头。依据：规则第 13、17—18、20—21、23—25、54 行。

开着的研磨机还要分三种停法：

1. **缺原料。** 上一批已完全进入取货格、没有在制批次，仍不能开工，则每个可用配方至少缺一种原料。只做 aA+bB 时就是 x_A<a 或 x_B<b。
2. **上一批出不去。** 输出格装不下整批缓存产物，缓存不能清空，便不能接下一批。输入两格可以是任意合法数量，不能据此断言它们都已满。
3. **种类组合不对。** 研磨机两格分别被蓝铁粉末、源石粉末占用时，即使各 50，也没有砂叶粉末，任何配方都不能开。两者各自是某配方原料，不等于这一对可制造。

这三条分别来自规则第 18、35、54、92—94 行。还在加工的机器必须把剩余进度带入起态，不能把它当已经停稳；开关不重置进度，见规则第 20 行。

对没有分叉、汇合、箱子或准入口的连续 FIFO 带段，停稳后，按“靠机器的格在前”编号：已有货只能占连续的一段前缀，不能在两个已停稳的有货格之间留下空格。理由是上游有货、下游空且已满足 1 tick 滞留，就仍可移动，违反停稳。上游还持续有可送货时，这段最终全满；此时带头那件必须被机器拒收。依据：规则第 23—25、59—60 行。

例如，停着的双料机两格已分别放 A、B，带头为 A，又没有别的占格问题，则稳定拒收要求 A 格已到 50。B 可以是 0…50 中受前史限制的值。这里不是说全部这些值都对该布局可达。多输入机器还必须同时检查其余每个料头；一个独立 B 入口会使前述堵住 A 的状态仍可能解开。

带上的先后顺序继承上游成功出货顺序。FIFO 不重排；汇流、分流、箱子的编号和轮询、准入口窗口可能改变后续输出。依据：规则第 29—32、64、67—68、72 行，约束第 16、68、102、106 行。**没有一个与布局无关的“堵满后的标准混料词”。**

### 2.2 可能集合应当怎样记；本轮做到哪里

固定布局 L、调试动作办法 P，以及一组允许隐藏取值 h。一个完整状态至少记录：

- 每个运输格的种类、是否够滞留时间；每个箱子的六格编号和数量。
- 每台机器的输入、输出、缓存内那一批及剩余进度。
- 通道是否接着、优先级、轮询位置。
- 准入口剩余额度、5 tick 窗口；传输冷却与相位。
- 仓库相关物品的可接收余量。

这些字段分别由规则第 13、17—18、20、23、27—32、36、59、64、72 行决定。缓存有无限的格上限，不表示能积压无限批；第 18 行的上一批条件使自动运行时最多挂着当前一批。

记 E(L,P,h) 为：从任务初始仓库和允许建造历史出发，按 P 做完后能出现的全部完整状态。堵满观察、清料、恢复入口的时差都要算进去。将 E 投影到某机器的输入库存、缓存、输出格、各输入路径有序内容，才是该机真正的候选集合。机器库存与料词必须作为同一状态的一对保存，不能把两个不同历史的结果随意拼接。

第 2.1 节给出这个集合的必要局部条件，没有给出充分的可达性刻画。直接枚举“两个数 0…50、所有可能排列”，只得到过大的包围集合；它过不了安全检查，也不能据此判布局不合格。

此外，“关闭末级后一定全厂静止”本身不是规则定理。蓝铁粉末经精炼变蓝铁块、再粉碎回粉末的支路可以继续周转，见规则第 82、89 行。堵满结束判据要针对受控部分，不能以等全厂不动代替算法。

**停止位置：本轮没有从任意 L、P 自动构造 E，也没有得到全部可能的后续混料词。** 这不是缺一个库存常数，而是缺布局到可达事件轨迹的推导。后面的区间不能替代这一步。

### 2.3 给定完整事件轨迹，库存可直接算

从释放时刻重记累计量。令 I_i(p) 是第 p 个事件后累计收到的原料 i，N_r(p) 是累计开工批数，C_i(p)=Σ_r a_ir N_r(p) 是累计从输入格扣掉的用料。已在缓存的一批不重复计入 N。由约束第 58 行：

```text
H_i(p) = C_i(p) − I_i(p)
q_i(p) = x_i − H_i(p)
0 ≤ q_i(p) ≤ 50

所以： max_p H_i(p) ≤ x_i ≤ 50 + min_p H_i(p)。                 (1)
```

证明就是把每个前缀的两边不等式分别移项，再取交集；p=0 也要算，H_i(0)=0。因此上下界自动限制在 0…50。整数库存取区间内整数。

对一个经过证明的轨迹族，把 max、min 扩到该族全部轨迹，得到**同一库存能容纳这整族指定收支**的区间。每条轨迹周期末 H 回到同值时，查瞬态加一个完整周期便覆盖这条轨迹的无限重复；周期末不回原值，偏差会逐期累加，有限库存接不住。

这完成了库存算术，没有单独完成运行证明：给定的开工时刻还要满足制造用时、缓存清空、产物整批出缓存、实际自动开工与通道事件。多配方机器还要保证同时占用的原料种类不超过两个输入格。只把每种原料各自压在 0…50，不能允许三个正库存同时出现。依据：规则第 13、18、35、54、92—94、111、114 行。

“某一种库存改变了制造时刻，上游料词随之改变”的布局，不能沿用旧库存跑出来的 N、I。必须重新检查耦合后的轨迹。这是式 (1) 的使用边界。

### 2.4 差值条件已有；整批条件不能省

只做 aA+bB 时，令 D=bI_A−aI_B、Z₀=bx_A−ax_B。由式 (1) 消去 N：

```text
−50a ≤ Z₀+D ≤ 50b
−50a−min D ≤ Z₀ ≤ 50b−max D。                               (2)
```

这就是约束第 58 行的直接重排。摆幅 max D−min D≤50(a+b) 已经由该正式约束推出；本轮没有新增一条独立的摆幅约束。

但消去整数批次会丢信息。给定一个前缀，可能的 N 还须满足：

```text
max(0, ceil((x_A+I_A−50)/a), ceil((x_B+I_B−50)/b))
  ≤ N ≤
min(floor((x_A+I_A)/a), floor((x_B+I_B)/b))。                 (3)
```

上下界没有整数交集，这个前缀就不可能全部收下。即使每个前缀都有整数交集，各前缀之间仍须是一条合法的开工过程，不能逐点另选互不相容的 N。

**可复算例子。** 封装 a=10、b=15，起步 (x_A,x_B)=(49,14)，唯一 FIFO 先送 10 个 A，再送 15 个 B，重复。Z₀=15×49−10×14=595；整个拟送词的 Z₀+D 在 595…745，始终落在式 (2) 允许的 −500…750 内。

第一件 A 收下后是 (50,14)，还不能做一批；第二件 A 前面没有 B 可补，永久堵住。到第二件的拟收前缀，式 (3) 下界为 ceil((49+2−50)/10)=1，上界受 floor(14/15)=0 限制，即要求 1≤N≤0。矛盾。这里连“立即制造”的宽松模型都不能救，真实 5 tick 制造更不能救。用量和时间见规则第 111 行。

这个例子否定“差值界满足便足够”，不声称已经构造了自动反复产生该词的全厂布局。

### 2.5 哪些时候任何库存都救不了

以研磨 2A+B、唯一 FIFO、输出可一直排走为例。开始连续来 A 时，原有 B 至多 50，故最多支持 50 批、吃掉 100 个 A；A 输入格原有 x_A，还能净增加 50−x_A。连续 A 最多接收：

```text
(50−x_A) + 2 floor(x_B/1) ≤ 50+100 = 150。
```

于是拟送词 A^152 B^76，即 152 个 A 再接 76 个 B，虽然总比例 2:1，**所有 51×51=2601 种库存都无法通过开头这一段**。它的 D 摆幅 152 也超过 50(2+1)=150。制造放得再快也接不完；前面的 A 不走，后面的 B 到不了。依据：规则第 17—18、92 行，约束第 58 行。

这成为某布局的必要排除条件，必须额外证实：该词确由该布局在某个不得依赖量下不可避免地产生，其他入口不能送来 B，没有旁路解队首，且这台机的失败必然破坏全厂交付。少任何一环，只能否定该词或该起态，不能否定整个布局；调试可能改变料词，别的机器也可能补产。

第 1 轮 A^102 B^51 的两个数字仍成立：从 (50,50) 在第 101 个 A 堵住，从 (0,50) 可反复完成 51 批/153 件。这说明库存选择重要，但没有回答这些词对任意具体 L 是否可达。

### 2.6 可以采用的规则，以及尚未补齐的步骤

对已取得**全部相关轨迹及其起态关系**的某个布局，可用以下明确规则：

1. 逐机枚举 0…50 的两种库存，排除错误种类组合；缓存、输出、在途词不能随意改成空。
2. 用式 (1)、(3) 排除不可能容纳的候选；保留下来的按真实制造、运输事件检查。
3. 对每个准备方案，把不精确操作可能留下的全部起态、以后离线重排都纳入检查。检查每个可达循环态产率，而非仅找一个安全周期。
4. 保留能用静态隔离、清料、补料、任意时刻恢复而实现的方案。需要某 tick 同步的候选不算调试办法。

这是有明确输入和判据的选择流程，但第 2 步不能只靠式 (2)，第 1 步之前的轨迹生成和第 4 步的统一可执行性，本轮未完成。不能把“枚举到安全状态”当作证明一定有解。

因此：**“不补，停在哪算哪”未证安全；“所有双料格都补到 50”已被料词例子否定；“按周期给每种料留空位”在完整轨迹已知时可按式 (1) 算，但仅按一个理想周期算不够。**

与正式约束的关系是：收支恒等式、50 上限、差值界、周期配比、摆幅上限均已在约束第 58 行。式 (1)、(3) 是其算术展开。新增的工作是把它们用到起步前缀、整批余数、库存与料词的关联，以及可实施调试；这些不是第 58 行已经给出的存在性结论。

## 3. 植物接回出口【给了局部反例】

### 3.1 反例为什么成立

只用砂叶。一台种植机 P，一台采种机 A，接成纯料回路：

```text
P 的一个出口 ── 连续带、一个只准砂叶的准入口、连续带 ──→ A
A 的一个出口 ── 连续带 ──→ P

P 的另一个出口 ── 直接相邻的汇流器 ──→ 粉碎机 F
F 的三个出口 ── 各一格带 ──→ 传输箱 ──无线→ 仓库
```

准入口不设累计或每 5 tick 数量限制。P、A、F 制造开着，箱子传输开着。开始把 P 到外送汇流器这一处断开，给回路补一批正确种子；后面不再从仓库补植物或种子。种植 1 粒变 1 株、采种 1 株变 2 粒，见规则第 103—108 行。

闭口时，回路没有植物或种子流失，每完成一次采种，合计数量加 1。容量有限，因此不能无限完成采种。两条运输路径本身不成纯运输环，种植、采种停下后，剩下运输也会停住。回路不可能全空，因为初始种子为正，合计数量只增不减。

两条回路带子最终都满。证明：某条带段不满，停稳时它的上游机器输出必为空，否则仍有可走的空位；输出为空且制造开着，就要求该机输入没有可开工原料。沿另一条带回推，再要求另一台机器输出为空、输入也没有可用原料；这使整个单一路径回路为空，与正的总存量矛盾。缓存已做好的东西面对空输出格也必须能整批排出，不构成例外。依据：规则第 18、23—25、35 行。采种输出可能因整批 2 件差一个空位而停在 49，这不影响两条带子全满。

现在接回外送汇流器。P 到 F 的取货级直接接汇流器，阻尼是 1；回 A 的路径由“带段、准入口、带段”组成，阻尼是 3。这两个级严格分开，所以外送级更高，不靠接通顺序。长带本身只算一个元件，阻尼 3 的原因是中间真有一个准入口。依据：规则第 26—27、30—31 行。

选一种允许且此后固定的同 tick 判定次序：先让外送汇流器把已滞留够的上一件送给 F，再让 P 输出；F 及时开工、三个输出口及时清掉上一批粉末。F 每 tick 能吃一株，三个口能运走每批 3 个粉末。因而外送汇流器每 tick 都能优先接走一株。规则第 25、35、59、68、84 行和任务第 15 行允许这种固定次序。

P 每 tick 最多新产一株。外送口每 tick 有一个优先服务位置，足以拿走它此后全部新增产出。最初 P 输出与缓存里的有限存货可能趁余量再进入回种带；这只增加有限的一次性回种量。

更精确地，把 P 输出看成一个队列。在队列非空的连续时段，每 tick 至少优先外送一件，而每 tick 新增至多一件；每成功回种一件，就额外少一件队列库存。队列空的时段，新来的一件先占外送位置，不能产生持续回种。P 的输出格最多 50，缓存最多一批 1 件，再放宽一个边界事件，开口后额外进入回种支路的总量至多 52。**这里的 52 是宽松上界，不是靠模拟观察的数。**

回种带和 A 的原有植株有限，后续回种也至多 52，所以采种总次数有限；所得种子有限，所以 P 此后的总种植次数有限；所有外送植株最终被 F 粉碎。最后回路供给为零，形成零产出的循环态。没有使用改变固定判定次序，也不需要任何离线变化。

这给出完整的逻辑链：**闭口能繁殖并把回路带填满 → 开口改变分配 → 回种只能再做有限批 → 有限起步库存用尽 → 以后零供应。**

### 3.3 按分区算前缀，哪些数真正够用

取一种植物和一组完整单位 U。不同植物分别算，箱子不能拆成虚构的独立单位来套分区守恒。记从开口起累计完成采种、种植、粉碎批数为 A、Z、F；跨 U 边界进入、离开的种子为 I_s、E_s，植株为 I_p、E_p；送仓库为 W_s、W_p。

将尚未完成的原料仍按原种类算在缓存里，则每个事件前缀都满足：

```text
S(t) = S₀ + 2A − Z + I_s − E_s − W_s = S₀ + Δ_s(t)
P(t) = P₀ + Z − A − F + I_p − E_p − W_p = P₀ + Δ_p(t)
S(t)+P(t) = S₀+P₀+A−F+I_s+I_p−E_s−E_p−W_s−W_p。             (4)
```

这是规则第 18、103—108 行逐事件记账，也是约束第 80、82 行的前缀展开。缓存中的种子在种植完成时变植株，植株在采种或粉碎完成时改变种类；不要在开工和完工各减一次。

首先必须满足每个拟持续周期的 Δ_s=Δ_p=0。没有外来种子、植株且不入库的独立分区，就是 Z=2A，Z=A+F，故 A=F。初存再大都不能弥补每周期固定亏损；亏 d>0 件、初存 C 件，至多经过 floor(C/d)+1 个这样的亏损周期，库存非负性便不可能继续成立。这一步已由约束第 74、80、82 行推出。

其次，给定实际可实现的轨迹族，聚合库存至少要有：

```text
S₀ ≥ −inf Δ_s，P₀ ≥ −inf Δ_p。                              (5)
```

有一个正确种类可用容量 K_s、K_p 的聚合上界时，还须 S₀≤K_s−sup Δ_s、P₀≤K_p−sup Δ_p。例如 Δ_s 在 −7…4、Δ_p 在 −5…3，最低总量为 S₀=7、P₀=5；所需容量至少为 7+4=11 粒、5+3=8 株。这只是公式算例，不是本轮构造出来的植物轨迹。

式 (5) 只保证“分区总数没有先变负”。远处的 20 粒种子不能立即补给眼前空着的种植机；一格植物也不能同时给采种和粉碎。因此还要逐个供货地点算。

### 3.4 足以证明持续运行的条件，缺一项会在哪里断

下面是一套可核验的充分条件，不要求回路分区相互独立，也允许把跨区流量写成明确的输入合同：

1. **开口之后的实际分配足量。** 每个分区同时满足式 (4) 的周期收支，各个粉碎出口获得其下游要求的量。全厂砂叶要 A=F=10.5、Z=21，荞花要 A=F=5.5、Z=11 批/tick；分区之间可分摊，不能把全厂合计替代每区检查。依据：约束第 44、74、80、82 行。反例在这一项失败。
2. **每个用料点都有来得及到的库存。** 对每个种植、采种、粉碎输入格，令 J_v(p) 为按真实路径拟送到此格的累计件数，K_v(p) 为累计开工批数。现行这三类植物配方每批吃一件，所以要求每个事件后 0≤q_v+J_v−K_v≤50。每次开工前至少有一件。运输延迟已经算在 J_v 内，不能把上游发货当到货。缓存与输出格也逐个检查整批容量、种类和出货。依据：规则第 17—18、23、35、83—84、103—108 行。
3. **全满运输格有合法腾空过程。** 拟采用的事件次序中，每次移动都由当时真实空位支持；已满的环不能靠“同时平移一圈”算通过。对所有固定判定次序分别检查。依据：规则第 23—25 行、任务第 15 行。
4. **调试结束的全部状态进入上述安全过程。** 起步瞬态也满足前缀界；重复周期的格内种类、数量、在制进度、轮询位置、窗口与传输相位能接续。离线重排后的全部可达后续仍满足同一条件族。不能只提交一条固定顺序下的好周期。依据：任务第 2、13—15 行、约束第 3—11 行。

这些条件的充分性可逐事件证明：初态合法；下一次收货有已核算空位，下一次开工有已核算原料且上一批已清，下一次出货有已核算路径和接受格，所以不会发生第一处与所验证过程不一致的欠料或堵塞。瞬态结束接上同样合法的周期状态，便可重复。全部允许分支都在条件族内，才得到全部可达循环态的结论。产率由第 1 项的实际完成和交付数确定。

这不是把总量条件升级成充分性：第 2—4 项需要实际路径和事件证据，不能由第 1 项代填。植物再生来路只证明必须有正流量再生回路；植物沿途存量给时间平均下界，均不保证任一时刻某台机器眼前有货。依据：约束第 84、90、92 行。

“先回种，余量再外送”可以修复第 3.1 节反例的分配方向，但它仍须达到要求的外送量，不能把所有植株长期留在回种一侧。用优先级落实时，回种阻尼必须对所有分叉取支严格较小；同阻尼先接上的做法不可靠。依据：约束第 14 行。这个办法没有在本轮被证明适合所有植物布局。

**对待证判断的结论：** “正常运行起来”若仅指封口时能繁殖、带子能填满，命题为假，本节给了反例。若指已经进入一个供应足量且不会被任何允许重排带出安全范围的状态族，后续无需再补植物可由上述逐事件证明得到；但这正需要开口分配、逐点前缀与重排封闭性，不是“填满”两个字已经包含的事实。

## 4. 传输箱清理后留成品格【条件版证明了】

### 4.1 先明确要保住的东西

箱子有六个编号格，每格最多 50。存入选编号最小的可放格，物理取出选编号最小的非空格。格子没有“给成品保留”的设定。依据：规则第 72 行。

要证明的可操作结论是：非成品始终局限在指定的前格，成品有独立可用格；不是笼统要求“总数不到 300”。例如第 1 格有 P、第 2 格有 1 个 X；传输清掉 P，再来 1 个 X，会进第 1 格，留下两个各装 1 个 X 的格。X 总量是 2，却占了两格。不能用 ceil(X总数/50) 当实际占格数。

### 4.2 单一非成品 X 的精确前缀条件

采用下列局部接口：

- 箱子非成品只有一种 X；仓库不接受 X，因而传输不会带走 X。
- 第 1 格初有 q 个 X，后五格全部清空。
- 箱子的物理出口在箱口只取 X，且供货、取货机会已按真实端口和下游能力算出。后面证明第 1 格不空，因此不会取到成品。
- 箱子持续供电、传输开着；本节成品进箱不因容量受阻的结论，先以仓库在每次传输都能接受箱内成品为边界条件。

X 的仓库余量为零可用初始已满的砂叶、荞花实现，不必假定其他非成品初始也满。依据：任务第 6 行，规则第 36、41 行。合格循环态非成品零入库及按仓库余量判传输，见约束第 74、76 行。

令 U_X(p)、V_X(p) 是参考运行中第 p 个事件后的累计 X 进箱数和物理出箱数，Δ(p)=U_X(p)−V_X(p)。参考运行允许第 1 格暂时超界，用于发现有限箱子的首次失败；取货服务不能用“已经取成功的次数”事后替代。

所需条件是：

```text
L = inf_p Δ(p)，R = sup_p Δ(p)，包括 p=0、全部允许的后续。
1−L ≤ q ≤ 50−R。                                          (6)
```

等价地，所有事件后都要求 1≤q+Δ(p)≤50。这样的整数 q 存在，当且仅当 R−L≤49，且区间内有整数；所有计数为整数时后一个条件自动满足。因为包含 Δ(0)=0，区间已在 1…50 内。

**证明。** 假定在某一事件前 X 全在第 1 格且数量在 1…50。下一件 X 到来时，式 (6) 保证加完不超过 50，因此按最小编号规则仍放第 1 格；取走 X 时，式 (6) 保证取完至少剩 1，其他格不会变成物理出货的箱头。传输不改变 X。成品不能进入非空的 X 格。逐事件归纳，X 永远不进入后五格，第 1 格永远不被成品占用。参考运行中所有这些动作都能在真实箱子里完成，直到第一次失败的反证闭合。依据：规则第 13、36、72 行。

**这个强条件是充分条件，不是所有好箱子的必要条件。** 有些好箱子允许 X 格短暂清空，仍能靠其他结构运行。R−L>49 只是否定“第 1 格永久只放 X”的这一方案，不能排除整张布局。

成品方面：箱子只有三个存货端口，每个端口每 tick 至多 1 件；任意相邻传输之间按两端事件都计入，最多 3×6=18 件成品。仓库每次都能收走这些成品时，每种成品在两次清空之间至多 18 件，小于一格容量 50。两种成品各占至多一格，后五格足够。初次释放成品到下一传输的等待也不超过 5 tick。依据：规则第 36、72 行，约束第 30 行。这里用的是单独给成品计数，**没有错误套用要求“仓库接受箱内全部物品”的约束第 100 行**。

容量够不代替进货优先级证明。某成品在汇流竞争中根本拿不到入口，式 (6) 不会替它创造流量；进入箱子的成品率仍须从实际来路证明。

### 4.3 第 1 轮接口的数字可以算到底

第 1 轮的明确接口是 X 每 tick 供 1 件、物理取 1 件，两边已经就绪；各自首事件在一个 tick 内发生。固定相位的任意前缀计数差在 −1…1，因此 L=−1、R=1，式 (6) 为：

```text
2 ≤ q ≤ 49。
```

q=25 给出 24…26 的全过程数量。第 1 轮写的 2…48 是更保守的可用范围，不是最大的整数区间。

一条成品 P 每 5 tick 来 1 件时，同一传输边界前后最多暂存 2 件。复算枚举 24 种固定事件次序、5 种供 P 相位、5 种传输相位，共 24×5×5=600 种，全部进入交付率 1/5 的周期，X 均限于第 1 格。连续相位的保证来自此前缀计数证明，600 个整数模型本身不充当连续相位或全厂证书。

后续离线重排会改变实际供取节奏的布局，必须重算式 (6) 的 L、R；不能把本例的 ±1 直接搬过去。本例的接口合同是始终保持上述周期供取，单一物理出线没有需要靠接通先后定序的竞争。

### 4.4 清到什么状态，怎样不靠操作速度

不能隔断 X 进、出线，清到 25，再要求玩家迅速接回两根线。以 q=25 为例，先送后取的净多送量最多允许 25；第 26 个净新增 X 会使第 1 格需要 51 个。先取后送最多允许净取 24；净取第 25 个会使第 1 格变空。操作间隔没有有限 tick 保证，故这种准备法不成立。依据：任务第 13 行、式 (6)。

有前缀合同的单一 X 接口可以改成以下动作办法：

1. 临时隔离所有成品来路，接好最终 X 进出线，让 X 的源与接收端处于已证明服务合同成立的状态。这不是靠观察几秒就猜永远稳定；服务合同必须从来路、端口和下游得到证明。恢复过程中可以任意久，此时尚不要求保成品格。等箱内旧成品被传走、观察到只剩 X；这依赖本节仓库可接受成品的条件。
2. 保持 X 进出线工作，单独清空第 1 格。后格的 X 暂时不动，此后仍只有 X 能进箱。
3. 在任意时刻向第 1 格一次补入 25 个 X，不要求补在进货或取货前。然后逐格清掉第 2…6 格残留的 X，操作之间可以任意久。
4. 后五格清完，再在任意时刻恢复成品来路。物品数量是精确的，时刻不需要精确。调试可以清货、补货，见任务第 12 行；与第 1 轮使用的手动补库存同类。

为了给这组动作留出明确余量，使用比第 4.3 节更宽松的合同：从任何事件切点开始，拟进 X 与可用取货服务的任意前缀差都在 −2…2。这个合同须包括后续允许的重排；下游服务位置只因箱子没有 X 才能闲置。

清空第 1 格后、补货前，**第 1 格**的 X 始终在 0…2；后格可以还有旧货。证明：第 1 格从最近一次为空以后，它非空时全部取货服务优先作用于它，积压就是这段的供取差，最多 2；它为空时，服务可以取后格的 X，但不会给第 1 格增加货。每次第 1 格变空都重新从 0 算。新增 X 总能放进第 1 格，不再补后格。

补入 25 后，第 1 格的 X 在 25…27。以补货后为新起点，此后净差在 −2…2，故这一格全过程在 23…29；不会再空，也不会溢出。此后所有 X 进出只用第 1 格，后格旧货可按任意速度逐格清理，清完不会复发。最后恢复成品早或晚都不改变这个不变量。此后第 4.2 节的成品存放、传输证明适用。

这里不是要求玩家边看数字边抢着补到 25，而是向已有 0…2 件的格**固定加 25 件**。一次物品转移动作的时刻可以任意；前后相邻事件也已包含在界中。此办法不要求先断 X 线，更不会在补货后产生一个等待接回另一根 X 线的危险空档。

适用边界也很明确：来路不具备上述服务合同，或者清箱本身会使下游长时间失去回流、导致合同失效，就不能用这一准备法。植物供给、混料上游与箱子耦合的布局，必须把这些反馈算入合同。

### 4.5 为什么平均收支和“清空一次”都不够

在箱体接口模型里，从空箱起，先有 300 个 X 每 tick 一个到来，物理出口暂时不能取；P 此时尚未恢复。六格依次各装 50。之后 X 每 tick 入 1、出 1，仓库拒收 X，P 每 5 tick 想进 1。

第 1 格只在 49 和 50 间变动，后五格的 X 永远轮不到物理出货。P 无格可进。长期 X 供取平均相等，仍永久卡住。这复算了“清空一次”缺前缀界的具体后果；300 是 6×50，并非无穷突发。它是边界供取合同的反例，没有声称任意上游布局都能生成这个启动延迟。

多种非成品时，问题还包括编号碎片、不同种类的取货资格、第一非空格阻住后格。总件数上界不能解决这些问题。正式约束第 115、117 行已经给出某些无无线外送情形的必要限制，但不能直接套用到同时传成品的全部状态。

仓库暂时不能接收成品时，式 (6) 仍能保证 X 不侵占后五格，前提是 X 的服务合同仍成立；却不能保证有限的后五格无限接收成品。需要把成品实际入箱减传出的累计量、各格种类和编号也算入，或者证明仓库阻塞后再恢复的全部瞬态仍安全。任务第 2 行的产量目标以仓库能同时接受两种成品为条件，第 9 行又允许间隔拿取；本轮没有把任意停收和恢复过程默认为 ±1 的正常接口。

**本项完成处：** 式 (6) 是单一非成品永久守住第 1 格的完整前缀条件；第 4.4 节给出合同满足时不靠计时的清理与释放办法。**本项停止处：** 任意多非成品共享箱、反馈耦合来路、仓库停收后的重启，尚无统一计算合同和构造准备状态的办法。不能将这个局部充分条件直接登记为全部共享箱的无损起法。
