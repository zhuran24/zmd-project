# 内核实现验证与边界

日期：2026-09-19。性质：第1轮修订前的实现席执行记录与证据快照，以下79项测试和指纹属于初版；当前状态、修复与验证入口见[修订记录](../修订记录.md)和[kernel README](../README.md)。本档案不冒充后续复核或当前完整验收。

## 交付范围

Rust crate [kernel](../README.md) 已加入 workspace。核心转移不调用 Python，不读取黄金轨迹决定后继；Python 只在集成测试和落盘验收中独立重算。黄金读取发生在4时刻轨迹生成完成后的比较阶段，不能修改计算中的库存、模板或日程。

持久写入为 `crates/kernel/`、workspace `Cargo.toml`、Cargo自动更新的 `Cargo.lock`、四份 `数据/样例/*-kernel.json`，以及获准新建的 [规格疑问](../../../规格/内核实现-对规格的疑问.md)。锁文件只加入本地 kernel 包及对已有 serde/serde_json 的依赖，未引入新外部包。构建产物位于求解器既有 `target/`。未 git commit/push，未写模拟器。

[开工只读基线](baseline.json)登记三份正式源、候选约束、既有规格及样例等1250个文件；[最终记录验收](record-validation.json)核对全部指纹未变。该核验包括原黄金、Python参考程序、两份旧运行记录和参数投影。新疑问文件不是规格正文修订。

## 测试与证据自审

完整 workspace测试结果：kernel 45+3、topology 1+30，共79通过，0失败。原始命令和输出见 [cargo-test.txt](cargo-test.txt)。[Clippy](clippy.txt) 对 kernel 全目标零警告。只写无 unsafe 的安全 Rust；运行值无浮点，算术溢出有显式停止值。

参考集成测试同时做三条等式：现场 Python 重算 = 原落盘运行记录；Rust每tick全部字段 = Python重算；粉碎机全部summary = 原黄金ticks。字典键集合、数组长度与顺序、JSON类型、所有叶值均参与。producer与工具指纹因产物来源不同而不冒充Python；输入Parameters和完整input_history仍按契约原样保存并另核。

四份实际文件经 [verify_outputs.py](../tests/verify_outputs.py) 重新读入，检查schema、参数与历史、源指纹、全记录事件身份、物品格容量/同种单格、端口预算、完整状态、事件、摘要和闭包，并与独立Python前缀相等。检查点增量还核规范编码，包含最后不足一个检查点区间的残段。验收结果见 [record-validation.json](record-validation.json)。

内核验收器另以独立运行重新构造整份kernel记录；篡改状态、摘要或增量路径均不能靠换检查点或重算散列蒙混通过。对象replace路径不穿数组，重复、祖先冲突及无变化替换由规范增量再编码检查拒绝。

补充手推不借原两份轨迹作为期望，见 [手推桥接轨迹](手推桥接轨迹.md)；独立机制数据在 [fixtures](../tests/fixtures/bridge.json)。它是条件性小场景检验，不是调试可达性证据。

## 工程与资源自审

运行开始仅加载并克隆一次输入状态。每次模板只读/修改相关格、进度、门状态或轮询指针；不在tick循环克隆整份State。记录关闭后不积累逐tick快照或完整事件日志。完整闭包投影仍需序列化和保存已见内容，因而内存不是常量；事件身份登记也随运行增长。当前刷新会对可动集合重复扫描，大布局优化尚未验收，不能用小样例成绩承诺工业规模性能。

[benchmark.json](benchmark.json)记录单次release 1000刻：循环478729017ns，含装载进程490328086ns。基准输入明确把环境覆盖延长到999，原样例短历史没有外推。它完成158批后受下游/缓存容量阻塞，后续仍执行真实判定和闭包；成绩不能解释为满载1000tick吞吐实验。

README与疑问文件已按陌生读者视角重读：状态、命令、数字口径、测试范围、未覆盖项和跨文件引用一致。完整交付路径与最终SHA见 [deliverables.json](deliverables.json)；构建缓存不计为源交付物。
