# 参数轴对内核输入请求的答复

日期：2026-09-19。状态：第三轮规格线接口交接；本文件描述当前规格，输入正文及样例由内核输入线维护。

已读取[内核输入对参数轴的修改请求](内核输入-对参数轴的修改请求.md)，共享轴表已并入；原91轴保留，现为96轴。逐轴稳定编码以[内核配置-v1.json](内核配置-v1.json)及[受限模型声明](受限模型声明.md)为准，转移细节以[受限转移定义](受限转移定义.md)为准。运行输入的轴表及配置指纹须在最后一次迁移时重新锁定。

| 请求 | 当前接口及据 |
|---|---|
| 三个具体语法 | 沿用event-order-v1、damping-branch-v1、poll-memory-v1，不增加状态语法轴；轴表、T2/T3/T4引用内核输入§5.2/§5.3/§6.3。 |
| 传送带生命周期 | 采用initialization.belt_shape_lifecycle，U，本版fixed_between_builds；另用connection.belt_shape逐建造生命段记录三种形状。建造选形、旋转保形、调试经重建重选及零干预后无玩家改形已定；直接改形尚无正面授权，不把绝无其它机制冒称已定。 |
| 新轮询轴 | polling.split_merge_scope=per_level；polling.split_merge_singleton=sole_member；polling.both_failure=advance_authorized。 |
| 时间与平局 | time.instant_order=chronological_phases；time.manufacture_events=completion_before_closure；polling.level_tie=fixed_arbitration（输入独立级序，不能替代connection.tie）；connection.port_meeting=shared_edge_opposite（已定F）。 |
| 已定字段迁移 | polling.direct_peer=physical_peer、gate.window_recovery=on_expiry_if_other_guards、initialization.rotation_stage=build_and_debug为F；其余以轴表现行标签为准。 |
| 窗口、空格与几何 | 保留wall_clock/identity_only_pause、排除全盘暂停；空格指派须已解决empty_identity；占格互斥与供电义务按最严读法，closed_touch保留。 |

**事件模板须对齐当前选择**：本版judgment.buffer_event_class=manufacture_subactions；一次制造判定按“旧批整批出缓存→新批整批归集→若启用立刻开始”执行。故本配置的event-order-v1模板集合只含PC move和单位manufacture/transfer，BC有结构/子动作日志，但没有独立internal_move模板。格式可表达独立BC的其它模型，本版不得仍把BC模板强塞给已选manufacture_subactions，也不能用旧独立BC轨迹充当本配置黄金轨迹。（据：缓存格、制造、判定；受限转移定义§2.2/§4.2）

**双端协调**：一侧授权即可尝试，成功须both；失败只推进判前已授权该边的侧，没有授权的侧不前移。物理可动先算，不含指针。分级侧先最高可动级，级内从next_channel找首个可动成员；不分级侧empty_turn。成功后的next_channel是完整环后继，不能每次重置到首/第二条。（据：轮询、优先级；受限转移定义§3）

**状态接口必须容纳三原因阻断**：identity_mismatch、total_exhausted、window_exhausted分别保留；满窗只解除窗口原因，不能用一个bool丢掉其它原因。无准入口样例不激活此字段；未来有准入口运行输入在原因状态不能无损恢复时须拒绝运行。窗口本地计数与断边观察分离，本版身份锁存，不读取断边上游候选货。（据：物品准入口；受限转移定义§3.4）

**停止项的编码**：内核配置表的stop记录是工具覆盖政策，不是游戏参数取值。有限实验未激活时用带域证据的not_applicable/机制引用，不能把stop说成一条新物理机制；发生对应离线、调试、拿取等事件时必须停止。初态可达性及仓库周期提升可以未证，但必须在输出verification_scope中说明合成条件轨迹，不能据“可回放”宣称蓝图鲁棒可达。（据：目标、循环态、操作精度）

已核内核输入请求§5的终态编码：arbitration.level_order与warehouse_empty_slot_order、judgment_context.phase及准入口blocked_reasons已进入输入格式；受限转移定义使用同名字段。仓库无身份空格按显式完整序分配，缺序报invalid；保留历史身份不授权修改现存物品。
