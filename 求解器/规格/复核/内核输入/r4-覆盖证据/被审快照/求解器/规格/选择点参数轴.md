日期：2026-09-19。状态：第6轮修订的99轴登记（含同刻窗口批维护及配方数量/额外物种关系）；覆盖登记方向，未证明语义域穷尽或全部组合合法。第一版实现组合见[受限模型声明](受限模型声明.md)，条文展开与证明见[选择点清单](选择点清单.md)和[运行语义](运行语义.md)。

## 1. 参数域与生命周期

`Parameters` 是下表具名字段的记录，不再有无结构语义兜底。字段名、枚举英文值是工程编码，中文单位/配方 id 是共享目录数据。`known` 为已定单值，`open` 为尚待规则审查的解释方向，`obligation` 为证明义务，不得把证明结果变成任取参数。每项方向默认包括而非穷尽；`open` 不表示已经获准的游戏行为。（据：判定、约束·不得依赖的量；编码约定）

生命周期列：`F`＝整场固定；`O`＝离线后可变；`U`＝固定性待证。对解释轴，`U` 表示条文未给真实机制或固定性；在一次模型实验中固定解释版本是工程约定，并不证明该机制的运行值整场固定。`F(global)/U(per_instant)` 明确依赖另一轴取值；在逐时刻读法下也可固定整个 `order_at(t)` 函数，但不能把它误写成常数排序。运行状态随事件演化的字段以 `U` 登记其演化规律，实际当前值留在 State，不让读者把 `U` 当任意重抽授权。（据：判定次序、离线、需电功能、物品准入口、轮询）

这些轴在语法上分开，不断言概率独立或全部笛卡尔组合可行。允许域是正式规则和适用约束对组合的筛选关系：如 T7 的单种＋逐格＋全部物种齐全组合 J 与达标循环不相容；不能从它直接排除单种或逐格各自的全部取值。达标必要条件不得作为物理守卫删去合法坏运行。（据：缓存格、物品格、约束·物料流量；运行语义条件证明）

## 4. 目录与联合核验依赖

目录 `units[].inventory` 的 `item_policy`/`capacity_scope=unresolved` 分别落 T7，桥接器 `capacity_status=unresolved` 落 T14，供电 `coverage.cell_set_status=unresolved` 落 T15。它们是已有字段的语义接口，不擅造目录字段或把空值转为默认。配方、单位 id 以运行语义表及目录为准。（据：物品格、桥接器、供电桩；工程映射）

必须联合核验的关系包括：T1/T2/T3 的重试和排序；T3/T4/T5 的成员、阻尼、平局；T6/T12 的传输与仓库接收；T7/T16/T17 的停留、闸门、制造耗时；T8/T10 的断边、无终点和权限重排；T11 的建造调试与全部初态。此清单不是关联穷尽证明。未实现字段的有效输入必须显式报告超出覆盖或规格未定义，不能通过默认值补齐后称完整认证。（据：上述各行据；目标、循环态）
