# 第 7 轮独立选择点清单

日期：2026-09-19。状态：独立基线已冻结；本文件形成于读取本轮被审规格清单与参数轴之前。

依据为仓库根的《明日方舟：终末地》游戏规则.txt（下称 R）、求解任务.txt（下称 Q）、求解约束.txt（下称 C）。行号为本轮读取版本。任务书2 §2、任务书3 §2 已定事项作为审查边界。下表中的备选是待过全部条文联合审查的语义族，不是仅因未写就获得合法性的取值。列表覆盖正式文件中会影响布局、状态、事件、参数生命周期、初态和认证的未定义接口；没有宣称任意自然语言读法已被有限穷举。

## 一、时间、移动、判定与轮询

| 独立项 | 未定义接口／待审取值 | 排除边界与依据 |
|---|---|---|
| I01 | 时间域：整数时刻、tick 内多个时刻、连续／有理事件时刻 | Q2、Q14 的同一时刻不是同一 tick；R4 只给计量单位。不能把所有同 tick 事件强制当同刻。 |
| I02 | 物理时刻何时结束：使能闭包、按状态变化重试、带有限轮数的尝试调度 | R24 所有物品一直尝试、R25 原子逐个判定；不能永久遗漏已具备条件的移动。有限轮数必须解释下一次尝试时间，不能任意削减正式速率。 |
| I03 | 同一通道／同一侧在一个时刻和 tick 内的再次尝试资格 | C30 每端口每 tick 至多一件不是每侧一件；C50、C54 排除把封装等每侧统一限为每 tick 一次成功。内部通道不经端口，不能直接套 C30。 |
| I04 | 失败判定是否构成事件、怎样触发重试和终止空转 | R25 定义尝试，R29 尝试后立刻传权；不能把已发生的失败尝试当没发生，也不能以无物品变动推断全部状态不变。 |
| I05 | 判断先后固定性的辖域：全局固定规则／各时刻固定次序；新实例的插入次序 | Q14 只写同一时刻；R25 先后无法确定，C10 不得依赖。按结果临时择有利次序被排除；将不同事件强行并发也被排除。 |
| I06 | 制造开始、计时、完成、出缓存与移动的同刻顺序和时间边界 | R35 用量进入后立刻开始，无冷却；R18 上批全进出格才可进下一批。不能增设正的制造冷却或在上一批尚未全部入出格时装下一批。 |
| I07 | 非运输物品格的最短停留；缓存两内部通道是否同刻连过 | R23 至少一 tick 只限运输物品格；R24 零时间不等于任意调度均级联。给内部通道套运输滞留没有依据。 |
| I08 | 端口速率窗口与运输进入／离开同刻边界 | C30、R23 共同约束；不能借两个微步在同一 tick 经同端口超过一件，不能把不足一 tick 当满一 tick。 |
| I09 | 双端权限：两侧共同许可／一侧驱动另一侧响应；缺另一侧权限时是否已有尝试，失败影响哪侧 | R29 两侧独立，各已发生尝试后立即传权；R30 分级权只能在能移动的最高级。不能使缺另一侧权限的失败静默丢失已发生侧的传权，也不能靠一侧调度破坏另一侧的优先级。 |
| I10 | 能移动的判断是否包含另一侧权限，双端循环等待怎样解开 | R30 的能移动与 R29 联合约束；不能只分别定义两侧而不定义共同可执行关系。具体组合须构造联合后继。 |
| I11 | 无分级侧遇不能移动通道：跳过／实际失败尝试后传权／等候后重试 | R30 前件是分级时；R29 尝试后传权，故“已尝试仍不传权”被排除。无尝试的等待仍须过 R24。 |
| I12 | 一般轮询起点；分流／汇流第二条的辖域：整侧第二／级内第二／只有至少两条时适用 | R29 指定分流汇流第二条，不能无据统一改第一条；一个通道不产生不存在的第二条。 |
| I13 | 级间切换后级内游标保留／重置，当前级的定义 | R30 最高可移动级，不能固定停低级并阻塞已能移动的高级；R29 轮流顺序仍须遵守。 |
| I14 | 阻尼与接通都相同的等级平局 | R31、R32 只给部分排序条件；任取必须完整登记，不能拿文件顺序当正式优先级。 |
| I15 | 接通同时的通道排序／等价组；离线后通道序如何重取 | R28 由后建端决定形成时刻，R9、Q13、C4 约束；不能把独立随机通道时间替代建造导出的时刻，也不能只覆盖蓝图次序而忽略离线。 |
| I16 | 离线后轮询位置、等级、阻尼分支、当前级、桥端身份等派生状态保留／重算 | Q13 只明确先后可变；不能据此任意清空库存或重置制造进度。未定派生状态须逐字段登记。 |

## 三、制造、物品格与缓存

| 独立项 | 未定义接口／待审取值 | 排除边界与依据 |
|---|---|---|
| I26 | “存货物品格不限制物品种类”是否例外允许混格；容量按总数／按物种 | R13 单格单种，R17 上限50且不限制种类。分配读法已由任务书2 §2 固定；混格须回应 R13，不得由“未定”直接放行。 |
| I27 | “符合某个配方”的论域：每格／全部存格／某个支持子集 | R18、R54 两格配多料；不能无条件要求单格同时包含两种配料且仍遵守单格单种。 |
| I28 | 数量满足：至少一批／恰好一批；额外物种允许／禁止 | R18 通过一次用量即关闭，R92–114 多料配方；“通过一次”固定通过量，不自动证明开启前原料必须恰好一批。无足量就开且永远等缺料须过“符合”。 |
| I29 | 开闸时机：条件满足即打开／制造判定时打开；多原料装入原子／分次 | R18 整批要求明确在出缓存端，进缓存只写一次用量；R35 完整用量到达立即开始。分次仍不能多收或串配方。 |
| I30 | 多个配方可行时选择、锁定点和中途重选 | R18、R35；不能消耗不对应一个正式配方的混合原料。选择先后不得由目标结果反向决定。 |
| I31 | 大机来料选哪个存格，空格身份和耗空后身份 | R13 一单位同种只在一格（储存箱与缓存除外），R54 两存格。存在同种另一格时选空格复制身份被排除。 |
| I32 | 唯一出格与输入格之间同种互斥；出缓存整批容量判定 | R13 是单位范围，R17/18；缓存例外不自动扩散至输入／输出格。前一批和新批同种可累计至50（C72），不同种不得混在出格。 |
| I33 | 缓存的原料、在制、成品怎样计数；失败出缓存后重试；是否可能累积无限多批 | R18、R35 限制下一批开闸，不能凭缓存无限容量取消上批清空门槛；也不能把物料变换和库存守恒重复记账。 |
| I34 | 断电／关机对装料、已开闸、完工待出料和普通物流的影响 | R20 功能停止进度保留，R35 制造需电；物流本身未列需电功能。不能让无电制造推进，不能丢弃已完成产物。 |
| I35 | 制造剩余时间的离散化、恢复时完成边界 | R20 保留，R35 配方耗时；任意清零和从头再做被排除。未走完规定时间不能完工。 |

## 六、已定而不是新选择轴的项目

1. 制造端口与存／取格的对应按斜线分配，R15–17 与任务书2 §2；内部通道另列，不并入外部端口。
2. 协议储存箱一次传输判定按单位，R25、R36；箱内冷却粒度与失败效果另审。
3. 仓库外回路守恒采用当前 C70；不重开旧文字笔误。
4. 供电与不重叠的最严合法性义务按任务书3 §2.1；不能对行为读法援引“最严”而取代全称覆盖。
5. T8 两个已排除恢复读法不得重新放回；身份专属暂停不能偷换成所有阻断暂停。
6. 全部已采纳约束都要在其前件成立时适用。未用任何“面积达到某级”的前件替代一般模型条件。

## 七、对照方法

后续报告逐行把 I01–I62 对到被审文件，核候选来源、排除依据、联合限制与覆盖损失。一个独立项可拆多个正交轴；反之几个独立项也可能受同一不可分的联合约束。轴数不同本身不是发现。对未证明可行的读法只能标待审；明确停止支持而不伪称覆盖，不单独算缺陷。T1/T3 必须另外核每一步完整状态后继与闭包停止是否唯一。
