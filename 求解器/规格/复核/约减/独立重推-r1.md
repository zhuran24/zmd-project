# 参数扫描约减：第1轮独立重推

日期：2026-09-19。性质：独立推导存档。本文在读取六份被复核文件正文之前形成；依据为三份正式文件与第五轮《受限转移定义》§1–5。与约减稿的比较另见同目录《复核-r1-独立重推.md》。初始版本指纹见《独立重推-r1-起点指纹.json》。

## 1. 论域与相等

只研究已建成固定布局、固定设定、固定参数及本版支持种子上的 `event-order-v1` 模板排列。规则L25规定串行判定，任务L14固定同刻先后；二者不直接给出任意事件交换律。受限转移§2.2增加有序重复扫描，§5.1选择首个重复的完整调度状态作为闭包。这些工程选值的交换定理不能升格为全部游戏读法的交换定理。

模板只有 `move(c)`、`manufacture(m)`、`transfer(b)`；完成、时钟递减、显式补矿、窗口到期不是此次全序中的模板（转移§2.1–2.2）。缓存内部搬运是制造的不可插入子动作（规则L18、转移§4.2）。失败访问也可能改变轮询指针，不能只统计成功移动（规则L29、转移§3.3）。

完整游戏状态包括库存与身份、批次与冷却、门计数与阻断原因、现存图、级与环及游标、端口预算、阶段和未处理事件。纯日志序列、轮号、失败次数不参与守卫，但任何尚用于恢复的扫描位置不能直接删去（转移§1、§5.1）。配置中的两份模板序本来不同，比较的是各自固定序下的运行状态，不要求参数文档字节相等。

## 2. 状态坐标与选择器读取

记 `I(u)` 为单位u全部格的物种、数量、年龄，制造含缓存；`P(u)` 为批次阶段、配方/锁定/候选、remaining或箱冷却；`W` 为整个仓库格表及历史身份；`O` 为当前匿名空格全序；`B(p)` 为端口预算；`Q(u,side)` 为当前级、各级环及next_channel；`G` 为现存/阻断PC、准入口原因、计数、窗口起点以及图导出的级序和阻尼。固定布局、设定、时刻、接通/级仲裁、分支表、配方/输入格序另记为只读上下文 `C`。

`Sel(c)` 是源与目标选择器的保守读集（转移§4.1）：

| 端点 | 必须读取的库存坐标 |
|---|---|
| 制造源 | 唯一取货格 |
| 制造目标 | 全部非缓存普通格；不仅存货格，取货格同种占位也可拒收 |
| 箱源/目标 | 六格；编号最小非空/最小能放，不能只看实际选中格 |
| 普通运输源/目标 | 唯一格、源入格年龄 |
| 桥源/目标 | 源对应轴；目标对应轴以及另一轴同种占位；两轴库存独立不等于同种约束或轮询独立 |
| 仓库源 | 被指派格当前内容/身份；若以容器级实现保守合并为W |
| 仓库目标 | W、O及固定取货指派；同种/历史格、新标签碰撞及容量均可影响结果 |

为便于人工及脚本审计，可把上述单位内精细格集合统一上包为 `I(u)`，仓库统一上包为 `W,O`。上包会多保留冲突，不会遗漏冲突。

## 3. 模板本体的读写集

以下先不含每次访问前的共同维护H；H在§4单列。写集是可能写入的坐标，不是只在某次轨迹实际写入的坐标。所有守卫和停止分支都属于读取。

### 3.1 移动M(c)

设c源为u、目标为v，`D(c)` 为u取货侧或v存货侧全部几何可能PC的并集，含断开后可能恢复者。授权先找最高物理可动级，再查该级环（转移§3.1–3.3），所以读集至少为：

`R(M(c)) = C ∪ G ∪ Q(u,out) ∪ Q(v,in) ∪ ⋃[d∈D(c)](Sel(d) ∪ B(d两端) ∪ gate(d))`。

这里同侧其他通道远端的库存会改变c的授权；只按c两端取读集不够。图/阻尼读取可能沿运输路径远达下一个非运输单位，不是一个几何邻域常数。保守使用整个G覆盖动态重算与无终点停止。

通常写集为c两端实际格、B(c两端)、判前授权两侧的Q（含失败前移）；若目标为运输，写entered_at；涉及仓库则写W/O及账；sufficient矿取货扣回同事务，矿数净不变不代表出库/补给账不存在。若目标为准入口，还写其计数/起点/原因，可能删入边并映射所有受影响Q、级序和阻尼，因此保守写整个G及全部Q。相关依据：规则L13、L23、L29–32、L64，任务L7，转移§3.3–3.4、§4.1。

`current_level`可作为当前G、库存、预算的派生量，但若要从交换比较中删去或重新规范它，必须说明规范化时点，并与§5.1首次重复判等一致；不能仅因称为缓存便删除。

### 3.2 制造F(m)

`R(F(m)) = C ∪ I(m) ∪ P(m)`；固定输入格/配方序、供电与开关在C中。`W(F(m)) = I(m) ∪ P(m) ∪ Pending(m)`及该机内部通过账。读整个普通格集，因整批出缓存还核存货格同种占位（转移§4.2第1步）；读缓存与批次以核completed、整批输出、idle取料、intake启动。其它机器的库存不被本体读取。新批至少一个tick，不能在同刻再次完成（规则L18、L20、L35及配方）。

Pending按活动事件的目标/类型/实际触发语义理解；若原始数组追加序参与判等，必须额外把数组作为共写字段，不能凭两台机器不同直接声称字节相等。

### 3.3 传输T(b)

`R(T(b)) = C ∪ I(b) ∪ P(b) ∪ W ∪ O`，其中C包括所有仓库取货指派，因为匿名格竞争停止会检查它们；`W(T(b)) = I(b) ∪ P(b) ∪ W ∪ O`及入库账。冷却未到、有电与开关守卫也是读取；空箱、容量拒收仍写冷却5，身份错误/竞争停止则没有游戏后继（转移§4.3）。

两个不同箱仍共享仓库容量、历史身份、匿名格序与新标签命名，不能用箱id不同判独立。不同物种也不自动独立：可能争抢匿名格，且有已指派匿名格时可观察。单种同仓库入库仍可能在80000上限附近竞争（规则L13、L36、L41、L72）。

## 4. 每次访问前的共同维护H

转移§2.2要求在**每个模板**前，从同一快照查看全部现存准入口入边上的源候选货；身份不符则批量加原因、删边，再按§3.4从完整前图一次映射到后图。H的读集包含所有相关源选择器、门身份设定/原因、现存图、受影响旧环/指针、接通与阻尼分支表；写集含门原因、G与受影响Q。H不因当前模板恰为另一台制造而免做。

因此实际访问是 `A_e = T_e ∘ H`，两个访问为 `T_f H T_e H`。只证明本体T_e、T_f互不读写，不能直接消去中间H。保守做法给每个模板并入H读写集。可更精细地识别H的干扰事件：其本体可能改变某准入口源选择器、门原因、图或维护所映射的指针。判别必须用所有支持状态的可能读写，不是当前源货恰好相符。

可用的更窄充分条件：在比较子域H为恒等，且e、f均保持这个子域；此时本体无冲突即可交换。若改用 `H(S)` 作为规范语义态，须另外证明：H幂等、规范关系对每类模板是同余、H与图/游标映射的插入位置兼容、整轮末及§5.1首次重复边界返回同一语义类。尤其“全体门同时维护”和“分别因两个事件分两次维护”的旧环映射，不能直接当同一事务。

## 5. 六类事件对与交换充分条件

定义保守冲突为 `W(e)∩(R(f)∪W(f)) ≠ ∅` 或反向同式；R/W须含上一节维护，或附有已证可剥离的维护前件。所有未证明的对保留为冲突。

| 对型 | 足够的独立条件与逐类理由 |
|---|---|
| M–M | 双向扩展授权读集与写集不相交，图维护稳定；则物理、授权、选格和失败后效均不受另一方影响，改写互异格/预算/游标，故同后态 |
| M–F | F机库存不在M扩展读取中，M不改F库存/批次，并满足H条件；配方匹配、输出容量、授权不变，各自写互异坐标 |
| M–T | 箱库存、仓库及O均不交叉，M不改T冷却，且H稳定；移动的选格/授权与整箱容量/竞争判定不变 |
| F–F | 不同机器，Pending按独立活动事件而非追加数组序比较，且H稳定；两组取料/出料/启动只改各自单位 |
| F–T | 制造与箱为不同单位，制造不读仓库，且H稳定；互不改对方输入/输出/冷却，局部本体交换 |
| T–T | 默认保留冲突；若另证固定互异仓库目标、无容量/身份/匿名格/标签竞争及H稳定，可再作局部细化，本次没有无条件删除该类边 |

证明模式不是要求两个事件一开始都成功：把无资格、失败、成功、停止分支均视作由R决定的结果。无冲突使另一方不改变所走分支；有游戏后继时两组写入可交换。若一方停止且另一方可能先提交，交换后“停止前完整状态”不一定相同；定理需限定双方全程有后继，或明确停止观察的商关系，不能将停止当普通恒等事件。

## 6. 从局部交换到排列约减仍需的条件

固定一个对称、无自环、对全部所声明输入状态及全程都有效的独立关系。交换全序中相邻独立模板必须在每轮同样交换，不能随状态临时改表。逐轮函数相同且扫描边界比较键相同，才能归纳seen集合、首次重复轮数与返回后态一致；仅“成功事件最终集合相同”不够（转移§2.2、§5.1）。边界制造完成排序若随模板序变动，还须用§2.1的异机完成局部性单独消去。

在这些前件满足时，冲突图上每个全序给出从先到后的无环定向；同一定向的全序是同一偏序的线性扩张，可用相邻不可比元素交换互达，而不可比元素间没有冲突边。反向每个无环定向存在拓扑序。因此排列商与无环定向双射。这一图论结论不替代冲突图正确性的证明；保守多添边只减小约减力度，漏边会合并仍需覆盖的序。

完整态全序不同、日志不同、Pending容器序不同、任意中途种子恢复位置不同，分别是不同问题。整轮规范后态交换即使成立，也不能未经映射直接复用原JSON种子或原始运行记录。

## 7. 独立推导形成的核对项

后续对照重点为：同侧竞争通道的远端读集；桥另一轴同种约束；制造全普通格占位；传输共享仓库与匿名格竞争；准入口共同维护及图映射；失败轮询、current_level和Pending的比较口径；停止分支；完整扫描边界与首次重复。本文未预先采纳任何样例类数或被审脚本的事件边。
