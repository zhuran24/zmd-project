## 16. S2-r5-L3-05：协议储存箱的最小非空格

**结论：refuted=false，未能否证。**

规则 L72 对存货写“编号最小的能放它的”，对取货写“编号最小的非空”；运行语义 L52 正确分开。参数轴 F1 L145 的“箱体逐次取编号最小合法格”没有定义合法谓词。回读其素材独立清单-r3 L391–399，原素材明确列了两条不同原文；“空格不另降级”主要说明存货侧，不足给取货侧新增可出资格。

## 17. S2-r5-L3-04：轮询前件“都”的辖域

**结论：refuted=false，未能否证；修正版排除论证仍不充分。**

1. 约束·研磨进料 L52 写的是“采种机恰 16 台时每台至少 2 条取货通道”。它不推出恰 2 条，也不推出必有少于 5 条的达标实例；至少 2 包含 5，且台数前件本身也不是存在性证明。

## 附录甲：独立条件算术及可复算代码

以下代码本轮以 Python 标准库、`python -B` 从标准输入实际执行；不写缓存或临时文件。机器按闭方块 [x,x+3]×[y,y+3] 算连续交集，正面积要求两轴严格大于零，闭接触要求两轴非负；互斥按整数占格检查。因此没有复用两份被核脚本的 covered_cols/cover_cols。

数字是给定排布的条件算术；断言通过是代码核验，不是实际游戏运行，也不是全体摆放的最优性证明。远处核心仅用于满足唯一核心结构，未声称达标布局。

```python
from itertools import product
import json

def cells(x, y, width, height):
    return {(i, j) for i in range(x, x + width) for j in range(y, y + height)}

def witness(pole, starts_x, starts_y, closed):
    a, b = pole
    pole_cells = cells(a, b, 2, 2)
    occupied = pole_cells | cells(50, 50, 9, 9)
    positions = []
    for x, y in product(starts_x, starts_y):
        footprint = cells(x, y, 3, 3)
        if footprint & pole_cells:
            continue
        assert all(0 <= i < 70 and 0 <= j < 70 for i, j in footprint)
        assert not footprint & occupied
        dx = min(x + 3, a + 7) - max(x, a - 5)
        dy = min(y + 3, b + 7) - max(y, b - 5)
        assert (dx >= 0 and dy >= 0) if closed else (dx > 0 and dy > 0)
        positions.append((x, y))
        occupied |= footprint
    return len(positions)

result = {}
for name, closed, start, count in [("positive_area", False, 23, 5), ("closed_touch", True, 22, 6)]:
    positions = list(range(start, start + 3 * count, 3))
    result[name] = {
        "interior": witness((30, 30), positions, positions, closed),
        "edge": witness((0, 30), [0, 3, 6], positions, closed),
        "corner": witness((0, 0), [0, 3, 6], [0, 3, 6], closed),
        "side_projection": [((g + (8 if closed else 7)) + 2) // 3 for g in range(7)]
    }
assert [result["positive_area"][k] for k in ("interior", "edge", "corner")] == [24, 14, 8]
assert [result["closed_touch"][k] for k in ("interior", "edge", "corner")] == [32, 16, 8]
orbits = {tuple(sorted(((s + r) % 4, (t + r) % 4) for r in range(4)))
          for s in range(4) for t in range(4) if s != t}
assert len(orbits) == 3 and all(len(orbit) == 4 for orbit in orbits)
result["belt_rotation_orbits"] = len(orbits)
print(json.dumps(result, ensure_ascii=False, sort_keys=True))
```
