# 蓝铁块与蓝铁粉末回转：局部核查

日期：2026-09-20。范围：独立的两台机器局部回路；不声称能嵌入任何既定整厂，不是达标布局证书。

依据为游戏规则第 11 行旋转、第 17—18 行制造格及缓存闸、第 23—24 行滞留与移动、第 35 行制造、第 44 行小制造单位、第 60 行传送带、第 76 行供电桩、第 82 行蓝铁块粉碎、第 89 行蓝铁粉末回炼；调试按求解任务第 12 行任意操作。

坐标为格坐标，两台机器输入输出方向相反：

| 单位 | 占格 | 存货侧 | 取货侧 |
| --- | --- | --- | --- |
| 粉碎机 | x=10…12，y=10…12 | 南 | 北 |
| 精炼炉 | x=14…16，y=10…12 | 北 | 南 |
| 供电桩 | x=10…11，y=6…7 | 无 | 无 |

粉碎机北侧端口 (12,12) 接三格带 (12,13)→(13,13)→(14,13)，末格向南接精炼炉北侧端口 (14,12)。

精炼炉南侧端口 (14,10) 接三格带 (14,9)→(13,9)→(12,9)，末格向北接粉碎机南侧端口 (12,10)。每个箭头两端为邻格；首末格各用相应的转弯存取货边，中间格为直带。所有单位占格不重叠。供电桩中心 (11,7) 的 12×12 范围覆盖两台制造单位的至少一部分。没有其他运输连接，每台仅一条承流存货及取货通道。

调试时在粉碎机存货格放一件蓝铁块，其余物品格空；维持供电并开启两台制造。以粉碎开始为 tick 0，以下为每个时刻全部相关动作结束后的状态：

| tick | 唯一物料所处阶段 |
| ---: | --- |
| 0 | 粉碎机开始处理蓝铁块，缓存含一批投入 |
| 1 | 粉碎完成，蓝铁粉末已进入带 (12,13) |
| 2 | 蓝铁粉末进入带 (13,13) |
| 3 | 蓝铁粉末进入带 (14,13) |
| 4 | 蓝铁粉末进入精炼炉，开始回炼 |
| 5 | 回炼完成，蓝铁块已进入带 (14,9) |
| 6 | 蓝铁块进入带 (13,9) |
| 7 | 蓝铁块进入带 (12,9) |
| 8 | 蓝铁块进入粉碎机，开始下一次粉碎，与 tick 0 同阶段 |

每次制造一 tick，每次运输格滞留一 tick，缓存整批一件能直接出格，没有容量冲突。完成时刻的移动按规则第 24 行持续尝试，因此不需玩家精确定时。八 tick 内两种配方各一批，平均各 1/8 批/tick。矿含量始终为一，净消耗原矿为零，净产出任何物品为零。

这个局部例子证明有实际规则机制对应配方收支中的回转项 r；它不能证明已有一个带此回路的完整达标布局。在整厂论证中，新增两台机器与六格带的占地、供电及产能必须一并计入，不能免费加入。
