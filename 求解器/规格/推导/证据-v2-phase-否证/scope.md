# 内核小样例与独立核算的范围

日期：2026-09-20。状态：内核装载失败；独立局部核算通过。

五个小样例仅用于检查回转、正确原料共享通路的停止、k=5周期限制与无周期限制的局部行为。输入使用当前内核的输入生成函数，生成目录改为本证据目录；既有生成器、目录及配置均未修改。每个样例的完整几何中附有未接线的协议核心，这不构成70×70达标布局。

任务第12行允许调试放料；其中一件蓝铁块也能由初始可得蓝铁矿经规则第87行加工取得，不需要假设调试可凭空创造物品。回转中没有争用，制造与运输阶段逐个各耗一tick，具体坐标和首尾状态由复核正文及probe_results.json列出。其余小样例为局部输入状态检查，不承担完整上游供料、完整起法或全参数可达性证明。

五次内核seed调用均在正式源指纹校验处停止，错误为“求解任务.txt: 正式源指纹不符”。原始输入保存在各样例名.json，装载失败信息保存在各样例名-canonical.json，命令与返回码保存在各样例名-seed.json。没有产生游戏后继或内核轨迹，失败不能作为游戏中不可能运行的证据。

check_phase_v2.py中的独立核算仅覆盖所列配方守恒、两种灌装来料表、单件回转几何与八阶段账、k=5收件机会及局部停止条件。其结果不替代内核全参数或整厂验证。
