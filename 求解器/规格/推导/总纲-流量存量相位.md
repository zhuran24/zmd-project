# 总纲：流量、存量与相位的当前有效范围

日期：2026-09-21。状态：按任务书7任务3及总纲首次整体独立复核修订。已证窄式、必要条件和认证义务分列于第3—5节；重写全文的整体复核范围保持；本次终修已核现行来源及R36对所列收支/产能结论的影响，完整布局认证仍待完成。L=0，必要条件上界U=1113，最优位置未知。R、T、C及其现行指纹见第6节。

## 1. 要回答的问题

对同一布局、设定和起法，研究其全部目标内可达循环共有的量。比较的循环均已达标时，两种成品的平均交付率相同；物品分布和节拍可以作为不同观察内容分别记录。具体布局有多少个循环及其状态差异，由该布局的证明给出。认证的任务是覆盖全部相关状态并保证交付。

## 2. 从三个方面观察循环

- 流量：选定周期内每种成品交付多少件、各配方加工多少批、每台机器分担多少、每条通道通过哪些物品。跨周期比较先除以各自周期时长。
- 存量：各物品格的种类和件数、缓存及在制批次、按植物种类分别记录的种子与植株总数和分布。
- 相位：轮询位置、制造进度、准入口当前窗口年龄与计数，以及各机器相对节拍。

R18、29、64 使这些观察内容共同参与运行。固定合法布局、设定、起法及“仓库收得下成品”的环境后，运行目标是 T2 所列全部目标内可达循环的平均交付；完整优化目标同时包含最大空矩形面积、同面积时短边择优及短边至少6格。状态删减的证明义务见第5节。（G-N01—G-N04。）

## 3. 达标循环的成品率与矿物收支

按 C34 的最终只取原矿配置，取仓库外全部库存及在制物料首尾复原、时长为τ的完整循环。令B、C分别为周期内电池、胶囊的实际入库件数，W为原矿出库数，M为非成品入库物品的矿含量。R81—114的配方保持矿含量，C22给每件电池含50件矿、每件胶囊含40件矿，C30、32给原矿出库上限，于是：

`50B+40C+M=W≤52τ，M≥0`。

T2 的两项下限给 `50B+40C≥50×0.6τ+40×0.55τ=52τ`。两式共同取等，得到以下已证必要结论（G-N05—G-N08）：

1. **成品平均交付率恰为电池0.6、胶囊0.55件/tick。** 周期交付件数分别为 `0.6τ、0.55τ`。20tick的12、11件和40tick的24、22件表示同一平均率；T10允许用重复周期比较，件数须先归一。
2. **52个原矿取货口分别满速。** 每口每tick至多一件，合计取等迫使各口各tick均出一件；蓝铁矿与源矿的平均量分别为34、18件/tick（C24、30、32、34）。
3. **非成品含矿物品在达标循环中零入库。** M的各项非负且M=0，复得C66。仓库外含矿库存的周期净变化为零，固定库存及周期内暂存均可存在。逐件计矿损失时使用物品矿含量，例如钢块为2、钢质瓶为4件矿（R88、92、97）。

上述结论以两项目标同时成立为前件。认证给定组合时，须从实际运行证明其目标内所有可达循环均达标；找到其中一个不达标循环，就否掉该布局、设定和起法组合（T2）。其他起法及其他布局分别审查。（G-N09。）

## 4. 净需求、加工、逐机分担与通道量

**成品净需求平均表已确定。** 按R92—100、111、114，从第3节成品率倒推成品链必要净消耗，单位为件/tick：

| 用途 | 净需求 |
| --- | --- |
| 封装 | 钢制零件6；致密源石粉末9 |
| 灌装 | 钢质瓶5.5；细磨荞花粉末5.5 |
| 配件与塑形 | 钢块6+11=17 |
| 精炼钢块 | 致密蓝铁粉末17 |
| 三种研磨 | 蓝铁粉末34；源石粉末18；荞花粉末11；砂叶粉末31.5 |

这些是成品消耗所需的净量。实际加工量另计回转及额外植物加工，逐机分担另列机器，逐通道通过量另列路径与物品；同一件物品依次经过多条通道时，每条通道各记一次。（C44、48；G-N02、G-N14。）

**六类机型的条件满载已定。** 在达标循环内，对粉碎机、精炼炉、配件机、种植机、采种机、封装机这六类中的某类，其台数恰为C46机型下限时，C50规定该类每台连续制造：1tick配方每tick一批，5tick配方每5tick一批。选定τ后，逐台总批数相应为τ或τ/5；混做机器的各配方份额另计。研磨机、塑形机、灌装机以及台数有余量的机型，逐机分担按各自供料、出口及能力约束继续求解；同图不同循环的分担实现性归G-U01。（G-N10—G-N14。）

**蓝铁回转的产能分支已定。** R82允许“1 蓝铁块 → 1 蓝铁粉末”，R89允许“1 蓝铁粉末 → 1 蓝铁块”，均耗1tick。记回炼的平均完成批率为r≥0，粉碎、精炼台数为n粉碎、n精炼。成品需要蓝铁粉末34、源石粉末18、荞花粉末11、砂叶粉末31.5，植物粉碎的必要批率分别为5.5、10.5（R83—84）；每批回炼还需补一次块粉碎。因此：

`粉碎批率≥18+(34+r)+5.5+10.5=68+r`；
`精炼批率≥34+17+r=51+r`。

R18、35、81—89使每台粉碎机或精炼炉每tick至多完成一批，故 `0≤r≤min(n粉碎−68,n精炼−51)`。粉碎恰68台或精炼恰51台，任一前件都推出r=0。C113的“故 A=1113 时九机型恰为下限”使该面积分支同时满足两项前件，因而r=0；九机型恰下限只给该面积结论的必要资源条件，面积的实现仍由几何与运行证明承担。

只有粉碎、精炼两类均有余量时，上述计数才保留r>0的产能可能；仅增加其中一类或其他机型仍受另一类限制。两类都有余量时，附加植物加工、空间与服务条件还会收紧能力，完整达标回转仍待实现证明。r=0分支的逐机分担与逐通道路由也仍须单独核验。（任务书7 §1.3；执行复核P-N02—P-N04。）

**G-U01：全送料表及逐机分担唯一性，缺推导。** C44写“每 tick 至少需”，C48写通道“至少”，C50只给上述六类的条件满载。合用已得到净需求平均表和r的产能界；从这些合计量到每台机器、每条通道的唯一实现仍缺证明。完整达标布局中不同分担或正回转的实现也仍待构造或穷尽核验，局部回转保留其局部证据范围。

**植物收支与必要存量已定。** 植物矿含量为零，成品配方仍给荞花、砂叶的必要粉碎量。停止外部补入后，按C70逐种记录 `ΔN=H−G−I`，H、G分别是采种和植株粉碎的完成批数，I是该种种子与植株入库件数，N含在制份额。恰32台种植机的达标循环按C66、70有植物零入库；按C74，同刻全部判定完成后两种植物合计种子至少64、植株至少64，荞花两类平均存量各至少22，砂叶各至少42。一般增机域及过渡段保留实际I；结构性断开植物入库可以作为具体设计的充分防漏条件。（G-N15、G-N17。）

**G-U02：植物充分存量集合，缺推导。** C70的“完成的批次”给收支，C74的“至少”给必要下界；R18还按逐机配料和上一批出缓存条件开工。合用条文已得到上段的量账，整厂持续供料、排货及默认起法释放安全仍缺具体连接上的充分条件。[回路第二版 §3.7](回路总数决定论-v2.md)的Z界在其单机混线前提下排除输入互等；满输入到末级释放的实际字序及整厂接口由U3、U5、U7承接。

## 5. 认证器仍须完成的三项义务

下列是具体布局的证明义务。第3—4节的已达标必要性质用于核对证明结果；候选达标性由供料、制造、出货及状态覆盖的推导建立。

1. **流量。** 对交付布局、最终设定和起法，证明每个目标内可达循环的两项成品入库量除以各自周期时长均达目标，再按第3节得到(0.6,0.55)、矿口满速和非成品含矿零入库。配方净需求、实际加工、逐机分担及逐通道量分别记录。采用矿口满速和零入库作中间性质时，证明继续覆盖两种成品的正确配比。（G-N14、G-N16。）
2. **存量。** 证明起法的全部后置状态及释放过程满足逐种、逐位置的供料与排货条件，按完成批次计入过渡损失和植物入库。充分安全集合仍为G-U02的缺口；恰32种植机的循环零入库、一般过渡的实际入库和结构防漏条件各按第4节使用。库存删减交任务6，保留或证明覆盖防饿、防堵所需信息。（G-N17、G-U02。）
3. **相位与起法。** 默认执行“关机、填满、开机、末级最后”（任务书7 §0.1）。证明须覆盖不精确操作留下的全部状态、离线造成的接通先后变化，以及C3—11所列每种不得依赖量；T15的判定先后作为一次运行内的固定参数。相位和状态判等的删减交任务6，由保留后继行为、交付与周期对应的证明完成。（G-N18—G-N19。）

采用直接结构证明或局部不变量时，证明覆盖全部相关状态、连接与参数后即可交付。采用轨迹周期证书时，核周期两端、时长、交付账及与任务T10循环的对应；采用状态合并时，核合并后的后继和产率保持。各循环精确库存与周期长度可分别取值，平均产率相同提供的是交付约束，状态删减的充分依据仍须由上述证明给出。“全部执行最终必进循环”只在实际使用这一命题的证法中承担。（T2、10；G-N19—G-N20。）
