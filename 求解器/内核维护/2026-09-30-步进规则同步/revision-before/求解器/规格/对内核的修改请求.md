## 2. 循环接口与级二停止

- public cycle_key须严格实现转移§6.2字段表和[键编码参考](第五轮规格修订/cycle_key_reference.py)。旧私有closure_key保持同刻完整判等，不能换成生产投影。
- `kernel cycle`用execution_mode=production_abstraction；D.1–D.5逐项核，遇会读取矿容量的回矿候选（含满仓拒收候选）/非空O/成品仓库取货等返回明确unsupported；回矿检查须先于容量/physical/授权，不能在抽象外继续产证。普通run保持finite_concrete并可给这些合法坏运行前缀。
- 每tick开始前的成品归零是选择生产代表，不是玩家操作；representative_adjustment独立记扣量，完整代表状态仍保存。接口须允许从(a,after_closure)重跑P次，按输出§5.3核每刻事件、状态、台账和终态键；有记录逐字段比较，无记录独立重建并核周期账、接收域及完整终态。
- 两矿模式对比：矿未耗尽且无读取矿容量的回矿尝试时非仓库、物流和实际交付应相同；sufficient矿库存恒定，补回量=出库量；explicit仓库矿差与补给量按守恒式核，不能强求这两类字段逐字相等。
- 级二F只要求未满不足：79999+2的整箱拒收使投影/入库账不同，详见转移§6.5。periodic_lift现在只阻断级二；K线可以产级一，但不得启用full_base成功证书。不是把全部循环检测继续挡在旧stop轴后。
- 计数/年龄精确保留，特别是无累计上限门的total_received未删除，长期增长会漏检一些实际周期；不能在代码自作主张截断为0。有限预算无重键是未决。

def check_documents(schema):
    body = (SPEC / '内核输出.md').read_text()
    fields = re.search(r'所有结果必填`([^`]+)`', body).group(1).split(',')
    assert len(fields) == 20 and set(fields) == set(schema['$defs']['CycleResult']['required'])
    forbidden = ['后者内含可独立验收的v3记录', '完整StateSeed、Parameters和读取的原始输入在文件内',
                 '完整正式源/规格指纹在run_record', 'domain_checks引用support_domain']
    assert not any(phrase in body for phrase in forbidden)
    for name in ['内核输出.md', '对内核的修改请求.md', '修订记录.md']:
        document = (SPEC / name).read_text()
        for destination in re.findall(r'\[[^\]]+\]\(([^)]+)\)', document):
            if '://' not in destination and not destination.startswith('#'):
                assert (SPEC / destination.split('#')[0]).exists(), (name, destination)
    return {'required_field_set': 'PASS', 'field_count': 20,
            'old_inline_contract_phrases': 'absent', 'markdown_link_targets': 'PASS'}
