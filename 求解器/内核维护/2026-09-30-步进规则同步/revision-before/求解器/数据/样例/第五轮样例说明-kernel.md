# 第五轮内核样例与证据范围

日期：2026-09-19，验收补充至2026-09-20。状态：合成执行样例；具体状态与参数由输入文件锁定，可达性按每份输入的`initial_state.reachability`单列。库存预置是条件种子，不代表已给出满足操作精度的玩家起动程序。

| 输入名称 | 实际机制与结论边界 |
|---|---|
| 混做粉碎机两下游、分流器三路轮询 | 原有4刻/12刻黄金及完整独立参考；新输出使用`-运行记录-v3`，原v2文件保留历史身份 |
| 桥接器双通路 | v3完整历史/参数/种子；两种成品从独立源箱经两桥轴到有电传输箱，实际无线入库。方向在运行前已解，先接仅作输入历史检查，无运行定向事件 |
| 传输拒收与暂停核验 | 满仓砂叶与电池的整箱事务拒收；另一停用箱保留正冷却。暂停后再启用没有发生 |
| 研磨混做核验 | 两原料来源箱与真实输送；研磨机依次完成蓝铁、源石两种致密粉末，产物经箱入库；有限原料不代表持续生产 |
| 阻尼连续带核验 | 非运输取货侧两个级，实际请求含连续两带的阻尼路径，只覆盖path_runs带串计数；几何邻接轴未调用 |
| 阻尼切支恢复核验 | 依当前可用集查固定分支表，窗口限额切边并在到期后恢复；精确累计计数没有截断 |
| 生产循环环带 | 有真实循环运动的运输环及空箱传输周期；保存完整键和生产部分周期结果，零周期交付率构成条件低产反例，不是完整任务无解 |
| 轮询均分核验及序0–序5核验 | 仓库蓝铁矿真实供料，精炼炉同级三支；逐件核收后1 tick清空和下一组前释放，六局部模板全序均检有限前缀的均分 |
| 密集结点核验 | 两独立仓库口持续供矿，D/E直接竞争M，有限前缀内两者正流量；有限末端箱不能证明循环前件 |
| 密集结点闭环核验 | 各出路反馈至两供料箱；额外条件库存占位，尝试寻找实际闭合周期。预算内未获证，不将正前缀流量当周期流量 |
| 密集制造闭环序0–序5核验 | 非仓库空条件种子，真实仓库4件蓝铁矿起动，粉碎/精炼1:1回流；固定其它字段只排列D三模板。4份周期通过独立重跑和前件审计，直接分流比为0或1；序2/5在1000 tick内未决。未证明空条件种子的全部可达史或全局模板全序 |
| 密集结点循环种子核验 | 由上述物理配置另选条件检查点，箱内`entered_at`显式取null；这改变了完整种子，不是原轨迹逐字段可达证明，也没有修改生产键删除年龄 |

生成入口为[基础场景](../../crates/kernel/tests/round5_scenarios.py)、[密集闭环](../../crates/kernel/tests/dense_cycle_round5.py)、[条件检查点](../../crates/kernel/tests/dense_seed_round5.py)、[六种局部序](../../crates/kernel/tests/variants_round5.py)和[密集制造闭环六序](../../crates/kernel/tests/dense_manufacturing_round5.py)。它们使用共享目录导出几何、端口和全部PC，不手填随意连线。分支全表的备用选择是样例明确给出的参数点，内核没有缺表默认选择。新增种子必须保留显式级仲裁；`kernel seed`计算冗余上下文，不声称求得全称可达初态。

每份v3记录单独锁定来源，验收先核指纹和schema，再核逐笔仓库账、箱体整批账及Rust完整重跑。两旧样例另与独立Python参考全部字段比较。六局部序和有限前缀均不能替代R线的参数域约减或S线的一般规则相容性证明。

K6仍缺三项运行覆盖：connection.bridge_first_contact需建造/先接转移，transfer.resume_event需暂停后的开关/供电恢复转移，均超出固定已建成运行段；damping.belt_adjacency专供geometric_components，本版path_runs不调用。桥上搬运、普通冷却到期、连续两条带分别不能替代上述三项机制证据。

制造闭环的场景前件见[独立审计](../../crates/kernel/evidence/round5/dense-manufacturing-audit.json)：同一物品在M内停留恰1 tick、D服务前两旁路首格全空且其实际收货也恰1 tick释放、D总出量和另一来源E入M量在周期内均正、两制造源确有完成、两直接入边正式接通键相等，全部按真实事件核验。序0/1周期190 tick、分流比1；序3周期105 tick、序4周期395 tick、分流比0。目标成品率均为0，因此证书为条件低产反例，不是达标布局或全称无解证明。
