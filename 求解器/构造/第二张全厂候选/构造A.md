# 构造 A：S2 固定接法的边界布线障碍

日期：2026-10-02。状态：**已证明本任务固定的 S2 纯带接法无法实现；没有布局，静态通过为 false，未实现空矩形。**

不要求空矩形时，这条接法也无法在 70×70 内无交叉布线。障碍只用到 S3 砂叶粉碎机、B3/B4 蓝铁粉末研磨机、O4 源石粉末研磨机、E2 封装机及其部分上下游：**三个研磨机分别连接同一砂叶粉碎机、同一封装机和基地外边界，形成 K₃,₃ 的细分。** 纯传送带进路互不共格时不能实现这一结构。

这是一份固定接法的不可行证书，不是搜索超时，也不是所有达标布局都不可行的结论。本席没有抬高正式下界 L。

## 2. 必须实现的局部接法

S2 第 2.2 节第 1—4 项和第 2.3 节的 S3 行已经强制以下结构，不依赖如何分配具体端口或如何摆放机器：

- S3 分别向 B3、B4、O4 送砂叶粉末。
- B3→R3→P3→E2，B4→R4→P4→E2，O4→E2。
- B3 的两条蓝铁粉末来路中，选第 5 条蓝铁矿链；B4 选第 7 条蓝铁矿链；O4 的两条源石粉末来路中，选第 7 条源矿链。

第 7 条源矿链来自仓库取货口，因为 S2 只把前六条源矿链接到协议核心。两条蓝铁矿链也来自仓库取货口。因此，三个选定来源都是任务要求放在左、下边界的真实仓库取货口。

为精确列路，补充以下 ID；原 S2 的 B、O、S、R、P、E 编号保持不变。

| ID | 单位身份 |
|---|---|
| WFE5 / WFE7 | 第 5 / 7 条蓝铁矿通道的仓库取货口 |
| RF5 / RF7 | 第 5 / 7 台把蓝铁矿炼成蓝铁块的精炼炉 |
| KF5 / KF7 | 第 5 / 7 台把蓝铁块粉碎成蓝铁粉末的粉碎机 |
| WO7 | 第 7 条源矿通道的仓库取货口 |
| KO7 | 第 7 台把源矿粉碎成源石粉末的粉碎机 |
| X | 基地外部的辅助顶点，仅用于数学证明，不是游戏单位或实际通道 |

九条无向路径如下；“—”表示邻接，成品支路逆向列写不改变实际物流方向。

| 两端 | 经过的顶点 | 真实物品流 |
|---|---|---|
| X—B3 | X—WFE5—RF5—KF5—B3 | 蓝铁矿、蓝铁块、蓝铁粉末 |
| X—B4 | X—WFE7—RF7—KF7—B4 | 蓝铁矿、蓝铁块、蓝铁粉末 |
| X—O4 | X—WO7—KO7—O4 | 源矿、源石粉末 |
| S3—B3 | S3—B3 | 砂叶粉末 |
| S3—B4 | S3—B4 | 砂叶粉末 |
| S3—O4 | S3—O4 | 砂叶粉末 |
| E2—B3 | E2—P3—R3—B3 | 致密蓝铁粉末、钢块、钢制零件 |
| E2—B4 | E2—P4—R4—B4 | 致密蓝铁粉末、钢块、钢制零件 |
| E2—O4 | E2—O4 | 致密源石粉末 |

其中 X 接三个仓库取货口的边是辅助边，其余每一段都是 S2 明列的一条真实进路。总计 14 台制造单位、3 个仓库取货口、18 条真实进路。九条路径的内部顶点两两不相交，也不包含六个分支顶点；S2 又要求不同进路的运输格互不共用。

机器可读证书保留既有程序的零基名字和原进路 ID，便于直接核对：[S3—E2 证书](构造A/证据/不可平面证书-S3-E2.json)。例如 `铁研磨2` 是 B3，`源研磨3` 是 O4，`砂叶粉碎2` 是 S3，`封装1` 是 E2；证书中的 `仓库取货口40` 是 WO7。

## 3. 为什么任何摆放都会矛盾

先假设存在满足全部结构条件的布局。把 70×70 的每个格作为一个顶点，正交相邻格之间连边，得到平面方格图。每个制造单位或仓库取货口的矩形占格是一个连通子图，每条纯带进路是一个连续格路径。不同实体不重叠、不同进路不共格，所以删除不需要的格和边、收缩每个机器矩形及路径内部格后，得到的连接图仍然是平面图。

所有仓库取货口都接触方格图的外边界。在基地外面加一个顶点 X，把它连接到三个选定仓库取货口，可以让这三条辅助弧只在 X 相遇、不穿过基地内部。这是在原图的外面添加数学辅助边，并没有给实际布局添加物流功能。等价地，先给完整方格图的外边界加一个公共外部邻点，再取子图和做收缩。

保留第 2 节的九条路径，压缩全部度为 2 的内部顶点。剩下的两组分支顶点是：

`{X, S3, E2}` 与 `{B3, B4, O4}`。

两组之间的九种配对各有一条边，正好是 K₃,₃。它有 V=6、E=9。若能在平面上嵌入，欧拉公式给 F=2−V+E=5；这个简单二分图没有桥，每个面的边界至少长 4，因此必须有 2E≥4F，即 18≥20，矛盾。也可直接写成二分平面图上界 `E≤2V−4`，而这里 `9>8`。

因此，本任务固定接法没有合法几何实现。这个障碍在放宽机器尺寸、端口朝向、供电、H6/Q6 等长及空矩形限制后仍然成立；任何更严格的逐格模型也无解。仅增加绕路长度、转动机器或扩大矩形基地，都不能消除同一外边界来源与纯带不相交之间的矛盾。

不能省略“取货口在外边界”这一前提：既有完整逻辑图在不要求边界来源共处外面时是平面的；加上外部辅助顶点以后才不可平面。[独立库复核](构造A/证据/拓扑复核结果.json)明确记录了这个区别。

## 4. 计算结果与检查边界

[接法生成器](构造A/代码/build_s2.py)独立转写了 230 台机器、325 条进路及有理数设计流量，与冻结的 `graph_98040.json` 逐项比较，缺失和多余进路均为 0。机身面积重算为 3567 格；每台机器的输入、输出守恒按精确分数核验。这个结果只验证接法转写，不是可运行几何证书。

[证书检查程序](构造A/代码/check_topology.py)直接读取冻结的原始逻辑图，不导入本席接法生成器。它核验原进路存在、辅助边只接边界取货口、九条路径内部不相交、压缩图为完整 K₃,₃，并分别生成 S3—E2、S5—E3 两份证书。删去九种配对中的任意一条后，小图都恢复可平面嵌入；三种损坏证书均被拒绝，避免把任意图一概判死。

六个度 3 顶点的循环次序共有 64 种。[完整枚举](构造A/证据/全部64种旋转系统.json)得到 40 种有 3 个面、24 种有 1 个面，没有平面嵌入需要的 5 个面。[CP-SAT 程序](构造A/代码/cp_sat_presolve.py)精确编码这张表及欧拉条件，返回 `INFEASIBLE`；[撤去平面条件的对照](构造A/证据/CP-SAT-撤去平面条件对照.json)返回 `OPTIMAL`，最大面数为 3。另用 NetworkX 独立检查，两个局部细分与添加边界辅助点的全图均不可平面；完整 70×70 方格图加外部邻点本身是平面的。

逐格整数模型以[文档中的数学约束](构造A/整数模型.md)给出。实际执行在展开坐标变量前由必要子问题终止，**没有声称跑完一个已实现的全尺寸坐标 CP-SAT 模型**。不要求空矩形的阶段已经有确证矛盾，故未继续固定宽度至少 6 的矩形做扩大搜索。

本席静态程序提供占格、端口重建、额外自动通道、纯带路径分解、S2 逐路匹配、配方、供电、仓库端口、等长、最大空矩形和精确平均流检查入口，单位 ID 采用本报告定义。其几何组件经过[对照测试](构造A/证据/静态程序组件对照.json)，包括 80 张小图的最大空矩形与独立穷举比较。但是没有完整布局输入，不能宣称这些坐标检查实际通过；[静态结果](构造A/证据/静态检查结果.json)逐项保留“无布局，未执行”。程序的整体静态通过值为 false，运行认证为 false。

旧检查器 A/B 的固化指纹与本轮快照不一致。由于没有可以复查的布局，本次未复制修改它们的逻辑、未做版本适配、未调用候选入口。[复查状态](构造A/证据/旧检查器复查.json)包含原入口及目录数据的指纹，并明确不是 A/B 的通过或拒绝结论。

## 5. 与 737 格的关系及剩余范围

S2 第 9.3 节的 737 格来自：

`4900 − 3567 − 81 − 46×3 − 4×11 − 333 = 737`。

这只是满足机身、核心、仓库取货口、最低桩数和最低运输格数的面积预算。它没有保证指定接法能够在平面中嵌入。这里的差距不是“多用了多少格”，而是固定接法的可行域为空；没有一张实现了某个空矩形面积的布局可与 737 相减。

第 4 节调试和每个可到达循环态达标未执行，也没有凭抽象图模拟抬高 L。本结果没有直接否证“若几何结构和起态成立，则达标”的动态蕴含；它证明本任务指定的几何结构前提不能成立。若改变砂叶粉碎机分组、矿石来源或运输结构，须重新检查几何和相应运行充分条件；这样的新接法不属于本次已证明不可行的固定范围。
