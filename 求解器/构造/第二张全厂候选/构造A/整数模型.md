# S2 接法的摆放与纯带布线整数模型

日期：2026-10-02。状态：平面性必要子问题已证不可行；未展开全尺寸坐标模型，没有布局。

模型域为 [逻辑接法.json](逻辑接法.json) 的 230 台制造单位、46 个仓库取货口、1 个协议核心、325 条进路，以及数量可变的供电桩。没有桥接器、分流器、汇流器、物品准入口或协议储存箱。以下是完整逐格整数约束的数学定义；可执行的 [CP-SAT 程序](代码/cp_sat_presolve.py) 求解它的必要拓扑子问题。不能把这个程序称为已经实现或运行了全部坐标约束。

## 1. 摆放

令 G={0,…,69}²。每个固定非运输单位 u 的合法位置和旋转集合为 P_u；制造单位按规则分别占 3×3、5×5、6×4 或 4×6，协议核心占 9×9。仓库取货口的位置只枚举左、下边界的 1×3、3×1，端口朝内。每个候选 p 记录占格 C(p)、全部存取端口及其外侧邻格。

对每个 p∈P_u 设二元变量 x[u,p]，要求 Σ_p x[u,p]=1。对供电桩的每个 2×2 合法位置 q 设二元变量 h[q]。供电范围按列 q.x−5…q.x+6、行 q.y−5…q.y+6 计算。对每台机器及每个候选位置要求：

`x[u,p] ≤ Σ_{q: C(p)与q的供电范围相交} h[q]`。

这允许机器只被覆盖一部分，符合规则。没有预固定桩数、机群位置或相对朝向。

## 2. 逐格进路

对于每条逻辑进路 e=(u,v,item)，每格 c 设二元变量 z[e,c]，表示该格属于本路的传送带；对每一对正交相邻的有序格 (c,d) 设二元变量 f[e,c,d]，表示本路从 c 送到 d。

对起点候选 p 的每个取货端口 k，外侧格为 c 时设二元变量 s[e,p,k]；对终点候选 p 的每个存货端口 k 同理设 t[e,p,k]。外侧邻格不在 G 的端口不能被选择。

约束为：

1. Σ_{p,k}s[e,p,k]=Σ_{p,k}t[e,p,k]=1，且 s[e,p,k]≤x[u,p]、t[e,p,k]≤x[v,p]。
2. 同一实体端口在同一候选位置上，所有进路的 s 之和或 t 之和至多为对应 x[u,p]。核心六个取货端口均设置源矿，六条指定源矿路分别选择不同端口；七条成品进路选择七个不同的核心存货端口。
3. 每格 c 的入度：Σ_d f[e,d,c]+Σ_{起点端口外侧格=c}s[e,p,k]=z[e,c]。
4. 每格 c 的出度：Σ_d f[e,c,d]+Σ_{终点端口外侧格=c}t[e,p,k]=z[e,c]。
5. 设置整数距离 r[e,c]∈{0,…,4899}。f[e,c,d]=1 蕴含 r[e,d]≥r[e,c]+1；选定起点格的 r 为 0。这样没有有向环，也不能靠与实际进路分离的循环满足守恒。
6. 每路 Σ_c z[e,c]≥1。

只有一个起点、一个终点，且使用格入度、出度均为 1，无环条件使所有使用格构成唯一的简单有向路径。每格的前后方向唯一确定传送带的存、取货边，方向不能相同。路径入度和出度中的每一条边必须采用真实相向端口，不能经过其他机器或跳格。

## 3. 占格、自动通道与等长

对每格 c 要求：

`Σ_{u,p: c∈C(p)} x[u,p] + Σ_{q: c∈C(q)} h[q] + Σ_e z[e,c] ≤ 1`。

因此机器、核心、取货口、桩与所有进路互不重叠，各进路也不共用运输格。运输单位全部来自 z，不另有游离运输格。每个传送带的两个端口已经由本路相邻边占用，邻格唯一，不能再与第三个单位形成自动通道；其余两边没有端口。非运输单位直接相邻不形成通道。由此要求的自动通道集合恰为路径的逐段通道，静态检查器仍须从全部单位端口独立重算这一点。

H6→F4 与 Q6→F4 分别对应 e₁、e₂，加入 `Σ_c z[e₁,c]=Σ_c z[e₂,c]`。每台机器只接收接法指定的物品，配方固定为设计声明，不能把它当作游戏中的过滤设定。

## 4. 空矩形阶段

第一阶段不添加空矩形限制。找到完整可行布局以后，才能选定一个宽、高均至少 6 的格矩形 R，并对 c∈R 强制第 3 节占用和为 0；随后枚举更大面积，同面积优先较大短边。R 外的实际最大合格空矩形仍由检查器重算。

本实例第一阶段已经不满足必要平面性，因此没有执行空矩形扩大。面积上限 737 不是可行性保证。

## 5. 可证明的拓扑预处理

任一完整整数解，在方格邻接图中将每个机器矩形收缩为一个顶点、把纯带路径压缩为边，就得到接法的平面嵌入。所有仓库取货口在外边界，故还可以在基地外添加一个辅助顶点 X，以互不相交的外部弧连接选定取货口；这些弧仅用于证明，不是游戏通道。

[逐路证书](证据/不可平面证书-S3-E2.json) 给出一个 K₃,₃ 细分。压缩度 2 顶点后，六个分支顶点均为度 3，各有两种循环次序，共 2⁶=64 种。令 q_i∈{0,1} 为循环次序，F 为有向边置换的面循环数。穷尽 64 种组合后得到 F 只能为 1 或 3；平面嵌入由 V−E+F=2 要求 F=5。

CP-SAT 用一个允许元组表精确表示 `(q₁,…,q₆,F)`，并加入 F=5。结果为 **INFEASIBLE**，没有时间限制触发或数值误差问题。独立纯 Python 校验还核对了九条路径内部顶点互不相交，并使用简单二分平面图的界 `9≤2×6−4=8` 得到直接整数矛盾。NetworkX 仅为第三种复核，不是唯一证据。

这一步是全尺寸整数模型的必要条件预处理：任何全模型解都将诱导这个子问题的解；子问题无解足以终止全模型搜索。未生成坐标候选，未把“机器机身能装入”误报成合法全厂摆放。
