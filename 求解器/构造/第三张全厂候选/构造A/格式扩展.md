# 相邻桥接器与诊断文件的表示

日期：2026-10-02。`未通过候选.json` 使用原有 `full-factory-static-v1`，记录完整单位坐标及实际接通的部分进路；文件名、报告和静态结果均说明它未通过。其桥接器互不相邻，原格式足够表达。

相邻桥的局部检查样例使用 `full-factory-static-s2-bridges-v2`。它保留 v1 的单位、坐标、端口引用、物理通道和逻辑进路字段，作以下明确扩展：

| 字段 | 含义 |
|---|---|
| `schema` | `full-factory-static-s2-bridges-v2` |
| `temporary_rules_sha256` | 冻结的流水线临时规则的 SHA-256 |
| `design.class` | `s2_isolated_paths`；不冒充原 v1 的 N4b/P5 类 |
| `design.physical_channels` | 包含全部前向通道及相邻桥自动形成的逆向通道 |
| `design.logical_feeds[].path` | 仅顺序列出本进路的前向通道 |
| `design.bridge_reverse_channels` | 逐条列出真实逆向通道的 ID；不是删除这些通道的开关 |
| `diagnostic_only=true` | 明示局部或未完成接线的检查样例，完整静态闸门必须拒绝 |

检查程序不使用 `H_in`、`V_in` 生成桥端口，而先把桥的四边都还原为存取兼用端口。它从几何重建所有通道，再沿每轴的对边分解进路；仅允许已使用前向桥—桥通道的真实反向通道作为附加边。同一轴只能归一条进路，两轴归不同进路；不用轴必须没有通道。不允许用一个桥的 H/V 合并节点转轴。

这些字段只记录静态结构，不编码或直接指定物品的“刚离开的单位”。S2B 的正向来源记录、满库存起态、制造进度与货龄，需要其独立调试及运行证明。局部桥样例只检查端口、通道和路径几何，没有全厂物料或循环态认证。

旧检查器 A/B 的完整 v1 入口仍不支持这个扩展。本目录仅在无相邻桥的 v1 失败候选上复用其未改动的几何和平均流模块，并明确没有适配其完整 77 条台账及动态条文。
