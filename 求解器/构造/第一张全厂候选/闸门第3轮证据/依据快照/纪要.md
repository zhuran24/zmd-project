# 会议 3 纪要：带子这一层怎么表示

2026-09-22。八席：seat-opus-1…4（Claude opus）、seat-codex-1…4（codex，经转发层）；主席为主会话，不发言。会议结束时八席一致认可冻结稿 共识稿-v4-7aae9e20.md（SHA256 7aae9e20fdfab4edc5cb44b4de5a083436c86874449af654e9b0ee9871da5578），冻结后只追加了一条勘误（C2 测点）。报信席 seat-opus-4。没有需要 owner 定的事。

本纪要由主席按冻结稿、勘误和各席终稿整理，是转述；冻结稿是正本。

## 讨论的问题

1. 带子这一层（传送带、分流器、汇流器、准入口、桥接器）在几何模型里怎么表示。
2. 流量和「谁接给谁」怎么写进这一层。
3. 规则里决定谁先动、谁能进的那些机制，推出的条件怎么落到这一层上。

## 一致的结论

**表示。** 每个格子取一个有限的状态：空、某个非运输单位的一部分、传送带 12 种、分流器 4 种、汇流器 4 种、准入口 4 种（另带放行种类和两种上限的设定）、桥接器。两格之间有没有通道，由两边朝向对方的端口一取一存推出，「当且仅当」。桥接器每条轴的方向也是推出来的：两端一取一存时，接通先后怎么变方向都一样，由设计定；两端同为取或同为存时才随接通先后变，那是坏设计。机器按「机型×朝向×位置」建布尔变量，不给机器编号，70×70 上约 15.6 万个；每种机型的台数是这些变量之和，只要求不少于下限。

**放松不漏布局的判据。** 对每张达标布局，都能给出它在放松模型里的像，这个像满足放松模型的全部约束，空矩形不变小。删变量、删约束、把各物品的流相加，都可以这样证明。

**流量和谁接给谁。** 不另设「谁接给谁」的变量。物理上谁和谁相连由格状态推出；谁的产物供给谁，是按物品的平均流量做路径分解。流量取一个实际可达的达标循环态里、每条通道每种物品一周期通过件数除以周期。这一层只要求存在一份满足必要条件的平均流，不证明运行能实现它。流量用连续变量；用固定分母 1/K 的模型解不出，不能拿来降 U。能留在 CP-SAT 里取整的是按物品子集分开的几份流，每份单独是网络流，拼不回联合流的部分交给连续 LP，再以割的形式送回。

**先后机制。** 压 U 这一头，第一档不为这些机制另写约束：它们推出的大多是「前提成立时才怎样」的条件句，前提由运行决定，还没落成几何约束。删掉约束永远是放松，所以这样做不漏布局。准入口的放行种类和每 5 tick 上限可以直接写。抬 L 这一头，候选用受限的办法避开机制被触发（N1 不触发取货分级、N2 不触发存货分级、N3 准入口不设累计上限且不被堵死、N4 桥每轴一取一存且两桥不相邻、N5 每条结构通道设计流量为正），每条限制登记它丢掉的布局。储存箱按「最小编号格」的规则逐个核，不能当成随取的池子。

**抬 L 的流程。** 摆放发生器 → 启发式布线 → 两份独立检查器按「当且仅当」重算全部通道 → 连续 LP 核分物品流量 → 运行条件、调试办法、内核。第一个受限类是点对点：只用传送带和桥，每条通道只走一种物品，从一台机器的取货口直通另一台的存货口，粉碎机和采种机每台只做一种配方。它只覆盖 219 台以上那一支（这一支的算术上限 1108），用来造第一张布局，不管顶端。

## 测点（每条只说明那一次，负载 10–32，24 核上多席同时跑）

| 测点 | 规模 | 结果 |
|---|---|---|
| 只要求端口外有运输格（E0），无流量、无矩形 | 70×70，217 台 | 15–27 s 出解 |
| 把 E0 的解拿去跑最大流 | 同上 | 两个解都不可行，缺 103、107 件/tick（相对总量 305.65 只作量级参照） |
| 钉住 E0 的机器位置，运输格和流量放开 | 同上 | 1.3 s 判不可行 |
| E0 加不分物品的流量层（E1′） | 70×70 | 900 s 没找到解 |
| 固定 21×53，只要求端口外有运输格 | 70×70 | 600 s 判不出 |
| 玩具 12×12，几何主问题加割循环 | 12×12 | 200 轮不收敛；人摆 11 格运输即可行 |
| 粗网格割循环（C2，不放矩形） | 70×70 | 29 轮 1800 s 不收敛，缺口最低到全缺的 68% 后回升，第 28 轮主问题解不动 |
| 摆放＋布线一起交 CP-SAT | 6 台 / 12 台 | 48 s 最优 / 120 s 没找到 |
| 摆放固定，CP-SAT 只布线 | 96、102 台 | 300 s 没找到 |
| 同样摆放，启发式布线器 | 96、102 台 | 0.9 s、15.4 s 布通，两份检查器零错；钉回 CP-SAT 1 s 内判可行 |

由这些测点得到的读法：只带端口邻接的几何放松离流量可行差得很远，所以流量层有可能真正压 U；70×70 上「解得动」目前没有正面测点；抬 L 这一头，启发式布线在 CP-SAT 找不到的地方布得通，摆放需要带上「布得通」的条件。

## 未决

- 70×70 上能覆盖全部达标布局、又解得动的模型还没有。粗网格、子集流、LP 回送割的组合与代价要继续测；割每条只切一小块、积累多了主问题解不动。
- 摆放发生器里「布得通」的代理条件：端口邻接太松，带流量联合又解不动，中间还没有测点。
- 全厂第一张静态候选（219 台，用哪些砖、走廊多宽、空矩形放哪，和真实取货口、核心、供电桩一起摆）还没做。检查器还没接核心、取货口、储存箱、供电桩。
- 混料：「比例对、偏差有界、两格各 50」不是充分条件，局部反例见 seat-codex-2.md 6.3；偏差要有具体数值界。
- 三处规则读法暂不问 owner：两座桥相邻时端口怎么定型（抬 L 先避开）；「一段连续的传送带」按通道还是按几何相邻读（只影响阻尼）；桥两轴共同存货分级时「能移动」的读法。
