# 全厂静态检查器 A

日期：2026-09-22。状态：本实现已迁移到现行 72 条约束版本（`a67c18de…`），版本 `checker-a-1.1-gate1`；61 项原有自测和 7 组闸门回归通过。入口格式为 `full-factory-static-v1`。尚无一张完整几何候选在本检查器上取得 `static_pass`。静态通过不认证运行，不更新 L 或 U。

## 使用

在仓库根目录执行：

```bash
python -B 求解器/构造/第一张全厂候选/检查器A/check_full.py 候选文件.json \
  --out 求解器/构造/第一张全厂候选/检查器A/候选检查报告.json
python -B 求解器/构造/第一张全厂候选/检查器A/selftest.py
python -B 求解器/构造/第一张全厂候选/检查器A/verify_certificate.py \
  求解器/构造/第一张全厂候选/检查器A/format_example.json \
  求解器/构造/第一张全厂候选/检查器A/format_example.report.json
```

依赖 Python、SciPy（包含 HiGHS）、NumPy、NetworkX；无内核依赖。LP 单线程，BLAS/OMP 也设为 1。`--time-limit` 默认每次 LP 调用 60 秒；基础可行性、必要时的第一阶段、最大化共同 δ 是不同调用。单候选最多三次调用。出口码 0 为静态通过，1 为拒绝，2 为未决。无虚拟接口、旧格式或示例放行开关。`--out` 限制写入 `第一张全厂候选/` 内；输入只读。

入口将语法/正式文件指纹、几何、受限类、平均流及后验必要条件共同作为闸门。任何违反或未决均不得给 `static_pass`。72 条覆盖及下文编号对应所支持的当前版本；旧指纹不再被当作当前正式输入接受。`runtime_pending` 是本工作流明确留给运行阶段的义务，`blocked` / `partial_blocked` 表示前置检查失败导致依赖检查未执行，不能读作通过。

报告绑定候选 SHA-256 和七个生产模块的字节 SHA-256，包含全部重建通道、机器数、供电覆盖、最大空矩形、限制检查、精确流见证或对偶证书，以及失败覆盖域。成功实例最多保留三个前件示例，每一项失败保留具体证据。

## 核心语义

- **真实单位。** 仓库取货口是完整 3×1/1×3 实体，只能在左/下边界，长边中点向内取货；两边各23个及 18 源矿/34 蓝铁矿设置另核。核心唯一、9×9、14存口/6取口，六个取口分别播种其设定物品；核心收进物品不会自动变成别的取口来源。机器按 `model` 和 `recipe_ids` 查正式配方，不解析显示字段 `role`。
- **供电。** 2×2 桩锚点 `(x0,y0)` 覆盖格列 `x0−5…x0+6`、行 `y0−5…y0+6`。机器/箱体只需一格重叠；仅边界相碰不算。无电/关闭制造将 LP 批率置零，无电/关闭无线只把箱体无线量置零，物理端口仍在。
- **桥和通道。** 桥方向先从非桥邻端口推导，与 `H_in/V_in` 比对；单端、同类两端或相邻桥均不能通过。单端桥仍根据已接邻端推导方向并保留真实连接，不能用 N4a 拒绝来删除 N5a 应重建的边。桥两轴是不同物品格，可以承载同种物品。所有满足“相邻、一取一存、至少一端运输单位”的端口对必须出现在声明中，漏边、假边及错误 offset 均拒绝。准入口过滤和开关不删除结构边。
- **协议储存箱。** 检查3×3占格、三存三取端口、供电/无线开关、物品传播及平均入=物理出+无线；P1直接拒绝有箱的 p2p 候选。n_restricted 的箱体仍保留编号格、最小编号取放、有限容量、相位等运行义务。没有箱体仍核 B0=B1=0 的“箱体接口/预算/过站”。
- **种类风险。** 不用 `allowed_items` 挡货。从各真实源取口、声明配方产物开始，对所有结构通道和完整机型配方求最小不动点；桥分轴、准入口只按真实 filter、箱体物理转发。分别报告本机型误料、设计外原料和通道设计范围外种类。保守可达风险只拒绝该受限候选，不证明物品必然到达或几何全域不可能。
- **空矩形。** 对整张70×70占格图枚举行区间，扫描共同空列，独立取 `(面积,短边)` 字典序最大；两边至少6，并列位置任意。实体包括关机、未用桥轴所在格、无流量单位及桩，供电覆盖区不占地。与声明的面积/短边和占空性比对。后续面积约束使用独立算得的最大值。

## N1–N5b 与 P1–P6

| 项 | 执行检查 | 依据 |
|---|---|---|
| N1 | 全部非运输单位结构取货通道≥2时，无直接汇流器分支；包含核心、仓库口和箱体。 | 约束#5“取货分级”；格式§8.2；共识第三节第3条。 |
| N2 | 一个物理单位结构存货通道≥2时，无来自分流器的输入；桥先两轴汇总。 | 规则“存货优先级”；约束#6“密集结点”；格式§8.2。 |
| N3a | 有结构通道的准入口不得设累计上限（与 N5b 联用）；LP另核累计设定的长期零流及 k/5。 | 约束#29“准入累计”；格式§8.2–9。 |
| N3b | 每个被限种准入口拒绝的上游可能物品，在同一物品格/共用侧须有另一条首格不按身份拒绝的结构出口；不跨桥轴或核心定物品口。 | 规则“物品准入口”；格式§8.2；共识 N3b。 |
| N4a | 两邻端口一取一存或均无端口；独立推导方向，与声明逐轴相等。 | 规则“桥接器”；共识§1.1.3；格式§6。 |
| N4b | 拒绝任意两桥正交相邻，包括声明 null 的轴。 | 格式§6/8.2 的保守加强。 |
| N5a | 逐 PortRef 比较全部重算通道与声明集合，不仅比较条数。 | 规则“通道”；约束#11“端口对接”；格式§8.1。 |
| N5b | 联合分物品 LP 或附带见证中，每条通道总流≥同一精确 δ>0；不可用拓扑替代。 | 共识第三节第3条；格式§9。 |
| P1 | 只有 belt、bridge，且无储存箱。 | 共识§1.3 P1；格式§8.2。 |
| P2 | 从非运输取口出发沿同轴/同格分解，到非运输存口终止；每路一种物品，全部通道恰覆盖，记为 `P2_structure`；完整 `P2` 另用精确可行流逐路径核等速。没有精确流时为 `blocked`。 | 共识 P2；格式§8.2/8.4。 |
| P3 | 所有结构通道均有正流，无暗接零流；引用 N5b。 | 共识 P3；格式§8.2。 |
| P4 | 使用轴两端都接通，未使用轴无邻口；正流结合 N5b/P3。 | 共识 P4；格式§6/8.2。 |
| P5 | 两桥不相邻；引用 N4b。 | 共识 P5。 |
| P6 | 每台粉碎机和采种机恰一个 recipe_id；其他机型单配方另登记。 | 共识 P6；格式§8.2，非 P2 的推论。 |

两类都拒绝没有非运输来源或去处的纯运输循环。n_restricted 的 P 项标为前件不适用，绝不假称 P 类通过。N1 违反直接拒绝本格式受限类，不尝试用阻尼定序放行。

限制 ID 的可执行语义为：必选 N/P；`single-recipe`=全部机器单配方；`fixed-layout`=固定当前候选全部占格/朝向/设置；`fixed-recipes`=固定当前候选的配方集合；`recipe-subsets`=固定 recipe_ids 配方子集，statement 须为“recipe_ids 限定本候选的配方集合；不把它当成游戏开关。”；`fixed-logical-feeds`=固定所列路径和精确速率；`candidate-b`=逐项保持原 B 合同。只有实际配方真子集才需额外登记；正式机型本来只有一个配方时不算额外限制。其他额外自由文本限制明确报未覆盖/未决，禁止静默当作已执行。通用限制四项文字的真实性仍需人工审查；机器不把中文自由文本当可执行程序。

## 连续 LP 和证书边界

变量是通道×允许物品的非负连续流、机器×声明配方的批率、箱体×物品的无线量，桥按轴守恒，非桥按一个物品格共享容量。同一机器输入、输出分开；同机 `Σ耗时×批率≤1`。每个真实源取口只供其设定矿且恰1；非成品入库为0，两个成品目标分别 `3/5`、`11/20`；LP还核准入口 filter、k5、cum 和固定逻辑路径速率。

无见证时先求基础可行性，再最大化全部结构通道的共同 δ。HiGHS 的浮点结果只作候选，尝试有理重建后用 `Fraction` 精确核每个非负界和每一行；这不是给可行流预设分母。重建不成功报告数值未决。得到精确正见证即足以认证严格正性，不宣称 δ 最优。

不可行时，用第一阶段得到乘子，精确核 `y≤0`、`Aᵀy≤0`、`bᵀy>0`，才给固定矩阵的 Farkas 证书。δ=0 只有精确对偶界 `δ≤0` 时才拒绝固定支持，否则未决。附带 `flow_witness` 则逐项检查完整覆盖、物品域和精确等式，不用求解器替它改成另一份见证。

后验正式约束按这份精确见证的正流支撑计数。若该见证未通过后验投影，只能拒绝这份见证；本程序不另做正支撑分支搜索，也不据此证明同一几何的所有其它连续流都失败。这一局限写入每份报告的失败覆盖域。

## 已知边界

1. 没有完整几何全厂正例，因此尚未实测整张布局从输入到最终 `static_pass` 的端到端正例。219台速率层和局部几何反例不能代替它。
2. 本实现只支持格式v1的两个受限类。桥串、取货分级放开后的阻尼、未登记的额外自由文本限制不会放行。没有把这些拒绝推广成一般游戏规则禁止。
3. 数值求解器不保证找到可有理重建的解；不能核实的浮点结果为未决。正见证证明存在正流，不证明最优δ。后验投影失败不自动排除其它流选择。
4. 多配方/混料、箱体编号格、50件存货界、准入口真实窗口、轮询、调试初态、离线接续及全部可达循环态均未被静态通过替代。两份独立检查器已对同一被拒绝全厂候选重建互核；仍无共同通过的全厂正例。
