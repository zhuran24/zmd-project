# 契约目录第四轮门禁验证

日期：2026-09-19。性质：修订与验证存档。状态：C3-r4-L1-01、C3-r4-L3-1 均已修订并完成自查。目录仍为 `2026-09-19-contract-r3`；此版本标识数据内容，本轮没有改变目录或候选契约字节。

## 发现、原因与处置

| 发现 id | 原因与修订 | 正式依据 |
|---|---|---|
| C3-r4-L1-01 | 原回源入口只比部分投影，Rust 固定对照又漏类别与供电范围。统一入口现严格比较 18 类单位全部字段、18 条配方全部字段与数字类别；cargo 将编译内置目录交给它，并运行逐字段变异回归。 | 任务书2 §3.B.1 的共享目录与逐项一致性要求；任务书 §3.B.1 的数字分类；规则 L41、L76、L89。 |
| C3-r4-L3-1 | 与上条共享根因；配方投入／产出、耗时和供电覆盖两维均纳入回源。研磨蓝铁粉末投入改为 3 的独立反例被拒绝；不依赖候选是否用到该配方。 | 规则 L92 明写投入蓝铁粉末 2、砂叶粉末 1，产出致密蓝铁粉末 1，耗时 1 tick；L76 明写覆盖 12×12。 |

这里的正确配方量、耗时、尺寸为条文直引；故意变异的 2 tick、13 格、投入 3 等只是错误测试输入，不是允许取值。条目数量、字段数量、报告分组为算术计数；测试通过、拒绝和退出状态为工具实测。id、行号、版本、哈希为编码元数据。

## 门禁如何回源

入口为 [formal_catalog.py](../../工具/formal_catalog.py)，单位投影为 [formal_units.py](../../工具/formal_units.py)。比较预期不读取待核目录的数值，不读取候选 B。先逐字节核三份源指纹及完整行文本，再分别从正式原文解析或按目录编码约定重建预期；这两层各自必须通过。单位／配方按唯一 id 比较，不要求对象键顺序和两类条目的排列顺序，但拒绝重复 id、缺项、多项和未知字段。

| 字段范围 | 预期来源与推导 |
|---|---|
| 配方机型、投入／产出物品及批量、耗时、类别 | 规则 L80–114 全部配方逐条解析；批量和耗时为直引。配方 id 沿用接口映射，不按候选使用情况删配方。 |
| 单位族类、宽高、面积 | 规则“单位”各分组及尺寸；宽高直引，面积为宽×高，标算术推论。 |
| 存取端口数、每个规范型的边／位置／角色／桥轴 | 规则 L12、L41、L44–57、L60–73；整边端口数按一口一格计算，核心 14/6 为直引；格位减一换码为算术推论；三种带型、四种桥型是允许角色的规范表示。 |
| 格数、容量、角色、唯一性与例外、null 状态 | 规则 L13、L17–18、L41、L44–59、L63、L72–73。无限、未定及共享仓库引用保留各自字段，不把 null 当零。 |
| 需电功能、开关、准入口与箱体传输字段 | 规则 L19–22、L25、L35–36、L64、L72。箱冷却 5 tick 与冷却粒度未定分别核验；不由静态目录裁定运行轴。 |
| 制造机型与两侧通道下限 | 正式约束“机型下限”“通道下限”逐机型解析，数值为直引。 |
| 供电覆盖宽、高、中心与未定状态 | 规则 L76 的中心 12×12，核两个维度及类别；边界格集合保持未定，由规格参数轴承接。 |
| 依据、说明、身份编码及静态状态 | 按已审目录接口逐字段严格核对，防止说明与机器可读状态漂移；修改编码需要同步审查门禁，不能静默忽略。 |

全部 Quantity 同时比较 value、category；对象键集合、值类型、列表长度和 null 也参与比较。既有约束分节、据、全称义务、任务与静态阈值的回源检查保留。版本时间戳等元数据不作为游戏条文推论；本次保护快照另核数据字节未变。

转换器删去独占的配方解析路径，直接调用统一门禁。Rust 通过 `--catalog -` 传入编译内置字节，避免只验证磁盘上另一份目录。CLI 报告的“目录/版本”明确只是版本信息；正式验收须先通过独立回源和 cargo 测试。没有把独立来源校验塞成候选守恒是否碰巧失败的副作用。
