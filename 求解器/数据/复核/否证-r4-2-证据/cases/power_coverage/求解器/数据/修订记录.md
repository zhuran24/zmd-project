# 契约线修订记录

性质：修订及工具验证存档。截止日期：2026-09-19。当前格式说明见 [送料契约.md](送料契约.md)，本记录不替代格式正文。

## 第二轮任务书 §3.B.1：共享单位目录

[正式静态目录.json](正式静态目录.json) 扩为 static-catalog-v2，含全部 18 类单位、原有 18 个配方及 56 条正式约束。单位条目包含宽高、占格、端口边和位置、存取端口数、各角色物品格数与容量、需电功能和依据。单位 id 使用正式中文名称，配方 id 保持不变；制造契约的 kind、配方 kind 引用单位 id。端口坐标只是编码约定，桥接器方向必须服从先接端，不作为额外自由度。据：单位、端口、旋转、桥接器。

目录显式区分未定与无限：制造输入格混装／容量计数域、桥接器容量例外、供电覆盖格集合仍交由规格参数轴处理；缓存无限、核心格数不限及仓库取货口引用仓库另列说明。未把这些空白变成默认规则。据：物品格、存货/取货物品格、缓存格、运输单位、协议核心、仓库取货口、供电桩。

Rust 的 KINDS 常量删除，spec 从目录读取；机型两侧端口容量、面积、台数／通道下限以及核心容量均以目录值为输入。当时转换器读取同一目录且不重写它，但仅核配方与约束 name/text，漏了分节与据；其它正式阈值也仍留在运行代码中。两项缺口在第三轮分别补齐，不能沿用当时“全部硬编码仅留测试”的说法。规格和内核可直接引用 units[].id、recipes[].id；本文不改写另两条线的规格文件。

正式“回路守恒”现行条文为“仓库外（含缓存格）”；当时目录同步原文，来源指纹仅在候选 B 来源清单中；共享目录自身的指纹缺口于第三轮补齐。这里没有修改正式文件；主席在任务书中已说明正式修正。据：求解约束·回路守恒、第二轮任务书 §2。

## 第二轮任务书 §3.B.2：储存箱分段

协议储存箱为非运输端点，不能藏在运输 via 占位中。feeding-v2 删除 via.storage，加载器拒绝任何残留值（含 null/false），避免静默迁移。据：运输单位、仓储单位、协议储存箱。

A→X→B 中 X 为储存箱，须有 A→X 与 X→B 两条逻辑送料记录。以每个正流量端点接口独占为条件，两段共 S=2、R=2；相对无箱直达，S、R 各增 1。多物品记录共用同一端点接口时按端点及端口去重。无线传输入仓库没有端口相遇，不虚构额外的 S/R。据：通道、端口对接、运输端口收支、传输、入库途径；以上数字为条件算术推论。

增加 feed_interface_counts 与合成分段／复用测试。当前候选仍排除箱体，完整带箱实例在端点引用与受限模型检查处失败；测试只验证分段计数，不代表已经支持箱体交付、混流或运行认证。将来带箱格式须显式增加箱体表、箱体收支及无线交付，不能恢复 storage 布尔快捷方式。

## 第二轮任务书 §3.B.3：三类边分名

契约升级 feeding-v2：channels 改为 logical_feeds；原 C 数字编号保留但前缀改 LF；Rust 类型改为 LogicalFeed。端口相遇通道约定为 physical_channels／PC，缓存内部通道约定为 buffer_channels／BC；后二者未伪造进速率契约。据：规则“通道”“缓存格”；字段名及 id 为工程编码约定。

候选转换脚本、contract.json、校验器、测试、契约说明、转换说明和生成报告同步。旧复核目录是第一轮存档，没有覆盖其中的脚本与报告；其中 recompute.py 仍读取旧 channels 字段，后续复核席使用时须自行适配 feeding-v2。此处新添的 check_revision.py 是修订人自查，不标成独立异源复核。

## 第三轮处置范围与工作流解释

本节为本轮实际修订及验证存档；第二轮的计数和结论是历史快照。第三轮依据为工作流目录 `2a1af1b1-ede2-4b4a-8f95-41e78df48af0/scratchpad/step1/` 中两轮任务书、本轮派发的十一条发现及转发器附注。当前修改范围是 `求解器/数据/` 和 `求解器/crates/topology/`；没有改写规格正文或正式文件。

用户原话：“理解了，不过这样下去claude侧的额度反而可能会先用完，那后面只能把部分的审查工作，或者说，除主力开发以外的部分其他工作也交给codex了，这次就先算了，下次”。存留两种读法：一是把“这次就先算了”理解成本轮契约修订不再继续；二是理解成把审查等非主力开发工作移交 codex 的分工调整延至下次。二者对当轮派发动作的后果相反，不把其中一种冒充主席裁定。

转发器采用第二种读法，给出的依据是：直接宾语落在“把审查等非主力开发工作移交给 codex”，不是“本轮契约修订”；codex 继续担任主力执行的既定分工没有被该句撤销；同批 A/C 及否证席在相邻 12:22–12:39 时间窗口继续正常派发。最后一点是转发器提供的工作流证据，本席未另取 harness 原始日志独立认证。当前任务明确要求逐条修改，故执行本次修订，不再交空轮。对前一轮停派解释及责任的最终判断仍需主席／owner 确认，本席及任一复核席均不单方面盖棺。此未决不阻止当前明确派发任务的实现。
