存在 放置顺序、连接顺序数个数组
基建元件指工厂+物流元件
工厂指协议箱、各自制造类工厂
物流元件指物流器+传送带
物流器指分流器、汇流器、物流桥

放置工厂或物流元件时
	假如放的是物流元件
		假如物流元件下游有工厂 #这里可能有点问题
			将该工厂加入连接顺序数组末端
		否则
			连接到一个虚拟工厂#虚拟工厂应该在连接顺序数组头部
	加入放置顺序数组末尾

删除工厂或物流元件时
	如果是物流元件
		如果下游工厂不是虚拟工厂
			如果下游工厂没有输入
				从连接顺序删除下游工厂
	从放置顺序数组删除

特殊BFS：#实现计算顺序
	从前向后轮询 放置顺序 数组
		清空临时变量q1数组
		将工厂上游物流元件加入q1数组 #常规使用队列
		# 这里实现层级，每层按放置顺序输出，层级导致了阻尼出现，层内放置顺序导致
		# 假如是虚拟工厂就再向上找一级，因为末端物流元件不可能输出，这一点实现了断尾传送带阻尼小1的现象
		重复 当 q1长度不为0时
			从前向后轮询 放置顺序 数组 取 a
				假如 a 在 q1 中
					a 输出
					将a的未标记的上游物流元件或工厂加入q2并标记
			将q2赋值给q1

分流器输出 #实现分流器轮询
	#分流器维护属性 计数器 i、 分流器下游基建元件数组ap（与放置顺序同序），假如要将4n卡1s纳入体系，可能还需要考虑记录输入的时间或者某种时间戳
	#这部分的思路是有汇流器输入辅助函数，但是分流器忘记引用了，导致出现优先汇入现象
	令 轮询次数 整数 p 为 1
	if ap[(i + p) % len(ap)]可以接受物品:
		输出物品到ap[(i + p) % len(ap)]
		i += 1
		return
	else
		i += 1
		p += 1
	if p == len(ap)
		return

汇流器输入辅助方法
	if 下游物流元件是汇流器:
		参考分流器输出实现下游汇流器输入，但是输出物品改为带标记调用输出函数
汇流器输出
	汇流器维护属性 计数器i、 分流器上游基建元件数组ap
	如果不带标记
		汇流器输入辅助方法
	否则
		输出到下游
传送带输出
	如果不带标记
		汇流器输入辅助方法
	否则
		输出到下游
工厂输出
	#工厂维护属性 计数器i、 下游物流元件数组ap
	如果不带标记
		将上一步BFS中的工厂下游物流元件加入ap末尾 #保证简单的放置顺序也可以正确计入，且BFS越早遇到就越靠前
	#工厂的输出统一在BFS结束后再处理，保证ap包含所有下游物流元件和先入后出
	否则
		#BFS结束后，我不太确定这里怎么实现比较好，ap第一个是汇流器就直接输出，否则把ap中所有非汇流器的放在一起轮询，但是这个目的性太强。
