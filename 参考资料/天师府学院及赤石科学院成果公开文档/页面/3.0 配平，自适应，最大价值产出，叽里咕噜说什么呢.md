# 3.0 配平，自适应，最大价值产出，叽里咕噜说什么呢

> 原文：https://docs.qq.com/aio/DTmluZ1diWlpQZldw?p=lZhn9NxeSAXQ7W0ANuqKFR　上级：[反应控制与前沿研究](反应控制与前沿研究.md)

什么是<span style="color:#ef6c00"><b>配平</b></span>：给定原材料供应量，设计产线使得原材料全部稳定的被消耗（至少经过一步加工）

<b>阻塞生产/自适应是达成配平的一种手段，但并不是唯一手段。</b>硬分流也能直接达到配平，使用时钟信号震荡重息壤生产也能达到配平。

自适应也并非仅仅是为了配平。我们前面已经给出了很多例子了。

两种配方通过阻塞生产/自适应配平，是<b>平衡型阻塞</b>的体现。其中一种产物满仓后，变成另外两种配方自适应配平，这一过程是<b>切换型阻塞</b>的体现。它们在根源上都是利用了<b>不同位置</b>的阻塞信号

<b>以上讨论仅涉及把原料消耗做成成品，并不牵扯到价值体系。</b>一般来说，加工后的产物价值总是高于原材料直接卖掉的价值，否则就没必要加工了。进一步地，加工后的产物价值需要相对合理，才能说配平生产某些产物，使得原材料全消耗时产出价值最高。否则，比如灼铜零件价格巨tm高，还会出现铜全部做灼铜，直接卖掉多余的息壤的产出价值高于配平的情形。当然，现在并不是这样的。

目前没有任何机制能够让产线能够自适应产出调度券最大的方案，只有人来根据要求规划好了生产方案产能再进行实现。就目前的简单情况，基本都是直接通过简单线性规划得出产能最大或净产能最大，或者满足更多限制情况下的产能最大等的具体生产方案（拿xxx原料做xxx产品），具体如何做到这一生产方案，则有直接分流分配，自适应等路线之分。

根据Cipolla的指导，一种较严格的定义如下

- 精确分流生产：存在一个正整数组成的向量N，若当前生产线的缓存向量（因为有很多个生产线的缓存嘛）增加到N，则机器处永不发生阻塞。

- 阻塞生产/自动匹配：对任意正整数向量N，若当前生产线的缓存增加到N，则总能找到时间T，当t\>T时机器处发生阻塞
