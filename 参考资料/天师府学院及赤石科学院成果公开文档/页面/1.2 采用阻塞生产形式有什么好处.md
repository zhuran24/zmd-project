# 1.2 采用阻塞生产形式有什么好处

> 原文：https://docs.qq.com/aio/DTmluZ1diWlpQZldw?p=vjw47WlrDGyaYlemKyfnH8　上级：[反应控制与前沿研究](反应控制与前沿研究.md)

相对于传统的定速生产，合理的阻塞生产设计能为进阶的生产需求带来很大的便利。例如：

1. <span style="color:#7b1fa2">我想先生产</span><span style="color:#7b1fa2"><u>一仓库的紫晶瓶</u></span><span style="color:#7b1fa2">，然后再开始生产</span><span style="color:#7b1fa2"><u>高晶瓶</u></span><span style="color:#7b1fa2">。</span>

2. <span style="color:#7b1fa2">我想</span><span style="color:#7b1fa2"><u>保证仓库内一直有钢零件随用随取</u></span><span style="color:#7b1fa2">，在不用时也不浪费钢的产能，都去做谷地电池。</span>

3. <span style="color:#7b1fa2">我想让赤铜块</span><span style="color:#7b1fa2"><u>先做赤铜零件</u></span><span style="color:#7b1fa2">，为了防止铜块爆仓堵住污水，赤铜零件做满后需要</span><span style="color:#7b1fa2"><u>让赤铜块继续做赤铜装备元件</u></span><span style="color:#7b1fa2">。</span>

4. <span style="color:#7b1fa2">我想让息壤</span><span style="color:#7b1fa2"><u>优先满足中容武陵电池</u></span><span style="color:#7b1fa2">的生产需求，多余的息壤再做别的，这样即使我偶尔从谷地搬运多余的源石粉末到武陵，也能够消耗掉。</span>

5. <span style="color:#7b1fa2">我想</span><span style="color:#7b1fa2"><u>把原材料全部用完做成成品</u></span><span style="color:#7b1fa2">，即使成品产速为一个复杂分数，使用自适应方案也能自动达到这一产速。</span>

6. <span style="color:#7b1fa2">我不想让转化机白吃息壤，我需要它有多少原料给多少息壤</span>

以上这些常见的进阶生产需求，如果采用传统的直接生产方案，往往需要进行一定的手工调整，如调整机器生产配置等，不仅麻烦，还容易出现忘记操作，或者无法在合适的时间上线而导致材料浪费乃至停电的情况。阻塞生产则通过特定的产线设计，让生产方案得以自动切换，从而在无需操作的情况下实现此类目标，减少我们的操作负担。
