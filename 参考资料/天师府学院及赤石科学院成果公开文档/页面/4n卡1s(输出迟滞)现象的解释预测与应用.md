# 4n卡1s(输出迟滞)现象的解释预测与应用

> 原文：https://docs.qq.com/aio/DTmluZ1diWlpQZldw?p=fpMndghZj3dpXscC34t8jt　上级：[任务板](任务板.md)

## 应用：

传送带的4n卡1s最终导致8n总共卡2s=1物品，所以输出为8n/(8n+1)，最具代表性的结果为n＝3时的24/25，方便起见给出下表速算结果

|  |  |
| --- | --- |
| 1 | 8/9 |
| 2 | 16/17 |
| 3 | 24/25 |
| 4 | 32/33 |
| 5 | 40/41 |
| 6 | 48/49 |
| 7 | 56/57 |
| 8 | 64/65 |
| 9 | 72/73 |

对于管道，由于其流速为传送带的4倍，会出现2n卡0.5s=1流体，输出为2n/(2n+1)，理论输出分母最大2\*80+1=161的所有大于1的奇数。
