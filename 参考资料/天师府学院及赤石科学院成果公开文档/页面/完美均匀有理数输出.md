目前通用实现方案有以下几种

@xyIvneu\_ 的闰年规则

@Cipolla\_ 的引入加法闰年规则改进版

@桜夜天華 的回流式完美均匀输出

各方法均使用了以下思路，目前认为该思路由闰年规则首次提出

对于任意序列x，若操作f的结果f(x)在x为完美均匀序列时为完美均匀序列，则多个f\_i(x)嵌套依旧为完美均匀序列；通过将目标x\_i多步改写为f\_i(x\_(i-1))使最终x\_0容易实现，即可使用x\_0和f\_i输出x\_i

以下是我们目前找到的可行的f

取补操作：将序列中0-1互换， f(x) = 1 - x

取商操作：将序列中1每隔n个保留一个，其他全部删去，f(x) = x / n

加法操作：对每一位加1或者说加n（n为整数，相当于多次+1），f(x) = n + x

假设 x\_i = 最简分数 a / b，b = a \* q + r即q = b // a, r = b % a

<b>标准闰年规则：</b>

x\_i = a / b = (1 - r / b) / q = (1 - x\_(i-2) ) / q

x\_0 = \[1\]

<b>闰年规则改进：</b>

x\_i = a / b =(1 - r / b) / q 或 (1 + r' / b) / q'，使用搜索算法取展开较短式

前一种情况与标准闰年规则一致

后一种情况r' = a-r,q' = q + 1; x\_(i-2) = r' / b

x\_0 = \[1\]

<b>回流式：</b>

x\_i = (A + x\_(i - 2)) / B

限制A的可能取值后，使用搜索算法取所有可能展开中的最短

x\_0 = x\_n，表示与输出完全相等的回流作为输入，这使得结构末尾必然是二分

该展开不适用于2^n\*3^m为分母的分数，但是这类分数可以使用其他方式构造
