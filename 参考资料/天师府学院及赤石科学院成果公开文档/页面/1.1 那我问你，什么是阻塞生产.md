# 1.1 那我问你，什么是阻塞生产

> 原文：https://docs.qq.com/aio/DTmluZ1diWlpQZldw?p=quUTb9JSv879txqKEKI0BS　上级：[反应控制与前沿研究](反应控制与前沿研究.md)

在<span style="background-color:#ffecd2">终末地工业</span>的智能生产领域，由于缺少智能化的原件（例如判断库存达到某个值时，控制阀门打开），目前应用较为广泛的可能仅有<span style="color:#e53935"><b>时钟信号、阻塞信号</b></span>。本教程主要探讨<span style="color:#e53935"><b>阻塞信号</b></span>在智能生产中的应用。

> 利用时钟信号也能做出很神奇的产线，比如本人曾使用时钟信号实现单烘炉重息壤生产[基于时钟信号的单烘炉重息壤方案](基于时钟信号的单烘炉重息壤方案.md)，本页面下半部分的信号控制也有相关内容，也欢迎其他群友在此处引用相关成果。
>
> [单个反应池生产壤晶废液](单个反应池生产壤晶废液.md)

正如传送带-分流汇流系统中，流通到阻塞的状态变化会引起流量的<u>重分配</u>（参考[理想系统的流量理论](理想系统的流量理论.md)，[4.0 从阻塞流理论基石上建起阻塞生产学的大厦（缓更）](4.0%20从阻塞流理论基石上建起阻塞生产学的大厦（缓更）.md)），<b>生产流程中发生的阻塞也会引起流量的重分配，进而导致生产情况发生变化</b>。我们可以利用这一特性，实现<b>生产方案的智能切换</b>，达到多种进阶的生产目的。

多种具有实际生产意义的信号，都可归结为某种特定场景下的阻塞信号，例如：

1. <span style="color:#7b1fa2">机器满速或达到预定速度生产 → 机器原料缓存阻塞（除原料供给速度=生产速度的临界情形外）</span>

2. <span style="color:#7b1fa2">产物仓储已满 → 生产该产物机器的输出缓存阻塞，连带着输入缓存也阻塞</span>

3. <span style="color:#7b1fa2">流量达到6/m → 设置限速6的准入口，形成阻塞</span>

4. <span style="color:#7b1fa2">液气机反馈中，仅当原料液体充足时，才供应液化息壤 → 原料液体阻塞液化息壤的循环回路，让液化息壤进入液气机供给路线</span>

由此可见，我们可以根据实际的生产需求，有意地构建可能形成阻塞的结构，利用不同阻塞状态下流量产生的变化来达成智能生产的目的。阻塞生产原理所要探讨的内容就包括：<b>如何构建这些结构，这些结构在何种条件下会形成阻塞，该阻塞会导致产线流量发生怎样的重分配，是否能达成最终的生产目的</b>。

阻塞生产并不是神秘高深的理论，只需要你在原有产线基础上再接着往下多想一步，大家或许已经在各种地方见到过使用过了，相比之下更关键的是如何认识这一现象。

> 爆仓当然是阻塞的一种表现，所以爆仓时产线会如何发生变化，也是阻塞生产原理所关注的重要内容（爆仓动力学.jpg）

> 如果说初级的产线设计是达到把一定数目或者速率的原料x\*供给做成一定速率的产品y\*（即做完后报表图显示正确），f(x\*) = y\*, 那么本文所讨论的就是更高一层次的产线设计：在前者基础上，探讨在外部环境（如原料供给，或产物堆满）发生变化的情形下，产线的响应是什么，以及如何应用这些产线的响应达到我们想要的更复杂的生产需求。我们需要分析函数f是否对一定范围内的x都能给出正确的y；产线在原料x\*的供应量发生变化时，y\*是否能够正确地反映我们想要的结果；或者在y\*发生变化时，x\*能否正确发生相应的响应。
