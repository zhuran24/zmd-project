### 构造原理

考虑一个 $1/3^k$ 阻塞流

在一般流中，$A_k$ 和 $B_k$ 的上界是 $3^k$，而在这个阻塞流 $1/3^k$ 中，$A_k$ 和 $B_k$ 达到上界当且仅当所有的分流器 $S_i$ 的两条出边都连接 $C_i$，每个 $S_i$ 的两条出边全部连接 $C_i$ 的结构引入了一次乘以 $3$ 的乘法

<b>但这个乘法实际上来自三个相同的 </b><b>$A_k$</b><b>相加，</b>由于 $B_{k-1} = A_{k-1}$ 在该流中恒成立，我们有

$$
A_k = A_{k-1} + \min\{B_{k-1}, A_{k-1}\} + \min\{B_{k-1}, A_{k-1}\} = 3A_{k-1}
$$

如果引入一对新的 $\to C_n \to S_n \to$，然后删除一条 $S_n \to C_n$ 和一条 $S_i \to C_i$ 并新连接 $S_n \to C_i$ 和 $S_i \to C_n$，则根据算法

$$
A_n = A_{n-1} + \min\{B_i, A_{n-1}\} + \min\{B_{n-1}, A_{n-1}\} = A_{n-1} + 3^i + 3^{n-1}
$$

我们可以继续修改另一条边并得到

$$
A_n = A_{n-1} + \min\{B_i, A_{n-1}\} + \min\{B_j, A_{n-1}\} = A_{n-1} + 3^i + 3^j
$$

如果恰好 $i=j$，则我们有 $A_n = A_{n-1} + 2 \cdot 3^i$，对应三进制中的 $2$

<b>除了最高位的 </b><b>$2$</b><b> 的情况需要一次单独修改重连一条边以外（</b><b>$+ 3^r + 3^a$</b><b>），其他的一次修改重连一条边或两条边，正好可以表达三进制</b>；为了方便，我们让其两两配对进行连接（$+3^a + 3^b$），对于 $d_i = 2$ 的情况，记两次相同的 $3^i$ 即可

### 构造算法

1. 写出三进制表示 $(d_0d_1\cdots d_r)_3$，长度 $r+1$，最高位 $d_r$

2. 画出长度为 $r$ 的主链 

$$
\text{In}\to C_0\to\cdots\to C_{r-1}\to S_{r-1}\to\cdots\to S_0\to\text{Out}
$$

其中每个分流器 $S_i$ 都有两条指向 $C_i$ 的回流

3. 如果 $d_r=2$：在主链正中央增加 $\to C_r\to S_r\to$（其中 $S_r$ 的两条回流都指向 $C_r$），然后

   1. 选一个满足 $d_i\neq0$ 的 $i$（例如最大的那个 $i$）

   2. 断开一根 $S_i\to C_i$

   3. 连接 $S_i\to C_r$

   4. 连接 $S_r\to C_i$

   5. 把 $d_i$ 减去 $1$

4. 把剩下的 $d_i$（$i=0,\dots,r-1$）中所有 $d_i\neq0$ 的 $i$ 写成一串数（$i$ 写 $d_i$ 次），从小到大排好，每两个合成一对。对每一对 $(i,j)$：在主链正中央新增一对 $\to C_{k+1}\to S_{k+1}\to$（其中 $S_{k+1}$ 的两条回流都指向 $C_{k+1}$），然后

   1. 断开一根 $S_i\to C_i$

   2. 连接 $S_i\to C_{k+1}$

   3. 断开一根 $S_j\to C_j$

   4. 连接 $S_j\to C_{k+1}$

   5. 断开 $S_{k+1}$ 的两条 $S_{k+1}\to C_{k+1}$

   6. 连接 $S_{k+1}\to C_i$

   7. 连接 $S_{k+1}\to C_j$

$$

### 代码

```python
def base3(q):
    d = []
    while q > 0:
        d.append(q % 3); q //= 3
    return d

def build_edges(q):
	# step 1
    d = base3(q)
    r = len(d) - 1
    
    # step 2
    # (i, j) := S_i -> C_j
    E = []
    for i in range(r):
        E += [(i, i), (i, i)]
    k = r
    
    # step 3
    if d[r] == 2:
        i = max(t for t in range(r) if d[t] != 0)
        n = k; k += 1
        E.remove((i, i))
        E += [(i, n), (n, i), (n, n)]
        d[i] -= 1
        
    # step 4
    seq = [i for i in range(r) for _ in range(d[i])]
    for t in range(0, len(seq), 2):
        i, j = seq[t], seq[t + 1]
        n = k; k += 1
        E.remove((i, i)); E.append((i, n))
        E.remove((j, j)); E.append((j, n))
        E += [(n, i), (n, j)]
        
    return k, E
```

### 算法扩展

由于该算法基于 1/n 阻塞流的主链与回流结构的数学性质，扩展到 2, 3 混合进制应当是相当容易的。

但我太困了明天再说。

实验表明，2, 3 混合进制总是不差于 2 或 3 进制。这和其中涉及的逐 digit 和有关系。

该算法不能搜到一些已知最优解，这是因为这类解往往涉及更一般的加法结构，无法单纯用进制表达。如要搜索，难以避免 (k!)^2 级的算法。
