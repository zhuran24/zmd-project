# 串联结构的误差传播

> 原文：https://docs.qq.com/aio/DTmluZ1diWlpQZldw?p=LbIb8qSMuIb0YhWSlQiP1F　上级：[任务板](任务板.md)

定理：若序列 a 与 b 串联（b 的输出作为 a 的输入触发），生成序列 c，则波动幅度满足：

M\_dev^c \<= M\_dev^a + T\_ideal^a \* M\_dev^b

证明：

设 a 的1的位置序列为 {t\_i^a}{i=1}^{K\_a}，理想间隔 T\_ideal^a = L\_a/K\_a；

b 的1的位置序列为 {t\_i^b}{i=1}^{K\_b}，理想间隔 T\_ideal^b = L\_b/K\_b。

串联后 c 的第 i 个1位于 a 的第 t\_i^b 个1处：

t\_i^c = t\_{t\_i^b}^a

且 K\_c = K\_b，T\_ideal^c = T\_ideal^a \* T\_ideal^b。

c 的第 i 次输出误差：

E\_c(i) = t\_i^c - i \* T\_ideal^c

\= t\_{t\_i^b}^a - i \* T\_ideal^a \* T\_ideal^b

\= \[E\_a(t\_i^b) + t\_i^b \* T\_ideal^a\] - i \* T\_ideal^a \* T\_ideal^b

\= E\_a(t\_i^b) + (t\_i^b - i \* T\_ideal^b) \* T\_ideal^a

\= E\_a(t\_i^b) + E\_b(i) \* T\_ideal^a

因此：

max\_i E\_c(i) \<= max\_j E\_a(j) + T\_ideal^a \* max\_i E\_b(i)

min\_i E\_c(i) \>= min\_j E\_a(j) + T\_ideal^a \* min\_i E\_b(i)

两式相减得：

M\_dev^c \<= M\_dev^a + T\_ideal^a \* M\_dev^b
