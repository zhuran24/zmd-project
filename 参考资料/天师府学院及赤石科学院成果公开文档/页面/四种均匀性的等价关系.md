# 四种均匀性的等价关系

> 原文：https://docs.qq.com/aio/DTmluZ1diWlpQZldw?p=0UWq18LU5z08cMqBDGHmT2　上级：[任务板](任务板.md)

定义（统一符号）：

Bresenham-M均匀：对所有 n 属于 Z+，\|S\_cum(n) - d \* n\| \< M

Beatty-M均匀：对所有 i,j 属于 Z+，\|S\_cum(i,j) - (j-i) \* d\| \< M

其中 S\_cum(i,j) = S\_cum(j) - S\_cum(i)

Cipolla-M物品均匀：sup\_n(S\_cum(n) - d \* n) - inf\_n(S\_cum(n) - d \* n) \< M

Cipolla-M时间均匀：sup\_n(t\_n - n \* T\_avg) - inf\_n(t\_n - n \* T\_avg) \< M

注意 T\_avg = 1/d

定理1：Bresenham-M均匀 等价于 Beatty-2M均匀（双向蕴含，常数因子2）

证明：

(=\>)：\|S\_cum(j) - j \* d\| \< M 且 \|S\_cum(i) - i \* d\| \< M，故：

\|S\_cum(i,j) - (j-i)d\| \<= \|S\_cum(j)-j \* d\| + \|S\_cum(i)-i \* d\| \< 2M

(\<=)：取 i=1 即得Bresenham-M均匀。

定理2：Beatty-M均匀 等价于 Cipolla-M物品均匀（等价，常数一致）

证明：

(=\>)：由Beatty-M，任意两点偏差 \|E(i) - E(j)\| = \|S\_cum(i,j) - (j-i)d\| \< M，故极差 \< M。

(\<=)：若极差 \< M，则对任意 i,j，\|E(j) - E(i)\| \< M，即 \|S\_cum(i,j) - (j-i)d\| \< M。

定理3：Cipolla-M物品均匀 等价于 Cipolla-(M/d + 1) 时间均匀（双向蕴含，常数转换）

证明：

(=\>)：由 S\_cum(n) = k 当 t\_k \<= n \< t\_{k+1}，有 t\_k - k \* T\_avg = T\_avg(k \* d - t\_k \* d) = (1/d)(k - S\_cum(t\_k))。

利用 t\_n - n/d 与 S\_cum(n) - n \* d 的对偶关系，可证：

sup\_n(t\_n - n/d) - inf\_n(t\_n - n/d) \<= (1/d) \* M

(\<=)：对于 n 属于 \[t\_k, t\_{k+1})，S\_cum(n) = k，有：

t\_k - k \* T\_avg \<= n \* T\_avg - S\_cum(n) \* T\_avg \< t\_{k+1} - k \* T\_avg = (t\_{k+1} - (k+1)T\_avg) + T\_avg

故时间均匀 =\> 物品均匀，且 M\_item \<= d \* M\_time + 1。
