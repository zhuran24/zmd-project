# 完美均匀的理论下界

> 原文：https://docs.qq.com/aio/DTmluZ1diWlpQZldw?p=MaVX8KkK08q5s2fvVTX5wg　上级：[任务板](任务板.md)

<a id="6FBuyRd8Sv5Uo5NO56QkZE"></a>

定理：对于占空比 d = K/L（L 与 K 互质）的任意周期01序列，其波动幅度满足：M\_dev \>= (K-1)/K

且该下界可通过构造 t\_i = floor(i \* T\_ideal) 达到。

证明：

步骤1：误差离散性

定义第 i 次输出误差 E(i) = t\_i - i \* T\_ideal = t\_i - i \* L/K。

令 k\_i = K \* t\_i - i \* L，则 E(i) = k\_i/K，即 E(i) 必为 1/K 的整数倍。

步骤2：误差互异性

设 0 \< i \< j \<= K，若 E(i) = E(j)，则：

(t\_i - t\_j) \* K = (i - j) \* L

因 L 与 K 互质，存在整数 m 使 i - j = mK。但 -K \< i - j \< 0，矛盾。

故 E(1), E(2), ..., E(K) 互不相同。

步骤3：下界推导

K 个互不相同的 1/K 整数倍数值，分布于区间 \[E\_min, E\_max\] 内。

该区间可容纳的 1/K 整数倍点数为 K \* (E\_max - E\_min) + 1 = K \* M\_dev + 1。

故：

K \<= K \* M\_dev + 1 =\> M\_dev \>= (K-1)/K

步骤4：可达性构造

取 t\_i = floor(i \* T\_ideal) = floor(iL/K)，则：

E(i) = floor(iL/K) - iL/K = -{iL/K}

因 L 与 K 互质，当 i=1,...,K 时，{iL/K} 取遍 {1/K, 2/K, ..., (K-1)/K, 0}。

故 E(i) 取遍 {-(K-1)/K, ..., -1/K, 0}，得：

M\_dev = 0 - (-(K-1)/K) = (K-1)/K

因此 min(M\_dev) = (K-1)/K。
