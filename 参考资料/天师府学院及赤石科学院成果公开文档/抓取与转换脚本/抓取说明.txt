怎么抓的
  页面内容不是从网页上抠的字，而是从编辑器内存里的块缓存读的：
  window.__coreEditor.dataCore.defaultMemoryCache.cache。
  每个块有类型、文字（富文本）、子块顺序，比网页上的字全，公式、链接目标、图片原地址都在里面。
  逐页打开 ?p=<页面id>，等该页的子块都进了缓存再整份导出（crawl2.js）。
  导出后找出所有被引用、但还没抓的页面，再抓一轮，直到没有新的（findnew.py）。

  有三处要特别处理：
    折叠块里的画廊，要把折叠块点开才会加载，有两页是这样补抓的。
    附件要先调 /v2/file/attachment/detail 拿到带签名的下载地址，再下载，大小都和原记录一致。
    图片直接下载要带 Referer: https://docs.qq.com/，不带会返回 403。

  经典文档用 /dop-api/opendoc 接口取原始数据。
  它的公式是 OMML 结构，由 ext_classic.py 转成 LaTeX。
  物流结构分类那个空间用 crawl_space.js 抓。

转换规则
  convert.py 把块数据转成 Markdown，按原顺序输出标题、列表、待办、引用、提示块、代码、公式、分隔线、表格。
  为了在 GitHub 和常见阅读器里都不走样，有几处特意这样写：
    正文里的 Markdown 特殊字符都加反斜杠。原文的 * 多半是乘号，不转义就会被当成斜体吞掉。
    加粗、斜体、删除线、下划线、行内代码用 <b> <i> <s> <u> <code>，不用 ** 这类符号。
      中文标点挨着 ** 时，常常不被认成加粗。
    文字颜色、背景色写成 <span style="color:…">。
      原文里颜色有意思：灰字是「不太重要」，文案里橙色是「待改」、红色是「待加」。
      GitHub 网页上不显示颜色，但源文件里留着，VS Code、Typora 这类阅读器能显示。
    块内换行用 <br>。
    段落下面挂的子块用 <div style="margin-left:2em"> 包住；不用空格缩进，空格缩进会变成代码块。
    分栏和画廊用 HTML 表格排成一行几格；画廊一个条目一行。
    折叠块写成 <details><summary>。
    原表没有表头时，用空表头，所有行都当数据行。
    编号列表按原文的「继续编号」接着编。字母编号 Markdown 没有，写成「a. 」开头的段落。
    代码块的围栏比代码里最长的反引号串多一个，代码里的空行原样保留。
  页内链接改成指向本地 md。
  链到某一节的，在目标块前放 <a id="块id"></a>，链接带 #块id。
  链接显示的文字和原网页一致：链到别页的某一节显示「页面-节标题」，链到本页的只显示节标题。
  原网页会把太长的链接标题截成「...」，这里保留全名。
  丢掉的只有评论锚点。
  原文里已删掉、只剩缓存的旧块不输出；链到这种块的链接，只指向所在页面。
  经典文档（ext_classic.py）写法相同，另外：
    整段只有公式的段落写成 $$ 块；
    求和、连乘的上下限按原文放在正上方、正下方（\limits）；
    表格按行、格标记还原；
    编号段落按原文的编号定义输出。

  PNG 做了无损重压：只在逐像素比对完全相同时才替换，没有去掉色彩信息，体积小了约四分之一。
  JPEG 只做了无损的 Huffman 优化。GIF 没动。

怎么核的
  verify.py
    网页渲染出的正文逐行比对，侧栏 122 页只有 2 行对不上，都是原网页把长链接标题截成「...」。
    所有本地链接和图片文件都存在，所有 #块id 都落在 <a id> 上。
  verify_blocks.py
    原始数据里每个块的文字都在它所在页的 md 里，图片一张不缺。
  render_check.py
    用 markdown-it 实际渲染每一页，查多出来的代码块和露出来的标记符号。
  经典文档按段落核过中文全文。
  从 原始数据/ 重新生成一遍，和现在的 md 逐字节相同。
  另派了五席 codex，逐页对照原始数据查格式，并用 markdown-it、pandoc 实际渲染：
    第一轮报了 135 条，转换脚本据此重写；
    第二轮逐条复核：130 条已改好，剩 5 条；另报了 7 条新问题，其中 5 条是同一类。这些随后都改了：
      链接里原有的按标题定位的片段照原样保留；
      页面标题里的引用保留成链接；
      网址形式的链接文字少转义；
      列数不同的画廊行分表；
      经典文档补了章节标题、公式里的字面花括号、公式内换行，以及 \nolimits。

以后重抓
  1. 在浏览器里打开空间任一页，用 crawl2.js 逐页导出块缓存。
     这些脚本是在 ego-browser 下跑的，脚本里的路径要改成自己的工作目录。
     种子页面列表可以取侧栏，也可以直接用 原始数据/blocks.json 里的 tree。
  2. 反复跑 findnew.py 和 crawl2.js，直到没有新页面。
  3. 下载图片（带 Referer）和附件（先拿签名地址）。
  4. 在本目录运行：
       python3 convert.py <输出目录> 配置-主空间.json
       python3 convert.py <输出目录> 配置-物流结构分类.json
     经典文档：
       python3 ext_classic.py <opendoc.json> <原文地址> <输出.md> ../ ../原始数据/资源对照.json
  5. 核对：
       verify_blocks.py <备份目录> <原始数据/blocks.json> 页面
       render_check.py <备份目录>
       verify.py 要先用 crawl_text.js 抓一份网页上显示的正文（pages/*.json）和侧栏目录（tree.json），在它们所在目录运行。
