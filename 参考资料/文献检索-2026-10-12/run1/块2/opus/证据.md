# 块2 证据：每个可到达的循环态都要达标，以及怎么进到循环态

## 本块小结

**一句话：** 别的领域里已经有「带优先级的定时 Petri 网 → 分段线性动力学 → 逐个枚举稳态策略、每个策略的吞吐唯一可算」这一整套（Gaubert 一派，2015–2025），它最接近「把每个循环态都检查一遍」；同一派还明说整数时延下离散轨迹会偏离流体稳态，正对上本题 n/(n+1) 掉速。无竞争的部分则有标记图的回路令牌数不变量，它对所有可到达状态同时成立，能直接写成布局条件。

**查了哪些领域（9 个）：** 离散事件系统与 max-plus/min-max 代数；Petri 网（标记图、加权 T-系统、home state、带优先级的定时网）；排队论与制造系统调度（全局稳定、对抗排队、Kumar–Seidman）；组合与概率（rotor-router、chip-firing、abelian network、耦合从过去）；自动机与电路验证（同步词、无复位电路的对齐、片上通信结构 xMAS、NoC 性能验证）；分布式系统（自稳定、令牌环、BGP 稳定路径、交换机 iSLIP 轮询）；博弈与验证（均值博弈）；系统生物学（布尔网络吸引子）；统计物理交通元胞自动机（BML、规则 184、带优先路口的 min-plus 交通）；另有实时系统与嵌入式数据流（时序异常、时间单调、场景数据流的最坏吞吐）和离散事件仿真（同时事件排序）。

**最可能对本题有用的 5 篇：**
1. Allamigeon、Capetillo、Gaubert 2025（arXiv:2505.02729）及 2024（arXiv:2411.12437）：把带优先级的定时 Petri 网的全部稳态按「瓶颈策略」枚举，每个策略用 LP 多项式时间判可实现，吞吐唯一且有闭式。把「每个循环态都达标」变成「每个可实现策略的吞吐 ≥ 目标」，规则里的级别正是他们的优先级规则。
2. Allamigeon、Bœuf、Gaubert 2017（arXiv:1612.07661）：时延之间有算术关系时，整数（离散）轨迹可能不收敛到稳态，吞吐不同于流体稳态。这解释了本题 n/(n+1) 那类掉速，也说明用流体或 LP 证达标不够。Theorem 7 给出「稳态流量只由初始标记决定」的可检查条件。
3. Commoner 等 1971（经 Murata 1989 的 Theorem 6、19 与第 VIII-A 节）：标记图里回路令牌数在任何激发下不变，周期 ≥ max（回路时延/回路令牌数）。所以没有汇流竞争的子网，其所有可到达循环态的交货率由起法定下的令牌数唯一确定。这直接给出布局上能检查的条件，也直接推出「无出口的物料回路堵满就死」。
4. Dai、Vande Vate 2000（10.1287/opre.48.5.721.12408）及 Bertsimas、Gamarnik、Tsitsiklis 1996：用网络流或 LP 求一个分段线性 Lyapunov 函数，它一次证明「每一种调度都不积压」。这给了「对所有建造、接通、判定先后都达标」的证书形状，两站内是精确判据。可计算的另一条路是 H 节的 Geilen–Stuijk 2010：把每种汇流模式写成一个 max-plus 矩阵，所有切换序列下的最坏吞吐就是 max-plus 自动机的最大回路均值。
5. McKeown 1999 iSLIP（10.1109/90.769767）：「只在成功时前移、从成功者下一位开始」的轮询，就是规则里的元件轮询；满载下指针会自发去同步、进入固定轮转。这是证明「轮询状态被离线清空后回到同一循环态」最可借的现成机制。

## 研究问题与检索词

- RQ1 确定性离散事件系统什么时候、经过多长瞬态进入周期，周期均值由什么决定，和初态有没有关系？
  词：max-plus transient / cyclicity / CSR expansion；timed event graph cycle time；self-timed execution SDF periodic；min-max functions cycle time；cellular automaton traffic Rule 184 / BML attractor。领域：离散事件系统（max-plus）、数据流（SDF）、统计物理交通元胞自动机。
- RQ2 哪些结构下「所有可到达状态的吞吐都一样」（与判定先后、初态无关）？
  词：marked graph circuit token invariant reachability；live safe marked graph；abelian network / abelian property；Kahn process network determinacy；confluence order independence。领域：Petri 网、分布式计算（abelian network）、并发语义。
- RQ3 对手选先后（建造先后、接通先后、离线重建）时，怎么证「每个循环都达标」？最坏情况下的周期均值是什么。
  词：mean-payoff game；min-max function duality cycle time；global stability all work-conserving policies；Kumar–Seidman instability；adversarial queueing universal stability；timing anomaly；Boolean network attractor enumeration。领域：博弈与验证、排队论/制造系统调度、实时系统、系统生物学（布尔网络）。
- RQ4 固定次序轮转（分流器、汇流器的轮询）组成的网络，从任意初态是否必然进入周期、周期长度和偏差有多大？
  词：rotor-router periodic Eulerian；Propp machine；parallel chip-firing period；rotor walk load balancing discrepancy；deterministic random walk。领域：组合/概率（chip-firing）、分布式负载均衡、多机器人巡逻。
- RQ5 怎么把系统带进一个已知的循环态（起法）：从任意初态把状态收拢到已知状态，以及初始标记怎么选才不死锁、吞吐最大？

## 证据行

### A. 固定次序轮转（rotor-router / chip-firing / abelian network）

- [arXiv:1612.09145 / W2962820682] Kosowski、Uznański 2016（arXiv，v3 2017），Ergodic Effects in Token Circulation
  解的问题：每个结点把手里的全部令牌按轮转次序分给邻边（rotor-router 的多令牌版），问进入循环态后每条边上的时间平均负载。
  方法：把动力学对应到对称有向图上欧拉回路的遍历，用加法组合（sumset）估计偏差。
  规模：一般图，m 条边、k 个令牌；初始化阶段是多项式长。
  对应本题：结点的轮转 ≈ 分流器「元件轮询：按接通先后循环，从上次成功的下一条开始」；「循环态」≈ 论文的 recurrent state；结论的形式正是「在**每个**循环态里，任一条边在长 T 的窗口上的平均量都贴着 k/m，偏差 Õ(1/T)」——这是「所有可到达循环态都达标」这类命题在别的系统里被证出来的样子。
  不对应的：论文的轮转不跳过、没有容量（一条边可以同时有很多令牌）；本题分流器「跳过起点中没有可移动物品的通道」，下游满就判定失败、指针不动，且每格上限 1、有反压。偏差界依赖 gcd(m,k) 这种数论条件，本题没有对应物。
  对本题有什么用：块2，给 U/L 都不直接用；给的是证明模板：先刻画循环态的结构（这里是欧拉回路），再在结构上证时间平均。本题若能把「分流器树＋满载线」的循环态刻画成某种固定轮转模式，可照这个套路证「每个循环态的平均分配比都等于 1/3」。
  依据：摘要

- [arXiv:1407.3200 / W1745615300] Chalopin、Das、Gawrychowski、Kosowski、Labourel、Uznański 2014（arXiv，v3 2015），Lock-in Problem for Parallel Rotor-router Walks
  解的问题：k 个令牌同时在 rotor-router 上走，系统确定，问何时、以什么周期锁进周期行为（lock-in）。
  方法：用稳定态的结构性质「subcycle decomposition」刻画周期行为，能多项式时间判一个格局在瞬态还是已在极限周期里。
  规模：稳定时间 O(m⁴D²+mD log k) 和 O(m⁵k²)；周期可以是图规模的超多项式（推翻了「周期 ≤ 2m」的猜想）。
  对应本题：令牌 ≈ 物品，结点轮转 ≈ 分流器轮询；「判一个格局是否已进入周期」≈ 我们要判模拟内核是否已到循环态；周期可超多项式提醒：多股轮询交织时，循环态的周期可能非常长，内核「跑到出现重复状态」的停止法可能跑不完。
  不对应的：无容量、无反压、无汇流器；令牌之间不互相挡。
  对本题有什么用：块2，给内核用的判据思路：不靠「看到状态重复」判进入周期，而是找一个结构性质（这里是 subcycle decomposition），一旦满足就保证此后是周期的。另给一条规模警示：周期长度不能默认是多项式。
  依据：摘要

- [10.1007/s00453-003-1030-9] Yanovski、Wagner、Bruckstein 2003（Algorithmica 37:165–186），A Distributed Ant Algorithm for Efficiently Patrolling a Network
  解的问题：一个只按「轮着走出边」规则的智能体（即 rotor-router），从任意初始指针出发，会不会进入固定巡回。
  方法：证明瞬态之后智能体进入扩展欧拉回路，每条边被走相同次数。
  规模：单个智能体在 2|E|D 步内进入欧拉回路；多个智能体在 2(1+1/k)|E|D 步后各边访问数平衡到 2 倍以内。
  对应本题：「从任意初始指针出发都收敛到同一种周期行为」≈ 本题「离线后轮询状态可能清空」——轮询指针被打乱后能不能回到同一个循环态；单智能体的结论就是「循环态和初始指针无关」的一个已证例子。
  不对应的：单令牌、无容量；本题是很多件物品同时在网里，接近多令牌情形，而多令牌已被上一篇证明周期可很长、结构复杂。
  对本题有什么用：块2，属于「指针状态被清空也不影响长期平均」这类结论的出处，可当类比或引理来源；不能直接搬。
  依据：网页搜索给出的摘要与后续文献（Bampas 等）的转述

- [arXiv:1309.3445] Bond、Levine 2013（SIAM J. Discrete Math. 30:856–874，2016，DOI 10.1137/15M1030984），Abelian networks I. Foundations and examples
  解的问题：图上每个结点一个自动机，靠边传消息；什么条件下最终输出与各自动机处理输入的先后无关。
  方法：给出两条局部公理（局部交换性），证明满足它们的网络「全局输出与处理次序无关」，并证最小作用原理、停机二分。
  规模：理论文。
  对应本题：「处理次序」≈ 本题的判定先后、建造先后、接通先后——玩家看不见、控制不了的那几个量；abelian 性质正是「这些先后不影响结果」的一个充分条件，而且是局部可检查的（每个结点自己满足交换性就够）。
  不对应的：abelian network 是停机（有限输入算到停）的设定，没有时间、没有吞吐；本题汇流器的轮询选择在有竞争时不满足局部交换性（两路同时来货，先收谁会改变后面谁被挡）。传送带容量 1 的反压也破坏交换性。
  对本题有什么用：块2，给一种「布局上可检查的条件」的写法：若某一片子网每个单位都满足局部交换性，就能整片判定「先后不影响」。可以拿来逐个机制过：哪些单位（单进单出的带子、单料机器）是局部交换的，哪些（汇流器、分流器在下游会满时）不是。U 用不上，L 的验证可用来缩小要穷举的先后。

### B. 无选择的部分：标记图（marked graph / T-system）里「所有可到达状态吞吐相同」

### E. 带优先级、带分流比例的定时 Petri 网：非单调动力学的稳态（与本题最像的一组）

- [arXiv:2411.12437] Allamigeon、Capetillo、Gaubert 2024（arXiv，ACM 会议格式），Stationary regimes of piecewise linear dynamical systems with priorities
  解的问题：带「优先级规则」和「预选（分流比例）规则」的定时 Petri 网，写成计数函数 z_q(t)（到 t 为止变迁 q 激发了几次）后是分段线性的时滞动力学，系数可以为负（因而**不单调**）。问：是否一定存在稳态解（不变半直线 x(t)=u+tρ，ρ 就是吞吐向量）。
  方法：在线性部分的谱上加结构条件（Assumption A、B），借拓扑度理论和 MDP 的 Blackwell 最优性（引入折扣因子 α，再令 α→1）证明稳态解存在（Theorem 9；max-min 版 Theorem 11）；Kohlberg 1980 的非扩张映射不变半直线定理是推论（Corollary 12）。第 5 节说明带优先级和预选的定时 Petri 网自动满足其中一条谱条件（一种守恒律）。
  规模：例子是巴黎急救呼叫中心（PFAU）与两条环形路一个路口（右侧优先）；理论文。全文第 2.1 节：「A priority rule associated to a place p is defined by a total order ≺p on the downstream transitions」，冲突时「the token is used by the one with higher priority」；库所有持有时间 τ_p，令牌待满 τ_p 才「mature」。
