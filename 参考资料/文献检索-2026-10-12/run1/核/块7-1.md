核对日期：2026-10-12。对象仅为 [找空白.md 的块7-1](../块7/找空白.md)，原文第112–186行。规则依据为 `/home/zhuran24/zmd-research-fresh/《明日方舟：终末地》游戏规则.txt`；行号均以本次读取的文件为准。仓库只读，实验仅核静态几何与下界，没有运行游戏模拟内核。

**判定：部分成立。** 六个文献 KEY 都对应所称论文，四篇取得全文，两篇只核摘要；原文确有可交接候选图、联合生成与嵌入、匿名目标网络流、邻接子图等方法。剩下可用的是：**预计算合法端口直连候选，保留单元结构、流量与长进路回退，在摆放时共同选择机位及同物料配对，作为抬 L 的受限候选发生器。** 文献与现有下界没有证明它能造出合格整厂，也没有证明会比现有模型快。原文的“其余两边遇端口就冲突”不符合传送带规则，“全部需求等于直连数”的模型无法容纳所引用采种单元的反馈长路。

### 1.1 W4405469782：Zeng 等

精确解析为 *Budget-optimal multi-robot layout design for box sorting*，DOI `10.48550/arXiv.2412.11281`。[原文 PDF](https://arxiv.org/pdf/2412.11281v2)，[本地全文](块7-1附件/W4405469782.txt)。`python3 lit.py full W4405469782` 成功。读取版本为 **v2，2025-03-07**；2024 是最初提交年份，不能把该全文版本标成2024版。

**依据：全文 §IV-A–C，PDF p.3；输送带扩展 §V-A，p.4；对照实验 §VI-A，p.5。**

> “Equation 2 can be further formulated as a mixed-integer linear programming (MILP) problem using network flow.”

- **成立：** §IV-A 在每个安装格点枚举机器人类型，逆运动学与碰撞检查决定可交接边；§IV-B 选最小成本连通子图；§IV-C 用边选择布尔量和按目的地分商品的流表示连通。机器人型号在同一格点互斥。输送带另在 §V-A 扩展，不是 §IV-A 就已经一并枚举完全部输送带。
- **成立但限定范围：** §VI-A 的约100倍加速针对该文的 A* 启发式基线和特定格点分辨率，没有比较本题 CP-SAT。不能迁移成预计加速倍率。
- **不能照搬：** §III（p.2）明确只考虑单个箱子的送达几何，不给特定输入时间序列；§IV-D（p.4）再安排异步任务和运动。本题的容量、反压、批量配方及所有循环态吞吐不在该连接图保证内。“机器人放在格点”也不表示其实体或运动包络没有体积，不能用它支持“边完全没有副作用”。

## 3. 尝试反驳：找到的具体失效情形

### 3.1 全部需求都等于直连数：植物反馈回路必被排掉

规则64规定采种机、种植机均为5×5，进货边和出货边互为对边；规则117、121为“1 荞花种子 → 1 荞花，1 tick”“1 荞花 → 2 荞花种子，1 tick”。`求解充分条件.txt`17、23采用采种机 C 与种植机 A 的 `C→A→C` 反馈，不能取消回路。

具体摆放：坐标 y 向下，C 占 `(10..14,10..14)`、A 占 `(16..20,10..14)`，两者进货边朝西、出货边朝东。C→A 用 `(15,12)` 一格西入东出的带子。A→C 的合法回路可走：

```
(21,12) → (21,11) → (21,10) → (21,9)
→ (20,9) → (19,9) → … → (9,9)
→ (9,10) → (9,11) → (9,12) → C的西侧端口
```

运输格都在基地内且不占机身，拐弯依规则74设置。只看 C、A，A 东侧出口外格与 C 西侧入口外格完全不同，所以回程没有一格直连候选。把两机挪动或旋转也救不了“来回都一格”：[geometry_probe.py](块7-1附件/geometry_probe.py) 枚举全部可能近邻锚点和16种朝向组合，得到1408个非重叠案例，其中108个允许 C→A 一格，**0个允许来回均一格**。共享外侧格要求每个坐标方向的锚点差至多6，因此 `[-6,6]²` 覆盖全部可能；直带、拐角带、桥均须具有这个共同外侧格，枚举没有漏掉桥。

这反驳的是被核稿第180行“每台机器按配方的进出条数，等于选中的直连数”被直接推广到植物单元：至少一条反馈路必须回退为长路。它不反驳“多数直连＋长路回退”作为启发式的可能用途。上述是合法局部几何，不是达标整厂，也没有验证回路存量或循环态产率。

### 3.2 字面冲突规则会错删一个合法的研磨机第三路

按规则58、68、74放置以下局部布局，坐标两端均包含：

| 单位 | 占格 | 进货边→出货边 |
|---|---|---|
| 蓝铁粉末粉碎机 P1 | x=10..12，y=10..12 | 北→南 |
| 蓝铁粉末粉碎机 P2 | x=13..15，y=10..12 | 北→南 |
| 砂叶粉末粉碎机 S | x=7..9，y=12..14 | 西→东 |
| 致密蓝铁研磨机 G | x=10..15，y=14..17 | 北→南 |

P1、P2 分别经 `(11,13)`、`(14,13)` 的北入南出带进 G。S 经 `(10,13)` 的**西入南出拐角带**进 G。三路分别提供规则106要求的两路蓝铁粉末及一路砂叶粉末。该拐角带北边紧贴 P1 的取货端口，但它北边没有存货端口，规则17不生成 P1→这格的通道。

独立按实际端口重建，只得到六条期望通道，没有额外通道，且机身、三条带子均不重叠；结果由附件几何脚本确认。若照被核稿第135、175行，把直连格“另两条边正对别的机位端口”一概禁掉，就会错删此合法第三路。

因此“两台3×3粉碎机占满6格宽，所以第三路不能一格”不能作为一般不可行性证明；两台机的投影占满6格，实际使用的带格只需两个，第三路可以从端点拐入。第四张规划第11行所说的是**特定连续车道封住两头**的限制，不能推广到任意摆放。此例只验证输入侧几何，其他供料、供电、起态和运行产率未验证。

### 3.3 分物料各自有流，仍可因共用一格而同时失效

固定四台机器围绕格 `c=(20,20)`：西侧粉碎机占 `(17..19,18..20)`、出货朝东；北侧研磨机占 `(20..25,16..19)`、进货朝南；东侧粉碎机占 `(21..23,20..22)`、出货朝西；南侧研磨机占 `(15..20,21..24)`、进货朝北。四个机身不重叠。

只考察两条进路：西侧蓝铁粉末要向北，东侧砂叶粉末要向南。每种物料独立检查都可在 c 放一条拐角带，找到一格路径；合起来却不能在 c 同时放两条带（规则8、73、74），桥也只能对边直穿，不能同时实现西→北与东→南两个拐角（规则77）。若改走外侧长路或改变机位，这个冲突可以修复；**独立最大流本身不提供修复，也不证明联合直连可行。**

此例否定“匿名以后19个单物料检查足以完成联合摆放布线”的理解，不否定保留共格冲突的 CP-SAT 模型。物料度数只是局部义务，不能替代联合占格约束。

| 原指定配对 | 2301 | 84 |
| 保守匿名 | 2064 | 83 |
| 保留植物四种回路物料，其余匿名 | 2006 | 83 |
| 全部物料匿名 | 1869 | 81 |

也复现34个完全没有可用端口外侧空格的单位侧，涉及29条原指定进路。固定机位下仅换配对仍至少断81路，确实救不了这张候选。2301到2064、1869分别下降约10.3%、18.8%；**这只能说明距离下界降低，不是实际可布线长度节省。**

脚本用最小费用一一匹配计算距离，用另一份0/1匹配计算连通块不相交数。两次匹配独立求最优，未必同一配对同时达到两列值。它没有铺带，没有实现桥轴方向，也没有证明所有同物料配对满足对应流率和单元结构；距离还允许把被机身占用的端口外侧格纳入候选，以保持低估。因此1869、2006不是两张新布局或新接法证书。

原文“978个空格全用双轴桥得1956”是脚本口径：非运输机身等占3886格，并预留6×6空地，余 `4900−3886−36=978` 格。规则77本身有四个有向物品格；按轴端点一取一存、只使用两条正向独占路时，每桥计算两个可用物流槽才成立。**1956应标作该受限双轴口径的容量上限，不能直接从规则77推出所有合法桥用法一律最多两个物品格。** 本次不据此扩大或推翻全题 U；断路下界已独立否定该固定机位的专用进路接法。

## 5. 最终保留与证据边界

可以保留的试验是：在铁砖等无植物反馈的小窗口内，预枚举矩形摆法及合法直带、拐角带、双轴桥候选；联合选机位和同角色、同速率来源，按真实端口重建全部通道。进入整厂时，必须显式保留植物反馈及其他长进路义务，预留能布线的空间；不能一边把所有进出度都绑定直连，一边声称之后才补长路。双轴共享格需作为同一实体处理。

这是一种可操作的候选表示改进，文献支持其构造思想，复算支持“单换配对不够、需连同机位改变”。仍未核实的收益包括直连覆盖率、候选边数量、求解规模、速度、整厂可布线性及达标循环态。出解后需按规则17重建通道，再核供电、调试起态及全部可到达循环态；`求解任务.txt`2、8、14的义务没有被静态候选图代替。纯一格模型失败只排除该受限类，不构成全题不可行或 U 的证明。
