# 块1-1：四篇论文原文核对

核对对象：`run1/块1/找空白.md` 的「块1-1」。本文件仅核对 Campos 1992、Lu–Koh 2003、He–Li–Giua 2017、Gaubert 1995 四项引文及它们支持的边界。核对日期：2026-10-12。下述页码为取得的作者稿或会议 PDF 自身的页码；不将作者稿页码冒充期刊页码。

结论：四个 KEY 均可解析，四篇均取得全文。它们确实支持单位标记图的 LP/关键回路分析、固定拓扑与候选区域容量约束的缓冲 MILP、加权标记图到单位标记图的严格变换，以及有限 max-plus 模式任意切换的最坏增长率。但这些论文没有证明本题的制造规则或离线重排已经成为同维、同事件索引的 max-plus 系统，也没有证明只加配方权即可沿用单位弧的势不等式。

## 1. Campos 等，10.1109/81.139289

论文：J. Campos, G. Chiola, J. M. Colom, M. Silva, *Properties and Performance Bounds for Timed Marked Graphs*, IEEE TCAS-I 39(5), 386–401, 1992。

来源：作者 [2007 年授课材料](https://webdiis.unizar.es/asignaturas/SPN/aux/barcelona07.pdf) 的第 190 页参考文献直接链接到 [作者全文 PS 文件](https://webdiis.unizar.es/CRPetri/papers/jcampos/92_CCCS_CAS.ps.gz)。本地保存为 `Campos1992.ps.gz`，经 `ps2pdf` 得到 `Campos1992.pdf`，全文文本为 `Campos1992.txt`。作者姓名、标题和文献条目与 KEY 解析一致。

原文一句（§3.1，Theorem 3.3 的证明，作者稿 p.9）：

> We know from [19] that for deterministic timing the bound is reached.

核对：**成立，但有模型条件。** §2.2 Theorem 2.1（p.4）把最小支撑 P 半流与有向基本回路对应；§3.1 Theorem 3.1（p.8）的 LPP2 为最大化 `Yᵀ Pre θ`，约束 `YᵀC = 0, YᵀM₀ = 1, Y ≥ 0`。Theorem 3.2（p.9）保证可选一个最小 P 半流达到最优，等价于取各回路「总时延/令牌数」的最大值。对活、强连通、确定性标记图，该界即精确周期时间；对随机时延，论文所说的是可达的吞吐上界，不能将它理解为每种随机分布都达到该界。

§3.1 作者稿 p.10 的 LPP4 为 `min γ`，约束 `−Cz + γM₀ ≥ Post θ, γ ≥ 0, z ≥ 0`；LPP5 是其对偶。论文证明在活强连通条件下 LPP5 约化为 LPP2。这支持「P 半流回路界与时刻/势不等式可用对偶连接」。它不替本题证明物品格、制造状态和判定顺序已经忠实转为该标记图。

## 2. Lu–Koh，10.1109/ICCAD.2003.159694

论文：Ruibing Lu, Cheng-Kok Koh, *Performance Optimization of Latency Insensitive Systems through Buffer Queue Sizing of Communication Channels*, ICCAD 2003, pp.227–231。

来源：[SIGDA ICCAD 2003 目录](https://cecs.uci.edu/~papers/compendium94-03/papers/2003/iccad03/htmfiles/sun_sgi/iccadtoc.htm) 的 3D.3 条目和 [会议全文 PDF](https://cecs.uci.edu/~papers/compendium94-03/papers/2003/iccad03/pdffiles/03d_3.pdf)。本地文件：`LuKoh2003.pdf`、`LuKoh2003.txt`。Crossref 对给定 DOI 返回相同标题及 pp.227–231，保存于 `Crossref-159694.json`；不是 KEY 查不到。

原文一句（Abstract，p.227）：

> An algorithm based on mixed integer linear programming is proposed.

核对：**成立。** §4（p.229）给定 LIS 图、候选缓冲区域、各区域容量和通道到区域的映射，选择每条通道的附加缓冲数；§4.1（pp.229–230）用图势函数控制最大回路均值，并给出 min-cost 与 maximum-performance 两种 mixed-ILP。附加缓冲为整数变量，势与回路均值为实变量，区域容量是独立的线性约束。

边界：论文的拓扑、已有模块位置和通道到候选区域的映射均已给定，物理设计中的布图已基本确定；它证明了**带区域容量约束的通道缓冲分配**可以做 MILP，未证明「任意单位位置、任意连接拓扑、本题特殊几何与 throughput」的统一模型已经建立。因此块1-1把它当作固定拓扑布局约束的先例成立，把它读成解决拓扑可变的本题不成立。

## 3. He–Li–Giua，10.1109/TCST.2016.2613967

论文：Zhou He, Zhiwu Li, Alessandro Giua, *Cycle Time Optimization of Deterministic Timed Weighted Marked Graphs by Transformation*, IEEE TCST 25(4), 1318–1330, 2017。

来源：[Giua 作者文献页的 17tcst 条目](https://www.alessandro-giua.it/UNICA/papers.html) 和 [26 页作者稿 PDF](https://www.alessandro-giua.it/UNICA/PAPERS/JOUR/17tcst_draft.pdf)。PDF 首页明确标出给定 DOI。另有 [大学库同稿](https://iris.unica.it/retrieve/handle/11584/213688/220049/17tcst_draft.pdf)；浏览搜索可读该稿，直接 Python 请求该库返回 403，采用作者网页下载成功。本地文件：`HeLiGiua2017.pdf`、`HeLiGiua2017.txt`。

原文一句（§II.C，作者稿 p.7）：

> This equivalent TMG system depends on the initial marking M and the minimal T-semiflow x of the TWMG.

核对：**「加权图可以严格转换」成立；「仅按配方加权便可直接套原来的每弧势条件」未获支持。** §II.A（pp.4–6）要求每个 place 唯一前继/后继，固定确定性时延、ASAP、单服务器语义；研究范围限于强连通且每个回路中性的加权标记图。§II.C 的 Algorithm 1（pp.8–9）依据最小 T 半流分量展开 transition，并依据初始标记的商/余数展开 place；这是保持优先约束与周期时间的变换，不是简单给弧乘一个生产/消耗系数。

§II.B（pp.6–7）明确区分：一般 TWMG 的 LP 先给周期时间下界，而转成等价 TMG 才能精确计算。§IV 的优化需按初始标记的同余类处理不同等价图。因此本题封装机、灌装机等可以作为建加权模型的动机；它们是否满足上述结构、单批互斥与容量放行语义仍须独立证明。特别是不同制造配方的 batch rate 不能不经归一化就与物品 rate 共用一个 `Θ`。

## 4. Gaubert，10.1109/9.478227

论文：Stéphane Gaubert, *Performance Evaluation of (max,+) Automata*, IEEE TAC 40(12), 2014–2025, 1995。

来源：[Gaubert 作者文献页](https://www.cmap.polytechnique.fr/~gaubert/papers.html) 给出的 [作者全文 PDF](https://www.cmap.polytechnique.fr/~gaubert/PAPERS/IEEE-TAC-93-172-preprint.pdf)。本地文件：`Gaubert1995.pdf`、`Gaubert1995.txt`。下面的公式另经 `Gaubert1995-page6.png` 原图核对；PDF 字体使文本提取遗漏数学符号，公式不可只凭提取文本读。

原文一句（§V，Theorem 2(ii)，作者稿 PDF 第 6 页）：

> If (α, μ, β) is trim (but M not necessarily irreducible), we have ρ(M) = limsupₖ (y|Σᵏ)¹⁄ᵏ.

这里指数、根号及乘积按 max-plus 运算理解，普通数值意义为每事件的线性增长率。

核对：**在有限同维 max-plus 矩阵、每事件可任意选择模式的前提下，逐项最大矩阵的谱增长率等于最坏切换增长率，确实成立。** §III.D 给出有限值非平稳 max-plus 线性动力学的表示；§V 式(26) 明写对全部长度 `k` 的模式字串取最大可用分配律化为 `αMᵏβ`，其中 `M = ⊕ₐ μ(a)` 就是逐项最大。Theorem 2(ii) 在 trim 条件下把其渐近增长率识别为 `ρ(M)`。不可拿普通实数矩阵的 joint spectral radius 反例否定这条 max-plus 结论。

条件与本题缺口：trim 指相关状态既从初始端可达、又能通向输出端；不可保留无关慢回路后把全矩阵谱半径当成指定输出的精确增长率。若模式只能遵从某个合法语言，§VI 通过合法语言自动机与矩阵表示的张量积重新求谱；裸逐项最大是无约束切换的包络，通常只给保守结果。本题只有离线后才重排、事件之间存在 batch 索引与存量约束，块1-1仍须证明同维同索引表示与模式切换不会丢失这些状态。文献本身不证明该本题映射。

## 适用边界

1. Campos 的 LP/回路比与对偶势、Lu–Koh 的区域容量 MILP：论文方法确实存在，结构条件须保留。
2. He–Li–Giua 的加权规范化：存在严格等价变换，不能省略 T 半流、初始标记、展开图及适用结构，直接把单位弧的 `m−Θd` 作为所有加权配方的充要条件超出了论文结论。
3. Gaubert 的逐项最大谱率：作为 max-plus 任意切换代数定理成立；本题应用仍是待证映射，保守性需要共同事件状态和单调比较，而不只是一句分配律。
