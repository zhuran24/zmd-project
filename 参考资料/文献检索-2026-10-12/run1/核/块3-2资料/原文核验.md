## 1. `10.1109/tcad.2010.2066030`：GRIP 期刊版

**身份成立。** Tai-Hsuan Wu、Azadeh Davoodi、Jeffrey T. Linderoth，*GRIP: Global Routing via Integer Programming*。作者[研究主页](https://jlinderoth.github.io/research.html)列为 *IEEE Transactions on Computer Aided Design*, 30:72–84，2011；DOI 中的 2010 不是正式刊年。OpenAlex 单篇元数据给的年份为 2010，与作者正式书目存在这一差异。

**一句原文：**

> The boundary between two adjacent global bins is modeled as an edge e ∈ E.

出处：§II-A **Global Routing Formulation**，作者稿 PDF 第 2 页。随后正文定义每条边的容量为相邻 bins 间可用布线资源的上限。源：[作者全文](https://jlinderoth.github.io/papers/Wu-Davoodi-Linderoth-10-PP.pdf)；本地：[GRIP期刊稿.pdf](GRIP期刊稿.pdf)、[GRIP期刊稿.txt](GRIP期刊稿.txt)。

**核到的方法：**

- §II-A，第 2 页：先根据 placement 将芯片分为 rectangular global bins；bin 是图顶点，公共边界是图边。这个图是全局布线图，后续详细布线再把导线分配到具体 routing tracks。
- §III，第 2 页，ILP-GR 式 (1)–(2)：每个 net 从候选 Steiner 树中选择一条；所有被选树在边 e 上的占用和不得超过 `u_e`。路长和 via 成本进入目标；无法布线的 net 可由松弛变量付出惩罚。这支持“可将粗区域公共边界资源写成整数模型”，但不是逐格游戏物流模型。
- §V-A，第 6 页：为缩小 IP，将多个 global bins 划为更大的 rectangular **subregions**；用 floating terminals 保留跨 subregion 连接位置的自由。**基础 bin 图和 IP 子问题 subregion 是两个层次**，不能全部混称为 tile。
- §V-C **Integrating Solutions of Subproblems**，第 8 页：先解各子问题，暂时固定伪端点；再删掉端点到骨干的连接枝，释放资源，并用 IP 重接相邻子问题的骨干。因此“GRIP 有子问题重接”成立。

**版本关系：** 作者稿首页脚注明确说明 DAC’09 [30] 是本文的 extended abstract；第 12 页参考文献 [30] 列出 2009 DAC、320–325 页的 *GRIP: scalable 3-D global routing using integer programming*。故与 `W1977024562` 是期刊稿／会议短版关系。

**不支持的说法：** 原文容量是可用导线资源，不是自动等于几何边界长度；其 multi-layer 模型还有水平／竖直金属层和 via（§II-B）。论文没有证明游戏里的自动接通、桥接转向限制、物品反压和确定性轮询可由这组边容量约束覆盖。

## 2. `W1977024562`：GRIP，DAC 2009

**身份成立。** `W1977024562` 的 DOI 为 `10.1145/1629911.1629999`；OpenAlex 标题简写为 *GRIP*。取得的作者全文标题是 *GRIP: Scalable 3D Global Routing Using Integer Programming*，作者同上，首页 DAC 2009 标识成立。作者主页将其列为 DAC 2009，320–325 页。

**一句原文：**

> Each floating terminal represents a portion of a subregion boundary through which the net will connect to another subregion.

出处：§3.1 **Subregion Extraction / IP Decomposition**，PDF 第 4 页、Figure 2 附近。源：[作者全文](https://jlinderoth.github.io/papers/Wu-Davoodi-Linderoth-09.pdf)；本地：[GRIP会议稿.pdf](GRIP会议稿.pdf)、[GRIP会议稿.txt](GRIP会议稿.txt)。

**核到的方法：** §3.1 将 IP 拆成非重叠矩形子区域；用一个 auxiliary node 连接该段边界上的多个图节点，辅助边容量无限、成本为零。这把“从哪一个边界位置出去”的选择留给子问题。§3.2（第 4–5 页）处理跨多个区域的长 net；§3.3 **Integrating Subregion Solutions**（第 5 页）先固定浮动端点取得初始解，再删除连接枝并以 IP 重接。

**对块3-2的支持程度：** “矩形子问题＋边界端点选择＋解后整合”成立。floating terminal 与本题的“过界格”只能在求解后选定位置的意义下相对应；**原生概念对应的是允许过界的一段边界／候选格集合，不是已经指定的单格**。

**不支持的说法：** 它不是在逻辑接法后只算一张粗整数多商品流、再直接逐格布线的现成算法。候选 Steiner 路径、短 nets 的区内占用和子区域重接都属于其方法；删掉这些只取边界容量账，是本题自己的抽象。

## 3. `W2166264746`：Wu 等，DAC 2010 并行 IP 与 patching

**身份成立。** Tai-Hsuan Wu、Azadeh Davoodi、Jeffrey T. Linderoth，*A Parallel Integer Programming Approach to Global Routing*；DOI `10.1145/1837274.1837323`，DAC 2010，194–199 页。下载的是作者 7 页稿，不能将其 PDF 页码当作会议刊版印刷页码。论文在 §4 将实现称为 **PGRIP**。

**一句原文：**

> These windows are then passed as the feedback to the two subproblems during the repricing phase.

出处：§3.3 **Distributed IP-based Patching**，PDF 第 4 页、Figure 3 和 ILP-PATCH 附近。源：[作者全文](https://jlinderoth.github.io/papers/Wu-Davoodi-Linderoth-10-2-PP.pdf)；本地：[Wu2010并行.pdf](Wu2010并行.pdf)、[Wu2010并行.txt](Wu2010并行.txt)。

**核到的方法：**

- §2，第 2 页，复用 GRIP 的候选路整数模型及边容量约束，并说明 GRIP 先解某子问题、再让相邻子问题遵守已固定的伪端点。
- §3.2，第 4 页：各子问题先独立 LP pricing，跨区伪端点可以落在子问题边界任意位置。
- §3.3，第 4 页：针对每一对相邻边界，ILP-PATCH 同时考虑不同 nets 的伪端点连接组合；为每个 net 选一个允许伪端点位置的 **restricting window**，再反馈给两边。
- §3.4，第 5 页：按这个窗口重做 adjusted pricing，之后用 IP 生成遵守窗口的各子问题解。
- §3.5，第 5 页：最后删去跨区 net 的连接枝、固定骨干，并行重接相邻区域。

**归属判断：** GRIP 2009／期刊版已具备子区域整合与重接；**一次同步的 patching-window 反馈、使相邻子问题能并发处理**是这篇 2010 PGRIP 工作的具体增量。若块3-2的“GRIP 带拼接反馈”指这一套窗口反馈机制，应归到 W2166264746；若仅指 GRIP 有重接步骤，则成立。原文没有“粗层可行但逐格层失败，逐格反例再返回粗层”的 CEGAR 式反馈；其反馈发生于全局布线子问题之间。

## 4. `W1979569488`：Burstein–Pelavin，1983

**身份成立；方法核验仅到摘要。** Michael Burstein、Richard N. Pelavin，*Hierarchical Wire Routing*，DOI `10.1109/tcad.1983.1270040`，*IEEE TCAD* 2(4):223–234，1983。`lit.py full` 无链接；论文 DOI 页要求浏览器机器人验证，网页搜索未取得原文 PDF。核验依据是[IBM Research 论文页正式摘要](https://research.ibm.com/publications/hierarchical-wire-routing)，本地快照：[Hierarchical-IBM.html](Hierarchical-IBM.html)。

**一句原文：**

> Uniformity of the wiring substrate is the crucial assumption of the method.

出处：**Abstract** 第 2 段。这是摘要，没有取得正文，不能填正文节号或页码。

**摘要确实支持：** 方法用于 gate arrays、switchboxes 和 channels 这类均匀布线基底；水平和竖直导线位于不同层，每次转向使用 via；不允许 wrong-way jogs。摘要也把其较快的运行归于 hierarchical nature，并声称最终布局不依赖 net／pin 的排序。因此“1983 层次布线”这个来源名成立。

**未能核实：** 其正文是否正好使用块3-2所提的“粗边界整数多商品流→区块内详细布线”，以及具体递归分区、容量公式、拼接算法。不能用后人引用补充成本文已核实的方法。尤其不能把摘要里的均匀双层基底当成已满足本题机器阻挡、桥接器和自动接通的前提。

## 5. `W2133435384`：BoxRouter 2.0，ICCAD 2007

**身份成立。** Minsik Cho、Katrina Lu、Kun Yuan、David Z. Pan，*BoxRouter 2.0: Architecture and Implementation of a Hybrid and Robust Global Router*；`W2133435384` 对应 DOI `10.5555/1326073.1326176`，ICCAD 2007 会议稿。核对的是这个 2007 版本，未以 2009 的另一个 BoxRouter 2.0 期刊题名代替。

**一句原文：**

> Each edge has maximum routing capacity, and each wire passing the edge takes some routing capacity based on its width/spacing.

出处：§II-A **Global Routing Background**，印刷第 **504** 页／PDF 第 **2** 页。源：[UT Austin 作者全文](https://www.cerc.utexas.edu/utda/publications/iccad_07_boxrouter_2.0.pdf)；本地：[BoxRouter2.pdf](BoxRouter2.pdf)、[BoxRouter2.txt](BoxRouter2.txt)。

**核到的方法：** §II-A 将矩形区域表示成 G-cells／网格图节点，图边表示公共边界；导线需求超过容量定义为 overflow。§III–IV（印刷 504–505 页）是 2D global routing，通过协商式 A*、topology-aware wire ripup 降拥塞。§V（印刷 506 页）再以 via/blockage-aware progressive ILP 做 layer assignment。

**对块3-2的支持程度：** 支持“粗格边容量可作为拥塞账”，也支持需要考虑 blockage 和 layer 资源。**不支持把 BoxRouter 2.0 整体方法说成先解整数多商品流、再仅在区块内部解详细模型**；其 2D 阶段的主要机制是启发式拥塞搜索与 ripup，ILP 的重要用途是层分配。§II-B 讨论渐进扩箱 IP 是 BoxRouter 1.0 的背景，不应直接挪到 2.0 的算法名下。

## 6. `arXiv:cs/0508045`：Albrecht 等，2005

**身份成立。** Christoph Albrecht、Andrew B. Kahng、Ion I. Măndoiu、Alexander Zelikovsky，*Multicommodity Flow Algorithms for Buffered Global Routing*，arXiv v1，2005-08-06。[arXiv 摘要页](https://arxiv.org/abs/cs/0508045)，[PDF](https://arxiv.org/pdf/cs/0508045)；本地：[Albrecht2005.pdf](Albrecht2005.pdf)、[Albrecht2005.txt](Albrecht2005.txt)。`full` 确实取得全文。

**一句原文：**

> We find a near-optimal solution to the fractional relaxation of the above integer program.

出处：§3 **Buffered Global Routing Via Multicommodity Flow Approximation**，高层步骤 4，印刷／PDF 第 **4** 页。

**核到的方法：**

- §2，第 2–3 页：tile graph 的顶点是 tiles，相邻 tiles 之间有边；每条边 `w(e)` 是两 tile 之间可用 routing channels 数，每个 tile 还有 `b(v)` buffer-site 容量。输入是 nets `N_i`，每个 net 有指定 source `s_i` 与 sink `t_i`。
- §3.1，第 4–5 页：用 gadget graph 编码 buffer wireload 约束，每个 source–sink 路径一个 0/1 变量；式 (1.1) 每个 net 选一条路径，约束所有路径共同占用的线／buffer 容量。
- §3.2，第 5–9 页：求分数松弛的近优多商品流。一个 commodity 对应一个 net 的源汇需求，不是不同金属层，也不是物料种类。
- §3.3，第 10 页：以 randomized rounding 将分数流变为一 net 一路径；容量足够大时，舍入后的相对拥塞只增加小因子。它没有给出“任何小容量实例 LP 可行就能零超容取整”的保证。
- §3 第 3 页步骤 1 允许使用 tile graph；第 3.1 页的基本假设是所有 tiles 同尺寸。后文讨论非均匀 tiling 以改善精度与运行时间的折衷。

**对块3-2的支持程度：** “用多商品流／路径变量给粗资源记账”成立；“Albrecht 的多商品流 LP 对应每种物料一层”不准确。可直接借用的是**每条有指定源汇的进路一个 commodity**，或者在证明目标／来源可互换后按 `(物料, 源区块, 汇区块)` 聚合；只按物料聚合会丢掉不同源汇的配对要求。这里的“层”应只是本题变量索引的类比，不能与金属布线层混为一谈。

**不支持的说法：** 该论文针对有预设 buffer sites、wireload／sink-delay 条件的 buffered routing；buffer 是电信号重复器，不是本题存货箱。其近似保证服务于自身的布线资源模型，不能直接转作本题运输时序或所有循环态吞吐的保证。

## 对块3-2出处的总判断

| 块3-2使用的概念／归属 | 原文核验 |
| --- | --- |
| 全局区域图、公共边界边容量 | GRIP §II-A、BoxRouter §II-A、Albrecht §2 都成立 |
| 整数规划选候选路径并受边容量限制 | GRIP §III、Albrecht §3.1 成立；不是 BoxRouter 2.0 全体 2D 路由阶段的算法描述 |
| 矩形子问题与 floating terminals | GRIP 两版成立；浮动端点是边界候选位置集合 |
| GRIP 子问题解的重接 | GRIP DAC 2009 §3.3、期刊 §V-C 成立 |
| 拼接窗口反馈／调整 pricing 以实现相邻子问题并行 | Wu 2010 PGRIP §3.3–3.4 成立；不能概括成逐格失败向粗层回传 |
| Burstein–Pelavin 1983 的层次布线 | 正式摘要支持一般层次方法；具体整数粗流／拼接正文未能核实 |
| Albrecht LP 的 commodity 是每种物料一层 | 原生 commodity 按 net 源汇划分；按物料聚合是尚需证明的本题改造 |
| 容量仅等于边界可用格数，桥横竖各一次 | 文献没有游戏规则依据；需要游戏规则与方向、端口、占位模型另行判断 |
| 粗解通过就能细格布通或达到游戏吞吐 | 六篇均未给这种本题结论 |

剩下可借用的内容是：在逻辑接法与逐格模型之间，用**已证明安全的区域边资源上界**和**保留源汇身份的整数进路模型**产生拥塞诊断；为细格失败保留重新选择边界位置、重新分区和重接的接口。文献足以支持这种表示和流程的来源，未证明本题这个具体容量公式、聚合方式、150 行实现或预期提速。
