# 块3 带子这一层怎么表示（布线模型）：证据表（opus 席）

## 本块小结

**一句话：** 本题的带子层在 VLSI 里有现成的名字，叫「Manhattan 型开关盒布线（Steiner 树打包）」：两条线共用一格时只能各自直穿，这正是桥接器。「中间物品自产自销」是逐格模型里一个有名的漏洞（无源环），文献里有三种补法：割不等式、整数势（递增标号）、方向受限。能扩到 70×70 级的做法都不用「每格×每条线」的变量，而是路径列、拓扑先行或构造加压缩。

**查了哪些领域（9 个）：** VLSI/PCB 布线；纳米电路（QCA/FCN）物理设计；流式微流控芯片；运筹学的设施布局 + 物流通道 / AGV 流路；化工厂布局 + 管道；FPGA/CGRA 映射；图绘制（正交画法、端口约束、拓扑-形状-尺寸）；多智能体路径规划；谜题（Numberlink/Flow Free）。另有工厂游戏（Factorio）。

**最可能有用的 5 篇：**
1. Grötschel、Martin、Weismantel 1997，Steiner 树打包（10.1007/BF02614374）：本题带子层和 Manhattan 开关盒布线一一对应，桥接器就是「直穿交叉点」。用 Steiner 割不等式表示连通性，就不会有无源环，LP 也比流模型紧。knock-knee 是更宽的放松，在它下面证出不可行，本题也不可行，可以拿来压 U。
2. Patterson 等 2023，Factorio 蓝图（arXiv:2310.01505）：给每个带子格一个整数势 ≤ w+h，沿带子严格递增，环就排除了。这是补「自产自销」漏洞最便宜的办法，能直接写进 CP-SAT。他们的三段分解（台数→装箱→布线）也和我们的放松模型同构。
3. Hofmann、Walter、Wille 2025，FCN 布局后优化（10.1109/tcad.2025.3549354），加上 2024 年的 A* is Born：先用 A* 按拓扑序构造，再「门搬家」（就是只含一台机器的小窗口工具），再删掉只穿过导线的整行或整列并合拢（压缩），把空面挤出来。实测能到千万瓦片，可以直接照着搭抬 L 的流程。
4. Wu、Davoodi、Linderoth 2011 GRIP（10.1109/tcad.2010.2066030），加上 Jørgensen–Meyling 2002 分支定价（10.1002/net.10029）：每条线一列，定价是带对偶价的最短路或 Steiner 树；按区域分解，长线用浮动端子过界，开关盒尺度能解到最优。如果改用路径变量，这两篇就是现成的做法；定价时要多带一个「进入方向」状态，才能表示「只许直穿、共格付一个桥」。
5. Walker、Anderson 2019，按连通性的 CGRA ILP（10.1109/fccm.2019.00019）：摆放模型里不放逐格带子，只放「上下游端口距离 ≤ k」和区域拥塞约束，冲突的地方再加细节。这给「先粗后细、按需加约束」的表示提供了实测。

**这块里真没找到东西的方面：**
- 单层布线加跳线（单面 PCB 自动插跳线）的学术算法：搜了「single-layer routing with jumpers」（网页、Crossref）和「single-layer routing with crossovers jumpers minimization」（Crossref），只找到工具文档（tscircuit、Altium、Specctra 论坛）和 80 年代的单层布线理论，没有能引的算法论文。所以最近的学术对应是 Manhattan 模型和 FCN 的交叉块。
- 「端口挨上就自动接通，要禁掉不想要的相邻」作为建模约束：专门的论文没找到。最近的有三处：设计规则约束（Nadel 2016）、QCA 导线最小间距（Walter 2018 提到，没展开），以及 A* FCN 反过来把自动接通当成特性用。
- 汇流的有向布线，也就是多源到一汇的有向 Steiner 树，在格子上做打包：GMW 的施引文献里有有向 Steiner 树打包、有向路径打包的纯理论，没找到用在格子布线上的算法。
- 一条带同时走几种物料，并且按流量拆线（一条满载 1 件/tick）：搜 Factorio 和 GRIP 时都看了，Factorio 那篇明确简化成「每格一种物品」，GRIP 只有边容量，没有汇流的轮询，所以没找到。
- 一格里四个方向各一条通道、同一轴上两个反方向都能过（本题桥接器的四个物品格）：哪个领域都没对应，Manhattan 模型的一个交叉点只容两条线。
- 格点手术（lattice surgery）的不相交路径编译：搜过（EDPC 和后续），它解决的是「每个时间步一批不相交路径」，和静态占格不同，判为关系小，没有写进证据行。
- 网页检索没找到 Klausnitzer–Lasch 2019、Columba、Guirardello–Swaney 的开放全文，这几条的依据只有摘要。

## 证据行里用到的规则原句（《明日方舟：终末地》游戏规则.txt）

- 传送带：「传送带：大小1x1，任意一条边为存货端口、其他任意一条边为取货端口」→ 每格只走一条线，可以拐弯。
- 桥接器：「桥接器：大小1x1，四条边都为存货兼取货端口，四个物品格各只与一条边的存货端口和对边的取货端口相连」→ 共用一格的线只能直穿，就是 Manhattan 模型的交叉点；一条线连着直穿几个相邻的桥，就是连续几个交叉点。同一轴上两个反方向也能各走一条，这一点 Manhattan 模型没有。
- 自动接通：「通道：…不同单位的取货端口与存货端口相对紧贴、且至少一方是运输单位时，自动形成通道」→ 相邻就是连接，不想要的相邻要显式禁止（见小结「没找到」的第 2 条）。
- 机器端口：「小制造单位：大小3x3，一条边全为存货端口，对边全为取货端口」（中、大制造单位同类）→ 端子是「整条边上任选一格」，对应 group Steiner 树里的端子组，也对应数据流图排版里「端口在指定边、边内位置自由」那一级端口约束。
- 分流、汇流：「分流器：大小1x1，任意一条边为存货端口、其余三条边为取货端口」「汇流器：大小1x1，三条边为存货端口、一条边为取货端口」→ 线是有向树（汇流是多源一汇），不是无向的两点连线。

## 研究问题与检索词

RQ1 交叉怎么表示：网格上单层布线、交叉只能用 1×1 的「跳线/桥」，相邻桥可串成链。
- VLSI/PCB：single-layer routing with jumpers；planar routing crossover；via minimization；topological routing；switchbox routing integer programming
- 纳米电路（QCA/FCN）：wire crossing tile；field-coupled nanocomputing placement and routing；exact physical design SMT
- 微流控：flow channel crossing switch；planar microfluidic biochip routing
- 图绘制：orthogonal graph drawing crossings dummy vertex；topology-shape-metrics

RQ2 几十种物料、几百条线、每格一条：多商品布线的紧凑表示，避免逐格 x[cell,commodity] 爆炸，并且不出现无源的「自产自销」环流。
- VLSI：Steiner tree packing；global routing ILP；multicommodity flow routing column generation；negotiated congestion（PathFinder）；rip-up and reroute
- 组合优化：vertex-disjoint paths grid graph；integer multicommodity flow formulation；subtour/cycle elimination in flow formulation
- 谜题/SAT：Numberlink SAT encoding；Flow Free；no-touching path constraint

RQ3 摆放和布线一起解：带端口的方块放上格子阵列，再在空格里布线。
- CGRA/FPGA：CGRA mapping ILP SAT；joint placement and routing；spatial architecture compiler
- 微流控：co-layout synthesis continuous-flow biochip（Columba）；placement and routing flow-based biochip MILP
- 运筹：facility layout and flow path design；AGV unidirectional flow path；conveyor layout design；plant layout pipe routing MILP
- 图绘制：port constraints dataflow diagram layout；orthogonal layout with node sizes

RQ4 「端口一挨上就自动接通」：相邻关系即连接，要在模型里禁掉不想要的相邻。
- QCA/FCN：crosstalk adjacency；clocking scheme 2DDWave
- 谜题：Numberlink 不许自我相邻（no U-turn）
- VLSI：design rule spacing in routing；adjacency conflict graph

RQ5 规模：哪些方法在 70×70 级、几百网络、多商品的格子布线上真解到过，用了什么分解。
- global/detailed routing decomposition；hierarchical routing；lattice surgery routing（量子：网格上每步一批不相交路径）；MAPF on grid（conflict-based search）

## 证据行

### 一、纳米电路（QCA/FCN）物理设计：单层格子、导线也占格、交叉要专门的「交叉块」

- [W2798373485] Walter, Wille, Große, Sill Torres, Drechsler 2018，An Exact Method for Design Exploration of Quantum-dot Cellular Automata（DATE 2018，DOI 10.23919/DATE.2018.8342060）
  解的问题：把一张门级网表（DAG）一次性放上 x×y 的瓦片格子并布线，每块瓦片放一个门或一段导线；可选允许交叉；求最小格子面积。
  方法：SMT（Z3）。变量 g[c,o]（瓦片 c 放门 o）、g[c,w]（瓦片 c 放导线 w 的一段）；每格至多一个（C2）；门、导线段都要求「出边方向的相邻瓦片里有它在网表上的后继（门或同一条导线的下一段）」（C3、C4）；格子上的数据流方向由时钟分区（USE 方案）给定，只允许从 c 走到时钟号 +1 的邻格。面积由小到大逐个试，第一个可满足的就是最小。
  规模：最大例 4:1 MUX，35×35 个 QCA 单元（约 7×7 瓦片），5131 秒；几个门的例子 1–60 秒。
  对应本题：瓦片 ≈ 格；门 ≈ 机器（但本题机器占 3×3 以上）；导线段 ≈ 带子格；「交叉块」≈ 桥接器；「每段导线后面必须接同一条导线的下一段或目标门」≈ 带子的有向连续性。特别对应：论文明说只靠 C3、C4 会出现「不连任何门的导线环」，这正是我们 30×30 逐格模型里「中间物品在同一格自产自销」那类漏洞。他们的补法是传递闭包 p[c,c']（N² 个变量、N³ 条约束）禁止 p[c,c]。
  不对应的：每条导线 w 一组变量（变量数 = 格数 × 导线数），和我们逐格多商品模型同一个爆炸源；USE 时钟分区预先规定了每格能往哪走，本题带子方向自由；网表固定、门 1×1；没有汇流、分流的流量；没有「挨上就自动接通」。
  对本题有什么用：块3，作反面教材和现成补丁：①「无源环」漏洞在文献里有名有姓，补法有传递闭包（太贵，70×70 不可用）、见下面 Factorio 那篇的递增标号、见 FCN 后续的单向时钟方案（方向受限⇒天然无环）；②给了一条规模数据：逐格×逐线的精确 SMT 只到 7×7 瓦片级。用在 L 的小窗口重解可以，整厂不行。
  依据：全文第 III 节（C1–C8）、表 I。

- [W2910579672] Walter, Wille, Sill Torres, Große, Drechsler 2019，Scalable Design for Field-coupled Nanocomputing Circuits（ASP-DAC 2019，DOI 10.1145/3287624.3287705）
  解的问题：同上，但要几万个门的规模。
  方法：把 FCN 放置布线看成正交图绘制（OGD）：网表先拆成度 ≤3 的图，按拓扑序逐个放门，新门只许放在已放门的南或东；给每条边预先指定方向（东/南），要求「同一顶点的入边同向、出边异向」，冲突时把边拆开插一个辅助顶点（当导线）；交叉用交叉瓦片（第二层）。多项式时间。
  规模：约 4 万门，几秒；作者自己说面积离最优差好几倍。
  对应本题：辅助顶点 ≈ 拐弯或桥接器；「只往南、东放」≈ 把整厂的物料流定成单调方向，带子不会绕回、不会成环；交叉瓦片 ≈ 桥接器。
  不对应的：面积差几倍，本题要的是空矩形最大，等于要紧凑；门 1×1、度 ≤3；本题机器大、端口整边、汇流器三进一出。
  对本题有什么用：块3/块6，抬 L 用：「先定拓扑序和每条边的东/南方向，再按序放」是一种可以在 70×70 上秒出的构造法，可用来生成第一张粗布局，再交给小窗口工具压紧。对 U 无用。
  依据：全文第 III 节 A、B（算法 1）；规模见摘要。

- [W4415154489] Hien, Walter, Hofmann, Wille 2025，A Fully Planar Approach to Field-coupled Nanocomputing: Scalable Placement and Routing Without Wire Crossings（arXiv:2504.09012）
  解的问题：交叉块在物理上不可靠，要完全不用交叉块地放置布线。
  方法：先在网表层面把图改成平面（复制扇出等），再用正交布局放置布线。
  规模：读摘要，未读到具体数字。
  对应本题：交叉块 ≈ 桥接器；本题桥接器可靠但占格、相邻可串，所以问题方向正好相反：我们想知道「用几个桥」与面积的取舍。
  不对应的：他们通过改网表消掉交叉（复制逻辑门），本题不能随便复制机器（台数和流量算死）。
  对本题有什么用：块3 只给一条思路：「交叉数」可以作为网表层面（谁连谁、按什么顺序穿过）的决策先定下来，再做几何。用处有限。
  依据：摘要。

- [10.1109/nano61778.2024.10628808] Hofmann, Walter, Wille 2024，A* is Born: Efficient and Scalable Physical Design for Field-coupled Nanocomputing（IEEE NANO 2024）
  解的问题：同 FCN 放置布线，要又快又接近最小面积。
  方法：门按拓扑序逐个放；搜索树的节点是「部分布局」，一步 = 放一个门并用 A* 把它的入线从前驱拉过来；代价 = 剩余门数，平局按当前布局面积。2DDWave 时钟方案下信号只能向东、向南，于是空瓦片只有 7 种填法（4 种单线、2 种双线即交叉或并行、空），布线不需要逐线变量。相邻且网表上相连的门自动接通。
  规模：最大 150 门（含扇出），0.4 秒，面积比 OGD 法小约 70%；全部例子都在 1 秒内（高效模式）。
  对应本题：「部分布局 + 按拓扑序加一台机器 + 立即把它的进料线拉通」可以直接搬成本题的构造法：配方链是 DAG（矿→粉→块→零件/瓶→成品），按配方层逐台放机器、立即用 A* 连带子；「每格只有少数几种局部填法」≈ 本题每格是 空/带(4×3 方向)/桥/分流/汇流，可以把格的「局部类型」当变量，物料身份另算。「相邻且应相连就自动接通」与本题端口挨上就自动接通是同一条规则，但他们只利用它，不防它。
  不对应的：信号单向（东/南）是工艺决定的，本题没有；门 1×1、度小；不考虑流量（每条线只要接通），本题一条带满载只过 1 件/tick，要按流量拆线；自动接通在本题会造成不想要的连接，要显式禁止。
  对本题有什么用：块6/块3，抬 L：最像一个「第一张合格布局」的构造器原型。可以替掉「人摆」，作为小窗口工具的初始解来源。对 U 无用。
  依据：全文第 IV、V 节，表 I。

### 二、流式微流控芯片：器件 + 流道，在格子上一起放置布线，流道交叉要放开关

- [10.1109/aspdac.2017.7858377] Grimmer, Wang, Yao, Ho, Wille 2017，Close-to-Optimal Placement and Routing for Continuous-Flow Microfluidic Biochips（ASP-DAC 2017）
  解的问题：给定器件（矩形，带进出口）和流道（器件对之间的连接），在 w×h 格子上同时放置和布线，最小化交叉数、流道长、面积。
  方法：SAT/SMT（Boolector）。每格每器件一个布尔量、每格每流道一个布尔量；每格至多一个器件、至多两条流道（允许交叉时）、器件与流道不共格；流道格要恰好两个同流道邻格（端口旁一个）；交叉数 = 「有两条流道的格」的个数，作为可限的总数。两种剪枝：等比缩小器件和格子（f=5）求解再放大；把实验切成 4 份各自求最优再当成大器件拼。
  规模：精确法解到 13×13 格、60 个器件、48 条流道，0 交叉；原尺寸的例子精确法 4 小时内全部解不出，缩小+分块后能出。
  对应本题：「一格至多两条流道 = 交叉」≈ 桥接器格（两个方向各一条）；「流道格恰好两个同流道邻格」≈ 带子连续；缩小、分块 ≈ 小窗口工具和分层拼装。
  不对应的：流道是无向的，没有方向、没有汇流分流；一条流道只连两点；「两个同流道邻格」这一类度约束同样允许无源环（论文没处理，因为目标是最短）；每格×每流道的变量，和我们逐格多商品模型一样爆。
  对本题有什么用：块3 给规模数据：逐格×逐线的精确 SAT 到 13×13 级就到头了，和我们 30×30 解不出一致。块6 给两种明确会丢最优、但能出解的剪枝（等比缩小、分块再拼），可用在 L。
  依据：全文第 IV 节（式 1–10）、第 V 节、表 I。

- [10.1145/2897937.2897997] Tseng, Li, Ho, Schlichtmann 等 2016，Columba: Co-Layout Synthesis for Continuous-Flow Microfluidic Biochips（DAC 2016）；[10.1109/tcad.2017.2760628] Columba 2.0（TCAD 2018）
  解的问题：从网表出发，同时综合流层和控制层的版图，保证可制造（平面）。
  方法：把芯片结构限定在一个「保证平面」的架构模板里（器件挂在直的主干流道上），在模板内用 MILP 定位置；交叉用开关模块。
  规模：Columba S（DAC 2018）报告 200 多个功能单元 3 分钟内。
  对应本题：「先限定一个保证可布线的架构骨架，再在骨架内优化位置」≈ 本题可以先限定「机器成排、排间是带子通道」这样的骨架；开关模块 ≈ 桥接器/分流器。
  不对应的：流体两层（流、控制）的耦合本题没有；连续流，没有按步移动。
  对本题有什么用：块3/块6：一种「用架构模板换可解性」的现成先例，用在 L；会丢最优，不能用在 U。
  依据：网页检索摘要和 TUM 页面介绍（未读全文）。

### 三、工厂类游戏里的带子模型

- [W4387355460] Patterson, Espasa, Chang, Hoffmann 2023，Towards Automatic Design of Factorio Blueprints（arXiv:2310.01505，CP 工作坊）
  解的问题：给定蓝图区域、来料位置和速率，求组装机、机械臂、传送带的布局，最大化产率、最小化建筑数。
  方法：Essence Prime + Savile Row。传送带用两种表示合并：方向表示（每格 0..4）+ 递增表示 routes[y,x] ∈ 0..w+h：起点为 1，非起点的格必须大于所有流入它的格（取最长链），终点值最大。这样环天然被排除（环上无法处处递增），又允许几条线合流。每格只许一种物品（carrying[y,x] ∈ 0..num_items），不用三维 items×w×h 矩阵。单一模型解不动，拆成三段：配方/台数 → 装箱 → 布线，不可行就回上一段换解（类 Benders）。
  规模：5×8、8×8 的蓝图；作者自己说一体化模型对非平凡蓝图不可行。
  对应本题：「递增标号 ≤ w+h」直接对上我们的「自产自销」漏洞：给每个带子格一个整数势，沿带子严格递增，环就不可能存在，代价是每格一个小整数，而不是传递闭包；「每格一种物品」与本题传送带格同时只能有 1 件、一般只走一种料的用法相近（本题允许混料带，见规则「两种料混在一条带上」）；三段分解与我们「装箱+挨着运输格」放松模型思路一致。
  不对应的：Factorio 的机械臂取放、两条车道、无反压的 450/分钟连续速率，本题是按步移动、每格 1 件、汇流轮询；规模小两个数量级；w+h 上界是作者猜想（未证），在 70×70、几百台机器的密排下不一定成立。
  对本题有什么用：块3：给「中间物品自产自销」漏洞一个最便宜的补法——带子格整数势（MTZ 型），可以直接加进 CP-SAT 模型；也给了「每格一种物品」把商品维压成一个整数变量的做法。注意本题汇流后同一格可能混料，要另外处理。
  依据：全文第 4.2、4.3 节，第 5 节。

- [arXiv:2102.04871] Reid, Miralavy, Kelly, Banzhaf, Gondro 2021，The Factory Must Grow: Automation in Factorio（arXiv）
  解的问题：「物流传送带问题」：在 12×12 带障碍的格子上，用传送带和地下传送带把一个源连到一个汇。
  方法：0-1 变量 X[类型,位置,方向]；可行性靠在游戏里实测；比较模拟退火、遗传规划、进化强化学习。
  规模：12×12，单条路径。
  对应本题：地下传送带 ≈ 桥接器（跨越别的单位），但 Factorio 的地下带一次能跨几格，本题桥接器只占 1 格、相邻可串成链，所以「一串相邻桥」≈ 一段地下带。
  不对应的：单源单汇、不建模多线争格；没有给出可用的整数规划约束（只有变量和目标）；没有反压、汇流。
  对本题有什么用：基本没用；只证明「游戏带子布线」在学术上还停在 12×12 单路径这一级。
  依据：全文第 3、4 节。

### 四、VLSI 布线：Steiner 树打包、开关盒、全局布线、协商拥塞

- [10.1007/BF02614374] Grötschel, Martin, Weismantel 1997，The Steiner Tree Packing Problem in VLSI Design（Mathematical Programming 78）；配套 [W2082591111] 同作者 1996，Packing Steiner trees: a cutting plane algorithm and computational results（Math. Prog. 72，DOI 10.1007/BF02592086）
  解的问题：开关盒布线：矩形格子图，端子在外边界，每个网络要一棵 Steiner 树，网络之间边不相交；两种模型：knock-knee（两条线可在同一节点相遇，甚至在那里各自拐弯）和 Manhattan（两条线在同一节点相遇时都不许拐，只能直穿）。
  方法：每个网络每条边一个 0-1 变量 x^k_e；连通性用 Steiner 割不等式（每个把端子分开的割至少有一条边被用），不用流变量；容量不等式（每条边至多一个网络）；Manhattan 模型多一类「Manhattan 不等式」(3.2)：对每对相邻的两条同向边和网络集的每个二分，限制「在这个节点拐弯」与「别的网络从这里穿过」不同时发生，按需分离。分支切割，另有 Steiner 划分不等式、交错环不等式等。
  规模：文献中标准开关盒例子（约 15×23 格、20 多个网络），多数解到最优；并证出若干例子在 Manhattan 模型下不可行而在 knock-knee 下可行。
  对应本题：**Manhattan 模型正是本题的「桥接器」规则**：两条带子共用一格时只能各自直穿（桥接器四个物品格各连一条边进、对边出），不能在共用格里拐弯；knock-knee 则是本题不允许的。所以本题带子层 = 「Manhattan 型开关盒布线 + 共用格必须放桥（占单位、计入空矩形）+ 普通格只走一条」。Steiner 割不等式是消除「无源环」的标准办法：连通性用割约束而不用逐格流守恒，就不会出现与端点不连的环。
  不对应的：网络是无向 Steiner 树，本题带子有向、有汇流（多源到一汇 ≈ 有向 Steiner 树/树形图）、有分流；端子固定在外边界，本题端点是机器端口、位置是变量；变量仍是「网络×边」，几百条线 × 70×70 格太大；没有流量（满载一条带 1 件/tick）。
  对本题有什么用：块3，L 和 U 都能用：①给我们的带子层一个有名字、有多面体研究的对应模型（Manhattan 开关盒 Steiner 树打包），桥 = 「直穿交叉点」；②「割不等式代替逐格流守恒」直接补「自产自销」漏洞，且 LP 松弛比流模型紧；③「Manhattan 不可行而 knock-knee 可行」一类的不可行性证明可以借来压 U：只要在放松里允许 knock-knee（更宽），证出不可行就对本题也不可行。
  依据：1997 篇全文第 2–4 节（ZIB 预印本）；1996 篇据 Semantic Scholar 摘要。

- [10.1109/tcad.2010.2066030] Wu, Davoodi, Linderoth 2011，GRIP: Global Routing via Integer Programming（IEEE TCAD 30(1)）；会议版 [10.1145/1629911.1629999] DAC 2009
  解的问题：芯片全局布线：几十万条线在粗网格（每条边有容量）上选路，最小线长和通孔。
  方法：路径（列）变量的整数规划：每个网络从候选 Steiner 树里选一棵；LP 定价阶段按对偶价（拥塞）生成候选；整块 IP 切成平衡的矩形子区，长线用「浮动端子」穿过子区；拥塞子区里的长线可以用 IP 绕开。
  规模：ISPD 2007 全局布线基准（工业级），线长和通孔比当时最好结果好 3.9%、11.3%。
  对应本题：「每条线选一条候选路径」= 立题里提到的「基于路径变量的列生成布线」的工业级先例；子区分解 + 浮动端子 ≈ 70×70 切成块、块边界上的「过界点」当变量。
  不对应的：全局布线只到粗网格（每条边有容量 >1），不管格内细节；本题每格只能走一条带、交叉要放桥，是详细布线层次；路径是无向的；不建模汇流、分流和流量。
  对本题有什么用：块3：如果改用路径变量，GRIP 是现成的规模化做法（定价 = 带对偶价的最短路；分区 + 浮动端子）。可以做「粗网格全局布线」一层：把 70×70 切成如 5×5 的块，每块边上每格是容量，先定每条物料线穿过哪些块，再在块内做详细布线。用在 L；粗层的 LP 下界在容量写对时也可给 U 用（需要证明放松正确）。
  依据：网页检索得到的摘要和作者讲稿要点，未读全文。

- [10.1145/201310.201328] McMurchie, Ebeling 1995，PathFinder: A Negotiation-Based Performance-Driven Router for FPGAs（FPGA'95）
  解的问题：FPGA 布线：在有限的布线资源图上给所有网络找路，资源不能共用。
  方法：协商拥塞：先允许共用，每轮对所有网络重新做最短路，资源代价 = (基价 + 历史拥塞) × 当前拥塞罚，过度使用的资源越来越贵，直到无共用。
  规模：工业 FPGA（据常识；本行规模未从原文核）。
  对应本题：资源图节点 = 格（普通格容量 1；桥格两个轴向各容量 1）；协商拥塞 = 多条物料线先重叠、逐轮涨价分开。
  不对应的：FPGA 资源图是固定的，本题格子里放不放带、放什么是变量；没有汇流的轮询、流量；启发式，不给最优性证明。
  对本题有什么用：块6/块3，抬 L：在机器位置固定后给几百条线布线的最成熟启发式；比逐格 MIP 快几个数量级。小窗口工具里的布线步可以直接用它。对 U 无用。
  依据：通识 + Semantic Scholar 记录（摘要为空），未读全文。

- [W1979569488] Burstein, Pelavin 1983，Hierarchical Wire Routing（IEEE TCAD，DOI 10.1109/tcad.1983.1270040）
  解的问题：门阵列、开关盒、通道上的布线。
  方法：层次化：布线区递归二分成粗格，每一层只在很小的粗格（2×N）上精确求解，逐层细化；结果与网络顺序无关。
  规模：摘要说比迷宫布线快一个数量级，密度更高。
  对应本题：70×70 可以做 2×2 递归切分，每层只解小问题。
  不对应的：假设横竖分层、拐弯打通孔，与本题单层 + 桥不同；不管流量。
  对本题有什么用：块3：「递归二分的粗格」是逐格模型之外的另一种表示，用于 L 的构造。
  依据：摘要（引用链扩展得到）。

### 五、运筹学：设施布局与物流通道一起设计

- [W2900723210] Klausnitzer, Lasch 2019，Optimal facility layout and material handling network design（Computers & Operations Research，DOI 10.1016/j.cor.2018.11.002）

### 一（续）FCN：引用链扩展得到的

- [10.1109/tcad.2025.3549354] Hofmann, Walter, Wille 2025，Efficient and Scalable Post-Layout Optimization for Field-Coupled Nanotechnologies（IEEE TCAD 44(10)）；前身 [10.1145/3611315.3633247] Post-Layout Optimization for FCN（2023）、[10.1145/3649329.3663491] Wiring Reduction for FCN（DAC 2024 LBR）
  解的问题：拿一张启发式生成、合法但松散的布局，在保持合法的前提下压缩面积。
  方法：两步交替。①「门搬家」：拆掉一个门的全部连线，按离左上角的距离给出 m 个更好的位置，逐个试放并用 A* 重新布线，能连通就接受，否则放回原处并恢复原线；直到一轮没有门能动。②「减线」：先给门加障碍保护，再用 A* 找一条横穿（或竖穿）整张布局、只经过导线格的「割」，删掉割上的导线格，把两半推到一起重新接上，反复做。都依赖 2DDWave 的单向流（只向右、向下）。
  规模：门搬家对小例子面积平均减 45.58%（最多 73.75%）；减线能处理 2000 万瓦片以上，几百万瓦片 1 分钟内。
  对应本题：「门搬家 + A* 重布」= 我们「小窗口工具」的最简形态（窗口只含一台机器和它的连线）；「找一条只穿过带子格的整行/整列割，删掉后两半合拢」= 版图压缩，正好用来往外挤出空矩形——一行全是直穿的带子（或桥）时，删掉这一行不改连接关系。
  不对应的：单向流保证删行不出环、不改拓扑，本题带子方向任意，删一行要检查每条穿过的带子是否在这一行拐弯或接端口；本题还要保证删行后不新增「挨上就自动接通」的相邻；没有流量、汇流器轮询，压缩后要重新过内核。
  对本题有什么用：块3/块6，抬 L：给「先松后紧」的路线一个现成的、能到千万格规模的两步压缩法：先用宽松构造（OGD/A*）出一张合法布局，再用「搬机器 + 删整行带子」把空出来的面挤到一边，直接对应「最大空矩形」目标。对 U 无用。
  依据：2025 篇全文第 IV 节 B、C（算法 1、2）和实验节。

- [10.1145/3312661] Walter, Wille, Große, Sill Torres, Drechsler 2019，Placement and Routing for Tile-based Field-coupled Nanocomputing Circuits Is NP-complete（ACM JETC，研究短文）
  解的问题：瓦片式 FCN 放置布线的复杂度。
  方法：归约证明 NP 完全。
  对应本题：瓦片 + 单层 + 交叉块的放置布线，是本题带子层（不含流量）的一个特例或近亲。
  不对应的：没有给算法。
  对本题有什么用：只给理论定位：本题带子层不可能有多项式精确算法（除非 P=NP），所以「换表示」的目标应是更小的搜索空间和更紧的松弛，不是多项式算法。
  依据：摘要。

### 四（续）VLSI：引用链扩展得到的

- [W2056884147] Jørgensen, Meyling 2002，A branch-and-price algorithm for switch-box routing（Networks 40(1)，DOI 10.1002/net.10029）
  解的问题：同 Grötschel 等的开关盒布线（Steiner 树打包，knock-knee 模型）。
  方法：分支定价：变量是整棵 Steiner 树（列），定价子问题 = 在带对偶价的格子图上求一棵 Steiner 树；重点在分支策略、定价策略、LP 扰动、提前停止列生成的下界。
  规模：7 个经典开关盒例子求到最优，其中 3 个此前无人解到最优。
  对应本题：「每条物料线 = 一列（一整条路径/树）」的精确版；定价 = 有向图上带价的最短路/有向 Steiner 树（汇流 = 多源一汇的树形图）。
  不对应的：knock-knee 模型（允许共点拐弯），本题要 Manhattan 型（只许直穿 + 放桥）；无向、无流量；端子固定。
  对本题有什么用：块3：与 GRIP 一起，说明「路径列 + 定价」在开关盒尺度可以精确解、在全局布线尺度可以近似解。若本题改用路径列，定价子问题要加「直穿才可共格、共格要付一个桥的代价」，这仍是带状态的最短路（状态 = 进入方向），可解。U 方面：列生成的 LP 界是合法下界，可用于证不可行。
  依据：摘要（OpenAlex/IAOR）。

- [W4241297471] Nadel 2016，Routing under Constraints（FMCAD 2016，DOI 10.1109/FMCAD.2016.7886670）
  解的问题：带设计规则的详细布线：一般布线（不相交的树）+ 一个位向量公式表示的任意附加规则。
  方法：DRouter：在 SAT 求解器里嵌一个 A* 布线器——决策策略按 A* 走、冲突分析用图结构、按网络重启和交换网络次序。连通性不编码成子句，而由内嵌的布线器保证（与 MonoSAT 同一路子）。
  规模：Intel 设计中的大片区，带多达数百万条设计规则实例，两个工业布线器都没布通的它布通了。
  对应本题：「附加规则」≈ 本题「端口挨上就自动接通、不能有不想要的相邻」这类局部禁令——可以写成格子局部的子句，交给 SAT，而连通性交给内嵌的寻路；「每条线是一棵树」≈ 带子线（汇流后是树形）。
  不对应的：无向、无方向性端口；无流量；交叉靠多层，不是单层桥接器。
  对本题有什么用：块3：给「逐格变量 + 局部禁令子句 + 连通性外包给寻路」这种混合表示一个工业规模的成功例子；老项目看过 MonoSAT，这篇是同一思路在详细布线上的规模证据。用在 L（找可行布线），也可在可行性判定上给出不可行证明（SAT 完备）。
  依据：摘要和会议讲稿要点（网页检索），未读全文。

### 六、图绘制：正交画法、端口约束、拓扑-形状-尺寸三段法

- [W2002025203] Tamassia 1987，On Embedding a Graph in the Grid with the Minimum Number of Bends（SIAM J. Computing，DOI 10.1137/0216030）
  解的问题：给定平面图和它的平面表示（各面的边序），求保持这一表示的网格嵌入，使拐点最少。
  方法：拐点 = 相邻面之间流过的流量，整个问题化成最小费用流，O(n² log n)。这是「拓扑-形状-尺寸」三段法的中间一段：先定拓扑（交叉处插虚顶点使图平面），再用流定形状（每条边在哪拐），最后压缩定尺寸。
  对应本题：交叉虚顶点 ≈ 桥接器；「先定谁和谁交叉、各线从机器哪一侧绕过（拓扑），再定拐弯（形状），最后定长度（尺寸，压缩出空矩形）」是逐格模型之外的一种分层表示，每层都是多项式或小 MIP。
  不对应的：顶点是点，本题机器是 3×3–6×4 的大块、端口在指定整边；三段法每段是对上一段固定后的最优，合起来不是全局最优；不管流量和自动接通。
  对本题有什么用：块3：提供「拓扑先行」的表示：决策变量是组合拓扑（交叉对、绕行侧），几何交给流和压缩。可用于 L 的构造与压缩；对 U 无直接用处。
  依据：摘要。

- [W1812000079] Spönemann, Fuhrmann, von Hanxleden, Mutzel 2010，Port Constraints in Hierarchical Layout of Data Flow Diagrams（GD 2009，LNCS，DOI 10.1007/978-3-642-11805-0_14）；同类 [W2949691584] Rüegg, Kieffer, Dwyer, Marriott, Wybrow 2014，Stress-Minimizing Orthogonal Layout of Data Flow Diagrams with Ports（arXiv:1408.4626）
  解的问题：数据流图（算子是带端口的方块，边从源端口到目标端口，正交走线）的自动排版；端口约束分五级，从「端口可沿边自由滑」到「端口位置固定」。
  方法：分层（Sugiyama）布局扩展到端口、超边、复合节点；或基于应力最小化加端口和对齐约束。
  对应本题：算子 = 机器，端口约束「整条边全为存货端口 / 对边全为取货端口」= 本题机器的端口规则（属于「端口在指定边、边内位置自由」一级）；数据流图的分层 = 配方链的层级。
  不对应的：目标是可读性（交叉少、弯少、紧凑），不是严格每格一条；交叉在画图里是免费的，本题要放桥；没有面积硬约束。
  对本题有什么用：块3/块6：分层布局 + 端口约束是一个现成的「按配方层排机器、层间正交布线」生成器（KIELER/ELK 开源），可用来出第一张粗布局（L）。用处中等。
  依据：两篇摘要；GD09 篇另据网页检索对端口约束分级的描述。

- [W2636797719] Jünger, Mutzel, Spisla 2018，Orthogonal Compaction using Additional Bends（VISIGRAPP/IVAPP 2018，DOI 10.5220/0006713301440155；arXiv:1706.06514）
  解的问题：正交画法的一维压缩，允许改变边的形状（多加拐点）以换取更小面积、更短边长。
  方法：基于流的压缩，拐点可加。
  对应本题：压缩 = 把布局往一边挤以留出空矩形；「允许加拐点换面积」≈ 带子多绕一下换空矩形更大。
  不对应的：画图里边无宽度约束以外的规则；无桥、无自动接通。
  对本题有什么用：块3/块6：L 的后处理（与 FCN 的「删整行带子」压缩同一类）。
  依据：摘要。

- [10.1145/127601.127622] Dai, Dayan, Staepelaere 1991，Topological Routing in SURF（DAC 1991）；同类 [10.1109/iccad.1990.129838] Rubber band routing and dynamic data representation（ICCAD 1990）
  解的问题：先求每条线的拓扑（相对障碍和别的线从哪边走，「橡皮筋」），再生成几何。
  方法：拓扑布线 + 橡皮筋表示，几何最后定。
  对应本题：同 Tamassia 一段：线的拓扑类（同伦类）作为决策变量，比逐格变量少得多。
  不对应的：多层、任意角度；没有单层桥。
  对本题有什么用：块3：表示思路的出处，用处有限。
  依据：标题和题录（Crossref），未读摘要。

### 七、CGRA/空间架构映射：把数据流图放上处理单元阵列并布线

- [W2913300152] Walker, Anderson 2019，Generic Connectivity-Based CGRA Mapping via Integer Linear Programming（FCCM 2019，DOI 10.1109/fccm.2019.00019）
  解的问题：把数据流图（算子 + 值）映射到 CGRA（处理单元阵列 + 布线网络），完全通用的 MRRG（模调度布线资源图）ILP 太慢。
  方法：不显式建模每个布线资源，只要求「算子放在某 PE 上 ⇒ 它的输入算子放在邻近的 PE 上」（邻近关系从器件模型推出），再在需要的地方加拥塞约束，迭代求解，保留大部分精确性。
  规模：对没有超时的基准平均加速 5.88 倍（通用 ILP 时限 7.5 小时）。
  对应本题：算子 = 机器、值 = 物料线；「先只约束距离/邻近，布线细节以后再说」≈ 把带子层先抽象成「生产者端口与消费者端口距离 ≤ k + 区域容量」的放松，放进摆放模型；只在冲突处加细节（类懒约束/CEGAR）。
  不对应的：PE 是固定阵列，位置离散有限；本题机器位置自由、尺寸不同；CGRA 布线资源是固定的，本题格子既可放带子也可放机器。
  对本题有什么用：块3：给「摆放模型里不放逐格带子，只放连接的距离和区域容量，冲突再加细」这一表示一个实测先例。用在 L（快出候选）；若距离和容量写成必要条件，也可进 U 的放松模型。
  依据：全文第 II、III 节开头和摘要。

- [10.1145/2491956.2462163] Nowatzki, Sartin-Tarm, De Carli, Sankaralingam, Estan, Robatmili 2013，A General Constraint-Centric Scheduling Framework for Spatial Architectures（PLDI 2013）
  解的问题：空间架构上的放置、布线、定时一体调度。
  方法：ILP，通用的约束式表述，跨几种空间架构。
  对应本题：放置 + 布线 + 定时一体 ≈ 本题摆放 + 带子 + 按步移动。
  不对应的：硬件资源图固定；规模和本题不同量级（未读到）。
  对本题有什么用：块3：作为 CGRA 方向的综述式入口，用处小。
  依据：摘要。

### 八、多智能体路径规划（MAPF）与不相交路径

- [W2963309123] Yu, LaValle 2013，Multi-agent Path Planning and Network Flow（WAFR 2012，Springer Tracts in Advanced Robotics，DOI 10.1007/978-3-642-36279-8_10）；期刊版 [10.1109/tro.2016.2593448] Optimal Multirobot Path Planning on Graphs: Complete Algorithms and Effective Heuristics（IEEE T-RO 2016）
  解的问题：图上多机器人路径规划，化成时间展开网络上的整数多商品流。
  方法：时间展开图 + 网络流/整数规划。
  对应本题：「同一格同一时刻只容一件」≈ 传送带每格 1 件；时间展开流 ≈ 按 tick 展开的物品流（块一），而不是布线本身。Factorio 那篇把它当作带子布线的近亲引用。

### 九、谜题：Numberlink / Flow Free

- [W2949390928] Adcock, Demaine, Demaine, O'Brien, Reidl, Sánchez Villaamil, Sullivan 2014，Zig-Zag Numberlink is NP-Complete（arXiv:1410.5845）
  解的问题：m×n 格子上 t 对端点能否用 t 条点不相交路径连起来并铺满所有格（Flow Free 规则）。
  方法：NP 完全性归约；文中回顾 Lynch 1975（不要求铺满时已 NP 难）与 Kotsuma–Takenaga 2010（限拐点最少时）。
  对应本题：「格上多对端点、点不相交路径」= 本题带子层去掉方向、桥、汇流后的骨架。
  不对应的：无交叉（本题可放桥）；铺满要求本题没有（本题反而要留大空矩形）。
  对本题有什么用：只给复杂度定位：带子层即使去掉交叉和流量，也已是 NP 难（Lynch 1975）。Numberlink 的 SAT 编码（Tamura 等 2014，IPSJ，无 DOI，未计入）和其「防环」做法与 Factorio 那篇的递增标号同类。
  依据：摘要。
