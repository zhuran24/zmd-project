# ERRATA — v1 → v2 逐条修正（2026-08-05）

这个包的第一版被一个独立验伤席审过，`verdict = BLOCK`，判决书全文在
`REFUTE_VERDICT_FULL.md`（5 个攻击面全部 FINDING）。本页把每条 FINDING 的处理写清楚，
编号与判决书一致。

**如果你只想知道「v1 到底哪里错了」，看下面这三条就够：**

1. **我们把供电语义搞错了，据此错杀了一整族孔位。** 权威谓词是「相交即覆盖」，
   不是「盖满机身面积」，所以 `杆 ≥ ⌈3325/144⌉ = 24` 这个下界**根本不存在**。
   → **h=4 落孔族重新开放**（F1-1）。
2. **我们把「一本账没算死你」写成了「已证明有解」。** k=1 那 96 组只是列子模型的
   算术存活，一格坐标都没落。→ 新等级**【列账存活】**（F2-1）。
3. **我们标了一堆【已证明】却没有对应脚本**，违反包自己 §0.1 的定义。
   → v2 补了两个脚本把 7 条补回来，**其中一条补出来是错的**（走廊极性，见 F2-2）。
