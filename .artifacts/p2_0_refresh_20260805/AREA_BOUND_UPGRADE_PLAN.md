## 结论形态（升格后长什么样）

**定理（目标）**：在钉死 production_targets + 严格空地语义 + P2.0 吞吐守恒下，
任何可行布局的空矩形面积 A ≤ B(P)，其中 B 是电杆数 P 的仿射函数
（当前粗算 B = 1,051 − 4P 单层 / 1,203 − 4P 双层松口径）。
配合电杆覆盖下界 P ≥ P_min ⇒ A 的无条件上界。

**与在案 U=(1188,18) 的关系（防误引）**：当前 conditional U 是**六谓词语义**
（吞吐 OUT-OF-SCOPE）的上界；本定理是 **P2.0 第七谓词语义**的上界。两者语义
不同、并存不互斥；P2.0 落地采纳后者才成为现役 U。文书引用必须带语义标签。
