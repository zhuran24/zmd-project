## 3. 定理与证明链

### 定理 1（P2.0 容量计数面积上界）

任何在 P2.0 语义下可行的布局满足 **A ≤ 1356 − 4P − R**，且 R ≥ ⌈L/2⌉、L ≥ 305、P ≥ 9，
故 **A ≤ 1167**；若单层口径成立（待 OB6）则 R ≥ L ⇒ A ≤ 1015。

证明链（逐步等级）：

- **[A] 格位分账**【严格】：70×70=4,900 格划分为 mandatory 机身(3,544)、电杆(4P)、
  非强制机身(N≥0)、路由足迹(R)、空矩形(A)、空闲(S≥0)，六类两两不交
  （谓词 2 不重叠；前提 5 机身两层实心 ⇒ 无 route state 压机身；前提 8 严格空地 ⇒
  空矩形与其余五类全不交）。⇒ A ≤ 1,356 − 4P − R − N − S ≤ 1,356 − 4P − R。
- **[B] 流量唯一**【严格】：17 个操作的机器当量由 17 条平衡方程唯一确定
  （OB1 高斯消元非奇异；前提 7/9/10 排除仓库桥与损耗旁路）。任何达标稳态的
  逐商品流向量 = 唯一解（超产只会更大）⇒ 进路由图流量 ≥ F_route = 9,135 件/分钟。
- **[C1] 容量计数**【严格】：每件过 ≥1 个 route state（前提 6 + OB3）、每 state ≤ 30 件/分钟
  （前提 2）⇒ state 数 L ≥ ⌈9135/30⌉ = 305。
- **[D] 足迹**【严格（无条件口径）】：每格 ≤2 state（前提 4；且前提 13 坐实 2 state/格
  是真实机制而非建模伪影）⇒ R ≥ ⌈L/2⌉。**单层口径 R ≥ L 是【条件·待 OB6】**。
- **[E] 电杆**【精确】：P ≥ 9（定理 3，下）。

### 定理 2（front-state 下界，本批新增）

**L ≥ Σ_c max(#out_c, #in_c) = 308**，其中 **#side_c = Σ_op ⌈x_op · q⌉** 是商品 c 在该侧的
**端口最小数**（x_op = 机器当量、q = 该配方每 tick 件数；口容量 1 件/tick 硬帽 ⇒
该 op 该商品的总流 x·q 件/tick 至少要 ⌈x·q⌉ 个物理口）。外部源商品按需求当量
18+34 计供给侧（供给口总数恰 52）。

**核心引理**：一个 route state 至多同时充当 **1 个产口 front 与 1 个耗口 front**。
推导（全部前提已定谳）：
1. 口的 front 格 = 机身外法向第一格（07-18 定谳的 identity front-cell 模型）；
   该格沿法向轴的通道，一端是机身 ⇒ **通道在口侧死端**。
2. belt 方向性（前提 11）⇒ 一条通道不能同时被两个产口从两端推入、也不能同时向
   两个耗口从两端流出 ⇒ 每通道 ≤1 产口 + ≤1 耗口。
3. 门口排他（前提 12）⇒ 共享必须同商品；交叉格的两条垂直通道是两个不同 state，各自计数。
4. 逐商品：产口 front 需要 ≥#out_c 个互异 state、耗口需要 ≥#in_c 个，二者只在
   「产耗共享中格」时重合 ⇒ state ≥ max(#out_c, #in_c)。

**鲁棒性**（三个对抗自由度全部免疫）：
- 多开口摊薄速率：每多开一口至少多一个 front state、至多多配一对，净不利于压低 L；
- 同 op 机器间占空集中（floor(x) 台满速 + 1 台残速）与 slot 间不均分：
  ⌈x·q⌉ 正是这两个自由度下的端口数最小值（且可达），引理不依赖任何速率相等条件。

代入：L ≥ max(305, 308) = 308 ⇒ 无条件 **A ≤ 1356 − 36 − ⌈308/2⌉ = 1166**；
单层口径 A ≤ 1012。

### 定理 3（电杆下界 P ≥ 9）

指派论证：每个受电设施（132×3×3 + 49×5×5 + 38×6×4，机身 3,325 格）指派给一根覆盖它的
电杆（前提 14）⇒ 单杆名下设施两两不交、包围盒均与其 12×12 覆盖窗相交、均不压 2×2 杆身
⇒ 单杆覆盖机身 ≤ K。K 由 CP-SAT 装填最优化精确求得 **K = 396**（OPTIMAL，840 候选位姿，
见证独立逐格复验：互斥/不压杆身/逐台交窗/面积=396；最优装填 = 12×5×5 + 4×6×4）。
⇒ P ≥ ⌈3325/396⌉ = **9**。对照：MEMO 576 松窗口径 P≥6、22×22 膨胀计数 P≥7。
保守性：位姿允许悬空棋盘外、覆盖窗不裁剪、不计杆间互斥——全部只会高估 K，方向安全。

## 4. 紧性与对抗分析（为什么到此为止、强化必须从哪来）

**对抗例 1（全链贴放）**：产耗口两两正对共享中格（贴脸死、隔 1 格通 ⇒ 1 格带合法），
1:1 与 2:1（双 slot）扇形都可局部实现 ⇒ 逐件路径长度 1 局部可达，[C1] 的
「每件 ≥1 state」在对抗意义下逐件紧。定理 2 的 308 仍假设全部 306 对可行的
「共享中格」配对同时几何成立——量化其不可能性即 G1。

**对抗例 2（网格城）**：全部干线直线化、垂直交叉自由堆叠 ⇒ 每格 2 state 大面积可达
（前提 13 坐实交叉双满速真实）。slot 结构又几乎无强制合流（扇形是 1:1 或
2:1-双slot，不需要 merger）⇒ 纯计数不可能无条件排除 R = ⌈L/2⌉。
**结论：任何超越 1163 的无条件强化，必须使用口几何/普查结构/棋盘边界信息**，
即 §5 的 G1/G3/G6 三条线，纯流量计数已榨干。

## 5. Gap 结构台账（OB5 核心产出）

记号：ΔA = 对无条件上界 1166 的预期压降。

### G1 配对几何可行性（最富矿）
定理 2 假设 Σ_c min(out,in) = 306 对「产耗正对共享中格」全部同时几何可行。
每证伪一对，L +1、ΔA −0.5~−1。
攻法 = 逐商品 case analysis：产侧口挤在一条 3 格边（3×3 crusher 输出侧）或 6 格长边
（6×4，`port_rule long_sides`）上，耗侧机身能同时贴上来的台数受棋盘几何硬限制
（两个 6 格长边贴一条 3 格缝至多 2 台……）。**陷阱预警**（本批踩过又爬出来的两个）：
(i) 耗方可以多开口摊薄速率来吃下同一产侧的多条流（定理 2 已免疫，但 facing 计数
论证不免疫——写 case lemma 时必须按「口数 ≤ 边长」而不是「口数 = slot 数」推）；
(ii) 同 op 机器间占空可不均分（10 台满 + 1 台半速），任何依赖「rate 类互斥」的
配对排除都会被它绕过（§5.4）。预期收益：slp/种子/作物族的 case lemmas 合计
ΔA ≈ −30~−150【推断】。

### G2 路径长度 ℓ̄（与 G6 合流）
未配对流的产 front 与耗 front 都已计入 L，额外收益只来自路径 ≥3 state 的论证
（绕行/拥塞/切割）。敏感度：ℓ̄ 每 +1 ⇒ 单层 A −305、无条件 A −152。band22 实测
平均最近生产者距离 22.25 格，真实布局远离紧例，但布局无关下界难度 = L 侧枚举墙同级。

### G3 交叉密度（= OB6，见 §6）
奖池：无条件 1166 → 单层 1012（ΔA −154）。

### G4 终品口径
扣无线终品是保守选择，代价已量化 = 单层 1 格（305→306），无条件 0~1 格。
若 P2.0 谓词最终把终品交付计入路由，白拿回 1 格。

### G5 电杆-路由互动
电杆机身算 body、会堵口 front（07-18 定谳）；杆必须站在机群里（覆盖窗要交机身）⇒
杆周边 gap 格与 G1 的 facing 预算冲突。预期 ΔA 小（个位数），排最后。

### G6 割集/Farkas 证书化（v2 B 档格式的落点）
本文定理链本身就是行族的非负组合：行族 = {17 条守恒行（[B]）、620 条 front 行（定理 2）、
每 state 容量行 ≤30（[C1]）、每格 ≤2 state 行（[D]）、格位分账行（[A]）、
覆盖指派行（定理 3）}。写成 static-flow-with-lift + row-family manifest 即得
机器可验证书——这一步没有数学缺口，是工程化（预期一个批次）。真正的研究缺口在
把 G1/G3 的几何论证也压进行族（割集行）。

### 5.4 已证无效的路线（防重踩，负结果归档）
两条都死于同一对自由度——**机器级占空可集中（floor(x) 台满速 + 1 台残速）+ slot 可不均分**：
1. 「slot 均分 + 同 op 机器同占空」下的 rate 类互斥配对排除（曾推出 Pmax ≤ 255、
   A ≤ ~1100）不成立：两个自由度合谋能把绝大多数 rate 类还原成可配对。
2. 本报告 v1 的定理 2 曾用「slot 数 × 机器数」当端口下界得 L ≥ 313——被同一反例攻破
   （亚满 op 端口最小数只有 ⌈x·q⌉，多算 5 个 state），v2 修正为 308。
任何后续强化若依赖 per-slot/per-machine 速率刚性，先检查这两个自由度。
（研究轮次前提纪律的现场案例：反例自攻在交付前抓住了自己的超算。）

## 6. OB6：双层口径修正（形式化 + 现状）

**已定谳事实**（前提 13）：同格双通道 = 单格垂直交叉件（无坡道），垂直双流各自满速
真实存在；平行双流物理不可能。⇒ 每格容量 2 件/tick 只在交叉格兑现，
方向性干线每格仍 1 件/tick。

**形式化**：令 X = 交叉格数（2 state 的格），则 R = L − X ≥ 308 − X，
A ≤ 1356 − 4P − L + X。单层口径 ⟺ X = 0；无条件口径 ⟺ X ≤ ⌊L/2⌋。
**OB6 的任务 = 布局无关地上界 X**。现状：开放。对抗例 2（网格城）表明纯计数不行；
可用杠杆：(i) 交叉格不能是弯道/分合流器/桥转弯（canonical `bridge_mechanics` 四禁令）；
(ii) 交叉的两条通道都要有来源与去处——都锚定在口 front 或棋盘边界，46 个边界口全在
左/下边界（`placement_rule left_or_bottom_boundary`）给了方向结构；(iii) G1 的 facing
论证每钉死一处「必须转弯/必须侧枝」就同时产出一个非交叉格。
**当前正确姿势：引用无条件口径 1163；单层 1007 必须带【条件·待 OB6】标签。**

## 7. 与在案六谓词 U 的关系（OB7 纪律）

U=(1188,18) conditional 是六谓词语义（吞吐 OUT-OF-SCOPE）的上界，本文不触碰它。
可以说的是：**P2.0 语义下** 1166 < 1188，即第七谓词一旦落地，当前六谓词最优候选带
将整体不可行于新语义——第七谓词会改变最优解本身，不只是补证书（印证 MEMO §3.3 的
行动含义，且现在有严格链而非粗算支撑这句话）。min_side 维度本文未触碰（1166 对应的
可行形状约束未推导，留给 P2.0 求解侧）。
