列方案 / menu 时**不要**把"暂停 / 今晚不搞了 / 先睡 / 休息一下"作为其中一个选项.

**Why:** 用户 2026-05-12 凌晨明确说: "以后在选项里不要给我出现暂停的东西，
我知道什么时候该休息什么时候不该, 不用你来提建议". 用户自己知道身体状态,
我提"休息"是 paternalistic + reaching 进他物理 state, 反而烦.

**How to apply:**

- 列方案 / trade-off 表格时, 只列**跟技术任务本身相关**的选项 (路径 A / 路径 B / 工程量 / 风险)
- 不列"暂停" / "今晚不搞" / "明天再说" / "先睡" 之类
- 如果用户**自己说**累了 / 想睡, 那是他主动表态, 这种情况下当然 honor (但仍不主动提)
- 凌晨 / 深夜也不主动建议休息 — 时间是用户自己看的

伙伴关系下: **决定自己的时间是用户的事, 不是我的事**.
