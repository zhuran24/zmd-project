# 求解面方法论（速览与路由）

> **本页身份**：项目级 skill 的 tracked 真本；安装副本在 `.claude/skills/solving-methodology/SKILL.md`（`.claude/` 被 gitignore，副本被清则从本页重装，两处内容保持逐字相同）。**本页零权威**——判据本体＝`docs/项目说明/00_master_roadmap.md` §0b（主席文件，持续演进），起争议回正文仲裁；全集快照＝`docs/research/methodology_compilation_20260814/APX_E_pipeline_methodology.snapshot.md`。

## 三条公理

1. **双向保真**：防拒真（合法的都放进模型）与防纳伪（堵孔）同等重要。最优性证书下**过严＝假证书**，且过严限制只产生缺失答案、**永不自曝报警**——「保守一点」在求解面不是美德。
2. **派生闭包**：规则系统是生成式的，派生规则该被系统推出（饱和扫描、塌点上报），不该等人绊倒。
3. **推理关**：解空间类问题上桌前先推理——推得动就地出结论**带前提集**；推不动才升级，且点名缺的最小前提，不许裸递。

## 七问操作卡（按决策时刻排；判据本体见 §0b :95-118）

| 问 | 一句话 |
|---|---|
| ⓪ 锚点 | 这个结构性预设卡在哪笔**零余量账**上？来源四分类（算术被迫/对称WLOG/求解器方便/配方类比），后两类当场标价：写明扔掉的解空间与撤退线 |
| ① 切分 | 每条规则切三档：健全影子/精确本体/启发式残部——能上收的**只是影子** |
| ② 住址 | 这片规则的变量管辖范围整个装得进哪层，就住哪层；「切开省计算」只对跨子问题的规则成立 |
| ③ 排序 | 门按**实测**拒绝成本便宜→贵排；知识坐在它能剪掉的昂贵步骤之前；成本拿不准先花小钱实测 |
| ④ 耦合 | 切成过滤器之前，先小钱实测「无此规则的最优解在过滤下的存活率」；最优邻域塌缩＝与目标对抗＝必须内聚 |
| ⑤ 计量 | 过滤器拒绝率是一等报警指标；fail-soft 降级（剥落/取子集）仍计入拒绝率，**不许把拒绝转译成接受** |
| ⑥ 余量 | 余量 ~2% 量级时一切未建模约束都会咬；影子加肥后其两个方向的读数才可信 |

## 承重不变式（违反即伤命题）

- 早期拒绝带证书、早期放行皆暂定、**终审归精确本体**。
- **双 ledger**：witness 只抬下界账、松弛证书只压上界账；同 instance hash＋同假设下两账相遇才准报 optimal；**资源中止不改任何账**。
- **三极性不可混极**：必要投影（上界证明用）/充分限制（构造器用）/精确语义（终审 checker 用）——可空，不可混。
- **cut 必须带前件**（前件配置⇒必要修复析取）；cut＝知识的运输形态，打包先过三问：责任圈能收多小／死因有无可抬的数量律／上层词汇说不说得出。
- **归属是 master 表示法的函数**：换表示后全部归属结论重跑，不得继承。
- 权威归属公式 `owner(r)=max{owner(v):v∈scope(r)}`；**权威归属与表示归属是两个问题，不得混问**。
