## 2.1 限制逐条六选一

判定只取：

1. `限制成立`：危险可达；保留；保守支必须填代价。
2. `限制多余`：危险不可达，保证方是物理或冻结数据；进入删除候选，仍须三签。
3. `守卫必留`：危险不可达，保证方就是本限制。
4. `非 soundness 保留`：危险出域；写真实理由与摘除条件。
5. `待核`：有 MISSING 或开放待判项。
6. `联合守卫`：保证方是本限制与其他限制的合取；不得直接进入删除候选。

保证方只取：`物理 / 冻结数据（给路径） / 本限制自己 / 另一条限制（给 id） / 未知`。

| 限制/guard id | 危险条件 | 参数账指针 | 六选一判定 | 保证方 | 代价或“非保守支” | 联合防线成员 | 摘除条件 | refute 复核 |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |
