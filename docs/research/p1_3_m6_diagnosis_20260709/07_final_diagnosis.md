# M6 诊断课题终报：master 首解为何这么难（2026-07-09）

> 课题来源：M5 收敛实测（`../p1_3_m5_convergence_20260708/m5_phase1_verdict.md`）BLOCKED_ON_COMPUTE 后 owner 立项诊断。
> 方法：四路 Fable 只读侦察（01-04 号文件）→ 八个隔离判决实验（05 号文件 + 本文）。

## 一句话诊断

**首解之墙 = 供电覆盖约束及其 witness 式编码，单一主墙、证据无混杂**：供电一关，任何形态（钉死/自由、有洞/无洞、单锚/4225 锚）都在秒到分钟级可解；供电一开，任何形态的搜索都以「百万分支 + ~0.1% 冲突率」的无引导形态溺死。曾被怀疑的打包规模、ghost 析取、anchor 多重性、种子、求解器参数全部无辜。

## 证据链（八实验）

| 2 | M6 | 钉死(greedy×3) | 钉锚 | 开 | UNKNOWN@300s 单核（钉死后仍在 763 杆槽空间狂奔 7.2M 分支） |

辅证（考古路）：witness 编码的 prod-scale master 有史以来零 FEASIBLE（含原机 24h campaign 检查点实证）；B1 旧 pose-bool 编码（供电为线性 x≤Σcoverers）同类题 53s OPTIMAL（~34×）；「历史解出过 6×6」经解码考证为缩减问题（72 机+599 杆，旧工件时代），不构成反例。

## 机制

master 必须在打包 266 设施的同时为每个受电设施留出电杆覆盖位。witness 式供电编码（几何 element 约束 + 763 个自由杆槽 ×~14 变量）给传播器的反推力≈0——搜索每一步都「看起来还行」，直到深处才发现覆盖格局早已挤死，冲突学习学不到可泛化的短子句 → 百万分支冲突率 0.1% 的溺水形态。反向印证：一旦布局钉死且火力足够，供电子模型可在 1-6 分钟内给出 INFEASIBLE 证明——约束本身可判定，是「与打包耦合的搜索」无引导。

## 重要副产物

1. **盲打包解全部供电不可行**（greedy×3 + CP-SAT 最优×1 全灭）→「先打包后补电」的天真两阶段路线死刑；任何构造启发式必须 power-aware。
2. **供电可行布局的存在性 OPEN**——两天所有实验从未产出一份供电可行完整布局，也无不可行证明。(0,0) 锚已证不可行（疑边线端口容量主导，F1/F6 类 cut 可提前剪——cut framework 价值论证+1）。
3. **冗余双 no_overlap_2d**（消融路出土）：core-only 版被 ghost overlay 组合版语义包含，最重传播器 ×2 纯浪费——低风险生产修复项。
4. 钉死验证管线已打通（presolve-off + 火力 profile）：任何候选布局可在分钟级获得 FEASIBLE/INFEASIBLE 判决——后续构造启发式的验收机制现成。

## 修复方向（呈 owner 拍板排期，均属生产工作）

- **A（主修复，reseal 量级）：供电编码手术**——witness 形态 → 线性 x≤Σcoverers 形态（B1 34× 证据 + 本诊断隔离证据双背书）或其他强传播编码。同时服务「找到首解」与「证明不存在」两个方向。
- **B（研究先行，不碰 sealed）：power-aware 构造启发式**——greedy 打包联动杆预置，产物走已打通的钉死验证管线；若命中一份供电可行布局 = 存在性解决 + 首解到手 + M5 战场开。
- **C（顺手修）**：冗余 no_overlap_2d 去重；(0,0) 类角落锚的边线容量预筛（呼应 F6）。
- M5 收敛 A/B 挂 A 或 B 任一落地之后。
