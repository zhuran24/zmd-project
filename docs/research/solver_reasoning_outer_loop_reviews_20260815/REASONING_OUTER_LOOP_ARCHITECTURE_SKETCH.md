## 1. 为什么现在没有施工总图

推理外环是把昂贵下游搜索反复暴露的失败或被迫结构，转成短小、可验证、可复用的语义判断，再把经过验证的判断送回上游减少残余搜索的循环。整条路线压在一个尚未被全局证明的赌注上：**死因可压缩**。这里的“可压缩”是指，大量具体的端口绑定选择（binding）、物流路径选择（routing）或布局失败能够由少量参数化定理解释，而不是只能保存为逐案例 nogood（只排除一个已知冲突组合的禁闭子句）、完整变量赋值（assignment）或对象字节摘要（hash）。

这项赌注采用阶梯门控。四层验证阶梯的完整定义在[第四轮盲态评审 §一](round4_blind_observability_experiment_sequence_and_binding_routing_wall_review.md#一推理外环有用在观测上应当长什么样)：

1. **存在性。** 困难区域中确有比底层搜索轨迹短得多、可独立复算的语义证书。
2. **真实系统消费一次。** 一条已证判断经过正确的 lowering（降译，即把抽象定理转成具体求解约束）进入真实路径，并在昂贵搜索之前确定性地减少工作。
3. **家族普遍性。** 同一条冻结的参数化定理、独立检查器（checker）、lowering 与触发条件，在未参与推导的非同构留出集（holdout）案例上自然复用，而不是成为动机案例的别名。
4. **全局面貌。** 理论不只排除散点，而是收紧字典序（lex）前沿——即先按面积、再按最短边比较后仍可能胜过当前见证的候选区域——或改变上下界、有效维数和主导计算方式。

每过一层，才有依据购买下一层的软件、验证和维护投资。第一层阳性只购买一次真实闭环 canary（最小真实闭环试验）；一次闭环阳性只购买冻结式家族实验；家族阳性才支持向全局理论库投资。当前缺少施工总图不是遗漏，而是尚未取得把全部器官一次建满的证据。本页把这套隐含蓝图明文化，使器官能够随阶梯推进逐层点亮；它不是排期表。

### 2.2 完整信息流

推理外环不再从“观察失败”直接起步。完整信息流是：

```text
canonical endpoint frontier
-> current claim / decision / lineage reconciliation
-> 选择最高价值的 canonical UNKNOWN
-> 观察
-> 猜想
-> 证明
-> 验证
-> 编译 / 构造
-> 测量并更新 canonical frontier
```

缺少⓪时，外环仍可能成为高质量的证明压缩机，却不是目标导向的求解系统。

## 3. 信任架构：创造不可信，检查可信

整机采用“创造不可信、检查可信”的信任架构。**Soundness（健全性）**在这里指系统作出的证明相关判断都由前提推出，尤其不能用未经证明的规则误排合法解。

猜想器官和证明器官不必自身逻辑可靠。它们可以由人、大语言模型（LLM，即根据文本与结构生成候选推理的模型）或启发式搜索承担，也可以高频产出错误命题、漏前提证明和不经济的家族。它们的输出在验证前只有候选身份，不能因生成过程昂贵、文本像证明或附带复算收据（receipt）就获得承重资格。

验证器官独占 soundness 闸门：

1. 它从钉死字节重建命题所需事实，不信创造器官转述的中间结论；
2. 它独立检查前提、触发条件、结论和证明对象，任何缺失或漂移都 fail-closed；
3. 它同时把守编译交接，确认 lowering 没有扩大定理允许拒绝或固定的集合；
4. 它只对明确的命题身份签字，不把一次通过外推到未登记家族、不同输入或更宽前提。

这条分工是整机可行性的前提。若要求创造器官先成为可信通用数学家，自动化会停在最难的一环；若允许创造器官绕过独立验证直接改可行域，系统又会把猜想错误升级成假证书。

## 4. 手动执行就是接口打样

每次在取得目标对账收据后，人工走通“观察 → 猜想 → 证明 → 验证”，冻结产物的形状就是未来器官的接口规格。证明器官的产品采用五件套：

1. **范围。** 命题量化哪些对象，绑定哪个问题、目标、上下文和输入字节。
2. **条件。** 命题何时触发；条件必须能在声明的消费位置求值。
3. **结论。** 命题精确允许推出什么，以及明确不推出什么。
4. **证明。** 从 canonical 事实与显式前提到结论的可复算推导。
5. **消费契约。** 哪类消费者可使用该命题、采用何种极性、允许何种 lowering、需要哪些指纹，以及输入或前提变化时如何失效。

checker 的依赖边界、复算顺序、错误处理和输出 receipt 构成验证器官的建造规格。问题、目标、上下文、前提和 checker 的字节指纹构成器官间交接纪律：接收方消费的是特定字节上的特定命题，不是同名文件或相似自然语言。

[W0 ghost-front（端口前格冲突）离线短证书](experiment_one_w0_ghost_front_offline_certificate_20260815/README.md)是实验一第一号对象，也是当前已点亮链条的首个完整打样件。其状态为 `COMPLETE_RESEARCH_ONLY`：`Judgment`（命题登记）钉死范围、单原子触发器、结论、证明对象和非蕴含项；独立检查器只用标准库，并对输入指纹 fail-closed。它的消费契约当前是负契约——`no_solver_integration`、`no_lowering`、`no_D3_or_D4`。因此，“完整打样”只表示观察、猜想、证明和验证的冻结接口齐全，不表示编译、真实消费或整条推理外环已经闭合。

## 5. 猜想器官如何结晶

猜想器官需要一套**说理语言模板库**：模板不是现成结论，而是把重复死因改写成参数化命题的表达骨架。[第四轮盲态评审的实验一](round4_blind_observability_experiment_sequence_and_binding_routing_wall_review.md#实验一短证书与低余量梯度实验)列出了容量、匹配、割、端口、奇偶、规范形与构造语言；结合 W0 第一号对象，首批模板包括：

- **单格冲突。** 同一格被一组前提强制占用，又被另一条规则强制禁占；W0 的活动端口前格与严格空矩形冲突属于此型。
- **容量／割计数。** 某区域、边界或网络割的可用容量小于必须穿过的需求；最大流／最小割（max-flow/min-cut）证书是其网络形式。
- **Hall 条件。** 对任意需求子集，可供匹配的邻居数量必须不少于需求数量；违反时可直接证明不存在完整匹配。
- **端口数量。** 必须暴露、接入或分配的端口数超过可用端口槽位。
- **奇偶性。** 局部连接、覆盖或配对要求与可实现结构的奇偶类不一致。
- **规范形。** 通过对称归约或支配关系，把等价结构压到少量标准代表，不把案例 ID 当语义。
- **局部充分构造。** 给出一组局部条件；满足这些条件即可构造合法局部模块，再由精确终验检查完整见证。

猜想搜索因此不是在自然语言中无界漫游，而是在“**家族参数化 × 说理模板**”的空间中组合：签名谱提供候选家族，模板提供可能的证明语言，触发条件规定何时可廉价求值，holdout 负责揭穿案例记忆。观察到高频签名只产生搜索优先级，不产生定理。搜索允许主动缩小家族，但必须服从下一节的护栏。

## 6. 缩圈纪律：缩小范围，不偷换身份

**缩圈**是把待证命题的适用家族收窄到更小区域。它首先处理的病名是“陈述身份与支撑范围错配”：命题表面声称覆盖宽家族，实际证据只支撑其中一小块。

窄陈述若确有证明，soundness 本身不受伤；真正的风险在记账与身份：

- 定理可能退化为动机案例的别名，形成只会识别已知对象的**身份化证书**；
- 被缩掉的区域可能静默变成 `UNKNOWN`（未判定）却无人记账，后来被误读成已证明为 false（假）或已被覆盖。过严限制只会让答案消失，不会自动暴露报警。

### 6.1 把缩圈动作分类并标价

只因“当前证不动”而缩圈，属于预设类动作。它允许存在，但必须当场写明：缩掉的参数区域；该区域状态为 `UNKNOWN` 而不是 false；何种新证据、反例或工况会触发撤退与重审。这里的标价沿用[求解面方法论 §二](../../项目说明/29_solving_methodology_skill.md#二预设榫头要插进榫眼)对方便型预设的解空间成本与撤退线纪律。

若已有正面理由证明缩掉部分不属于该家族，例如能给出家族定义所必需而补集不满足的性质，则该缩圈属于被迫类动作，不收解空间预设成本。它仍要留下范围与证据记录，不能只写“显然不是”。

### 6.2 缩掉区域进入开放欠账

每次缩圈都登记一笔开放欠账，至少包含：被移除的区域、当前状态 `UNKNOWN`、责任对象和可执行的复核触发器。沉默不登记会让后续消费者把“当前未证”误读成“已经覆盖”。账目形态可复用[规则系统重设计线的开放欠账台账](../rule_system_redesign_20260807/batch0_20260815/OPEN_DEBT_LEDGER.md)：稳定 ID、受控状态、阻断范围、触发器与关闭证据同列。

### 6.3 终局只有三种，不设缩圈次数帽

缩过圈的定理带债运行，出口只有三种：

1. **扩圈补证毕业。** 证明覆盖原先缩掉的区域，宽陈述恢复并清债。
2. **正面刻画例外。** 证明补集确实不属于该家族，把排除理由写进家族定义，而不是继续列案例黑名单。
3. **前提证伪退役。** 发现原猜想或其基础前提错误，停止消费并保留退役身份。

缩圈次数不设机械上限；真正的在线报警量是**案例补丁占比**，即需要靠实例 ID、特定 hash、逐案例常数或只命中动机样本的规则，在当前理论库或实际触发流量中的比例。该比例持续上升，说明猜想器官在缓存案例，而不是发现家族。

### 6.4 原地收敛并做反身份化自测

对尚未获得稳定发布身份的工作定理，缩圈必须在同一工作条目中改写宽陈述，或把旧读法显式移入 `superseded` 区；禁止两份都标为当前的宽、窄版本并存。若命题已经拥有不可原地换义的稳定 ID，则创建后继条目（successor），并让旧 ID 明确 `SUPERSEDED`，不能借“原地改写”绕过稳定身份纪律。

缩圈后必须做反身份化自测：新定理至少覆盖一个不在动机样本中的实例。若做不到，它只是一张对象身份证，按“闸写空了”处理，不得进入可复用理论库。

### 6.5 极性登记不可混

缩过圈且补集尚未关闭的定理登记为**充分限制**极：它只承诺在已声明的窄范围内使用是安全的，不声称自身等于完整游戏语义。它不得冒充**精确语义**极，即不得声称同时覆盖全部合法与非法情况。[求解面方法论 §五](../../项目说明/29_solving_methodology_skill.md#五诚实记账假证书的防线)规定必要投影、充分限制与精确语义三极可空不可混；缩圈债未清时尤其不得靠措辞把不完整覆盖包装成 exact（精确语义）。

### 6.6 编译器官建成后的机器护栏

未来每条可编译定理的前提集应带机器可见指纹。缩圈改变前提或家族范围，就必须改变指纹；存在下游消费者时，currency（新鲜度）测试随即阻断旧消费，直到 lowering 与检查器重核。这样，旧宽读法不能以同名条目、旧缓存或未刷新的生成视图继续幽灵存活。

[`rules/derived/` 非冻结派生层](../../../rules/derived/README.md)提供了可复用的形态先例：自动产物先进入 `UNREVIEWED`（未审），独立拒真后才能转 `ACTIVE`（可用）；前提指纹漂移使条目转 `STALE`（过期），有下游消费者时阻断；currency 测试冷启动重生成并逐字比较，不信文件时间戳。该目录自身不是 canonical，本页只承接其状态机、前提指纹与消费新鲜度设计，不把派生层条目升格为推理外环权威。

### 6.7 过缓也不会自曝

保守动作与过严限制有同一种盲点：缩圈、退守、加检和降速都不会自行报警说“整个问题正在因此更慢地得到解决”。这与求解面已登记的“过严限制只让合法答案消失、永不自曝”是同一结构的两面：**过严不自曝拒真，过缓不自曝停滞**。所以，缩圈与一切保守选择都是**明码标价的临时退守，不是美德**。方向盘的常态朝向是向上推进——扩圈毕业、形成更强定理并逼近真实问题；护栏负责让进攻保持健全，不负责把退守固化成默认方向。

Soundness 不可谈判，但“用降速换安全”仍是一笔需要 owner 签字的交易，不是默认姿态。准确性与推进速度出现张力时，张力本身必须显式上报 owner 裁量；禁止在无人看见的地方静默偏向保守，再把低产出解释成安全成本。

开放欠账与案例补丁占比同时是反保守仪表。债只进不出，说明临时退守正在固化；案例补丁占比只升不降，说明家族理论正在退化成逐案防守。任一趋势出现都构成**保守成瘾**信号，必须主动上桌，而不是等待系统自行暴露。整套缩圈纪律的目标是安全地进攻，不是体面地后退。

## 7. 人的位置

人保留两类不可下放的职责。

第一类是**新模板发明**：当现有容量、割、匹配、奇偶或规范形语言都解释不了稳定死因时，人提出新的数学中间概念和证明语言。猜想器官成熟后，人不必逐案例读日志，但仍负责扩展“系统能说什么”。

第二类是**治理**：决定资源投向哪一层验证阶梯，判断何时值得扩大实验，并为定理进入真实系统的闸门签名。改变精确求解边界、运行时角色或认证输出含义仍受[项目宪法](../../../PROJECT_LOCK.md)和 owner 显式裁决约束；自动检查器通过不能替代这项权力。

常规墙——重复死亡采集、签名统计、模板匹配、证明候选生成、独立复算、currency 检查和 A/B 计数——应随器官结晶逐步交给机器。人的位置由逐案例操作上退到模板发明与治理，不从 soundness 闸门中退出，也不把 owner 裁决自动化。

## 8. 本页不是什么，以及如何更新

本页不是立项书、施工排期、实现授权、实验发射命令或 production 义务；它也不证明推理外环整体有效。七器官分解描述的是若该路线继续通过验证阶梯时，能力应如何分工和验收；其中账本对账协议只约束本 dossier 及显式继承者的研究消费纪律。

在本研究包（dossier）仍处于 `active`（开放）工作流、且本页仍承担工作草图职责期间，每通过一层验证阶梯，应回到本页点亮对应器官，重述头部“一句话现状”，并同步收紧仍未测试的非蕴含边界。研究包关闭后，正文不再追随现态改写；后续变化通过后继条目、勘误（erratum）或新的现状知识记录承接。
