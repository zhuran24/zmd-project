## B. §0b 七问过堂

### ⓪ 锚点问

| 项 | 回答 |
|---|---|
| 结构性预设 | “下游大量具体死因可被少量短小、参数化、可复用的语义定理压缩。” |
| 前提集 | 重复死因确有稳定语义支撑；短证书能够独立验证；家族边界不是案例 ID 的别名；经验证的定理最终可以被正确 lowering。 |
| 来源分类 | **④ 有价架构假设。** 它不是算术被迫或对称 WLOG，也尚未由全局零余量账推出。低余量区域更容易结晶被迫结构只提供搜索方向，不把该假设升成定理。 |
| 当前锚点 | Phase -1 已观察到重复局部签名；W0 在钉死上下文中把 1007 个观测 binding selection 压成一条一格冲突定理。二者支撑“值得继续验证”，不支撑通用家族已成立。 |
| 余量账 | **未全局建立。** W0 的目标前格可用物流占用容量为 0，活动端口需求为 1，故“容量−需求”是 `-1` 格；这是直接越界矛盾，不是取等的零余量账，也不得外推成其他家族或全局问题的余量账。 |
| 价签 | 当前不丢可行解，因为草图没有 lowering 或运行时消费；代价是研究与软件投资可能没有摊销收益。若未来在未证明范围内缩圈或编译，必须另记被移除区域、`UNKNOWN` 状态和下游消费债。 |
| 撤退线 | 冻结式 holdout 若持续表现为身份化证书、案例补丁占比上升、累计避免成本不能覆盖发现／验证／维护成本，或全局 lex 前沿不动，则停止押注通用推理外环，只保留已验证的局部规则与逐点 exact search。 |

### ① 切分问

草图对未来每条候选规则采用三档切分；当前没有具体 runtime rule 可执行此切分，因此下表是接口判据，不是已落实现。

| 三档 | 草图中的归属 | 当前状态 |
|---|---|---|
| 健全影子 | 经过证明、可在昂贵搜索前求值的便宜触发器或必要条件；只能在定理范围内拒绝或收缩 | W0 有离线触发器，但 `no_lowering`，尚未形成运行时影子 |
| 精确本体 | canonical 语义、完整证明对象与独立 checker；留在验证侧作为复核官 | W0 单定理已有成品；通用器官未建立 |
| 启发式残部 | 签名频次、模板匹配分数、LLM／人工猜想与未证家族；只排发现优先级，不改可行域 | Phase -1 签名谱和人工猜想属于此档 |

切分红线：创造器官的输出默认不可信；只有验证器官签过的命题可以进入编译候选；lowering 不得强于定理。

### ② 住址问

| 片段 | 支撑域 | 设计住址 | 当前状态 |
|---|---|---|---|
| 死亡事件、签名谱、饱和窗 | research harness 可观测事件 | 观察器官 | 已有 Phase -1 原型 |
| 家族与触发条件猜想 | 冻结 discovery 材料和说理模板 | 离线猜想器官 | 纯手动 |
| 证明对象 | canonical 规则、钉死字节、显式前提 | 离线证明器官 | 纯手动，W0 有单件 |
| 精确复算 | 命题全部承重输入与证明对象 | 独立验证器官 | W0 单定理成品 |
| 上游约束 | 只有在消费位置可求值的已验证前件 | 编译器官，位于其能剪掉的昂贵步骤之前 | 未建立，D3 延后 |
| 完整语义终审 | 完整见证和 canonical 精确语义 | 下游验证／终验侧 | 不因上游影子而移除 |
| 效果计量 | 同输入、同顺序、同随机种子、同预算的 on/off 数据 | 测量器官 | 离线材料部分存在，D4 未执行 |

住址结论只确定职责与信任边界，不预先规定进程、模块或代码目录。具体定理出现后仍需按其变量支撑域重判住址。

### ③ 排序问

| 排序层 | 判据 | 当前结论 |
|---|---|---|
| 投资顺序 | 存在性 → 真实系统消费一次 → 家族普遍性 → 全局面貌；每层阳性才购买下一层投资 | 已明确，当前只有第一层 W0 局部阳性；不得提前按第四层规模施工 |
| 运行时门序 | 知识坐在它能剪掉的昂贵步骤之前，验证坐在它背书的步骤之后；门按实测拒绝成本从便宜到贵排 | **NOT_TESTED。** 尚无 lowering 和真实过滤器，不能给具体门拍成本顺序 |
| 成本资料 | W0 独立 checker 有离线成本；Phase -1 有事件计数与墙钟删失 | 只能说明检查可便宜、观察可自动化；不同任务不可冒充真实 A/B speedup |

### ④ 耦合问

**不适用于当前运行时切分，理由是没有规则已被编译成过滤器。** 这不是“试过没咬”，而是 `NOT_TESTED / D4_DEFERRED_BY_OWNER`。

首条定理进入真实系统前必须做目标耦合测试：在关闭该规则的基线中，按 lex 分数带测量最优邻域候选在规则过滤下的存活率。若 near-frontier 存活塌缩，规则与目标对抗，必须与求解上下文内聚或用带前件的禁闭子句反馈；只有耦合弱才允许作为独立过滤器。

W0 离线证书没有 lowering，也没有 on/off 求解路径，故不能据其 1007/1007 观测覆盖推断目标耦合弱。

### ⑤ 计量问

| 指标 | 当前观测面 | 状态与处置 |
|---|---|---|
| 死因事件与签名谱 | Phase -1 append-only journal 与结构化摘要 | 已有原型；删失口径必须保留 |
| 语义证书大小与覆盖 | W0 Judgment、proof、coverage snapshot、check receipt | 已测离线单对象；观测覆盖不是证明前提 |
| 真实过滤器拒绝率 | 无运行时过滤器 | `NOT_TESTED`；不得写 0 |
| fail-soft 剥落／降级 | 无 compiler 与消费路径 | `NOT_APPLICABLE_YET`，理由是执行面不存在；建成后必须计入拒绝率 |
| 零误杀 | 无 lowering、无 D4 配对 A/B | `NOT_TESTED`；不得由 checker PASS 外推 |
| 案例补丁占比 | 草图已定义为一等在线报警量 | 尚无理论库与触发流量，暂不可计算；首个家族实验起必须上报 |
| 缩圈债流量 | 草图要求每次缩圈登记区域、`UNKNOWN` 与复核触发器 | 当前无已编译缩圈定理；不得将“零登记”写成“零缩圈” |

### ⑥ 余量问

**全局数值余量不适用于当前草图，理由是本页没有提出一条带需求量与松弛上限的具体运行时规则。** 因此没有可诚实填写的统一余量百分比。

已有的窄读数只有 W0 钉死上下文中的一格冲突：同一目标前格必须有传送带，同时严格空矩形禁止任何物流件；可用容量 0 对需求 1，`容量−需求=-1` 格。该负余量读数只证明 W0 条件式不可行定理，不证明其他端口家族、矩形家族或全局求解面具有相同余量结构。

未来每条定理进入编译候选前，必须逐账写出“需求 vs 最松上限”；余量低于 5% 时，列出全部未建模约束及其预估代价，并把健全影子加肥后再解读可行与不可行两个方向。缺这张账时，定理只能停在离线研究身份。

## C. 过堂判词与开放项

| 项 | 判定 |
|---|---|
| ⓪ 锚点 | PASS WITH PRICED HYPOTHESIS；有局部负余量矛盾与明确撤退线，不冒充全局零余量锚点 |
| ① 切分 | PASS AS DESIGN CONTRACT；W0 只有离线影子／本体，runtime split 未实现 |
| ② 住址 | PASS AS RESPONSIBILITY MAP；具体代码住址留待定理支撑域实测 |
| ③ 排序 | PASS FOR EVIDENCE LADDER；runtime gate cost order 为 `NOT_TESTED` |
| ④ 耦合 | `NOT_TESTED / D4_DEFERRED_BY_OWNER`，不是阴性结果 |
| ⑤ 计量 | PARTIAL；观察与离线证书可量，拒绝率、零误杀、补丁占比尚不可量 |
| ⑥ 余量 | PARTIAL；W0 局部负余量不可行账成立，全局和未来家族余量未建立 |

本凭据支持的最高结论是：架构草图已把核心假设标价，给出三档切分、职责住址、阶梯顺序和未来测量义务，并显式保留 runtime 未测试项。

本凭据不支持的更强表述包括：推理外环已立项、六器官已实现、W0 已被真实系统消费、D3/D4 已解冻、家族普遍性成立、运行时零误杀、全局余量已核算或架构已改变最优性问题的全局面貌。

重新过堂触发器：首条定理申请 D3 编译、首次 D4 配对 A/B、家族边界或三极性改变、lowering 消费位置改变，或草图从 `non_authorizing` 申请升格。
