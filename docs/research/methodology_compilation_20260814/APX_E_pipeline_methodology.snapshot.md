# 附录 E · 管线与归属方法论（项目既有方法论权威）

## E.0 这份附录是什么，以及怎么读它

### E.0.1 身份

本附录是本项目**科学面的方法论权威**：一套关于「一条知识该住在计算管线的哪一层、管线本身该怎么切、
一个结构性预设该押在哪」的判据体系。

三件事必须先说清楚：

1. **它比主设计文书早**。第一版 2026-07-17 立，此后持续演进到 2026-08-07，共十一次入册（时间线见
   E.0.5）。主文书成稿于 2026-08-08。
2. **两者从未被系统性对照过**。本附录的核心术语在主文书三份材料里的机械命中数：「榫眼」0、「锚点」0、
   「门序」0、「四元组」0、「健全影子」0、「余量」0、「打包三问」0、「三腿」0、「超杀」0、「踏车」0、
   「过堂」0、「有序划分」0、「支撑域」0。唯一被吸收的是本体系**最新的一条**（E.11 双向保真公理，
   2026-08-07 入册），它以「P3 双侧保真」的形态进了主文书 §5.3；此外主文书 §10.2 借用了它派生出的
   `model_stricter_faces` 台账形态。**其余全部为零。**【项目实测】
3. **它不是主文书的草稿，也不是主文书的上级**。它是另一条独立演进的线，在同一个项目里、由同一批人
   在同一批案子上推出来的。哪些是同一思想的两个名字、哪些是真分歧、合流后归谁管——正是本轮要审的东西。

### E.0.2 它的适用域（本体系自己的声明）

自 2026-08-03 起，本体系声明自己是**尺度无关**的：适用于科学面上任何「知识 × 计算」的分解边界——
管线与管线之间、门与门之间、门的内部（子问题模型 vs 过滤器）、证明与检查之间、实验设计与分析之间。
它管的不只是「一条规则住求解器哪层」。

## E.1 操作卡：七问（日常执行入口）

适用域 = 科学 / 求解 / 数学面的**任何**「知识 × 计算」分解边界。七问按**决策时刻**排序，不按重要性排序。

### 押任何结构性预设之前——最先问

**⓪ 锚点问**（预设锚点判据）：这条预设卡在哪笔**零余量账**上（= 问题算术里被迫的结构，所有解本来就
得长这样）？来源属哪类——①算术被迫 / ②对称 WLOG / ③求解器方便 / ④配方类比？**③④类必须当场标价**：
写明扔掉的解空间与撤退线。
快诊断：多份独立方案的撞车点 ≈ 被迫结构，分歧点 ≈ 愿望区 = 审查火力集中处。

### 开线 / 设计新管线时

**① 切分问**：每条规则切三档——**健全影子**（不依赖下层决策即可求值的必要条件松弛）/ **精确本体** /
**启发式残部**。上收的只是影子，本体留在下游当复核官。

**② 住址问**（支撑域判据）：每一片的变量管辖范围装得进哪一层？整个装得进子问题的就住进子问题模型
（内聚代价是局部的）；「切开省计算」只对**跨子问题**的规则成立。

**③ 排序问**：门按**实测**拒绝成本便宜 → 贵排；知识坐在它能剪掉的昂贵步骤**之前**，验证坐在它背书的
步骤**之后**。成本拿不准就先花小钱实测，不许拍脑袋。

### 把一条规则切出去当过滤器之前

**④ 耦合问**（目标耦合测试）：先小钱实测「无此规则的最优解在过滤下的存活率随目标值怎么变」。
最优邻域存活塌缩 = 规则与目标对抗 = 必须内聚或以禁闭子句反馈；耦合弱才允许切开。

**⑤ 计量问**（报警计量完整性）：过滤器的拒绝率是**一等报警指标、必须上报**；任何 fail-soft 降级
（剥落 / 取子集）**仍计入拒绝率**，不许把拒绝转译成接受把报警清零。

### 读任何可行 / 不可行结果时

**⑥ 余量问**（余量-影子定律）：需求离松弛上限多近？余量 ~2% 量级时一切未建模约束都会咬，影子必须
加肥后其两个方向的读数才可信。

### 两条不变式

**早期拒绝带证书、早期放行皆暂定、终审归精确本体**；新开管线须按本卡过堂并留记录。

### 过堂表模板（任务书直接抄走填空）

```
【过堂表】管线:___  日期:___  过堂人:___
预设锚点: 预设 | 前提集 | 来源(①被迫/②对称/③方便/④配方) | 依据的零余量账 | ③④类价签(扔掉什么+撤退线)
逐规则: 规则名 | 三档切分 | 支撑域→住址 | 若为过滤器: 耦合实测值+拒绝率上报位置 | 证书形态
门序: 门 | 拒绝成本(实测/估) | 它剪掉谁 | 判死条件
余量核算: 需求 vs 最松上限 = 余量__%；余量<5% 时列出全部未建模约束及其预估代价
```

**执行纪律**：新批任务书必须内嵌**已填**的过堂表（在做方案时产出，不是事后补）。对抗审查方常设一条
「报警计量是否被 fail-soft 清零」检查。科学面任何新批 / 新方案 / 新实验，开工前至少过一遍七问——
过堂表哪怕逐项填「不适用」也要留痕，「试过没咬」与「没试」必须可区分。【owner 方法论裁决】

## E.2 归属四元组与有序划分（2026-07-17，方法论 v1 / v2 / v2.1）

**一条规则的归属不是「上收 / 下放」一维选择，是切分后各片的四元组位置。**

### E.2.1 四元组

1. **切分（纵向）**：每条规则先切成至多三档形态——健全影子（可传播的必要条件松弛）/ 精确本体 /
   启发式残部。上收从来不是搬家：**能上去的只是影子，精确本体留在下游当复核官**。fail-closed 双保险
   是切分的**必然结构**，不是保守偏好。
   先例：front 净空规则 = 计数影子进 master + 逐端口判留 RAB + 完整连通判留 routing；另一条超杀残部
   被降级为热启动启发式。

2. **住址（聚类轴）**：每片放它能通过三腿测试的**最高**上下文——**①尺寸紧凑 ②传播力足 ③机器兼容**。
   聚类判据 = 厚薄：共享决策变量、互相剪枝的片必须同住一个求解上下文（学习机器才能跨规则做冲突分析）；
   只交换判决的片允许分居（**薄腰 = 合法切口**）。跨层共享的计算必须单一真相源化。

3. **管线序（顺序轴）**：**知识坐在它能剪掉的昂贵步骤之前，验证坐在它要背书的步骤之后**；按实测
   拒绝成本从便宜到贵排（RAB 0.07 秒 → binding 秒级 → routing 分钟级 → master 百秒级）。
   踏车（下层反复学同类教训学不完）的顺序论解读 = 知识坐在了昂贵步骤之后。

4. **下游验证人**：每个早期拒绝带证书、每个早期放行是暂定，由该规则的**精确孪生**在最低管辖层终审
   （落 cut 前的独立不可行复验、终端验证器即此结构）。

### E.2.2 报警信号（双向对称）

- **上收信号** = 踏车：下层通道反复学同类教训学不完。
- **下放信号**：①**白吃饭**（高成本 × 低剪枝命中率，遥测可测）；②**超杀**（比真相强，高层会冤杀——
  降级为启发式 / 诊断，**不删除**）；③**越权判断**（所需信息在该层根本不存在）。

三腿的可推理程度不同：健全性 = 纯证明、尺寸 = 纯算术、传播力 ≈ 七成经验可预判、机器兼容只能靠带遥测的
便宜探针。**漏斗纪律** = 否决便宜（纸面终审）、通过昂贵（实测只施加于漏斗底部幸存者）。
**归属是 master 表示法的函数**：换表示（从姿态布尔编码换成坐标编码）后必须重跑全部归属测试。【判例归纳】

### E.2.3 层数与切口自身是被决定项（方法论 v2.1，同日补）

规则的完整归属方案是一个**有序划分**（给出分组 + 顺序后，「不与谁同住」自动蕴含）。而**划分的格数与
切口位置不是继承给定的**——当前 precheck → master → RAB 过滤 → binding → routing → 终验的格局是历史
累积（RAB 过滤层的分离即一次未被命名的加层）。

推导：格数 = **聚合力**（共享变量互相剪枝 → 同格，传播更强但单格更重）与**切分力**（拒绝成本梯度 →
分格漏斗 + 每格专用引擎）在**信息依赖 DAG**（规则需要某层决策结果才能求值 → 硬顺序）上的均衡。

**切分的正确切口 = 沿信息依赖边界下刀**：影子 = 规则中不需要下层决策即可求值的部分。
- 硬合并事故 = 违反信息依赖的硬合并；
- front 净空规则的计数影子可上收 = 计数形态**消掉了**对 binding 选择的依赖。

两格互不依赖且成本相近时顺序自由、可并行。

**对搜索硬度的层数响应**：单格 solve 解不动时先问「这格是否合并过头」——候选 = 两段式 master
（便宜松弛格先解，解作 hint 喂完整格）。

### E.2.4 历史校准

- 供电补全下放事故 = 一次**失败的下放**。教训：下放的前提是例外通道扛得动残余。
- 一条早期成功的切分上收 与 front 净空规则 = 两次**成功的切分上收**。
- 若 routing 层将来踏车，第一天照此办理（早期两轮已证其便宜代理不健全，**健全性腿是那里的主战场**）。

## E.3 cut 方法论：运输形态、打包三问、四问双向统一（2026-07-18，方法论 v2.2）

### E.3.1 cut 是什么

**cut = 住在下层的规则向 master 运送知识的运输形态**——上收是整条规则搬家，cut 是**分期付款的包裹**。

本项目历史上的九族割平面候选（2026-05 定型）是从早期失败样本**归纳**出来的，**没有覆盖性论证**
（其中一族建立在错误的游戏规则前提上还能立项，即铁证）。「cut 无方法论」这条指控成立，本节即补账。

### E.3.2 打包三问

给定一次下层拒绝，包裹的打法**不是选出来的、是问出来的**：

1. **责任圈能收多小**——点名越少禁得越多。早期的整层 nogood 踏车 = 没问此问：266 个实例全点名打一包，
   只杀掉一个点。
2. **死因里有没有可抬的数量律**——**计数型死因**（容量 / 口数 / 覆盖）可抬成算术律；**身份型死因**
   （具体形状咬合）抬不动，只能原样打包（那一族「个案快递」的正当业务就在这里）。
3. **抬出的定律上层词汇说得出吗**——说得出就发泛化版；说不出就退回**冲突核降级版**（连通性即此类）。

**cut 类型空间因此有界可枚举** = 各验证者的拒绝路径清单 × 每条的最泛化健全表达。
**覆盖性检查 = 有限审计**：个案快递族的兜底占比，就是「未覆盖失败流量」的在线测量。

### E.3.3 四问双向统一

上收判据与下放判据 = **同一套提问的正反两读**（由打包三问取反推出，把 E.2.2 的三个下放信号从**症状**
升级为**病理**）：

| 问 | 通 → | 卡 → |
|---|---|---|
| ① 责任圈 / 激活面宽吗 | 常驻上层有价值 | 激活面极窄 → 下层待命 |
| ② 有可抬的数量律吗 | 抬成算术律上楼 | 身份型零散 → 下层 + 个案快递（**白吃饭的病理**：命中率低 = 知识本质上泛化不了） |
| ③ 上层词汇说得出吗 | 直接编码 | 说不出 / 爆炸 → 下层 + 冲突核降级快递 |
| ④ 求值依赖下层决策吗 | 整条上收 | 依赖 → 只能保守猜 = **越权 → 超杀的因果链**（硬合并事故全链）；或切出不依赖的影子上楼、本体留守 |

**四问全通 → 上收；卡在哪问 → 卡点同时决定住址和该规则 cut 的打法**——归属判据与打包判据是同一次
提问的两个读数。

每族 cut 的终局三选一，九族历史上全部出现过：**毕业上收**（其中一族最终成了 front 净空规则的上收形态）、
**确认真例外**（个案快递族）、**前提证伪退役**（建立在错误游戏规则上的那一族）。

前瞻价值：routing 踏车之日，第一天即枚举其拒绝路径、逐条过三问生成 cut 族，**不再归纳两个月**。

## E.4 干净房间外部收编六条（2026-07-20，方法论 v2.3）

出处 = 两轮独立外部大脑对同一判据体系的重推与批判。【owner 方法论裁决】采纳。

1. **权威归属公式**：`owner(r) = max{ owner(v) : v ∈ scope(r) }`——一条规则的**权威** owner 由其语义
   所需变量的**最晚层**决定，更早的层只能持有**被证明的投影**。这是「精确本体留在下游当复核官」的
   形式化。**权威归属（语义必然，公式定死）与表示归属（性能选择，三腿测试定）是两个问题，不得混问。**

2. **三极性登记**（对 E.2.1 三档切分的扩容）：每条规则登记**三极**——
   **必要投影**（上界证明用）/ **充分限制**（构造器用：比真规则**严**，构造出的必合法）/
   **精确语义**（终审 checker 用）。**可空但不可混极。**
   注：三档切分里**没有**「充分限制」这一极；见证构造器的保守子集正是这个形态。

3. **cut 必须带前件**：每条学习 cut 表示为「**前件配置 ⇒ 必要修复析取**」；裸的正极障碍集**不得**做
   几何 cut——前件缺失 = cut 在前提变动后**幽灵存活**的病根。

4. **主动挖对偶**（对踏车警报的补充而非替代）：最强的 lift 不必等踏车报警——解**局部松弛的小对偶问题**
   （micro-oracle）主动挖计数不变量，经精确枚举验证后全局求和成证书。先例 = 供电光环 396 权重证书
   推出电杆数下界 `P ≥ 9`。漏斗序相应修订：**micro-oracle 插在前提数据核查与全局 build-only 之间**。

5. **等式挖矿**：全局不等式**近紧**时，每条成分不等式都是结构约束源——上限命中时的强制条件
   （恰 N 根电杆 / 零协议箱 / 内部矩形不贴边）即**构造规格**。

6. **双 ledger 汇报**：**下界账**（见证只抬此账）与**上界账**（松弛证书只压此账）分开记；
   **同 instance hash + 同假设**下两账相遇才准报 optimal；**资源中止不改任何账。**

## E.5 管线门序泛化（2026-08-03，方法论 v2.4）

本判据的管辖对象不只「一条规则住求解器哪层」，而是**任何管线的门序设计**——构造线 / 研究线的工作流
同样是管线，其工序位置服从同一套定律：

- 不依赖下层决策即可求值的必要条件（健全影子）**必须前置为便宜门**；
- 按实测拒绝成本从便宜到贵排；
- 早期门带证书、终审留给精确本体。

**反面校准 = 硬后置事故**：「先钉机身、端口后补」把可毫秒级求值、不依赖任何路由决策的端口合法性
隐式埋进末端的小时级大求解，**六次 UNKNOWN 被读成「难」而不是「无解」**；外部大脑用一个前置影子检查
**毫秒判死整条线**（219 个身位里 129 个绑不上端口；本方复算在仓库语义下结论更强，只有 91 个可活）。
【项目实测】

**与硬合并事故构成同构对偶**：那次是违反信息依赖的**硬合并**（把依赖下层决策的规则整条上收），
这次是违反管线序的**硬后置**（把不依赖下层的必要条件埋到最后）。

**执行纪律**：新开任何构造 / 求解管线，门序须显式对照本节过堂并留记录；**外脑交付的构造方案以
「待审管线设计」身份进场，不因算术闭合的美感免检。**

## E.6 管线门内归属四则（2026-08-03 夜，方法论 v2.5）

E.5 管的是门与门**之间**的次序；本条管门的**内部**——子问题模型与其过滤器之间，同一套归属原则要
再用一层。四则即操作卡的②④⑤⑥：**支撑域判据 / 目标耦合测试 / 报警计量完整性 / 余量-影子定律**。

**校准案例（房间网格生成器）**：它把连通性（支撑域 = 单房间 196 格，天生房间级）**后置为剥落式过滤器**，
三重失效叠加——

- **耦合未实测**：目标（最大化密度）与连通性对抗，直到「146 格摆 11 台 → 存活 2 台 / 50 格」才暴露；
- **剥落把拒绝转译成接受**：致「丢弃率 > 70% 即升级」的绊线**永远为零**（记为死体的拒绝 0 件，

- **余量仅 2%**（3,392 对 3,325）下影子过瘦——最终目录供给缺 212 格，该阶段双 INFEASIBLE 收场。

事后把连通性**搬进房间级生成模型**：90 秒内干净解从 134 涨到 138、20/20 全存活——坐实**内聚代价是
局部的**。【项目实测】

**另一半诚实账**：内聚买到了「找好解更快」，**尚未买到不存在性证明**（相应的判定仍是 UNKNOWN 未收敛）
——健全上界仍是缺口。

## E.8 预设锚点判据（2026-08-04，方法论 v2.7）

操作卡①-⑥管的是「规则怎么分家」；本条管更早的一步——**分家之前押下的结构性预设本身**。
每条路线都是先押一个结构性预设，再在预设之上做归属推理；**路线间推理的分歧全部来自预设的分歧。**

### E.8.1 判据本体

> **好预设不是搭在问题旁边的支架，是插进问题自带榫眼的榫头。榫眼 = 问题算术里余量为零、所有解被迫
> 同形的结构。**

卡在被迫结构上的预设几乎不损失解空间（所有解本来就得这样）；卡在「方便 / 愿望」上的预设在**偷偷扔解，
且不知道扔了多少**。

### E.8.2 预设来源四分类（按价签档次）

| 类 | 来源 | 价签 |
|---|---|---|
| ① | **算术被迫**（零余量账逼出「只能这样」） | 免费，随便押 |
| ② | **对称性 / WLOG** | 便宜，配一行证明 |
| ③ | **求解器方便**（「切了问题就小」） | **必须标价** |
| ④ | **配方 / 类比**（「这类问题一般用 X」） | **必须标价** |

③④的价签 = 写明**扔掉的解空间范围 + 撤退线**。

### E.8.3 撞车诊断（副产）

多份独立设计的**重合点 ≈ 被迫结构**（各自独立发现了同一个榫眼），**分歧点 ≈ 愿望区 = 可谈判区**；
**审查火力应集中在分歧区。**

### E.8.4 与余量-影子定律的对偶

同一枚硬币的两面——余量趋零处既是**危险区**（一切未建模约束必咬）又是**榫眼**（预设的合法锚点）。
**零余量既是杀手也是路标。**

### E.8.5 校准判例（2026-08-04，六方独立复核数据）

| 判例 | 判 | 依据 |
|---|---|---|
| 条带设计的高度账 | **①类免费锚点** | 54 + 15 = 69 零余量、带组成经审计为**唯一解**，算术全对站得住 |
| 46 个边界口的周长陷阱 | **被迫结构** | 138 格必铺满两边；三次独立设计（滑窗列生成路线 / 倒写处方 / 条带设计）**全部**钉死边界 = 撞车诊断实证 |
| 房间网格生成器的 14×14 网格 | **半锚** | 供电几何是真结构，但电杆并不被迫按网格摆；其**愿望半边**（机器不跨房 / 门洞固定死）恰是后续全部松绑候选所在 |
| 滑窗列生成路线的 12×12 / stride 6 | **无锚**（纯手感数字） | 生产规模第 0 轮即死 |
| 极性交替愿望 | **无锚愿望** | 死 |

现行房间网格生成器章程的八条构造限制**已诚实挂「充分限制」牌 = ③类已挂牌未标价**，价签补齐挂后续批。

### E.8.6 五条补记（2026-08-04 同日，操作化配方）

**① 榫眼组合规则。** 每个榫眼登记时带**前提集**：**无条件榫眼**（从问题本身算出，前提集为空）全兼容、
可任意叠加；**条件榫眼**（在某预设家族内被逼出，如条带设计的 54+15=69 之于「横带 + 单格走廊」）
只能与**同前提家族**叠加，合并判据 = 前提集之并自洽。
设计真正押注的只是**前提集**，榫眼是前提选定后的**免费产物**——「找齐榫眼」既白拿搜索空间缩减，又
提前暴露该家族的零余量脆弱点（条带设计的「5×5 恰 49 = 49」即审计找齐后现形）。

**② 系统性找法 = 余量审计表。** 把问题的每本资源账（面积 / 边界周长 / 台数容纳 / 端口槽位 / 供电覆盖 /
商品源汇 / 整除 / 模数）逐行算「容量 − 需求 = 余量」，**按升序排**——趋零行 = **无条件榫眼清单**
（设计必钉）；选定预设家族后**重算**，新增趋零行 = 条件榫眼 + 未来脆弱点。
**一张表两用**：正读 = 锚点清单（设计输入），倒读 = 危险清单（余量-影子定律的审查输入）。
撞车诊断随之升级为**交叉验证**：独立设计在趋零行上应精确一致，**不一致必有一方算错**。

**③ 条件的来源与产率读法。** 条件榫眼的条件 = 押下的③④类（偶含②类）愿望预设**本身**——条件榫眼是
**愿望买来的赠品**（付解空间，得被迫结构 + 搜索缩减）。
设计质量的经济学读法 = **单位解空间代价买回的榫眼产率**（条带设计一注条带愿望换一把被迫结构 = 高产率；
房间网格愿望贵、榫眼少）。
**递归性**：愿望 → 条件榫眼 → 内层再押愿望 → 更深榫眼成树，前提集 = 路径。
**隐藏前提审计技巧**：推导条件榫眼所用的每条前提**必须已申报于愿望清单**，推导逼暗桩现形
（例：条带设计「带组成唯一」的推导消耗了「每条带各有一根竖向输送支线」这条前提，该前提即必须挂价签）。

**④ 理论根基。** 自由有**两源**——**问题真余量**（被迫结构钉不死的地方问题不在乎、设计必须选）
+ **认知余量**（问题在乎但推导比猜贵，愿望 = 推导太贵处的替代品）。
自由为零 ⟺ 一切被逼死 ⟺ 解可直接读出 ⟺ 问题平凡，**故非平凡问题必有自由**。
方法必不唯一（解层 + 路径层双重多样性，区别在贵贱不在对错）；**方法空间的坐标 = 自由选择，
被迫核 = 一切正确方法的公共部分**——「方法不止一个」即「自由非空」在方法空间的直译，撞车诊断由此
成为**定义推论**而非经验规律。
**风险只住认知型自由**（真余量型怎么填都留解；认知型愿望**可能杀光解**——硬后置事故的死法），
价签制度专管认知型。
**动态观**：自由 / 被迫边界随计算投入移动（某些结论昨日自由今日被迫），探测 / 审计 / 证书 =
**用计算购买被迫性**；全项目一句话 = **不断把自由转为被迫，直到残余自由小到搜索器啃得动**
（上界链 = 同一件事在另一侧的成果）。【设计分析】

**⑤ 择愿五启发**（判例 = 外部大脑五次设计解剖）。愿望非均匀随机，择法有先验：
1. **瞄准最贵耦合使之按构造消失**（在问题最痛处人工制造条件榫眼：沙漏枢纽设计 / 条带设计的单向环 /
   房间网格的门洞桩）；
2. **锚在精确闭合恒等式上**（70 = 5×14、54+15=69——余量审计表零余量行的构造版用法：既是警报也是
   框架候选清单）；
3. **新愿望 = 上一张死亡证书的逆否**（倒写处方 = 硬后置事故死因倒写）；
4. **选死得便宜的愿望**（最脆的义务配最便宜的第一门：极性交替愿望守此条，故 0.018 秒判死——
   **好猜的标准不是不死，是死得快**）；
5. **产率评分**（候选愿望比「单位解空间代价买回的被迫结构」：条带设计高产率 vs 滑窗列生成路线零产率
   零锚而死）。

**总纲（初版「五条全优化检验成本」把两类混为一谈，已修正）：主线是伸，不是探。**
问题是**只会拒绝的神谕**：它在乎什么从不主动说，只对完整提案点头 / 摇头——
**测量探针**问小问题（探测臂、pricing 实验，纯学习、便宜），**愿望**问大问题（这副骨架驮得动一个完整
解吗），是从榫眼出发向完整见证伸出的**悬臂**；其试探价值是保险设计出的**副产品，不是目的**
（纯学习有更便宜的工具，**为探而愿 = 本末倒置**）。
期望收益 = 中奖概率 × 构造价值 + 死亡概率 × 信息价值 − 检验成本：启发 (1)(2)(3)(5) 抬第一项（伸的技艺），
(4) 抬第二项、压第三项（保险）。
战略节奏 = **测量 → 伸 → 断口判读 → 再测量 → 再伸**。每次死亡产出证书喂回 (3)，与「用计算购买被迫性」
同构闭环。

### E.8.7 补记⑥·撞车诊断二分修正（2026-08-05，两份独立构造样本实测推出）

撞车诊断的两半各加一条限定：

- **重合侧**：先**剔除任务书强加的共同输入**（两份都遵守同一份带高多重集，不构成独立佐证——**伪撞车**），
  剩余的**自发**重合才是被迫结构候选，**且仍是弱证据、非定理**。
- **分歧侧**：「分歧 = 自由区」**不总成立**。先分类：两边都活着的分歧是真自由度；
  **一边在该维度宣告「不可行」的分歧不是自由区，是前提冲突**（一方把自己的选择内化成了被迫结构），
  暗桩就在那，审查火力应指向该方的隐藏前提。**判据 = 该维度上有无不可行断言。**

**实证判例**：一份样本把「3×3 只进 3 高带」（模板-带高纯度）默认为铁律并据此建了一条不可行定理；
另一份把同一维当自由度用（混装 8 台）**直接产出可行见证、当场证伪该定理**——分水岭恰落在被误读为
「自由区」的那个分歧维上。【项目实测】

## E.9 补记⑦·零余量的第三种读法：可判性（2026-08-05）

零余量 / 低自由度有**三种**读法：

1. **杀手**（余量-影子定律：未建模约束必咬处）；
2. **路标**（榫眼：预设的合法锚点）；
3. **快速法庭：自由度越低的愿望判得越便宜——生死都快。**

第三读法的操作规则：**低自由度候选应插队先试**。判定成本低是**无条件**的，与成败无关；低自由度既可能
「几步构造完」也可能「几步撞死」（两份独立构造样本同料异果即实证）——**事前确定的只有「判得快」
这一件**。

**反面教材**：条带设计的首件审计早已算出「带组成唯一 / 某参数仅 4 个取值 / 5×5 恰 49=49」这些低自由读数，
却**全部归档为脆弱性证据**，没人翻过来读「剩余是有限算术 → 直接算完试试」，判定实验因此**迟到十天**。
病根 = 求解器项目的**工具形状偏置**（默认布局出自 CP-SAT，纸笔可完成的构造不入队）。

与择愿启发 (4)「死得便宜」的关系：(4) 选的是**败局便宜**，本条选的是**判决便宜**——**后者双向。**

## E.10 补记⑧·切分质量的两个隐藏维度（2026-08-05）

评价一条切分线，除了「切在天然松耦合处」，还有两问：

**㈠ 回传带宽**——切口两边怎么通信？「一次一条否定」式的**细通道**，在被拒方大量提案时**就是枚举墙**；
好的切分要在拒绝理由可编译时把它**整批编译回上游的选项域**（工况允许时，「开工前递整本地图」优于
「逐轮传一个字」）。

**㈡ 工况相关性**——耦合强弱**不是问题的静态属性，是「问题 × 工况」的属性**：同一刀在旧工况下是好刀
（`binding ↔ routing` 切分在 master 自产**稀疏**提案下多年无恙，死候选大多死在便宜的数数门），换工况
就成墙（**塞满**的设计布局让数数门形同虚设，所有死亡挤到 front 一格，细通道现形为 33 小时枚举墙与
正式门的两千余次盲试错）。**切分决策入档时应记下它成立的工况前提，工况迁移时重审。**

**修法方向的原则：先加粗通道，不先挪刀。** 挪刀退回巨模型会把切分的全部收益还回去（工具适配 /
证明模块化 / 贵贱门序），而加粗通道（固定布局下预筛端口域、按登记语义钉死见证绑定）**保刀保收益**。
反面教材 = 同一条约束（口面向走廊）在构造样本里是**零成本设计规则**，在门外只能**事后挨打**
（三次实证：33 小时枚举墙、正式门 2,259 次以上来回、构造样本零成本）。【项目实测】

### E.10.1 补记⑧续·「问题 × 工况」的具体判断方法（2026-08-05）

切缝（A 提案 → B 裁决）的**过路费**由两个可测量决定：

**㈠ 死因谱**——candidates 死在哪条约束上、**该约束住在缝的哪一边**（死在 A 模型内不花钱；死在缝对面
才付来回费）。

**㈡ 否决带宽**——B 每打回一次剪掉 A 多少候选空间，三档：**点否决**（nogood，最细）＜ **族否决** ＜
**可预编译**（拒绝理由在本工况下是常数，整批写进 A 的选项域，最粗）。

> **墙的预言式：死因集中在缝对面 × 否决只有点级 = 必撞墙。**

**测法不需专门实验**——门的拒绝原因日志本身就是**缝健康仪表**。三步：
1. **抽样看谱**（几十个 candidates 按「哪条约束杀的 × 住哪边」分类）；
2. **对谱查带宽**（大头在缝对面 → 查可否预编译 / 族化）；
3. **先修通道再放量**（预编译没做完不开大预算）。

反面实证：冒烟收据已给出谱（帽 3 内 2/3 为 front 阻塞、routing 零次），未换动作即开正跑 → 2,259 次
以上来回。【项目实测】

**工况复审三触发器**：①输入密度变了（稀疏自产提案 → 塞满的设计布局）；②变量变常数了（布局钉死 →
front 占用可查表，**预编译窗口打开**）；③预算量级变了（**删失谱勿当真谱**）。

**与「从规则推条件性规则」的合流**：死因谱告诉你条件性规则该往哪推——**往死因大头、缝对面、可预编译
的那条约束上推**（实例：「本布局下 front 被占的口不可激活」）。

## E.11 双向保真公理（2026-08-07，第一条公理级）【owner 方法论裁决】

「守卫堵孔就放心」是错的——**把所有合法规则放进模型（防拒真）与堵孔（防纳伪）同等重要**。
此前本项目几乎无视拒真侧。

**技术形态**：在 `max_lex` 全局最优性证书之下，模型**过严 = 假证书**。四象限：

| | 见证半边 | 最优性证明半边 |
|---|---|---|
| **模型过严** | 安全（见证仍合法） | **假证书** |
| **模型过松** | 假见证 | INFEASIBLE 结论安全 |

**最危险的性质**：**过严的限制只产生「缺失的答案」，永远不会自曝报警。**

**制度化落法**：分类学增设 exclusion 层；规则形态轨加**完整性台账**（`model_stricter_faces` 升为
一等审计面）与**墙审计**（能力盘点对账 = 孔审计的对偶）；流程轨加**双向保真验收步**；对抗审查方回测；
决策摘要须含首轮墙审计排期。

**守卫批验收必答两问**：这条守卫堵住了哪些伪？它有没有连带挡掉合法的真？

## E.12 规则派生闭包公理（2026-08-07，第二条公理级）【owner 方法论裁决】

**规则系统是生成式的**：基础规则 × 派生组合出下一级；**解空间的塌点会结晶出新规则**。
**派生规则该被系统推出，而不是等人绊倒。**

**当场验算成立的样板 = 「5 满 1 半」条件定理**：在「钢块免分流」这个条件下，某类机器的分配唯一——
五条前提把每台的占空逼进 `{1/2, 1}` 两档、总量定 `k = 5`；而**无条件时仍是 42 维自由**。
**同一问题、两个层级、两个答案。**【项目实测】

**制度化落法**：派生规则**一等登记**（带前提集）；饱和扫描设卡点；塌点上报是设计义务；正负样板校核。
承重结论出厂前须做**组合扫描至饱和**。

**配套硬闸（2026-08-07 晚立）**：**解空间类问题上桌前先过推理关**——推得动就地出结论并附前提集；
推不动才升级，且必须**点名缺的最小前提**，不许裸递。
判例：一个「某类边界口设备该不该建模」的问题原本要上升为需实测裁决的悬案，用三行计数就地关案
（该类设备只能落在长度 139 格的边界条带上，46 台必备设备已占 138 格，再加 3 格 = 141 > 139，放不下
⇒ 任何合法布局都不含它 ⇒ 不建模它零拒真）。**该案的所有前提当时都在同一份文件里，只是没人做那个乘法。**
