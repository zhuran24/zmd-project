## §3 求解操作层（§0b 操作卡 ＋ APX_E 全集）

> 本层判据本体一律回 §0b 正文（主席文件）；APX_E 快照是其超集快照。逐项 essence 见 extraction A/B。

- **七问卡 ⓪-⑥**：锚点（预设卡在哪笔零余量账＋来源四分类价签）→ 切分（健全影子/精确本体/启发式残部）→ 住址（支撑域）→ 排序（实测拒绝成本门序）→ 耦合（目标耦合测试）→ 计量（拒绝率一等报警、fail-soft 不清零）→ 余量（~2% 时影子须加肥）。〔roadmap:95-118〕
- **两条不变式＋过堂**：早期拒绝带证书、早期放行皆暂定、终审归精确本体；新开管线必过堂留记录，「不适用」也要留痕。〔:120-129,276-278〕
- **归属体系**：四元组（切分/住址/管线序/下游验证人）；报警双向对称（踏车↑；白吃饭/超杀/越权↓）＋漏斗纪律；归属是 master 表示法的函数；层数与切口自身是被决定项（沿信息依赖边界下刀；两段式 master）。〔:132-174〕
- **cut 方法论**：cut＝知识的运输形态；打包三问（责任圈/可抬数量律/上层词汇）；四问双向统一；族终局三选一（毕业上收/真例外/前提证伪退役）；cut 必须带前件。〔:176-206,220-222〕
- **v2.3 公理群**：权威归属公式 owner(r)=max{owner(v)}；权威归属与表示归属不得混问；三极性登记（必要投影/充分限制/精确语义，可空不可混极）；主动挖对偶 micro-oracle；等式挖矿；双 ledger 汇报。〔:211-231〕
- **泛化与门内**：门序泛化到一切工作流（硬合并/硬后置同构对偶：47,666 与 W0 seed）；门内四则递归复用（G1 病例）；适用域尺度无关（v2.6 owner 拍板）；科学面与发布/治理面权威分界注。〔:233-282〕
- **v2.7 榫眼系**：榫眼定义与组合规则；余量审计表（系统性找法）；条件榫眼产率经济学与隐藏前提审计；自由两源与「用计算购买被迫性」；择愿五启发＋「主线是伸不是探」；撞车诊断二分修正；零余量第三读法（可判性/快速法庭）；切分质量两维度（回传带宽/工况相关性）＋先加粗通道不先挪刀＋死因谱×否决带宽的墙预言式＋拒绝日志缝健康仪表＋工况复审三触发器。〔:285-413〕

## §4 证明与发布纪律层

- **绿灯≠关门族**：checker PASS 只证登记结构未漂移；receipt＝informational_record_only；owner_manual_decision 是唯一关门权威；方法存在≠入口存在≠release closure；存在性不授予权威；表是义务索引不是证明；检查器 PASS 文案须自带「不证什么」（§1.9，未实施，挂账 A12①）。〔PROJECT_LOCK 多处；gate JSON；FIRST:140,371-390〕
- **认证边界族**：certified/exploratory 隔离；flow diagnostic-only；强状态由 sink 独立 replay；独立复验不得抄被验实现（front 事故 common-mode 条款）；`model_stricter_faces` 三键（欠账台账/usage_rule/completeness——不在册≠等价）。〔PROJECT_LOCK；canonical:431-433〕
- **freeze/pin 族**：pin 是身份声明不是校验和，mismatch 绝不好心更新；freeze-ritual 迭代法；reseal 四链按「谁钉了字节」穷尽（按旧 sha 值搜、不按常量名搜）；活 pin 与史料 pin 分账；事故修复作用域＝当时可达面，promotion 前重扫同族。〔28 号 SOP-1/2；CLAUDE/AGENTS §5-6〕
- **测试卫生族**：解释器能力闭包自检；--full 不含 slow、认证核心必配慢 lane；@slow 集中登记；-p no:randomly＋独立 basetemp；验收审计 skip；认证链跑批期间整树冻结；大工件缺失是硬失败；日志全量落盘；长任务 DONE 标记；prod-scale 单跑＋OS 真量测。〔CLAUDE/AGENTS §2-3〕
- **git 族**：共享工作区精确 pathspec 事务；amend 前核 HEAD；untracked 不构成安全存储；禁提交路径。〔CLAUDE/AGENTS §6-7〕
- **搜索族**：承重结论 git grep 起手（rg 有投影漏报）；全称否定穷尽同义搜索；集合成员资格用 import print 验证。〔CLAUDE/AGENTS §7；记忆卡〕

## §5 协作与外部输入生命周期（C 组实践考古主产出，此前零登记）

- **外部输入生命周期四段**（建议按此合流成一个规程）：**受控发包**（臂标识中性化＋字节等同证明、调度说明书不随包、必须全新会话、treatment 逐 hunk 登记、硬归因预限制、逐主题可比性分级、回件身份写进文件头）→ **消化纪律预登记**（回件抵达前写死各层内容的证据等级与可引用池；正式实验侧＝预注册指标与有利方向）→ **核签书**（定型模板：自计量头部统计（含严重级下调数/复算 FAIL 数/捏造引用数）、每行号回源、外审脚本本地复跑逐字节比对、受控裁决词表含 DOWNGRADED-IN-REPO（包装欠账与数学欠账分账）、核签席不改本体不 commit、验算件落 `adjudication_checks/`）→ **落档**（禁修清单防「顺手修」与再立案，RESULT 逐条报「未改」；打回件重发三件套：判决书全文＋编号对齐 ERRATA＋主动申报段，被否脚本不改字节只作废结论段）。
- **自包含包法则**：收包人只见本目录；材料状态列 ACTIVE/SUPERSEDED/FROZEN；权威序写死；名词碰撞消歧；外部硬性要求整段抄入；MANIFEST sha 机检。
- **席位编排型**：逐判据扇出＋异源对抗席＋单一裁决席；被审席可具名顶回；审查序＝依赖序之逆（未经验证的材料先被攻击再被使用）。
- **止损 checkpoint**：判死条件写进任务书，撞上即停批成文交 owner，不加预算硬闯、不自动滑进相邻轴；止损页固定形态（性质声明/待定事项/证据四档/三句话经过/对照表/候选路）。
- **其他**：空手而归必须是有界断言（负结论交覆盖表）；活标本制度（事故封存为病例喂给下一个设计席当校验用例）；裁决与研究文书的 append-only 留痕例外（「默认不留痕」的受限反域）；worktree 隔离批（手术停在 reseal 前、留接入批）；换尺子先复算旧数（量具校刻度、跨口径分账）。
