## 背景 — F9 数学不变量 (PROJECT_LOCK §3A 锁)

F9 density_envelope 是 area-based capacity-overflow cut, 限制 group `g` 在 window `W` (axis-aligned rect, 70×70 grid 子集) 内 area 不超 `max_allowed_area`:

```
sum_{cell ∈ W} 1[cell_owner[cell].group == g] <= max_allowed_area
```

cut 触发条件 (evaluator): **strict** inequality `占用_area > max_allowed_area`.

锁的几条:
- **area-only**: generator 只接 `area_capacity_overflow` witness; routing/binding/pcr_cut overflow reject (closed-set whitelist)
- **strict**: 等号不 cut
- **ghost-bound**: scope.ghost_rect_id == GHOST_AGNOSTIC reject; cert.ghost_rect_repr byte-equal state.ghost_rect
- **safe_ub**: validator 独立 recompute `|W| - |(ghost ∪ exterior ∪ cell_owner_other) ∩ W|`, cert.max_allowed_area 必 ≤ safe_ub (oracle 不可宣称更松的 bound)
- **canonical witness**: oracle_assignment_witness 必排序使 permutation-equivalent witness 产生相同 cert_hash (CutStore dedup)

跟 evaluator 对齐核心: validator recompute 必须用 **UNION** 语义 (set of cells), 不能 sum-with-overlap, 因 evaluator 是按 cell_owner 迭代 cell 自然去重.

我的 fix (`src/cuts/families/density_envelope.py:346-375` 当前):

```python
def _recompute_assignment_area_overlap(
    witness_pairs: Tuple[Tuple[GroupId, PoseId], ...],
    window_cells: FrozenSet[Cell],
    state: BState,
) -> int:
    """Return |Union(occupied_cells(p) for p in witness) ∩ W|.

    Per Gemini F9 round 1 BLOCKER fix: validator must use UNION semantics
    matching the evaluator (which iterates ``state.cell_owner`` keyed by
    cell, naturally deduplicated). Summation across poses double-counts any
    cell shared by two pose footprints, allowing the validator to accept a
    cut on inflated area while the evaluator never sees overflow on the
    same witness — LBBD would loop on identical solutions.

    Returns -1 if any pose lookup fails (validator treats as unsound).
    """
    from src.cuts.helpers.candidate_placements import find_pose

    occupied_cells: set[Cell] = set()
    for (g, p) in witness_pairs:
        pose = find_pose(state, g, p)
        if pose is None:
            return -1
        for raw_cell in pose.get("occupied_cells", []):
            if not isinstance(raw_cell, (list, tuple)) or len(raw_cell) != 2:
                continue
            cell = (int(raw_cell[0]), int(raw_cell[1]))
            if cell in window_cells:
                occupied_cells.add(cell)
    return len(occupied_cells)
```

Regression test (`test_validator_overlap_witness_union_not_sum`): 两 pose 共享 4 cells, SUM=18, UNION=14; max_allowed_area=14 → UNION 14 ≤ 14 不 strict, 必须 reject. SUM 会算 18>14 误 accept.

```python
def canonical_bytes_for_cert(payload: JsonDict) -> bytes:
    return json.dumps(payload, sort_keys=True, ensure_ascii=False).encode("utf-8")
```

```python
def _validate_assignment_witness(
    cert_dict: Dict[str, Any],
    state: BState,
    cert_group_id: GroupId,
    t0: float,
) -> Tuple[Optional[ValidationResult], Optional[Tuple[Tuple[GroupId, PoseId], ...]]]:
    raw = cert_dict.get("oracle_assignment_witness")
    if not isinstance(raw, list) or not raw:
        return _vr("schema_err", t0, "oracle_assignment_witness must be non-empty list"), None
    pairs: List[Tuple[GroupId, PoseId]] = []
    for idx, entry in enumerate(raw):
        if not isinstance(entry, list) or len(entry) != 2:
            return _vr("schema_err", t0, f"oracle_assignment_witness[{idx}] must be 2-element list"), None
        g, p = entry
        if not _is_non_empty_str(g):
            return _vr("schema_err", t0, f"... group_id must be non-empty str"), None
        if not _is_non_empty_str(p):
            return _vr("schema_err", t0, f"... pose_id must be non-empty str"), None
        if g != cert_group_id:
            return _vr("unsound", t0, f"... group {g!r} != cert.group_id {cert_group_id!r} (F9 single-group invariant)"), None
        group_state = state.groups[cert_group_id]
        if p not in group_state.pose_domain:
            return _vr("unsound", t0, f"... pose {p!r} not in group {cert_group_id!r} pose_domain"), None
        pairs.append((cast(GroupId, g), cast(PoseId, p)))
    group_demand = state.groups[cert_group_id].demand
    if len(pairs) > group_demand:
        return _vr("unsound", t0, f"oracle_assignment_witness total instances {len(pairs)} > group demand {group_demand}"), None
    counts = Counter(pairs)
    for (g_p, count) in counts.items():
        if count > group_demand:
            return _vr("unsound", t0, f"... pose {g_p[1]!r} count {count} > group demand {group_demand}"), None
    return None, tuple(pairs)


def _compute_safe_max_allowed_area(
    window_cells: FrozenSet[Cell],
    cert_group_id: GroupId,
    state: BState,
) -> int:
    """|W| - |(ghost ∪ exterior ∪ cell_owner_other) ∩ W|."""
    blocked_other: set[Cell] = set(state.ghost_cells) | set(state.exterior_blocks)
    for cell, (owner_g, _slot) in state.cell_owner.items():
        if owner_g != cert_group_id:
            blocked_other.add(cell)
    return len(window_cells) - len(blocked_other & window_cells)


def _recompute_assignment_area_overlap(
    witness_pairs: Tuple[Tuple[GroupId, PoseId], ...],
    window_cells: FrozenSet[Cell],
    state: BState,
) -> int:
    """|Union(occupied_cells(p) for p in witness) ∩ W|."""
    from src.cuts.helpers.candidate_placements import find_pose

    occupied_cells: set[Cell] = set()
    for (g, p) in witness_pairs:
        pose = find_pose(state, g, p)
        if pose is None:
            return -1
        for raw_cell in pose.get("occupied_cells", []):
            if not isinstance(raw_cell, (list, tuple)) or len(raw_cell) != 2:
                continue
            cell = (int(raw_cell[0]), int(raw_cell[1]))
            if cell in window_cells:
                occupied_cells.add(cell)
    return len(occupied_cells)


def evaluate_geometric_density_envelope(cut: Cut, state: BState) -> bool:
    """sum(|cells_of_cert_group ∈ cell_owner ∩ W|) > max_allowed_area (strict)."""
    if cut.geometric_payload is None:
        return False
    try:
        cert_dict = _parse_cert_payload(cut.geometric_payload)
        if cert_dict.get("cert_kind") != "density_envelope_v1":
            return False
        window_rect = _parse_window_rect(cert_dict.get("window_rect"))
        group_id = cert_dict.get("group_id")
        max_allowed = cert_dict.get("max_allowed_area")
        if not _is_non_empty_str(group_id) or not _is_strict_int(max_allowed):
            return False
        wx, wy, wh, ww = window_rect
        occupied = 0
        for cell, (owner_g, _slot) in state.cell_owner.items():
            if owner_g != group_id:
                continue
            cx, cy = cell
            if wx <= cx < wx + wh and wy <= cy < wy + ww:
                occupied += 1
        return occupied > cast(int, max_allowed)
    except Exception:  # noqa: BLE001 — fail-safe
        return False


def watcher_keys_density_envelope(cut: Cut) -> Dict[str, List[Any]]:
    """F9 watches: cells inside window + cert.group_id + window region id."""
    if cut.geometric_payload is None:
        return {"cell_keys": [], "group_keys": [], "region_keys": []}
    try:
        cert_dict = _parse_cert_payload(cut.geometric_payload)
        rect = _parse_window_rect(cert_dict.get("window_rect"))
        group_id = cert_dict.get("group_id")
        if not _is_non_empty_str(group_id):
            return {"cell_keys": [], "group_keys": [], "region_keys": []}
        x, y, h, w = rect
        cells = [(x + i, y + j) for i in range(h) for j in range(w)]
        region_id = f"density_envelope:{x},{y},{h},{w}"
        return {"cell_keys": cells, "group_keys": [cast(str, group_id)], "region_keys": [region_id]}
    except Exception:
        return {"cell_keys": [], "group_keys": [], "region_keys": []}
```

```python
def generate_density_envelope_cuts(
    state: BState, *, witness_kind: str, group_id: GroupId,
    window_rect: Tuple[int, int, int, int], max_allowed_area: int,
    assignment_witness: Tuple[Tuple[GroupId, PoseId], ...], iter_index: int = -1,
) -> List[Cut]:
    if witness_kind not in ACCEPTED_WITNESS_KIND: return []
    if group_id not in state.groups: return []
    if state.ghost_rect is None: return []
    if not assignment_witness: return []
    if (not isinstance(window_rect, tuple) or len(window_rect) != 4
        or not all(isinstance(v, int) and not isinstance(v, bool) for v in window_rect)):
        return []
    x, y, h, w = window_rect
    if h < 1 or w < 1 or x < 0 or y < 0 or x + h > 70 or y + w > 70: return []
    if not isinstance(max_allowed_area, int) or isinstance(max_allowed_area, bool): return []
    if max_allowed_area < 0: return []
    window_cells = _window_cells(window_rect)
    if max_allowed_area > len(window_cells): return []
    for (g, _p) in assignment_witness:
        if g != group_id: return []
    try:
        safe_ub = _compute_safe_max_allowed_area(window_cells, group_id, state)
        if max_allowed_area > safe_ub: return []
        recomputed_sum = _recompute_assignment_area_overlap(assignment_witness, window_cells, state)
        if recomputed_sum < 0: return []
        if recomputed_sum <= max_allowed_area: return []
    except Exception:
        return []
    try:
        cut = _build_density_envelope_cut(state=state, group_id=group_id,
            window_rect=window_rect, max_allowed_area=max_allowed_area,
            assignment_witness=assignment_witness, iter_index=iter_index)
    except Exception:
        return []
    return [cut]

    if state.ghost_rect is None: raise ValueError("...")
    ghost_rect_repr = list(state.ghost_rect)
    # Sort for canonical cert_hash
    sorted_witness = sorted([[g, p] for (g, p) in assignment_witness])
    cert_payload_dict: Dict[str, Any] = {
        "cert_kind": CERT_KIND,
        "witness_kind": "area_capacity_overflow",
        "window_rect": list(window_rect),
        "group_id": group_id,
        "max_allowed_area": int(max_allowed_area),
        "oracle_assignment_witness": sorted_witness,
        "ghost_rect_repr": ghost_rect_repr,
    }
    cert_payload_bytes = canonical_bytes_for_cert(cert_payload_dict)
    cert_hash = hashlib.sha256(cert_payload_bytes).hexdigest()
```

## Round 2 specific 攻击向量提示

请考虑这些 adversary scenarios:

### A. **Pose footprint vs cell_owner divergence**
master 求解后 fill cell_owner: 是不是按 selected pose 的 occupied_cells 复制? 我担心若 master 不按 pose footprint 而是按 instance-cell binding 直接 fill cell_owner, validator union-based recompute (查 candidate_placements pose 的 occupied_cells) 跟 evaluator (查 cell_owner) 仍可能 drift. **请 push 这个 issue**.

### B. **`occupied_cells` 内含 ghost / exterior cell?**
若某 pose 的 occupied_cells 跨 ghost 边界 (master 必 reject 这种 placement), validator union 会 count 这些 cell ∈ W. 但 evaluator iter cell_owner 时, ghost 内 cell 永远 不在 cell_owner. → validator 算多, evaluator 算少 → divergence. 是否 corner-case?

### C. **Multi-pose total demand redundancy**
total instance check 加在 per-pose check 之前: 若 `pairs = [pA, pA, pB]`, demand=2 → total=3 > 2 reject. 但 `pairs = [pA, pA]` demand=1 → total=2 > 1 reject; per-pose pA count=2 > 1 也 reject. 两 check 一致. 移除 per-pose 安全吗? (minor — 不必修, 但 sanity check)

### D. **Sort 在 list of mixed-type 不稳**
witness entry 是 list-of-list-of-str (`[[g, p], ...]`). 全 str → lexicographic sort, OK. 但若 cert 含混合 entry (1 个 list 1 个 tuple?) — schema 严格 list, generator 端 sorted([[g, p] ...]) 显式 list comprehension 必生 list. 安全.

### E. **`find_pose` 在 pose_domain 通过但 pool 不含**
若 `pose_domain` 含 p 但 `candidate_placements["facility_pools"][ft]` 没 p → find_pose 返 None → recompute 返 -1 → unsound. 但 cert 已通过 `_validate_assignment_witness` (那只 check pose_domain, 不查 candidate_placements). 那 generator end: oracle 自己也调 _recompute, 若 find_pose 返 None 直接 [] — sound. validator 后端: unsound 报错 message "pose not findable in state.candidate_placements" — semantically 是 state inconsistency, 不是 cert 假, **报 unsound 对吗?** 还是应该 schema_err / 或 state_drift?

### F. **F9 是 ghost-bound, 但 watcher 不监 instance_to_facility_type / candidate_placements drift**
若 candidate_placements 在 cut emit 后 change (e.g. add pose), 已 dedup 的 cut 会 stale 吗? F9 cut scope 含 source_digest + artifact_hashes — 这些应监 candidate_placements 变. 我不查 lifecycle 不知道. **如果有 candidate_placements drift attack surface 请 flag**.

### G. **Validator ↔ Evaluator semantic alignment**
Validator union 基于 `find_pose(state, g, p).occupied_cells`. Evaluator 基于 `cell_owner[cell].group == g`. 二者 align 前提: **master 选 pose p for group g 后, cell_owner 必精确 fill = {(cell, (g, slot)) for cell ∈ pose.occupied_cells}**. 若 master 用别的 binding scheme (e.g. instance-cell partial assignment), 不 align. 这是 spec 假设 — round 2 你判断 spec contract 是否够强?
