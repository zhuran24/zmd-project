## 二、闭合算术（对机身需求 3,325 格）

- **evaluator 读法**（最乐观：各族同时打满实测极值）：不带孔 16×138+7×126+110 =
  3,200；孔放实测最优处（CORNER，代价 25）= **3,175，缺 150**。
  反推更硬：即使 CLEAN 全部打满已证上限 146、边界按实测 126、孔放 CORNER，
  需 CLEAN 均值 (3,325−882−85)/16 = **147.4 > 146**，与已证上限矛盾；孔放 CLEAN
  （15×146+110+882+110=3,292<3,325）或边界（需边界带孔 ≥123，而 171−123−42−4=2 格
  装不下任何 front 集）同样矛盾。
- **strict 读法**：16×120+805+109 = **2,834，缺 491**（未计孔洞代价）。

**结论的准确表述**：若实测平台即真极限（**未证明**——除 CORNER 带孔 85 外均无
不存在性证明），则本限制档位（八条 R-*）在两种读法下都够不着 3,325，G1 的
INFEASIBLE 是关于本档位的真结论、非仅 catalog 薄——证据显著压向「松绑」方向。
把该结论变成定理所缺 = 逐族健全上界；推翻它所需 = 超过平台的构造。两者均已
