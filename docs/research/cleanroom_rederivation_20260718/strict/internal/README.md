# Strict Clean-Room Experiment

This directory records experiment controls that must not be shown during the two independent derivation rounds.

The paste-ready Round 1 package is the sibling `external/` directory. Its bytes are generated by `scripts/cleanroom_strict/generate_bundle.py`; `--check` verifies both determinism and the leakage gate. Round 2 is staged here and must be used in a brand-new GPT Pro conversation only after the unedited Round 1 response has been saved and hashed.

The independent validator accepts a concrete layout witness and reports `LAYOUT_FEASIBLE`. That wording is deliberate: the validator recomputes the layout's objective but does not accept or certify an arbitrary global-optimality proof. It is pinned to the released `problem_instance.json` SHA-256 `e08a163336edf73e1b5c866034a73662a98870bbcd90a8bba4e8f7b32fca849c` and rejects replacement instance bytes even when a replacement witness is self-consistent. The validator and witness schema remain withheld through both derivation rounds.

## Controlled Sequence

1. Use Temporary Chat or an equivalent isolated session. Disable Memory, custom instructions, connectors, and web browsing; record the model snapshot, date, reasoning setting, tool state, and any control that could not be disabled.
2. Run the bundle generator with `--check` and verify `external/SHA256SUMS`; the check also rejects any unexpected file in `external/`.
3. Start the isolated GPT Pro conversation and paste only the external files.
4. Save the raw Round 1 answer without editing and record its SHA-256 digest.
5. Start a second isolated conversation with the same controls and paste the same external problem data plus `R2_prompt.md`. Do not include Round 1 text, critique, or repository material.
6. Save and hash the raw Round 2 answer.
7. Release the witness schema, validator, adjudications, and comparison rubric for internal evaluation.

No current candidate-placement artifact, solver source, historical architecture name, or result is part of either external prompt.
