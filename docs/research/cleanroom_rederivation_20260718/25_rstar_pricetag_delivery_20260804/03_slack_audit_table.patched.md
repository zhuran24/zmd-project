## C. 读这张表时必须守住的三条口径

1. **「67 格 / 2.0%」是危险度读数，不是价签**：它回答"离墙多近"，不回答"扔掉了什么"。
   本次任务要的是后者。
2. **catalog 口径 ≠ 解空间口径**：`2,749`、`3,113`、`244`、`220` 都是"我方已经造出来的那批
   局部 pattern 列"上的账，不是"该限制档位下一切合法 pattern"的健全上界。
3. **上界读数 ≠ 可行 witness**：`129/134` 是 packing 级上界读数；`101` 是机器证死的
   loose valid 天花板。已证命题是"面积账对真实天花板至少虚高 28 格"，**不是**"真能装 129"。
