## 1. 两个新证书（均已复算）

### 证书 A：供电光环 → P≥9

14 轨道权重 stencil（半格中心切比雪夫轨道，倍权整数算术，总权重恰 **396**）；**840 个**与杆覆盖 [-5,6]² 相交且不压杆体的制造机 placement（180+220+220+220，与断言逐个吻合）全部满足 Σλ(F)≥|F|（复算零违例）。记账论证：每台受电制造机记给任一覆盖它的杆，同杆设施 body 两两不交且 λ≥0 ⇒ 该杆名下总面积 ≤396 ⇒ 3,325 ≤ 396p ⇒ **p ≥ ⌈3325/396⌉ = 9**。论证结构自含（无 solver 状态依赖），已达 certified 级。权重来源是对称化局部 LP 对偶，但有效性只依赖 840 条精确不等式——**对偶只是找权重的方法，验证是初等的**。

### 证书 B：端口膜 → (1190,34)

链条：制造机口"输入一侧/输出恰在对侧"（strict 全模板全 mode 核实）⇒ 空矩形至多邻接对侧之一 ⇒ 每台入矩形端口 ≤ max(I,O)；(s,a) 八类表（155/12/11/32/17/32/3/3，复算逐字全中）full-contact excess=**63**；端点跨越接触 ≤8 个、每个额外 ≤3 ⇒ +24；⇒ 2K−L≤87、L≤2(w+h) ⇒ K≤w+h+43；核心出口 3+3 分侧（核实）+2 最终品 ⇒ U=w+h+48；矩形外接驳容量每格 ≤4（无同格同向双口，核实）⇒ 外部自由格 ≥⌈(580−w−h)/4⌉；叠加 P≥9（36 格杆体）⇒ **wh+⌈(580−w−h)/4⌉ ≤ 1320**；双实现全维扫描 lex-max = **(1190, 34)**（34×35；面积并列的 17×70 短边劣）。

## 3. 方法论批判面（M1-M6 的六条修正——元层增量）

1. **语义 ledger 取代单一归属**：每条规则三极性登记（必要投影/充分限制/精确校验），可空但不可混——比我方 v2.2 与 R2 的 owner=max scope 更进一步的三极分离；
2. **cut 必须带前件**：`antecedent ⇒ repair disjunction`——纯正极障碍集不得做几何 cut（我方 I1 纪律的强化版：cut 失效条件显式化）;
3. **主动挖举证书取代被动踏车**（对 M3 最重的批判）：不等踏车报警，直接解局部对偶小问题挖不变量——光环证书就是这么来的；**等式挖矿**：全局不等式近紧时每条成分不等式都是结构约束源；
4. **micro-oracle 阶段插入漏斗**（840 放置的局部问题比任何全局模型信息量大）；
5. **证明信任三段化**：领域证书/proof checker/witness checker——"完美证明一个误译模型仍是错证明"（我方 translation gate 纪律的独立重推）；
6. **双 ledger 汇报**（下界账/上界账分开，相遇才是 optimal；资源中止不改变数学状态）。
