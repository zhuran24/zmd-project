## 对悬空点的落定（A7 边界注记 / 残余 5.2#6 / P-c）

1. **「同商品多口并联可加性」**：同一商品在一台机上只有**一个槽**（容量 50），
   但落位判据是「槽未满」而非「每 tick 一件」——**瞬时**上双带同时喂同一槽合法；
   **稳态**受配方消耗率钳制（槽满 → 组内互斥 + 满容整节点拒收 → 两条带一起堵）。
   即「双带并联 = 2×30/min 持续进货」不成立（长期均值 ≤ 配方消耗率），
   「第二条带完全无用」也不成立（50 容量缓冲平滑突发/断供）。
2. **对认证谓词 (4) 的含义**：`slots=ceil(rate/cap)` 的口数换算是**需求侧带数
   下界**，机器侧多口共享同一 buffer、不构成额外上限——换算方向安全，
   组内互斥不会让同商品第二条带被结构性拒收（唯一钳制=满容，而稳态满容
   = 下游消耗不足 = 本来就是超供形态）。A7 边界注记的「悬空」可降级为
   「模拟器侧已闭、游戏终审待 owner」。
3. **P-c 判别实验的模拟器侧预答**：双带并联进货率非简单相加、受
   槽容量+消耗节拍钳制；若做游戏实测，预期 1 分钟入货量 ≈ min(60, 消耗量+50-初始)。
