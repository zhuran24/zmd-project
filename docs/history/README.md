# 历史快照目录

本目录保存已经退出当前职责的入口页、状态页和主题投影。它们回答“当时文档怎样描述项目”，不回答“项目现在是什么状态”。

当前查询请从以下入口开始：

- [当前机器与知识状态](../CURRENT.md)
- [任务式导航](../START_HERE.md)
- [claim、decision 与 dossier 总目录](../CATALOG.md)
- [当前开放问题](../OPEN_QUESTIONS.md)
- [当前文档职责索引](../GUIDANCE_INDEX.md)
- [当前文档分区](../SECTION_INDEX.md)

## 快照族

| 快照族 | 内容 | 使用边界 |
|---|---|---|
| [status/](status/README.md) | 知识脊柱启用前的根入口、文档入口和状态页原文 | 引用时必须检查后续 decision、claim 和机器状态 |
| [subjects/](subjects/README.md) | 旧的人工主题投影和完整性报告 | 只用于追溯旧主题结构，不作为自动同步或当前 completeness 证明 |
| [navigation/](navigation/README.md) | 退出职责的局部索引、架构图和知识树 | 通过 successor 返回当前 section、knowledge 或 framework 入口 |
| [deliveries/](deliveries/README.md) | 冻结的 IndustrialPlanner adapter delivery 说明 | “current” 只在历史 delivery 内有效，不代表当前 solver 或认证状态 |
| [convergence/](convergence/README.md) | 第三阶段职责收束前的现行文档原文 | 用于追溯被移除的批次状态、哈希和收据，不作为 current guide |

历史快照的原始正文原则上保持原字节；允许在文件头添加归档说明。若因移动目录导致相对链接失效，应按快照说明中的“原路径”解释。新归档必须有明确来源路径、归档日期和退出当前职责的原因。

- [形式化验证旧说明](formal/README.md)：退出当前入口职责的逐定理清单与审阅叙事。
