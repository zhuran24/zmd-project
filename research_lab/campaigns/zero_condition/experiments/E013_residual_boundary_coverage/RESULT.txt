Transport and quotient
----------------------
E013 starts from E010's 196 exact mismatch-component observations. Each named
boundary owner is transported to the pose-bool consumer object that can actually
change placement:

  mandatory owner -> operation-group pose literal
  optional owner  -> template-pose literal

The transported atlas contains 313 distinct consumer literals. For the set-cover
question only, literals touching exactly the same observation set are quotiented
into 151 coverage-equivalence classes. This quotient does not claim that class
members are interchangeable in placement or power.

The small-budget optimum is not power-pole dominated. At budgets 1, 2, 4, and 8,

New inner partition
-------------------
The next research neighborhood should not be pole-only and should not be one
spatial window. The problem-derived object is a dispersed portfolio of current
operation-group pose literals, with optional poles retained where they occur:

  fixed outside group/optional poses
  -> bounded dispersed release set
  -> exact placement and power repair
  -> fresh static-port and component-aware binding
  -> exact routing only after component support survives

Before building a large joint placement-binding encoding, the cheapest faithful
probe is to test which selected high-coverage literals are actually movable under
fixed outside geometry. Coverage is only an optimistic causal upper bound; a
literal may be locked by packing, group cardinality, or power.

Latent project issue
--------------------
The corrected transport exposes a broader version of the old partition problem.
Residual component failure is not owned by one facility family. Manufacturing
poses and power poles jointly form the boundaries, while the master sees mainly
placement, overlap, and power semantics. Binding sees terminal choice only after
those boundary decisions are frozen.

The missing layer is therefore not a special power-pole optimizer. It is a
bounded cause-bearing bridge from group-pose geometry into component-aware
terminal feasibility.

Truth boundary
--------------
Boundary touch does not prove that moving a literal repairs an observation.
Maximum coverage selects a candidate neighborhood; it is not a sound cut, a
sufficiency theorem, or evidence that every selected literal has an available
replacement pose.

Decision effect
---------------
E014 should first run exact fixed-outside mobility arms for the high-coverage
portfolio. Every feasible repaired geometry is immediately scored by actual
front-filtered binding domains and exact per-commodity component mismatch. If the
portfolio has little mobility or cannot improve the interface, the next model
must make selected pose and binding variables cohabit rather than widening a
scalar placement search.
