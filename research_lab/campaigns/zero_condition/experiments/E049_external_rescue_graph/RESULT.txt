instance IDs. That comparison is type-invalid and can never discover an edge.

Architecture effect
-------------------
E048 did not show that simultaneous body pairs lack value. It showed that a pair
language built only from complete fixed-outside actions and selected-set rescue
edges was incomplete. E049 exposes the missing feedback object:

  dead source action
    -> structured empty-owner set
    -> conditional rescue relation
    -> owner pose domain under the source move

This object is richer than a point nogood and narrower than a global native
geometry model. It can propose body sets from actual causal ownership rather than
mere boundary incidence.

The diagnostic schema itself must preserve owner records as structured data. A
stringified mapping is unsuitable for equality, joins, graph construction, or
consumer transport.

Decision effect
---------------
Carry the three rescued pose states into the faithful objective-144 middle layer.
The context compiler must compare pose changes relative to the immediate parent,
allow one or two occupied-body changes, and enable same-body modes at both changed
instances. Each frozen ordinary endpoint must calibrate before port mode,
operation assignment, and binding are released.

A strict joint value below 144 becomes the new leading state. Equality or harm
means the rescue relation is useful for admission but not continuation value and
pushes the work toward a broader native simultaneous geometry context. Objective
zero enters exact routing immediately.

Truth boundary
--------------
E049 tests eight clean external edges selected from E047's 94 frozen dead actions,
one representative source action per edge, and every exact owner alternative
under that source move. It does not exhaust multi-owner rescue, all external
owners, all source actions, every body pair, or native simultaneous pose domains.
Objective 143 is an ordinary fixed-assignment proposal value, not a final geometry-
conditioned value, component-compatible binding, routing witness, lower bound, or
certified claim.
