====================================================

Question
--------
For E062's physically distinct manufacturing-6x4 near miss, what is the complete
qiaoyu-hard objective-one presence face, and what causal object set does that face
actually justify for the next second-object search?

Method
------

2. Locate the unique legal alternative `grinder_dense_source_002` pose 6878 and
   verify it matches the frozen E065 E062 near-miss identity.
3. Rebuild occupied/free components, candidate-specific generic qiaoyu sink slots,
   and every current manufacturing-6x4 native target signature.
4. Reproduce qiaoyu-hard minimum fine mismatch one.
5. Enumerate the complete objective-one presence face by no-gooding only source,

6. Derive the union and intersection of unmatched components and a causal object
   inventory: multi-component boundary owners of the complete-face union, all
   current manufacturing-6x4 bodies, and every generic-input provider.
7. Materialize the parent solution and typed face/selection object for the next
   consumer instead of forcing it to reconstruct the same knowledge.

Decision rule
-------------
Complete face has one stable unmatched component
  Build a targeted second-object frontier around that component and target
  terminal family.

Complete face has several alternatives but is substantially narrower than the
retired pole parent
  Build a complete-face-derived second-object frontier, preserving face identity
  rather than one representative.

Complete face is broad or crosses incompatible qiaoyu sink regimes
  Do not copy E063's action language mechanically. First derive a narrower
  relation or consider another first-zero geometry.

Any UNKNOWN or incomplete face
  Preserve the nonterminal object and do not select a causal action set from an
  incomplete surface.

Truth boundary

state and evaluates the corrected target-signature relaxation. It does not change
