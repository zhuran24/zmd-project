Role language
-------------
E089 defines 32 label-independent atomic roles using:

  * distance to the y=41 seam;
  * distance to top/left/right grid boundary;
  * distance to protocol-core body and reserved terminals;
  * distance to the 52 inherited fixed-pole bodies;

Template and demand-class strata remain visible in the result. They are not
hidden inside one aggregate score.

Train-only selection
--------------------
Using training labels only, E089 exhausts unions of at most four atomic roles and
requires the union to cover at most half of the B universe. The exact objective is
maximum training coverage, then minimum universe coverage, then minimum number of
roles, then deterministic role identity.

The best admissible union is:

  core_gap:3_5
  fixed_pole_gap:6_9
  manufacturing_pressure:q1
  seam_gap:0

It covers:

  universe candidates       2,088 / 4,353   47.97 percent
  training failures            68 / 95      71.58 percent

The predeclared training target was 76/95, or 80 percent. The best possible union
inside the cap misses it by eight failures. Therefore the result is already
`SPATIAL_ROLES_TOO_DIFFUSE` before holdout labels are consulted.

Temporal holdout
----------------
After selection is frozen, the same four roles cover:

  holdout failures             52 / 83      62.65 percent
  all registered B failures   120 / 178     67.42 percent

The holdout target was 67/83. Later failures are less concentrated than the
training cohort, not more.

Stratum reading
---------------
Selected holdout coverage differs materially by template:

  3x3    38 / 50 holdout failures
  5x5     7 / 14 holdout failures
  6x4     7 / 19 holdout failures

The strongest apparent spatial signal is therefore not a uniform module-B hazard
zone. It is partially cohort- and template-dependent, with especially poor
transfer to later 6x4 failures.

Interpretation
--------------
E088 showed that rule shape is either too broad or too fine. E089 now shows that a
small stable spatial region does not rescue the same geometry language. Even the
best four-role union consumes nearly half of all B candidates while missing more
than one quarter of training failures and more than one third of future failures.

This is the predeclared stop condition for the fixed-52-plus-one-replacement
module-B geometry. Continuing to add point rules, changing one threshold or
running another seed would preserve the same representation after both its shape
and spatial compression tests failed.

Non-implications
----------------
E089 does not prove:

  * the y=41 operation partition infeasible;
  * module B globally impossible;
  * any candidate outside the selected regions feasible;
  * any candidate inside them infeasible;
  * all wider pole languages necessary;
  * a different partition better;
  * any terminal uniqueness, binding, routing or throughput property.

Effect on the next problem
--------------------------
Retire the bounded language that freezes 52 inherited poles and allows only one
replacement in the y=41 module-B constructor. Do not run a sixth candidate search
inside it.

The next experiment must be deliberately wider and must separate two hypotheses:

  1. pole rigidity is the obstruction, so allowing a bounded multi-pole repair
     makes native-front-feasible B geometry constructible while retaining the
     partition;
  2. the straight y=41 partition itself is the obstruction, so even wider pole
     mobility cannot make its B bay support the required front roles.

The cheapest honest discriminator is a nested relaxation comparison using the
same body/front language: first allow a small explicit multi-pole repair budget
while keeping y=41; only if that remains front-dead should the experiment move to
another E081 Pareto partition or seam geometry. Any positive must materialize the
body, pole and operation/mode endpoint before terminal uniqueness and
component-aware binding.

Truth boundary
--------------
This result is a temporal predictive failure of a fixed role language. It changes
the continuation budget and representation; it is not a mathematical
infeasibility theorem for the layout problem.
