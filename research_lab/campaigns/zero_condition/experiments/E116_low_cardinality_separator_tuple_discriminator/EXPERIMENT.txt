EXPERIMENT E116: LOW-CARDINALITY SEPARATOR-TUPLE DISCRIMINATOR
================================================================

Question
--------
Do any of the twelve exact separator class tuples inside E115's five lowest-
cardinality UNKNOWN template states admit the complete source-stable x42-high
native-front consumer?

Exact target set
----------------
E115 externalizes five UNKNOWN parent states with at most three E112-positive
separator class tuples each:

  separator template 0/0/0   1 tuple
  separator template 0/0/1   3 tuples
  separator template 0/1/0   2 tuples
  separator template 0/2/0   3 tuples
  separator template 1/0/0   3 tuples

Total: twelve exact eight-coordinate tuples.

Why this experiment
-------------------
E115's seven-second state models still contained a separator-class disjunction.
Uniformly adding time to all 25 UNKNOWN states would repeat the same instrument.
E116 removes that projection choice while leaving all 1,205 E103-live body
geometries, all same-footprint modes, the remaining high class allocation and
all cross-group interactions free.

Method
------
1. Pin E115's UNKNOWN packet and rebuild its exact state model from source-stable
   E095/E100/E101/E115 bytes.

2. For each of the twelve tuples, build a fresh full high-side model, fix the
   three separator template totals and every one of the eight separator class
   count variables, and preserve E112's allowed table as a redundant identity
   guard. E110's representative body geometry remains only a hint.

3. Solve first with a one-worker PSEUDO_COST profile. Retry only UNKNOWN with a
   fresh eight-worker AUTOMATIC_SEARCH model having the identical feasible set.

4. A high-side positive is sent immediately to E101's unchanged x42-low exact
   complement. A paired result is combined with E095's frozen module-A witness
   and independently replayed over all 219 manufacturing bodies.

Decision rules
--------------
Paired 219-body replay PASS
  Advance to terminal uniqueness, generic I/O and component-aware binding.

High-side tuple positive without a paired low result
  Preserve its exact geometry and high allocation. Continue only the allocation
  handshake for positive tuples before returning to broad state search.

All tuples of one parent exact INFEASIBLE
  Promote only that parent separator template state to an exact contextual
  negative.

Tuple UNKNOWN
  Remains local. It prevents parent-state closure and creates no rule.

Truth boundary
--------------
The twelve tuples cover only five E115 UNKNOWN states. Parent-state negatives are
contextual to manufacturing-free x42, E103's live-row filter and the fixed E092
skeleton. No routing, throughput, certification or U/L effect follows.
