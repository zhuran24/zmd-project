Latent problems exposed
-----------------------
A. Implicit object-space transport

  Historical certificates can name symmetric mandatory instances while the
  pose-bool consumer acts on quotient group-pose occupancies. A true certificate
  does not automatically authorize that lowering. New outer-loop judgments
  should prefer the consumer's semantic literal space or carry an explicit
  transport proof.

B. Misleading layout-difference metric

  Named-instance pose churn is not invariant under symmetric extraction, while
  pose-derived optional IDs can hide a physical move as deletion plus addition.
  Group-pose set difference is the faithful comparison for this representation.

C. Unsafe native checker surface

  OR-Tools 9.15 with Python 3.13 reproducibly SIGSEGVed inside
  cp_model_helper when ConstraintProto.has_linear() inspected the last constraint
  of this large model. The same call worked on a toy model and raised no Python
  exception on failure. Large-proto native child inspection must not be used as a
  fail-closed checker surface without an isolated crash boundary. E001 replaced
  it with pinned consumer source, distinct resolved variables, and exact
  constraint-count delta.
