研究惯性复盘
============

总判定
------
没有完全陷入研究惯性，但已经出现过两段明显的惯性带，并且当前仍有三种高风险惯性。
真正的突破几次都来自“退一步重新审查对象和接口”，不是来自把同一种搜索再跑久一点。

为什么不能说已经僵死
--------------------
这段时间内，问题语言实际发生了多次不可逆变化：

  point nogood
    -> static port-domain compilation
    -> aggregate binding resources
    -> component-aware shared binding
    -> beam state / action-value ledger
    -> operation-to-footprint assignment
    -> assignment-binding cohabitation
    -> native conditional owners
    -> body footprint / port mode 分离
    -> geometry-conditioned joint value
    -> structured rescue relation

每次变化都有旧表示无法解释的新数据，不只是换名字。E038 的伪增益被主动拒绝，E027、
E033、E046、E048 也都按照预设 stop signal 停掉了原动作语言。这说明研究仍能推翻自己。

已经出现的惯性带
----------------
1. E015 到 E027 的 unary/beam 数值爬坡。
   我一度连续问“再释放哪一个 literal 能把总和再压一点”。虽然它最终逼出了 beam、
   action-domain 和 simultaneous pair，但 E017 出现十二路并列时，其实已经提示应该更早
   转 joint model。E027 才正式结束 unary，偏晚。

2. E044 到 E048 的 singleton -> singleton -> pair -> pair revaluation。
   这段有明确停止阈值，因此没有无限延长，但工作形状开始重复。E048 得出 pair language
   饱和后，本来准备直接造 native simultaneous model。真正的 139 突破却来自回头检查
   E047 没被消费的死亡诊断，说明我们当时的注意力已偏向“扩大邻域”，而不是“旧数据
   是否在接口中被压坏”。

当前最危险的三种惯性
--------------------
1. 指标惯性。
   shared mismatch 已从 200 降到 139，但 19/19 commodities 始终全部为正，routing solve
   进入次数仍是零。总和持续下降不等于正在接近 component-compatible binding。下一轮
   不能只以 139 -> 更小为成功，还必须观察 positive commodity count、是否有商品归零、
   最大 mismatch 或直接 feasibility 是否发生结构变化。

2. 单一谱系／局部盆地惯性。
   E015 以后几乎所有状态都沿同一 E009/E024 祖先局部变形。我们越来越擅长优化这一
   盆地，但尚未证明这个盆地靠近零。应当保留当前 139 线，同时让一个异源 constructor
   或 native simultaneous geometry context 产生真正不同的 occupied-body state，防止把
   “在当前盆地继续下降”误认成“全问题正在闭合”。

3. 实验装置惯性。
   E038 的 post-build owner 漏阶段、E040 的 hash drift、E046 的续跑缺陷、E048 的 parent
   对象错位、E047 的 stringified-owner transport，都来自重复复制 campaign-local runner
   和 context reconstruction。最初避免过早平台化是对的，但这些机制现在已经重复承重：

     structured cause
     immediate-parent geometry delta
     conditional owner/mode registration
     calibration before free solve
     endpoint materialization
     joint continuation valuation

   它们已达到应从单个 E-number 中抽出为可复用 research method 的阈值。继续复制脚本会
   让隐藏接口 bug 的增长速度超过研究收益。

还有一个 proposer 偏置
----------------------
coverage 和 edge frequency 多次被证明不是价值函数。E049 最强的 139 关系只出现两次，
而频率更高的边只到 147 或更差。今后 coverage/frequency 仍可缩小候选集，但必须加入
“因果类型新颖性、owner 关系结构、是否跨当前选择集”等维度，不能总是优先高频高覆盖。

当前方向判断
------------
E049/E050 是一次真实的脱离惯性，因为它没有继续扩大 pair，而是回看旧死亡数据的运输。
但不能把“再挖下一批 rescue edge”本身变成新的惯性。

下一轮至少要同时满足两件事：

1. 从 139 endpoint 继续结构化 cause/rescue，只在产生新的关系类型或显著改变
   positive-commodity 结构时保留该线。
2. 开始把 native simultaneous geometry context 变成真实 consumer，让若干 body 的 pose
   domain 在共同 outside occupancy 下生成，而不是继续由外环枚举完整动作。

若下一批实验只是把总和从 139 再压几单位、19/19 仍全正、routing 仍为零，并且没有
新规则语言或新 consumer 出现，就应判定当前线已进入研究惯性，停止继续沿该谱系爬坡。
