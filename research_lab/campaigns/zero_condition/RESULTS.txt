R-ZC-000  Repeated point nogoods do not transmit the observed death family
--------------------------------------------------------------------------
status: measured
scope: fixed-layout binding/routing experiments under their frozen contexts

statement:
  Phase-minus1 v1 observed 7578 exact routing-precheck failures across nine fixed
  layouts. Every event was front_blocked and the actual feedback was a 285-literal
  full-selection point nogood. The feedback changed the next binding selection,
  but the next selection remained FEASIBLE and returned to the same death family.
  The v2 deep arms added 26508 more front_blocked events over three approximately
  eight-hour runs and still entered exact routing zero times.

non-implications:
  This does not prove any complete fixed layout infeasible. It does not prove a
  particular local signature is a sound placement cut.

effect on next problem:
  The binding-to-routing interface itself is a research object. Additional point
  enumeration is not the default answer to repeated front-blocked evidence.

evidence:
  tracked phase-minus1 verdict and v2 protocol; local V2_RUN_SUMMARY identity in
  INPUTS.txt.

R-ZC-008  Three hidden representation/checker hazards are now explicit
-----------------------------------------------------------------------
status: reproduced or mechanically demonstrated
scope: current pose-bool research pipeline and E001 instrumentation

statement:
  First, a certificate naming symmetric mandatory instances does not directly
  inhabit the pose-bool consumer's group-pose literal space; an explicit
  permutation-invariant transport is required. Second, named-instance churn is
  not a representation-invariant layout distance, and pose-derived optional IDs
  can hide a move as delete/add; group-pose set difference is the faithful
  measure. Third, OR-Tools 9.15/Python 3.13 reproducibly SIGSEGVed in
  ConstraintProto.has_linear() on the large E001 model while the same API worked
  on a toy model, so native proto-child introspection is not a safe in-process
  fail-closed checker surface here.

non-implications:
  The native crash does not imply CP-SAT solve unsoundness. The object-space and
  distance findings do not invalidate the source pocket theorem; they constrain
  how it may be consumed and measured.

effect on next problem:
  New judgments should use group-semantic literals when the consumer has already
  quotiented symmetry. Layout comparisons should report group-pose deltas.
  Native model introspection used for critical checking must be isolated or
  replaced by safer construction evidence.

evidence:
  E001 lowering audit sha256
  0c67f9272b8ab42f43ebb1e13e440438df91242eb8f7dca3d772ba7011e0642c;
  two kernel coredumps from the failed audit attempts; E001 RESULT.txt.

Current synthesis
-----------------
The campaign has crossed the threshold from "collect more deaths" to "change the
interface language". The evidence already supports this ordered conceptual
split:

  static port-domain compilation
    -> component-aware binding

Placement-level feedback should carry the smallest obstacle cause that survives
independent replay. The final physical layer count and feedback families remain
open and are to be derived from the next candidates.
