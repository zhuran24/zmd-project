No detailed multi-step plan is frozen. The current replacement has already
located the first interface wall at component support, not front occupancy or
duplicate terminal keys. Commodity minimization then produced the stronger 19/19
result, so commodity-by-commodity cut mining is no longer the default move.

The differently shaped mismatch objective has now confirmed that all 19
commodities remain fragmented even when binding optimizes for one commodity at a
time. The observed optimum boundaries are mixed: many have only 3 to 10 owners,
while components touching the main 405-cell region can have 154.

E005 has selected the representation fork. The one-cut repair changed only three
old components into two new ones; 95 exact components and their boundary semantics
survived. Geometric symptoms repeat, but full causal motifs remain a long tail.
The existing F4 cannot consume the actual object.

E006 has now produced the candidate rather than merely proposing the proxy. The
first monolithic objective solve spent its budget in presolve; the same semantic

where the knowledge belongs from which solver container can consume it.

The real-interface test and comparative atlas are now complete. E006 improves
component topology broadly but worsens ordinary port-domain survival. This is not
a reason to discard permeability; it proves the two resources share placement
variables and must eventually be optimized together.
