# 规则模型

把《明日方舟：终末地》游戏规则.txt（仓库根目录，下称规则文件）写成 Lean 4 代码。代码就是规则要表达的那个模型：规则文件的每个名词在这里有一条定义，规则没写清的地方在这里写不下去，写不下去的地方记在 [边界清单.md](边界清单.md)。

状态：刚起步。已经有配方、时间单位、两种轮询，和不带格子坐标的通道、元件、运输带、终点、终点的时刻、次序；端口、物品格、组和级别、判定顺序、一步怎么走还没写。哪些名词有了定义，用 `python3 查名词.py -v` 看。

## 怎么跑

Lean 4 经 elan 装在 `~/.elan`，版本由 `lean-toolchain` 定（v4.35.0），不依赖 Mathlib。

```
cd 规则模型
lake build              # 编译全部模块；定理在这一步检查，回放里的 #guard 对不上就编译失败
python3 查名词.py -v     # 每条声明和规则文件对得上吗；还有哪些名词没写
```

## 做法

1. **只存游戏里原本就有的东西，其余都算出来。** 存的是：建了什么、建在哪、建的先后、各项设定；每个物品格里的物品和它停了多久；轮询记着什么；制造进度；物品准入口的计数。通道、接通先后、元件、运输带、终点、次序、组、级别都写成从这些算出来的函数。规则里最容易藏东西的就是这些算出来的量，直接存一份就把它们藏回去了。
2. **每个函数对所有输入都要有结果，不留逃生口。** 不用 `partial`、`sorry`、`panic!`、`get!`，不拿默认值顶替「不会发生」。写到哪一步写不下去，那里就是一条边界，归到四类之一，记进边界清单：
   - 规则推得出：写成定理，证出来；
   - 本题不管：写进「合法基地」的条件（成环、断头带这些），在条件之外不要求有结果；
   - 没人知道：做实测；
   - 游戏有确定做法、只是我们不知道（蓝图内部的建成先后、离线重建的先后）：写成显式的参数，结论要对参数的每种取值都成立。
3. **表的先后只用规则定下的先后**（建成先后、接通先后、物品格编号）。规则没定先后的地方不许靠表里碰巧的顺序选一个，否则等于悄悄补了一条规则。
4. **实测和现象清单写成回放**（`Endfield/回放/`），编译时核对。被实测排除的说法也写成函数留着，核对它确实对不上。
5. **规则文件和代码逐行对应。** 每条声明的文档注释第一行，写它对应规则文件的哪一行，六种写法见 `查名词.py` 开头。规则文件改了字，`查名词.py` 会报出引它的声明。

名字用规则文件里的名词。Lean 不认裸的中文标识符，所以都写在 «» 里；局部变量用英文字母。

## 文件

| 文件 | 对应规则文件 |
|---|---|
| `Endfield/计量与基础.lean` | 「计量与基础」一块：步、tick |
| `Endfield/配方.lean` | 「配方」一块，和「制造单位」一块里存货物品格的个数 |
| `Endfield/判定与轮询.lean` | 「判定与轮询」一块：判定类型、元件轮询、非运输单位轮询 |
| `Endfield/单位.lean` | 「单位」一块：有哪些种类，哪些是运输单位 |
| `Endfield/通道与移动.lean` | 「通道与移动」一块：通道、接通；建成、接通、拆除的历史和某一刻的布局 |
| `Endfield/拓扑与级别.lean` | 「拓扑与级别」一块：元件、运输带、终点、终点的时刻、次序 |
| `Endfield/例子/拓扑.lean` | 照规则算一遍的小布局（不是实测）：半边接带子的分流器、拆掉带子那一支、两支先后接上 |
| `Endfield/回放/分流器出口变动.lean` | 实测-2026-11-09 的八组（分流器拆、接出口以后从哪个出口送） |
| `Endfield/回放/出货先后.lean` | 现象清单第 20 条（出口一个一个接上时第一次出货从哪个开始） |
| `边界清单.md` | 写代码时冒出来的、规则文件没写或写得不对的地方 |
| `查名词.py` | 核对声明和规则文件的对应 |

## 接下来的顺序

先纵向打通一条最小的线，再往两边加：

1. 传送带、分流器、协议储存箱这三种单位，从通道一路写到一步怎么走，先不管格子坐标，直接给出通道和接通先后。通道到次序已经有了，还差组、组的时刻、级别、物品格里的物品和滞留、移动判定、一步。打通以后能回放现象清单第 1、3、4、19、24 条。
2. 加汇流器（输入判定）、制造单位（缓存格、开始/结束制造）、物品准入口、桥接器、协议核心和仓库。
3. 接上格子：单位的位置和朝向、端口、「正对紧贴」形成通道、接通的先后。之后回放可以直接照实测记录里的格坐标写。
4. 建造和拆除作为状态的变化（终点的时刻、组的时刻、轮询的重置都在这里）。
5. 定理：合法基地上每一步都算得出来；同组内各起点元件次序相同；级别不会并列。
